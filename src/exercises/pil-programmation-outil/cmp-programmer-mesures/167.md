# Contexte

Après l'ouverture des volets, les élèves veulent observer les conditions dans une chambre. Ils vont relever quatre fois la température et la luminosité.

Le programme doit préparer les colonnes `temperature` et `luminosite` une seule fois. Ensuite, à chaque relevé, il doit mesurer les deux grandeurs, enregistrer leurs valeurs et attendre deux secondes avant de recommencer.

Dans les blocs, le mot « label » désigne le nom d'une colonne. Le minuteur est déjà réglé.

# Consigne

Classe chaque groupe de blocs selon l'endroit où il doit être placé pour construire le programme. Range dans la dernière catégorie les blocs qui ne permettent pas de réaliser le protocole demandé.

# Catégories

1. Une fois, avant « Répéter 4 fois »
2. Dans « Répéter 4 fois », à chaque relevé
3. Blocs à ne pas utiliser

# Feedback essai 1

Distingue le bloc qui prépare le journal des blocs qui doivent fonctionner pour chacun des quatre relevés. Vérifie ensuite que les deux grandeurs sont bien conservées.

# Feedback essai 2

Les deux colonnes sont créées avant la répétition. Dans la répétition, il faut enregistrer la température et la luminosité, puis attendre. Un bloc qui oublie une grandeur ou qui affiche seulement les mesures ne complète pas le journal.

# Feedback

Le bloc qui crée les colonnes `temperature` et `luminosite` est placé avant « Répéter 4 fois ». Le bloc qui mesure et enregistre les deux grandeurs ainsi que la pause de deux secondes sont placés dans la répétition. Enregistrer seulement la température laisse une colonne vide, tandis qu'écrire les deux valeurs dans la console ne les conserve pas dans le journal.
