# Contexte

Pendant que la classe est aérée, les élèves veulent relever trois fois la température et le niveau sonore.

Le programme doit préparer les colonnes `temperature` et `niveau_sonore` une seule fois. Ensuite, à chaque relevé, il doit mesurer les deux grandeurs, enregistrer leurs valeurs et attendre une seconde avant de recommencer.

Dans les blocs, le mot « label » désigne le nom d'une colonne. Le minuteur est déjà réglé.

# Consigne

Classe chaque groupe de blocs selon l'endroit où il doit être placé pour construire le programme. Range dans la dernière catégorie les blocs qui ne permettent pas de réaliser le protocole demandé.

# Catégories

1. Une fois, avant « Répéter 3 fois »
2. Dans « Répéter 3 fois », à chaque relevé
3. Blocs à ne pas utiliser

# Feedback essai 1

Repère d'abord ce qui prépare le journal une seule fois. Cherche ensuite les blocs qui doivent être exécutés pour chacun des trois relevés.

# Feedback essai 2

Les colonnes sont créées avant la répétition. Dans la répétition, il faut enregistrer les deux mesures réelles et espacer les relevés. Afficher des valeurs ou enregistrer des nombres fixes ne réalise pas le protocole.

# Feedback

Le bloc qui crée les colonnes `temperature` et `niveau_sonore` est placé avant « Répéter 3 fois ». Le bloc qui mesure et enregistre les deux grandeurs ainsi que la pause d'une seconde sont placés dans la répétition. Les blocs qui affichent seulement les mesures dans la console ou enregistrent `20` et `50` ne permettent pas d'obtenir le journal demandé.
