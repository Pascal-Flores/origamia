# Contexte

Un robot de serre a rejoint une plante. La carte micro:bit placée près du pot doit relever cinq fois l'humidité du sol et la luminosité reçue par la plante.

Le programme doit préparer les colonnes `humidite_sol` et `luminosite` une seule fois. Ensuite, à chaque relevé, il doit mesurer les deux grandeurs, enregistrer chaque valeur dans la bonne colonne et attendre deux secondes avant de recommencer.

Dans les blocs, le mot « label » désigne le nom d'une colonne. Le capteur d'humidité du sol est branché sur la broche P1 et le minuteur est déjà réglé.

# Consigne

Classe chaque groupe de blocs selon l'endroit où il doit être placé pour construire le programme. Range dans la dernière catégorie les blocs qui ne permettent pas de réaliser le protocole demandé.

# Catégories

1. Une fois, avant « Répéter 5 fois »
2. Dans « Répéter 5 fois », à chaque relevé
3. Blocs à ne pas utiliser

# Feedback essai 1

Après avoir repéré le bloc qui prépare le journal, vérifie pour chaque autre groupe quelle valeur est enregistrée dans chacune des deux colonnes.

# Feedback essai 2

Dans la répétition, la mesure d'humidité doit aller dans `humidite_sol` et la mesure de lumière dans `luminosite`. Les deux valeurs doivent venir des capteurs, puis une pause doit espacer les relevés.

# Feedback

Le bloc qui crée les colonnes `humidite_sol` et `luminosite` est placé avant « Répéter 5 fois ». Le groupe qui range chaque mesure dans la bonne colonne ainsi que la pause de deux secondes sont placés dans la répétition. Le groupe qui inverse les colonnes organise mal les données. Celui qui enregistre `500` à la place de la luminosité note une valeur fixe au lieu de réaliser la seconde mesure.
