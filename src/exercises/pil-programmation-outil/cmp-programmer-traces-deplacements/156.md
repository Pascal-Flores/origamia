# Contexte

Un robot de service transporte un document dans les couloirs de l'école. Il doit passer par la case bleue, puis par la case orange, avant de rejoindre la salle verte. La flèche indique sa position de départ et la direction vers laquelle il regarde.

# Consigne

```robot-grid
grid: 7x6
start: D6 nord
target: G3 vert
target: G5 orange
target: D5 bleu
```

Complète le programme avec les cinq commandes qui font passer le robot par les cases bleue et orange, dans cet ordre, avant de le conduire jusqu'à la case verte.

# Texte à trous

```
Algorithme : rejoindre la salle verte
Début
  [[1]]
  [[2]]
  [[3]]
  [[4]]
  [[5]]
Fin
```

# Étiquettes

1. avancer de 1 case
2. tourner à droite
3. avancer de 3 cases
4. tourner à gauche
5. avancer de 2 cases
6. avancer de 4 cases
7. faire demi-tour

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Découpe le parcours en trois parties : rejoindre la case bleue, rejoindre la case orange, puis atteindre la case verte. Repère les virages entre ces parties.

# Feedback essai 2

La case bleue se trouve une case au nord du départ. Depuis cette case, le robot doit aller vers l'est jusqu'à la case orange, puis se tourner vers le nord.

# Feedback

Le robot avance d'abord de 1 case vers le nord et atteint la case bleue en `D5`. Il tourne à droite, avance de 3 cases jusqu'à la case orange en `G5`, tourne à gauche, puis avance de 2 cases jusqu'à la salle verte en `G3`.
