# Contexte

Un robot prépare un parcours sportif. Il doit d'abord récupérer un plot sur la case bleue, puis le déposer sur la case verte. La flèche indique sa position de départ et la direction vers laquelle il regarde. La case orange est une fausse arrivée.

# Consigne

```robot-grid
grid: 6x5
start: D5 nord
target: B2 vert
target: F2 orange
target: B5 bleu
```

Complète le programme avec les quatre commandes qui font passer le robot par la case bleue avant de le conduire jusqu'à la case verte.

# Texte à trous

```
Algorithme : déposer le plot
Début
  [[1]]
  [[2]]
  [[3]]
  [[4]]
Fin
```

# Étiquettes

1. tourner à gauche
2. avancer de 2 cases
3. tourner à droite
4. avancer de 3 cases
5. avancer de 1 case
6. avancer de 4 cases

# Solution

1, 2, 3, 4

# Feedback essai 1

Observe la direction de départ avant de choisir la première commande. Cherche d'abord comment rejoindre la case bleue, puis poursuis jusqu'à la case verte.

# Feedback essai 2

Le robot regarde d'abord vers le nord, mais la case bleue se trouve à l'ouest. Il doit l'atteindre avant de se tourner vers le nord pour rejoindre la case verte.

# Feedback

Le robot tourne d'abord à gauche pour regarder vers l'ouest, puis avance de 2 cases et récupère le plot en `B5`. Il tourne à droite pour regarder vers le nord et avance de 3 cases jusqu'à la case verte en `B2`.
