# Contexte

Dans un musée, un robot guide doit rejoindre la salle représentée par la case verte. La flèche indique sa position de départ et la direction vers laquelle il regarde. Les autres cases colorées sont de fausses arrivées.

# Consigne

```robot-grid
grid: 5x5
start: B5 nord
target: E3 vert
target: A1 bleu
target: E4 orange
```

Complète le programme avec les trois commandes qui conduisent le robot jusqu'à la case verte.

# Texte à trous

```
Algorithme : rejoindre la salle verte
Début
  [[1]]
  [[2]]
  [[3]]
Fin
```

# Étiquettes

1. avancer de 2 cases
2. tourner à droite
3. avancer de 3 cases
4. avancer de 4 cases
5. tourner à gauche
6. avancer de 1 case

# Solution

1, 2, 3

# Feedback essai 1

Avant de remplir le programme, suis un chemin entre la flèche et la case verte. Repère la distance à parcourir avant le virage, puis la nouvelle direction à prendre.

# Feedback essai 2

Le robot regarde d'abord vers le nord. Il doit rejoindre la ligne 3, puis se tourner vers l'est pour atteindre la colonne E.

# Feedback

Le robot avance de 2 cases vers le nord et atteint `B3`. Il tourne ensuite à droite pour regarder vers l'est, puis avance de 3 cases et rejoint la salle verte en `E3`. Les autres combinaisons cohérentes le conduisent vers une autre salle colorée.
