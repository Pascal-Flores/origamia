# Contexte

Cette simulation transvase 100 mL d'eau dans quatre récipients de formes différentes. Toute l'eau est versée à chaque fois, sans perte.

La hauteur atteinte par l'eau change selon le récipient. Une bulle indique le volume simulé après chaque transvasement.

# Consigne

Dans le programme du sprite **Récipient**, repère le bloc violet **« basculer sur le costume Récipient 1 »**, placé juste sous le bloc **« quand le drapeau vert est cliqué »**.

Modifie uniquement le choix **Récipient 1** dans ce bloc :

1. lance la simulation avec **Récipient 1** et note le volume affiché ;
2. choisis **Récipient 2**, puis relance le drapeau vert et note le nouveau volume ;
3. recommence avec **Récipient 3**, puis avec **Récipient 4**.

Coche ensuite toutes les affirmations confirmées par tes quatre essais.

# Réponses

1. Les quatre récipients contiennent le même volume simulé : 100 mL.
2. La hauteur atteinte par l'eau peut changer lorsque la forme du récipient change.
3. Dans ce modèle, un transvasement complet conserve le volume de l'eau.
4. Le récipient dans lequel l'eau monte le plus haut contient forcément le plus grand volume.
5. La simulation prouve qu'il est impossible de renverser de l'eau lors d'un véritable transvasement.

# Solution

1, 2, 3

# Feedback essai 1

Ne te fie pas seulement à la hauteur de l'eau. Relève le volume indiqué dans la bulle pour chacun des quatre récipients.

# Feedback essai 2

La bulle indique 100 mL lors des quatre essais, alors que la hauteur de l'eau n'est pas toujours la même. Sépare ce que le modèle montre sur le volume de ce qu'il suppose en annonçant un transvasement sans perte.

# Feedback

Les quatre transvasements donnent 100 mL. Le volume est donc conservé dans ce modèle, même si la hauteur de l'eau change avec la forme du récipient. Le modèle suppose que toute l'eau est versée : il ne prouve pas qu'un véritable transvasement se ferait toujours sans perte.
