# Contexte

Pendant la récréation, votre groupe veut organiser une partie de ballon.

Avant de commencer, vous vous mettez d'accord sur trois règles :

- faire `2` équipes ;
- mettre `4` joueurs dans chaque équipe ;
- jouer pendant `10 minutes`.

Quatre programmes ont été proposés pour organiser la partie. Un seul respecte les trois règles.

# Consigne

Choisis le programme qui respecte toutes les règles décidées par le groupe.

# Réponses

1.
```
event: DÉBUT
move: FORMER (2) équipes
move: RÉPARTIR (4) joueurs dans chaque équipe
move: JOUER pendant (10) minutes
end: FIN
```

2.
```
event: DÉBUT
move: FORMER (3) équipes
move: RÉPARTIR (4) joueurs dans chaque équipe
move: JOUER pendant (10) minutes
end: FIN
```

3.
```
event: DÉBUT
move: FORMER (2) équipes
move: RÉPARTIR (5) joueurs dans chaque équipe
move: JOUER pendant (10) minutes
end: FIN
```

4.
```
event: DÉBUT
move: FORMER (2) équipes
move: RÉPARTIR (4) joueurs dans chaque équipe
move: JOUER pendant (15) minutes
end: FIN
```

1

# Feedback essai 1

Vérifie les trois nombres de chaque programme, un par un : le nombre d'équipes, le nombre de joueurs par équipe et la durée de la partie. Un programme n'est correct que si les trois correspondent aux règles décidées.

# Feedback essai 2

Les valeurs à retrouver ensemble sont `2` équipes, `4` joueurs par équipe et `10 minutes`. Écarte dès qu'une seule de ces trois valeurs est différente.

# Feedback

Le programme 1 est le seul qui respecte les trois règles : il forme `2` équipes, répartit `4` joueurs dans chaque équipe et fait jouer la partie pendant `10 minutes`. Les programmes 2, 3 et 4 modifient chacun l'un de ces paramètres.
