# Contexte

Près du lavabo, une affiche rappelle comment se laver les mains avant d'aller manger. Elle indique notamment :

- utiliser `1` dose de savon ;
- frotter les mains pendant `20 secondes` ;
- prendre `1` feuille d'essuie-mains pour se sécher.

En classe, on cherche à représenter cette procédure sous forme de programme. Quatre versions ont été proposées, mais une seule reprend correctement les trois informations de l'affiche.

# Consigne

Compare les paramètres des quatre programmes avec les indications de l'affiche. Choisis celui qui représente correctement la procédure.

# Réponses

event: DÉBUT
move: MOUILLER les mains
move: PRENDRE (1) dose de savon
move: FROTTER pendant (20) secondes
move: RINCER les mains

move: SÉCHER les mains
end: FIN

# Feedback essai 1

Les étapes sont les mêmes dans les quatre programmes. Concentre-toi sur les nombres entre parenthèses et compare-les avec les trois indications de l'affiche.

# Feedback essai 2

Pour être correcte, une proposition doit respecter en même temps la quantité de savon, la durée du frottage et le nombre de feuilles d'essuie-mains.

# Feedback

Le programme 1 est le seul qui reprend exactement les trois paramètres de l'affiche : `1` dose de savon, `20 secondes` de frottage et `1` feuille d'essuie-mains. Dans chacun des autres programmes, un de ces paramètres a été modifié.
