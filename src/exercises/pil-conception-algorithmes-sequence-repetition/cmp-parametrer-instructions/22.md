# Contexte

Pendant la récréation, votre groupe prépare une partie de ballon. Vous décidez ensemble de jouer avec :

- `2` équipes ;
- `4` joueurs dans chaque équipe ;
- une partie de `10 minutes`.

En classe, le professeur reprend cet exemple pour montrer comment des consignes peuvent être représentées sous forme de programme. Quatre propositions ont été écrites à partir des règles de votre partie, mais une seule reprend correctement les trois nombres décidés.

# Consigne

Compare les paramètres de chaque programme avec les règles de la partie. Choisis celui qui les représente correctement.

# Réponses

1.
```
event: DÉBUT
move: FORMER (2) équipes
move: METTRE (4) joueurs dans chaque équipe
move: JOUER pendant (10) minutes
end: FIN
```

2.
```
event: DÉBUT
move: FORMER (3) équipes
move: METTRE (4) joueurs dans chaque équipe
move: JOUER pendant (10) minutes
end: FIN
```

3.
```
event: DÉBUT
move: FORMER (2) équipes
move: METTRE (5) joueurs dans chaque équipe
move: JOUER pendant (10) minutes
end: FIN
```

4.
```
event: DÉBUT
move: FORMER (2) équipes
move: METTRE (4) joueurs dans chaque équipe
move: JOUER pendant (15) minutes
end: FIN
```

# Solution

1

# Feedback essai 1

Prends les programmes un par un. Pour chacun, vérifie successivement le nombre d'équipes, le nombre de joueurs par équipe et la durée. Les trois paramètres doivent correspondre aux règles de départ.

# Feedback essai 2

Une proposition n'est pas correcte si un seul de ses trois paramètres est différent. Cherche donc celle qui ne change aucune des règles décidées pour la partie.

# Feedback

Le programme 1 représente correctement les règles de la partie : il indique `2` équipes, `4` joueurs dans chaque équipe et `10 minutes` de jeu. Dans chacune des trois autres propositions, un seul paramètre a été modifié.
