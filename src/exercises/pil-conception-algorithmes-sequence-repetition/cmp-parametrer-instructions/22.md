# Contexte

Près du lavabo, une affiche rappelle comment se laver les mains avant d'aller manger. Elle précise notamment :

- prendre `1` dose de savon ;
- frotter les mains pendant `20 secondes` ;
- prendre `1` feuille d'essuie-mains pour se sécher.

En classe, un élève a commencé à traduire certaines étapes de cette affiche sous forme d'instructions de programme. Les actions sont déjà correctes, mais il faut vérifier les valeurs qu'il a choisies pour chaque instruction.

# Consigne

Parmi les trois instructions, sélectionne toutes celles dont le paramètre respecte l'indication de l'affiche.

# Réponses

1. ```
move: PRENDRE (1) dose de savon
```
2. ```
move: FROTTER les mains pendant (15) secondes
```
3. ```
move: PRENDRE (1) feuille d'essuie-mains
```

# Solution

1, 3

# Feedback essai 1

Les actions sont déjà correctes. Pour chaque bloc, regarde la valeur indiquée et retrouve l'information correspondante sur l'affiche.

# Feedback essai 2

Vérifie séparément la quantité de savon, la durée du frottage et le nombre de feuilles d'essuie-mains. Une instruction est correcte seulement si son paramètre correspond exactement à l'indication de l'affiche.

# Feedback

Les instructions 1 et 3 ont le bon paramètre : l'affiche demande `1` dose de savon et `1` feuille d'essuie-mains. L'instruction 2 est incorrecte : elle indique `15 secondes`, alors que l'affiche demande de frotter pendant `20 secondes`.
