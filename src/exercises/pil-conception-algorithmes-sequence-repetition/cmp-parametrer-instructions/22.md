# Contexte

Avant d'aller manger, une fiche rappelle les réglages à utiliser dans le programme qui décrit le lavage des mains :

- prendre `1` dose de savon ;
- frotter les mains pendant `20 secondes` ;
- rincer pendant `10 secondes`.

Trois instructions du programme ont déjà été paramétrées. Certaines respectent exactement la fiche, d'autres non.

# Consigne

Classe chaque instruction dans la bonne catégorie : **« Respecte la consigne »** ou **« Ne respecte pas la consigne »**.

# Catégories

1. Respecte la consigne
2. Ne respecte pas la consigne

# Étiquettes

1. ```blockly
move: PRENDRE (1) dose de savon
```
2. ```blockly
move: FROTTER les mains pendant (15) secondes
```
3. ```blockly
move: RINCER pendant (10) secondes
```

# Solution

1: 1, 3
2: 2

# Feedback essai 1

Vérifie les trois paramètres séparément. Pour chaque instruction, compare uniquement la valeur entre parenthèses avec la valeur correspondante donnée dans la fiche.

# Feedback essai 2

Deux instructions reprennent exactement leur paramètre dans la fiche. Une seule utilise une durée différente de celle demandée.

# Feedback

`PRENDRE (1) dose de savon` respecte la fiche, qui demande bien `1` dose. `RINCER pendant (10) secondes` est également correct, car la durée demandée est `10 secondes`. En revanche, `FROTTER les mains pendant (15) secondes` ne respecte pas la consigne : la fiche demande `20 secondes` de frottage.
