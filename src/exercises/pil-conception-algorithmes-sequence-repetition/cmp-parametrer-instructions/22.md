# Énoncé

Pour bien se laver les mains, il faut frotter avec de l’eau et du savon pendant 20 secondes, puis rincer et se sécher les mains.

Ci-dessous un programme indiquant comment bien se laver les mains.
Vrai ou faux : le paramètre `15 secondes` de l’instruction `FROTTER pendant` est correct.

```
event: DÉBUT
move: MOUILLER les mains
move: METTRE du savon sur les mains
move: FROTTER pendant (15) secondes
move: RINCER
move: SÉCHER
end: FIN
```

# Réponses

1. Vrai
2. Faux

# Solution

2

# Feedback

Le bon choix est `Faux`, car le paramètre doit correspondre à la durée indiquée dans la consigne : pour bien se laver les mains, on frotte pendant `20` secondes, donc `15` secondes n’est pas correct.
