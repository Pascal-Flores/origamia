# Contexte

Tu dois protéger la table avec 3 feuilles de journaux avant de commencer à peindre un tableau.

# Consigne

Vrai ou faux : le paramètre “2 feuilles” du programme ci-dessous est correct.

```
event: DÉBUT
move: PRENDRE (2) feuilles de journal
move: PROTÉGER la table avec les feuilles de journal
move: COMMENCER à peindre
end: FIN
```

# Réponses

1. Vrai
2. Faux

# Solution

2

# Feedback

Le bon choix est `Faux`, car le paramètre doit reprendre le nombre donné dans la consigne : pour protéger la table, il faut prendre `3` feuilles de journal, donc `2` feuilles n’est pas correct.
