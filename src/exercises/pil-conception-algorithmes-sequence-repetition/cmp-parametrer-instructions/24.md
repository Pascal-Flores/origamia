# Contexte

Pour préparer une chasse au trésor, une fiche d'organisation prévoit :

- `6` indices à préparer ;
- `2` équipes ;
- une durée de `20 minutes`.

Un élève a traduit ces trois choix sous forme d'instructions de programme. Les actions sont déjà correctes, mais il faut vérifier les valeurs utilisées dans les blocs.

# Consigne

Parmi les trois instructions, sélectionne toutes celles dont le paramètre respecte la fiche d'organisation.

# Réponses

1. ```
move: PRÉPARER (6) indices
```
2. ```
move: FORMER (2) équipes
```
3. ```
move: FIXER la durée à (30) minutes
```

# Solution

1, 2

# Feedback essai 1

Les actions sont déjà correctes. Pour chaque bloc, compare la valeur indiquée avec l'information correspondante sur la fiche d'organisation.

# Feedback essai 2

Vérifie séparément le nombre d'indices, le nombre d'équipes et la durée prévue. Une seule de ces trois valeurs a été modifiée.

# Feedback

Les instructions 1 et 2 ont le bon paramètre : la fiche prévoit `6` indices et `2` équipes. L'instruction 3 est incorrecte : elle indique `30 minutes`, alors que la durée prévue est de `20 minutes`.
