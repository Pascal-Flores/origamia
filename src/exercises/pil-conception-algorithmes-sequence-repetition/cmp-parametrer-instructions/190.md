# Contexte

Le robot doit avancer de 120 cm, tourner à gauche de 90 degrés, puis avancer de 60 cm.

# Consigne

Complète uniquement les paramètres numériques.

# Texte à trous

```
DÉBUT
AVANCER de [[1]] cm
TOURNER à gauche de [[2]] degrés
AVANCER de [[3]] cm
FIN
```

# Étiquettes

1. 120
2. 90
3. 60
4. 180
5. 30

# Solution

1, 2, 3

# Feedback essai 1

Reprends les trois valeurs dans l'ordre où elles apparaissent dans la consigne.

# Feedback

Les paramètres sont 120, 90 et 60. La structure des instructions ne change pas.
