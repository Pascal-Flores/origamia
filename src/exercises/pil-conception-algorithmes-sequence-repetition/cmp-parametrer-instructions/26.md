# Contexte

Tu dois envoyer un message poli sur l'ENT à ton enseignante.

# Consigne

La consigne précise :

- destinataire : `Mme Martin` ;
- objet : `Devoir de sciences` ;
- joindre le fichier `mesures.pdf`, car l'enseignante le demande pour cet envoi.

La pièce jointe est un paramètre optionnel : on ne l'ajoute que lorsqu'un fichier est demandé. Complète le pseudo-code avec les bons paramètres pour préparer puis envoyer ce message.

# Texte à trous

```
Algorithme : envoyer un message
Début
  créer un message pour [[1]]
  indiquer l'objet [[2]]
  joindre le fichier [[3]]
  envoyer le message
Fin
```

# Étiquettes

1. Mme Martin
2. "Devoir de sciences"
3. "mesures.pdf"
4. Service informatique
5. "Absence"
6. "photo.jpg"

# Solution

1, 2, 3

# Feedback

Le programme doit adresser le message à `Mme Martin`, indiquer l'objet `"Devoir de sciences"` et joindre `"mesures.pdf"` puisque ce fichier est demandé. Changer l'un de ces paramètres produirait un envoi incorrect.
