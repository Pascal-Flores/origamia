# Contexte

Tu dois envoyer un message poli sur l'ENT à ton enseignante.

# Consigne

La consigne précise :

- destinataire : `Mme Martin` ;
- objet : `Devoir de sciences` ;
- joindre le fichier `mesures.pdf`, car l'enseignante le demande pour cet envoi.

La pièce jointe est un paramètre optionnel : on ne l'ajoute que lorsqu'un fichier est demandé. Remets les bonnes étiquettes dans l'ordre pour préparer puis envoyer ce message.
# Réponses

1. `event: DÉBUT`
2. `move: CRÉER un message pour (Mme Martin)`
3. `move: CRÉER un message pour (Service informatique)`
4. `say: INDIQUER l'objet ("Devoir de sciences")`
5. `say: INDIQUER l'objet ("Absence")`
6. `move: JOINDRE le fichier ("mesures.pdf")`
7. `move: JOINDRE le fichier ("photo.jpg")`
8. `move: ENVOYER le message`
9. `end: FIN`

# Solution

1, 2, 4, 6, 8, 9

# Feedback

Le programme doit adresser le message à `Mme Martin`, conserver l'objet `Devoir de sciences` et joindre `mesures.pdf` puisque ce fichier est demandé. Changer l'un de ces paramètres produirait un envoi incorrect.
