# Contexte

Tu dois envoyer un message poli sur l'ENT à ton enseignante.

# Consigne

La consigne précise :

- destinataire : `Mme Martin` ;
- objet : `Devoir de sciences` ;
- joindre le fichier `mesures.pdf`, car l'enseignante le demande pour cet envoi.

La pièce jointe est un paramètre optionnel : on ne l'ajoute que lorsqu'un fichier est demandé. Complète le pseudo-code avec les bons paramètres pour préparer puis envoyer ce message.

# Texte à trous

```
Algorithme : envoyer un message
Début
  créer un message pour [[1]]
  indiquer l'objet [[2]]
  joindre le fichier [[3]]
  envoyer le message
Fin
```

# Étiquettes

1. Mme Martin
2. "Devoir de sciences"
3. "mesures.pdf"
4. Service informatique
5. "Absence"
6. "photo.jpg"

# Solution

1, 2, 3

# Feedback essai 1

Et si on relisait le message comme si on allait vraiment l’envoyer ? À qui, à quel sujet et avec quel fichier ?

# Feedback essai 2

L’objet est le titre du message. La pièce jointe est le document qu’on ouvre en plus. Les deux sont-ils à la bonne place ?

# Feedback

Le message va à Mme Martin, son objet est « Devoir de sciences » et le fichier joint est « mesures.pdf ». Tout vient de la consigne.
