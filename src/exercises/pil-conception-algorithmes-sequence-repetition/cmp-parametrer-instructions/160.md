# Contexte

Pour organiser les devoirs du soir, un planning prévoit :

- `20 minutes` de mathématiques ;
- une pause de `5 minutes` ;
- `15 minutes` de lecture.

Pour représenter ce planning sous forme d'instructions de programme, trois blocs ont été écrits. Les actions sont déjà correctes, mais il faut vérifier les durées indiquées.

# Consigne

Parmi les trois instructions, sélectionne toutes celles dont le paramètre respecte le planning.

# Réponses

1. ```
move: TRAVAILLER les mathématiques pendant (30) minutes
```
2. ```
move: FAIRE une pause de (5) minutes
```
3. ```
move: LIRE pendant (15) minutes
```

# Solution

2, 3

# Feedback essai 1

Les actions sont déjà correctes. Pour chaque bloc, compare la durée indiquée avec celle prévue pour la même activité dans le planning.

# Feedback essai 2

Vérifie séparément le temps de mathématiques, la durée de la pause et le temps de lecture. Une seule de ces trois durées a été modifiée.

# Feedback

Les instructions 2 et 3 ont le bon paramètre : le planning prévoit une pause de `5 minutes` et `15 minutes` de lecture. L'instruction 1 est incorrecte : elle indique `30 minutes` de mathématiques, alors que le planning en prévoit `20`.
