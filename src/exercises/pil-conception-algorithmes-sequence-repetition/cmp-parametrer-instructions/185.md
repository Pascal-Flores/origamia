# Contexte

Après avoir copié une leçon, la consigne indique : « Surligne exactement 2 lignes du résumé. »

Le programme contient :

`move: SURLIGNER ( ? ) lignes`

# Consigne

Quelle valeur faut-il mettre à la place de `?` ?

# Réponses

1. 1
2. 2
3. 4

# Solution

2

# Feedback essai 1

La valeur est donnée directement dans la consigne.

# Feedback

La consigne demande exactement 2 lignes : le paramètre doit donc être 2.
