# Contexte

Une machine de cuisine programmable prépare un chocolat chaud à partir d'une fiche recette.

Pour ta tasse, la fiche indique :

- verser `250 mL` de lait ;
- chauffer à `60 °C` ;
- ajouter l'option `cannelle`, choisie uniquement pour cette tasse.

# Consigne

Complète le pseudo-code avec les bons paramètres pour programmer la préparation demandée.

# Texte à trous

```
Algorithme : préparer un chocolat chaud
Début
  verser [[1]] de lait
  chauffer à [[2]]
  ajouter l'option [[3]]
  servir la tasse
Fin
```

# Étiquettes

1. 250 mL
2. 60 °C
3. cannelle
4. 500 mL
5. 90 °C
6. chantilly

# Solution

1, 2, 3

# Feedback essai 1

Un chocolat chaud à préparer ! Dans chaque trou, est-ce qu’on attend du lait, une température ou ce qui donne du goût ?

# Feedback essai 2

Les mL disent combien de lait on verse et les °C à quel point on le chauffe. Pour le dernier trou, qu’est-ce que demande la recette ?
