# Contexte

Une machine de cuisine programmable prépare un chocolat chaud à partir d'une fiche recette.

Pour ta tasse, la fiche indique :

- verser `250 mL` de lait ;
- chauffer à `60 °C` ;
- ajouter l'option `cannelle`, choisie uniquement pour cette tasse.

# Consigne

Complète le pseudo-code avec les bons paramètres pour programmer la préparation demandée.

# Texte à trous

```
Algorithme : préparer un chocolat chaud
Début
  verser [[1]] de lait
  chauffer à [[2]]
  ajouter l'option [[3]]
  servir la tasse
Fin
```

# Étiquettes

1. 250 mL
2. 60 °C
3. cannelle
4. 500 mL
5. 90 °C
6. chantilly

# Solution

1, 2, 3

# Feedback essai 1

Notre recette donne plusieurs réglages. Est-ce que chaque trou demande une quantité, une température ou un ingrédient ?

# Feedback essai 2

Les mL mesurent la quantité de lait, les °C sa température. Quel trou reste pour ce qui donne du goût ?

# Feedback

On chauffe 250 mL de lait à 60 °C, puis on ajoute la cannelle. On obtient le chocolat demandé par la recette.
