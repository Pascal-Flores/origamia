# Énoncé

Une machine de cuisine programmable prépare un chocolat chaud à partir d'une fiche recette.

Pour ta tasse, la fiche indique :

- verser `250 mL` de lait ;
- chauffer à `60 °C` ;
- ajouter l'option `cannelle`, choisie uniquement pour cette tasse.

Remets les bonnes étiquettes dans l'ordre pour programmer la préparation demandée.

# Réponses

1. `event: DÉBUT`
2. `move: VERSER (250 mL) de lait`
3. `move: VERSER (500 mL) de lait`
4. `move: CHAUFFER à (60 °C)`
5. `move: CHAUFFER à (90 °C)`
6. `move: AJOUTER l'option (cannelle)`
7. `move: AJOUTER l'option (chantilly)`
8. `move: SERVIR la tasse`
9. `end: FIN`

# Solution

1, 2, 4, 6, 8, 9

# Feedback

La recette demande `250 mL` de lait chauffé à `60 °C`, puis l'ajout de l'option `cannelle`. Les autres quantités, températures ou options ne correspondent pas à la tasse demandée.
