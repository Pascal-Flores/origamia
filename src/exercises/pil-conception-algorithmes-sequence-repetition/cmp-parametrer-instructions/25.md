# Contexte

Au musée, un audio-guide programmable permet d'écouter les explications d'une oeuvre.

# Consigne

La fiche de visite indique :

- piste à écouter : `7` ;
- volume à régler : `30 %` ;
- si l'on utilise des écouteurs, activer l'option `écouteurs`.

Tu utilises des écouteurs. Complète le pseudo-code avec les bons paramètres pour lancer la bonne piste avec les bons réglages.

# Texte à trous

```
Algorithme : écouter l'audio-guide
Début
  sélectionner la piste [[1]]
  régler le volume sur [[2]]
  activer l'option [[3]]
  lancer la lecture
Fin
```

# Étiquettes

1. 7
2. 30 %
3. écouteurs
4. 4
5. 80 %
6. haut-parleur

# Solution

1, 2, 3

# Feedback essai 1

Fais une petite liste des trois paramètres à retrouver : la piste, le volume et l'option liée au matériel utilisé.

# Feedback essai 2

Les écouteurs sont utilisés, donc l'option écouteurs doit être activée. Vérifie aussi que les deux nombres reprennent exactement la fiche.

# Feedback

La piste attendue est la `7` et le volume doit être réglé à `30 %`. Comme des écouteurs sont utilisés, l'option `écouteurs` doit aussi être activée avant de lancer la lecture.
