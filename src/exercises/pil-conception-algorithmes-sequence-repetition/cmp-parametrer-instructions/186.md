# Contexte

Avant une sortie, une fiche indique comment utiliser la crème solaire mise à disposition.

La fiche précise :

- Indice de protection : `50`
- Renouveler la crème après : `2` heures
- Nombre de zones à protéger : `3` — le visage, les bras et les jambes

Le programme ci-dessous suit cette fiche. Une valeur manque dans l'instruction qui indique quel indice de protection utiliser.

# Consigne

Complète le programme ci-dessous en écrivant la valeur de `???`.

```
event: DÉBUT
move: PRENDRE la crème solaire
move: UTILISER une crème d'indice (???)
move: APPLIQUER la crème sur le visage, les bras et les jambes
move: RENOUVELER la crème après (2) heures
end: FIN
```

Écris uniquement le nombre.

# Solution

50

# Feedback essai 1

Le `???` complète l'instruction qui indique **l'indice de protection** de la crème. Repère sur la fiche la valeur qui porte exactement ce nom, sans la confondre avec la durée avant renouvellement ou le nombre de zones à protéger.

# Feedback

La fiche indique un indice de protection de `50`. C'est donc `50` qui complète l'instruction `UTILISER une crème d'indice (???)`. Le nombre `2` indique après combien d'heures renouveler la crème, et le nombre `3` correspond aux zones à protéger : ces valeurs ont un autre rôle dans le programme.
