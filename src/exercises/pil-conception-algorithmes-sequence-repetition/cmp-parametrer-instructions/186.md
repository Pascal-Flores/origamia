# Contexte

Avant de rendre ta copie, tu dois utiliser une checklist pour vérifier que rien n'a été oublié.

Sur la fiche de vérification, plusieurs informations sont indiquées :

- Checklist à utiliser : `3`
- Nombre de points à vérifier dans cette checklist : `5`
- Nombre de questions sur la copie : `8`

Le programme doit ouvrir la bonne checklist, vérifier chacun de ses points, puis rendre la copie.

# Consigne

Complète le programme ci-dessous en écrivant la valeur de `???`.

```
event: DÉBUT
move: PRENDRE la copie
move: OUVRIR la checklist (???)
move: VÉRIFIER les (5) points de la checklist
move: CORRIGER la copie si nécessaire
move: RENDRE la copie
end: FIN
```

Écris uniquement le nombre.

# Solution

3

# Feedback essai 1

Le `???` complète l'instruction qui demande **quelle checklist ouvrir**. Cherche donc le numéro de la checklist à utiliser, et ne le confonds pas avec le nombre de points à vérifier ou le nombre de questions sur la copie.

# Feedback

La fiche indique qu'il faut utiliser la checklist numéro `3`. C'est donc `3` qu'il faut placer dans l'instruction `OUVRIR la checklist (???)`. Le nombre `5` indique combien de points cette checklist contient, et `8` correspond au nombre de questions de la copie : ces deux valeurs ont un autre rôle dans la situation.
