# Contexte

Une classe doit être répartie en 3 groupes. Le programme affiche un numéro de groupe entre 1 et la valeur indiquée.

# Consigne

Quelle valeur faut-il mettre dans `CHOISIR un nombre de 1 à (...)` ?

# Réponses

1. 2
2. 3
3. 6

# Solution

2

# Feedback essai 1

La borne supérieure doit correspondre au nombre de groupes possibles.

# Feedback

La valeur est 3 : les numéros possibles doivent être 1, 2 ou 3.
