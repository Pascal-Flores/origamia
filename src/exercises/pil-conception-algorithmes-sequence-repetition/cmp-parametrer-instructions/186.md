# Contexte

Avant de commencer un atelier en classe, tu dois préparer une petite trousse avec le matériel indiqué sur une fiche.

La fiche précise :

- Crayons à papier : `2`
- Gomme : `1`
- Règle : `1`

Le programme ci-dessous prépare la trousse en suivant cette fiche. Une valeur manque dans l'instruction qui ajoute les crayons à papier.

# Consigne

Complète le programme ci-dessous en écrivant la valeur de `???`.

```
event: DÉBUT
move: PRENDRE une trousse vide
move: METTRE (???) crayons à papier dans la trousse
move: METTRE (1) gomme dans la trousse
move: METTRE (1) règle dans la trousse
end: FIN
```

Écris uniquement le nombre.

# Solution

2

# Feedback essai 1

Le `???` correspond uniquement au **nombre de crayons à papier** à mettre dans la trousse. Relis la ligne de la fiche qui concerne les crayons, sans utiliser les quantités indiquées pour la gomme ou la règle.

# Feedback

La fiche indique qu'il faut mettre `2` crayons à papier dans la trousse. C'est donc la valeur `2` qui complète l'instruction `METTRE (???) crayons à papier`. Les deux valeurs `1` correspondent à la gomme et à la règle : elles servent à d'autres instructions du programme.
