En classe, tu dois créer un dossier avec ton prénom pour ranger ton travail.

Sur une fiche affichée près de l'ordinateur, tu vois plusieurs informations :

- Prénom à utiliser pour le dossier : Lina
- Nom du fichier à ranger : exercice1.txt
- Nom du dossier commun : Classe_CM2

# Consigne

Complète le programme ci-dessous en écrivant la valeur de ???.

```
event: DÉBUT
```
