# Énoncé

En début de cours, l’enseignant dit : « Sortez votre cahier, votre trousse et votre manuel. »

Puis il écrit au tableau : Page 72 — Exercice 4.

Le programme ci-dessous demande un paramètre : le nombre d’objets à vérifier (combien d’objets tu as sortis).

Complète le programme ci-dessous en écrivant la valeur de ???.

```
event: DÉBUT
move: SORTIR le cahier
move: SORTIR la trousse 
move: SORTIR le manuel
move: VÉRIFIER que tu as sorti (???) objets
end: FIN
```

# Solution

3

# Feedback

Pour compléter correctement le programme, il faut compter les objets demandés par l’enseignant : tu sors le cahier, la trousse et le manuel, donc tu vérifies que tu as sorti `3` objets.
