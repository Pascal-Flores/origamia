# Contexte

La consigne dit : « Prépare 3 vêtements : manteau, écharpe et bonnet. » Le programme propose :

`move: PRÉPARER (2) vêtements`

# Consigne

Le paramètre `2` respecte-t-il la consigne ?

# Réponses

1. Oui
2. Non, il faut 3
3. Non, il faut 4

# Solution

2

# Feedback essai 1

Le nombre attendu est donné dans la consigne.

# Feedback

Trois vêtements sont demandés. Le paramètre 2 est donc incorrect ; il faut 3.
