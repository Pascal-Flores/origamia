# Contexte

Un robot doit effectuer un quart de tour à droite. Le programme propose `TOURNER à droite de (180) degrés`.

# Consigne

Le paramètre proposé convient-il ?

# Réponses

1. Oui
2. Non, il faut 90 degrés
3. Non, il faut 360 degrés

# Solution

2

# Feedback essai 1

Un quart de tour correspond à un angle précis.

# Feedback

180 degrés correspond à un demi-tour. Pour un quart de tour, le paramètre doit être 90 degrés.
