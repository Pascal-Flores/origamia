# Énoncé

Tu dois préparer une salade de fruit, en mettant des morceaux de pommes, de poires et de clémentines dans un saladier, puis ajouter 2 cuillères de jus de citron.

Ci-dessous un programme indiquant comment préparer la salade de fruits.
Vrai ou faux : le paramètre “2 cuillères” de l’instruction AJOUTER est correct.

```
event: DÉBUT
move: METTRE les morceaux de pommes dans le saladier
move: METTRE les morceaux de poires dans le saladier
move: METTRE les morceaux de clémentines dans le saladier
move: METTRE (2) cuillères de jus de citron dans le saladier
move: MÉLANGER
end: FIN
```

# Réponses

1. Vrai
2. Faux

# Solution

1

# Feedback

Le bon choix est `Vrai`, car le paramètre du programme correspond bien à la recette : il faut ajouter `2` cuillères de jus de citron, donc la valeur indiquée est correcte.
