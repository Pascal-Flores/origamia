# Contexte

Une fiche recette indique les fruits à utiliser pour préparer une salade :

- `2` pommes ;
- `1` poire ;
- `3` clémentines.

Pour représenter ces indications sous forme d'instructions de programme, un élève a écrit trois blocs. Les actions sont déjà correctes, mais il faut vérifier les quantités qu'il a indiquées.

# Consigne

Parmi les trois instructions, sélectionne toutes celles dont le paramètre respecte la fiche recette.

# Réponses

1. ```
move: AJOUTER (3) pommes dans le saladier
```
2. ```
move: AJOUTER (1) poire dans le saladier
```
3. ```
move: AJOUTER (3) clémentines dans le saladier
```

# Solution

2, 3

# Feedback essai 1

Les actions sont déjà correctes. Pour chaque bloc, compare la quantité indiquée avec celle donnée pour le même fruit dans la recette.

# Feedback essai 2

Vérifie séparément les pommes, la poire et les clémentines. Une instruction est correcte seulement si la quantité affichée correspond exactement à la fiche recette.

# Feedback

Les instructions 2 et 3 ont le bon paramètre : la recette demande `1` poire et `3` clémentines. L'instruction 1 est incorrecte : elle indique `3` pommes alors que la recette en demande `2`.
