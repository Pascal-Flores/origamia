# Contexte

Au début d'une sortie scolaire, chaque élève reçoit une petite carte de regroupement pour savoir avec qui rester pendant les déplacements et où attendre en cas de séparation du groupe.

Sur ta carte, il est indiqué :

- numéro de ton binôme : `7` ;
- prénom de ton partenaire : `Lina` ;
- point de regroupement : `grille bleue`.

Pour l'activité, la procédure permettant de retrouver puis de vérifier son binôme a été écrite sous forme de pseudo-code. Les trois paramètres correspondant à ta carte ont été retirés.

# Consigne

Complète le pseudo-code avec les informations qui figurent sur ta carte. Attention à placer chaque paramètre dans l'instruction qui lui correspond : numéro du binôme, prénom du partenaire ou lieu de regroupement.

# Texte à trous

```
Algorithme : retrouver son binôme
Début
  rejoindre le binôme [[1]]
  vérifier que le partenaire s'appelle [[2]]
  attendre ensemble à [[3]]
Fin
```

# Étiquettes

1. 7
2. Lina
3. grille bleue
4. 4
5. Sami
6. portail rouge

# Solution

1, 2, 3

# Feedback essai 1

Observe la fonction de chaque trou : le premier attend un numéro de binôme, le deuxième un prénom et le troisième un lieu. Écarte les étiquettes qui ne correspondent pas au bon type d'information.

# Feedback essai 2

Relis ta carte de regroupement. Le numéro permet de retrouver le bon binôme, le prénom sert à vérifier que tu es avec la bonne personne et le lieu indique où vous devez attendre ensemble.

# Feedback

Le pseudo-code doit indiquer le binôme `7`, vérifier que le partenaire s'appelle `Lina`, puis faire attendre les deux élèves à la `grille bleue`. Les valeurs `4`, `Sami` et `portail rouge` décriraient un autre binôme ou un autre point de regroupement et ne correspondent pas à ta carte.
