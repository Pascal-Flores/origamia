# Contexte

En classe, tu allumes la tablette et tu dois te connecter.

Sur une étiquette collée sur la tablette, tu vois plusieurs informations :

- Code de connexion : 5074
- Code Wi-Fi de la classe : 7391

# Consigne

Complète le programme ci-dessous en écrivant la valeur de ???.

```
event: DÉBUT
move: ALLUMER la tablette
move: ATTENDRE l'écran de connexion
move: ENTRER le code de connexion (???)
move: VALIDER
end: FIN
```

# Solution

5074

# Feedback essai 1

Lis le nom du paramètre à compléter, puis cherche l'information qui porte exactement ce nom sur l'étiquette.

# Feedback

Pour compléter correctement le programme, il faut choisir la valeur du code de connexion indiqué sur l’étiquette : ici, on entre `5074`, car c’est ce nombre qui permet de se connecter à la tablette.
