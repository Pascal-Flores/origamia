# Contexte

Après une séance de lecture, une fiche de suivi indique :

- page atteinte : `48` ;
- avis sur le livre : `4 sur 5` ;
- mots nouveaux relevés : `2`.

Pour représenter ces informations dans un programme, trois instructions ont été écrites. Les actions sont déjà correctes, mais il faut vérifier les valeurs indiquées dans les blocs.

# Consigne

Parmi les trois instructions, sélectionne toutes celles dont le paramètre respecte la fiche de suivi.

# Réponses

1. ```
move: NOTER la page (48)
```
2. ```
move: DONNER une note de (3) sur 5
```
3. ```
move: AJOUTER (2) mots nouveaux
```

# Solution

1, 3

# Feedback essai 1

Les actions sont déjà correctes. Pour chaque bloc, compare la valeur indiquée avec l'information correspondante sur la fiche de suivi.

# Feedback essai 2

Vérifie séparément la page atteinte, la note donnée au livre et le nombre de mots nouveaux. Une seule de ces trois valeurs ne correspond pas à la fiche.

# Feedback

Les instructions 1 et 3 ont le bon paramètre : la fiche indique la page `48` et `2` mots nouveaux. L'instruction 2 est incorrecte : elle donne la note `3 sur 5`, alors que l'avis noté sur la fiche est `4 sur 5`.
