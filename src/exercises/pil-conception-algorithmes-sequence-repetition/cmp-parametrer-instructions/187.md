# Contexte

La consigne donnée pour cet exercice est : « revenir dans au plus `5 minutes` ».

# Consigne

Vrai ou faux : le paramètre `8 minutes` utilisé dans l'instruction est correct.

```
event: DÉBUT
move: ALLER aux toilettes
move: REVENIR après (8) minutes
end: FIN
```

# Réponses

1. Vrai
2. Faux

# Solution

2

# Feedback

Le paramètre doit reprendre la durée donnée dans la consigne. `8 minutes` ne correspond pas à `5 minutes`.
