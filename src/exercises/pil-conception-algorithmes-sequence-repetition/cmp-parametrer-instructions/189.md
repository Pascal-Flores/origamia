# Contexte

Avant une sortie, la classe compte 26 élèves. La consigne demande d'afficher le texte `Appel terminé` pendant 4 secondes lorsque les 26 noms ont été vérifiés.

# Consigne

Complète les paramètres du pseudo-code.

# Texte à trous

```
DÉBUT
VÉRIFIER [[1]] noms
AFFICHER "[[2]]" pendant [[3]] secondes
FIN
```

# Étiquettes

1. 26
2. Appel terminé
3. 4
4. 24
5. Départ
6. 2

# Solution

1, 2, 3

# Feedback essai 1

Les trois valeurs utiles sont données explicitement dans le contexte.

# Feedback

Le programme doit vérifier 26 noms puis afficher « Appel terminé » pendant 4 secondes.
