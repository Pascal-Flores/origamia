# Contexte

Ta classe va quitter le collège pour une sortie scolaire. Avant le départ, l'enseignant doit vérifier que le bon groupe est réuni, que l'effectif attendu est présent et que tout le monde rejoint le lieu prévu.

La fiche d'organisation de la sortie indique :

- classe concernée : `6e B` ;
- effectif attendu : `26 élèves` ;
- point de rassemblement : `portail nord`.

Pour l'activité, cette procédure de vérification a été décrite sous forme de pseudo-code. Les trois paramètres propres à cette sortie ont été retirés.

# Consigne

Complète le pseudo-code avec les trois informations de la fiche. Chaque trou correspond à un paramètre différent : la classe concernée, l'effectif attendu ou le point de rassemblement.

# Texte à trous

```
Algorithme : vérifier la classe avant le départ
Début
  sélectionner la classe [[1]]
  vérifier que [[2]] élèves sont présents
  rejoindre le point de rassemblement [[3]]
Fin
```

# Étiquettes

1. 6e B
2. 26
3. portail nord
4. 6e A
5. 24
6. cour centrale

# Solution

1, 2, 3

# Feedback essai 1

Repère d'abord ce que demande chaque ligne du pseudo-code. La première attend le nom d'une classe, la deuxième un nombre d'élèves et la troisième un lieu de rassemblement.

# Feedback essai 2

Reprends maintenant la fiche d'organisation ligne par ligne : l'intitulé de la classe doit aller dans la première instruction, l'effectif prévu dans la deuxième et le lieu exact du rendez-vous dans la dernière.

# Feedback

Il faut sélectionner la classe `6e B`, vérifier la présence de `26` élèves puis rejoindre le `portail nord`. Ces trois paramètres décrivent précisément la sortie indiquée sur la fiche. `6e A`, `24` et `cour centrale` correspondent à d'autres valeurs et modifieraient les consignes données avant le départ.
