# Contexte

À la bibliothèque, tu veux emprunter un livre puis le mettre dans ton sac. La carte doit être scannée avant que l'emprunt soit validé.

# Consigne

Quels programmes donnent exactement le résultat demandé ?

# Réponses

1. ```
event: DÉBUT
move: PRENDRE le livre
move: PRÉSENTER la carte
move: SCANNER le livre
move: METTRE le livre dans le sac
move: RANGER la carte
end: FIN
```
2. ```
event: DÉBUT
move: PRÉSENTER la carte
move: PRENDRE le livre
move: SCANNER le livre
move: RANGER la carte
move: METTRE le livre dans le sac
end: FIN
```
3. ```
event: DÉBUT
move: PRENDRE le livre
move: METTRE le livre dans le sac
move: PRÉSENTER la carte
move: RANGER la carte
move: SCANNER le livre
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Certaines actions indépendantes peuvent changer de place, mais le livre doit être scanné avant d'être rangé dans le sac.

# Feedback essai 2

Compare surtout les dépendances entre « scanner le livre » et « mettre le livre dans le sac ».

# Feedback

Les programmes 1 et 2 respectent les dépendances nécessaires. Dans le programme 3, le livre est mis dans le sac avant d'être scanné.
