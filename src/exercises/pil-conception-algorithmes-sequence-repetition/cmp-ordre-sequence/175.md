# Contexte

Pour commencer un atelier, tu dois quitter ta table avec ton cahier et ton crayon, rejoindre l'îlot bleu, puis t'asseoir. Prendre le cahier et prendre le crayon peuvent être faits dans n'importe quel ordre, mais il faut les avoir avant de quitter la table.

# Consigne

Sélectionne les programmes qui donnent exactement le résultat demandé.

# Réponses

1. ```
event: DÉBUT
move: PRENDRE le cahier
move: PRENDRE le crayon
move: QUITTER sa table
move: REJOINDRE l'îlot bleu
move: S'ASSEOIR
end: FIN
```
2. ```
event: DÉBUT
move: PRENDRE le crayon
move: PRENDRE le cahier
move: QUITTER sa table
move: REJOINDRE l'îlot bleu
move: S'ASSEOIR
end: FIN
```
3. ```
event: DÉBUT
move: PRENDRE le cahier
move: QUITTER sa table
move: PRENDRE le crayon
move: REJOINDRE l'îlot bleu
move: S'ASSEOIR
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Deux actions sont interchangeables, mais toutes deux doivent être terminées avant de quitter la table.

# Feedback essai 2

Vérifie si le crayon est encore accessible après avoir quitté la table.

# Feedback

Les programmes 1 et 2 diffèrent seulement par l'ordre de prise du cahier et du crayon. Le programme 3 quitte la table avant d'avoir pris le crayon.
