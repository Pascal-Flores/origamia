# Contexte

Tu dois écrire ton prénom sur une étiquette à coller sur ton cahier.

# Consigne

Parmi les 3 programmes donnés, identifie ceux qui donnent le même résultat (étiquette collée sur le cahier, avec ton nom dessus).

# Réponses

1. ```
event: DÉBUT
move: PRENDRE une étiquette
move: PRENDRE un stylo
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
move: RANGER le stylo
end: FIN
```
2. ```
event: DÉBUT
move: PRENDRE un stylo
move: PRENDRE une étiquette
move: RANGER le stylo
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
end: FIN
```
3. ```
event: DÉBUT
move: PRENDRE un stylo
move: PRENDRE une étiquette
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
move: RANGER le stylo
end: FIN
```

# Solution

1, 3

# Feedback essai 1

Hum, au bout de chaque programme, on voudrait voir notre prénom sur le cahier. Qu’est-ce qu’on aurait sous les yeux ?

# Feedback essai 2

Moi, je peux prendre le stylo ou l’étiquette en premier. Mais si je range le stylo tout de suite, avec quoi j’écris ?

# Feedback

Ah, le stylo ! Il nous le faut pour écrire le prénom avant de coller l’étiquette. On peut le prendre en premier ou en second.
