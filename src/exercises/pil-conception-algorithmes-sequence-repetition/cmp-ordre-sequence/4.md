# Contexte

Tu dois écrire ton prénom sur une étiquette à coller sur ton cahier.

# Consigne

Parmi les 3 programmes donnés, identifie ceux qui donnent le même résultat (étiquette collée sur le cahier, avec ton nom dessus).

# Réponses

1. ```
event: DÉBUT
move: PRENDRE une étiquette
move: PRENDRE un stylo
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
move: RANGER le stylo
end: FIN
```
2. ```
event: DÉBUT
move: PRENDRE un stylo
move: PRENDRE une étiquette
move: RANGER le stylo
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
end: FIN
```
3. ```
event: DÉBUT
move: PRENDRE un stylo
move: PRENDRE une étiquette
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
move: RANGER le stylo
end: FIN
```

# Solution

1, 3

# Feedback essai 1

Et si on suivait chaque programme jusqu’au cahier ? Qu’est-ce qu’on doit retrouver sur l’étiquette à la fin ?

# Feedback essai 2

On peut prendre l’étiquette ou le stylo en premier. Mais de quoi a-t-on besoin au moment d’écrire ?

# Feedback

Si on garde le stylo jusqu’à l’écriture du prénom, on peut ensuite coller l’étiquette. Le prendre en premier ou en second marche !
