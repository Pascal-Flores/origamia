# Contexte

Tu dois écrire ton prénom sur une étiquette à coller sur ton cahier.

# Consigne

Parmi les 3 programmes donnés, identifie ceux qui donnent le même résultat (étiquette collée sur le cahier, avec ton nom dessus).
# Réponses

1. ```
event: DÉBUT
move: PRENDRE une étiquette
move: PRENDRE un stylo
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
move: RANGER le stylo
end: FIN
```
2. ```
event: DÉBUT
move: PRENDRE un stylo
move: PRENDRE une étiquette
move: RANGER le stylo
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
end: FIN
```
3. ```
event: DÉBUT
move: PRENDRE un stylo
move: PRENDRE une étiquette
move: ÉCRIRE "ton prénom" sur l'étiquette
move: COLLER l'étiquette sur le cahier
move: RANGER le stylo
end: FIN
```

# Solution

1, 3

# Feedback

Les programmes 1 et 3 donnent bien le même résultat : l’étiquette est écrite puis collée sur le cahier. Dans le programme 2, on range le stylo avant d’écrire, donc on ne peut plus écrire sur l’étiquette.
