# Contexte

Une feuille de présence circule dans la classe. Quand elle arrive à toi, tu dois écrire ton prénom puis la passer à ton voisin.

# Consigne

Parmi les 3 programmes, coche ceux qui donnent le même résultat : ton prénom est écrit sur la feuille, puis la feuille est transmise au voisin.

# Réponses

1.
```
event: DÉBUT
move: PRENDRE la feuille
move: PRENDRE un stylo
move: ÉCRIRE son prénom
move: PASSER la feuille au voisin
move: RANGER le stylo
end: FIN
```
2.
```
event: DÉBUT
move: PRENDRE un stylo
move: PRENDRE la feuille
move: ÉCRIRE son prénom
move: RANGER le stylo
move: PASSER la feuille au voisin
end: FIN
```
3.
```
event: DÉBUT
move: PRENDRE la feuille
move: PRENDRE un stylo
move: RANGER le stylo
move: ÉCRIRE son prénom
move: PASSER la feuille au voisin
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Si j’étais le voisin, qu’est-ce que je devrais retrouver sur la feuille quand elle arrive jusqu’à moi ?

# Feedback essai 2

Moi, avec le stylo déjà dans la trousse, je ne pourrais plus signer. Où est le stylo au moment de l’utiliser dans chaque programme ?

# Feedback

Ah, le stylo était la clé ! On prépare le stylo et la feuille, on signe, puis on la passe. Si le stylo est rangé, plus de signature !
