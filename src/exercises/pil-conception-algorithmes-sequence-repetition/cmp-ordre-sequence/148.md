# Contexte

Une feuille de présence circule dans la classe. Quand elle arrive à toi, tu dois écrire ton prénom puis la passer à ton voisin.

# Consigne

Parmi les 3 programmes, coche ceux qui donnent le même résultat : ton prénom est écrit sur la feuille, puis la feuille est transmise au voisin.

# Réponses

1.
```
event: DÉBUT
move: PRENDRE la feuille
move: PRENDRE un stylo
move: ÉCRIRE son prénom
move: PASSER la feuille au voisin
move: RANGER le stylo
end: FIN
```
2.
```
event: DÉBUT
move: PRENDRE un stylo
move: PRENDRE la feuille
move: ÉCRIRE son prénom
move: RANGER le stylo
move: PASSER la feuille au voisin
end: FIN
```
3.
```
event: DÉBUT
move: PRENDRE la feuille
move: PRENDRE un stylo
move: RANGER le stylo
move: ÉCRIRE son prénom
move: PASSER la feuille au voisin
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Regarde quelles actions peuvent changer de place sans empêcher l'écriture du prénom.

# Feedback essai 2

On peut prendre la feuille ou le stylo en premier. En revanche, le stylo doit encore être disponible au moment d'écrire.

# Feedback

Les programmes 1 et 2 donnent le résultat attendu. Dans le programme 3, le stylo est rangé avant l'écriture.
