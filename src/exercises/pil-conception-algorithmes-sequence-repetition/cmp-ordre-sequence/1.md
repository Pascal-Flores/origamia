# Contexte

La sonnerie de fin de récréation retentit.

# Consigne

Remets les étapes dans l'ordre pour rentrer correctement en classe.
# Réponses

1. `move: Se METTRE en rang`
2. `move: ATTENDRE le signal du professeur`
3. `move: SUIVRE le professeur jusqu'à la salle de classe`

# Solution

1, 2, 3

# Feedback essai 1

Cherche ce qui doit être vrai avant chaque action. On ne peut pas suivre le professeur tant que le groupe n'est pas prêt à partir.

# Feedback essai 2

La première action est de se mettre en rang. Le signal du professeur vient juste avant le déplacement vers la classe.

# Feedback

Pour bien rentrer en classe, on commence par se mettre en rang, puis on attend le signal du professeur avant de le suivre jusqu'à la salle : chaque étape doit être faite dans l'ordre pour que tout se passe calmement.
