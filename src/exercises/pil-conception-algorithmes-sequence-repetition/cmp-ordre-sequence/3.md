# Contexte

Tu as du temps libre dans la classe, et tu décides de lire un livre.

# Consigne

Remets les étapes dans l’ordre pour décrire correctement les actions à faire pour lire le livre.
# Réponses

1. `move: ALLER prendre un livre dans la bibliothèque`
2. `move: LIRE le livre pendant le temps libre`
3. `move: ALLER ranger le livre`

# Solution

1, 2, 3

# Feedback essai 1

Au début, le livre est à la bibliothèque. Qu’est-ce qu’on fait avec lui entre le début et la fin ?

# Feedback essai 2

Si le livre est déjà rangé, est-ce qu’on peut encore lire la suite de l’histoire ?

# Feedback

On prend un livre, on le lit, puis on le range à la bibliothèque. On retrouvera la suite une autre fois !
