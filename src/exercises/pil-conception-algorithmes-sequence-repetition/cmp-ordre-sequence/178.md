# Contexte

Pour préparer le plan d'un petit parcours sportif, on veut tracer avec Turtle un rectangle de `100 × 40` pixels.

# Consigne

Dans l'interface Vittascience, assemble les blocs fournis pour obtenir le contour demandé.

Le programme doit contenir exactement **8 instructions**.

# Feedback essai 1

Le tracé alterne toujours une avance et un quart de tour.

# Feedback essai 2

Les côtés opposés ont les mêmes longueurs : 100, 40, 100, 40.

# Feedback

Le bon ordre alterne les quatre avances `100, 40, 100, 40` et quatre rotations de 90°.
