# Contexte

Pour préparer le plan d'un petit parcours sportif, on veut tracer avec Turtle un chemin composé de trois lignes droites reliées par trois virages arrondis.

# Consigne

Dans l'interface Vittascience, assemble les **8 blocs fournis** pour reproduire le parcours demandé.

Les paramètres restent ceux proposés par défaut dans les blocs : `avancer de 50`, `arc de rayon 50 et d'angle 90°` et `tourner à droite de 90°`.

Tu dois uniquement assembler les blocs, sans modifier leurs paramètres.

# Feedback essai 1

Le tracé commence par une ligne droite. Chaque virage arrondi vient après une ligne droite.

# Feedback essai 2

Après les deux premiers arcs, un quart de tour vers la droite remet Turtle dans la direction nécessaire pour continuer le parcours.

# Feedback

L'ordre correct est : avancer, arc, tourner à droite, avancer, arc, tourner à droite, avancer, arc. Tous les paramètres gardent leurs valeurs par défaut.
