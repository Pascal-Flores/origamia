# Contexte

Un crayon numérique doit tracer un escalier de deux marches identiques. Il part vers la droite. Chaque segment mesure 40 pixels.

# Consigne

Remets les huit blocs dans l'ordre pour tracer deux marches : droite, haut, droite, haut.

# Réponses

1. `move: AVANCER de (40) pixels`
2. `move: TOURNER à gauche de (90) degrés`
3. `move: AVANCER de (40) pixels`
4. `move: TOURNER à droite de (90) degrés`
5. `move: AVANCER de (40) pixels`
6. `move: TOURNER à gauche de (90) degrés`
7. `move: AVANCER de (40) pixels`
8. `move: TOURNER à droite de (90) degrés`

# Solution

1, 2, 3, 4, 5, 6, 7, 8

# Feedback essai 1

Après un segment horizontal, le crayon doit regarder vers le haut ; après un segment vertical, il doit de nouveau regarder vers la droite.

# Feedback essai 2

Le motif « avancer, gauche, avancer, droite » est utilisé deux fois.

# Feedback

Chaque marche est obtenue avec avancer, tourner à gauche, avancer, tourner à droite. En répétant ce motif deux fois, on trace les quatre segments dans le bon ordre.
