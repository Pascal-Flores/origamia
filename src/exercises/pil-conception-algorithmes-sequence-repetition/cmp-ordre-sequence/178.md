# Contexte

Dans la classe, un petit casier sert à ranger les clés du matériel. Pour le repérer facilement, on veut préparer une étiquette avec un **pictogramme de clé**.

Le dessin est simplifié : un grand anneau rond en haut, une tige droite, puis un petit panneton en angle droit à l'extrémité.

# Consigne

Dans l'interface Vittascience, assemble les **8 blocs fournis** pour tracer le pictogramme de clé.

Tous les paramètres sont déjà corrects. Tu dois uniquement placer les blocs dans le bon ordre, sans modifier leurs valeurs.

# Feedback essai 1

Commence par l'anneau rond de la clé. La tige part ensuite du point où le cercle se termine.

# Feedback essai 2

Après le cercle, un quart de tour oriente Turtle vers le bas. Deux avances forment la tige. Les trois derniers changements de direction et déplacements dessinent le panneton.

# Feedback

Le bon ordre est : `cercle de rayon 50`, `tourner à droite de 90°`, `avancer de 50`, `avancer de 50`, `tourner à gauche de 90°`, `avancer de 50`, `tourner à droite de 90°`, `avancer de 50`.

Le cercle forme l'anneau, les deux avances successives forment la tige et les trois dernières instructions dessinent le panneton de la clé.
