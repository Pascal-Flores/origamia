# Contexte

Pour préparer un petit parcours sportif, on veut dessiner un **drapeau de départ** qui servira de repère sur le plan du parcours.

Le dessin est simple : un long mât vertical et, en haut du mât, un drapeau rectangulaire qui part vers la droite.

# Consigne

Dans l'interface Vittascience, assemble les **12 blocs fournis** pour tracer le drapeau de départ.

Tous les paramètres sont déjà corrects. Tu dois uniquement placer les blocs dans le bon ordre, sans modifier leurs valeurs.

# Feedback essai 1

Commence par le mât : Turtle doit d'abord s'orienter vers le haut, puis avancer trois fois.

# Feedback essai 2

Une fois arrivé en haut du mât, trace le contour du drapeau : deux avances vers la droite, une vers le bas, puis deux avances pour revenir jusqu'au mât.

# Feedback

Le bon ordre est : `tourner à gauche de 90°`, trois fois `avancer de 50`, `tourner à droite de 90°`, deux fois `avancer de 50`, `tourner à droite de 90°`, `avancer de 50`, `tourner à droite de 90°`, puis deux fois `avancer de 50`.

Le programme trace ainsi un mât vertical de 150 pixels et un drapeau rectangulaire de 100 pixels de large sur 50 pixels de haut.
