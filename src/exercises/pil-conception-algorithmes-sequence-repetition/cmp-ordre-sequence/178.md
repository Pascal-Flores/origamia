# Contexte

Pour marquer le départ d'un petit parcours sportif, on veut tracer avec Turtle un fanion : un mât vertical surmonté d'un triangle.

# Consigne

Dans l'interface Vittascience, assemble les **8 blocs fournis** pour reproduire le fanion.

Tous les blocs sont déjà paramétrés : tu dois uniquement les placer dans le bon ordre.

# Feedback essai 1

Commence par construire le mât. Le triangle doit ensuite partir de son extrémité supérieure.

# Feedback essai 2

Le mât mesure `120` pixels. Après l'avoir tracé, tourne à droite puis utilise les trois avances de `80` pixels et les deux rotations de `120°` pour fermer le triangle.

# Feedback

Le programme commence par orienter Turtle vers le haut et tracer le mât de `120` pixels. Il se tourne ensuite vers la droite et trace un triangle équilatéral avec trois côtés de `80` pixels séparés par deux rotations de `120°`.
