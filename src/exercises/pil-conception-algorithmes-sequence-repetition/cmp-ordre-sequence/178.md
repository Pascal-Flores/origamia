# Contexte

Un robot ouvre la marche vers le gymnase sur un plan quadrillé. Son trajet est donné : avancer de 3 cases, tourner à gauche, avancer de 2 cases, tourner à droite, avancer de 4 cases, tourner à gauche, avancer de 1 case, puis s'arrêter.

# Consigne

Remets les huit blocs fournis dans l'ordre du trajet.

# Réponses

1. `move: AVANCER de (3) cases`
2. `move: TOURNER à gauche`
3. `move: AVANCER de (2) cases`
4. `move: TOURNER à droite`
5. `move: AVANCER de (4) cases`
6. `move: TOURNER à gauche`
7. `move: AVANCER de (1) case`
8. `end: S'ARRÊTER`

# Solution

1, 2, 3, 4, 5, 6, 7, 8

# Feedback essai 1

Recopie mentalement la suite donnée sans modifier les distances ni les directions.

# Feedback essai 2

Les trois virages sont gauche, droite, gauche.

# Feedback

Les huit blocs sont ordonnés exactement comme le trajet décrit ; modifier l'ordre d'un virage ou d'un déplacement change l'arrivée.
