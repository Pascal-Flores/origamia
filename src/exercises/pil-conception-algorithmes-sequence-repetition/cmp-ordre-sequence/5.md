# Contexte

Tu prépares ton sac pour la séance de sport.

# Consigne

Parmi les 3 programmes donnés, identifie ceux qui donnent le même résultat (il doit y avoir dans le sac une gourde et une chasuble, et le sac doit être fermé et posé près de la porte).
# Réponses

1. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la gourde dans le sac
move: METTRE la chasuble dans le sac
move: FERMER le sac
move: POSER le sac près de la porte
end: FIN
```
2. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la gourde dans le sac
move: FERMER le sac
move: METTRE la chasuble dans le sac
move: POSER le sac près de la porte
end: FIN
```
3. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la chasuble dans le sac
move: METTRE la gourde dans le sac
move: FERMER le sac
move: POSER le sac près de la porte
end: FIN
```

# Solution

1, 3

# Feedback essai 1

On vérifie notre sac ensemble ? Près de la porte, il devrait être fermé. Mais qu’est-ce qu’il y a dedans à ce moment-là ?

# Feedback essai 2

Si je ferme mon sac alors qu’un objet est encore dehors, je dois le rouvrir. Est-ce qu’un programme nous met dans ce cas ?

# Feedback

Ah, je vois ! Gourde et chasuble entrent dans l’ordre qu’on veut. Une fois les deux dedans, on ferme et on pose le sac près de la porte.
