# Contexte

Tu prépares ton sac pour la séance de sport.

# Consigne

Parmi les 3 programmes donnés, identifie ceux qui donnent le même résultat (il doit y avoir dans le sac une gourde et une chasuble, et le sac doit être fermé et posé près de la porte).
# Réponses

1. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la gourde dans le sac
move: METTRE la chasuble dans le sac
move: FERMER le sac
move: POSER le sac près de la porte
end: FIN
```
2. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la gourde dans le sac
move: FERMER le sac
move: METTRE la chasuble dans le sac
move: POSER le sac près de la porte
end: FIN
```
3. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la chasuble dans le sac
move: METTRE la gourde dans le sac
move: FERMER le sac
move: POSER le sac près de la porte
end: FIN
```

# Solution

1, 3

# Feedback essai 1

Pour chaque programme, vérifie les quatre résultats attendus : les deux objets dans le sac, le sac fermé et le sac près de la porte.

# Feedback essai 2

Écarte tout programme qui ferme le sac avant que la gourde et la chasuble soient à l'intérieur.

# Feedback

Les programmes 1 et 3 donnent bien le même résultat : la gourde et la chasuble sont dans le sac, puis le sac est fermé et posé près de la porte. Dans le programme 2, on ferme le sac avant d’y mettre la chasuble, donc le résultat n’est pas le même.
