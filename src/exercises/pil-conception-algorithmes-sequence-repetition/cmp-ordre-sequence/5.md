# Contexte

Tu prépares ton sac pour la séance de sport.

# Consigne

Parmi les 3 programmes donnés, identifie ceux qui donnent le même résultat (il doit y avoir dans le sac une gourde et une chasuble, et le sac doit être fermé et posé près de la porte).
# Réponses

1. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la gourde dans le sac
move: METTRE la chasuble dans le sac
move: FERMER le sac
move: POSER le sac près de la porte
end: FIN
```
2. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la gourde dans le sac
move: FERMER le sac
move: METTRE la chasuble dans le sac
move: POSER le sac près de la porte
end: FIN
```
3. ```
event: DÉBUT
move: OUVRIR le sac
move: METTRE la chasuble dans le sac
move: METTRE la gourde dans le sac
move: FERMER le sac
move: POSER le sac près de la porte
end: FIN
```

# Solution

1, 3

# Feedback essai 1

Imaginons qu’on arrive près de la porte. Comment est le sac ? Qu’est-ce qu’on retrouve dedans ?

# Feedback essai 2

L’ordre entre la gourde et la chasuble change selon le programme. À quel moment la fermeture du sac nous gênerait-elle ?

# Feedback

On peut ranger les deux objets dans n’importe quel ordre. On ferme le sac quand ils sont dedans, puis on le pose près de la porte. Prêts !
