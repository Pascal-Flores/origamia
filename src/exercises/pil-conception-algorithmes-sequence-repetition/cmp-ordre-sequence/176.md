# Contexte

Pour préparer une rotation d'ateliers, il faut poser les étiquettes des trois tables et déposer le matériel. Ces deux préparations peuvent être faites dans n'importe quel ordre. Ensuite seulement, on place les groupes, puis on donne le signal de départ, puis la rotation commence.

# Consigne

Sélectionne les programmes qui produisent exactement ce résultat.

# Réponses

1. ```
event: DÉBUT
move: POSER les étiquettes
move: DÉPOSER le matériel
move: PLACER les groupes
move: DONNER le signal
move: COMMENCER la rotation
end: FIN
```
2. ```
event: DÉBUT
move: DÉPOSER le matériel
move: POSER les étiquettes
move: PLACER les groupes
move: DONNER le signal
move: COMMENCER la rotation
end: FIN
```
3. ```
event: DÉBUT
move: POSER les étiquettes
move: PLACER les groupes
move: DONNER le signal
move: DÉPOSER le matériel
move: COMMENCER la rotation
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Les deux premières préparations sont indépendantes. Cherche surtout ce qui doit être terminé avant le signal.

# Feedback essai 2

Le matériel doit être en place avant que les groupes commencent.

# Feedback

Les programmes 1 et 2 installent étiquettes et matériel avant de placer les groupes et de lancer l'activité. Le troisième donne le signal trop tôt.
