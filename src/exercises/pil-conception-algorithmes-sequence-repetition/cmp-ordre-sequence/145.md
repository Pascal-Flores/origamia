# Contexte

Une feuille est posée sur la table du professeur. Tu es assis à ta place et tu dois aller la chercher.

# Consigne

Remets les trois actions dans l'ordre.

# Réponses

1. `move: SE LEVER de sa chaise`
2. `move: PRENDRE une feuille sur la table du professeur`
3. `move: REVENIR s'asseoir à sa place`

# Solution

1, 2, 3

# Feedback essai 1

On est encore assis à notre place. Est-ce qu’on peut déjà attraper la feuille ?

# Feedback essai 2

Quand on revient s’asseoir, est-ce qu’on a déjà eu le temps de prendre la feuille ?

# Feedback

On se lève, on prend la feuille sur la table du professeur, puis on revient s’asseoir avec elle. La feuille est arrivée à bon port !
