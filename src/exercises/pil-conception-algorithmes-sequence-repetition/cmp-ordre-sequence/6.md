# Contexte

Tu prépares une tartine pour le petit-déjeuner.

# Consigne

Parmi les 3 programmes donnés, identifie ceux qui donnent le même résultat (la tartine doit être beurrée puis confiturée, et posée dans une assiette).
# Réponses

1. ```
event: DÉBUT
move: PRENDRE une assiette
move: POSER l’assiette sur la table
move: POSER une tranche de pain sur l’assiette
move: METTRE du beurre sur la tartine
move: METTRE de la confiture sur la tartine
end: FIN
```
2. ```
event: DÉBUT
move: PRENDRE une assiette
move: POSER une tranche de pain sur l’assiette
move: POSER l’assiette sur la table
move: METTRE du beurre sur la tartine
move: METTRE de la confiture sur la tartine
end: FIN
```
3. ```
event: DÉBUT
move: PRENDRE une assiette
move: POSER l’assiette sur la table
move: POSER une tranche de pain sur l’assiette
move: METTRE de la confiture sur la tartine
move: METTRE du beurre sur la tartine
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Compare l'état final de la tartine, mais vérifie aussi l'ordre entre les deux garnitures.

# Feedback essai 2

Le beurre doit être étalé avant la confiture. Écarte le programme qui inverse ces deux actions.

# Feedback

Les programmes 1 et 2 donnent bien le même résultat : la tranche de pain est posée sur l’assiette, puis la tartine est beurrée avant d’être confiturée. Dans le programme 3, on met la confiture avant le beurre, donc le résultat n’est pas le même.
