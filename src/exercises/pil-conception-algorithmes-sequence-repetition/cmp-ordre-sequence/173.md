# Contexte

Tu as terminé une fiche et tu dois la rendre.

# Consigne

Remets les trois étapes dans l'ordre pour rendre correctement ta fiche.

# Réponses

1. `move: VÉRIFIER que ton prénom est écrit sur la fiche`
2. `move: LEVER la main pour signaler que tu as terminé`
3. `move: DÉPOSER la fiche à l'endroit indiqué`

# Solution

1, 2, 3

# Feedback essai 1

Cherche ce qu'il faut vérifier avant de signaler que le travail est prêt.

# Feedback essai 2

La fiche doit déjà être identifiable avant d'être déposée.

# Feedback

On vérifie d'abord le prénom, puis on signale que le travail est terminé et enfin on dépose la fiche. Cet ordre évite de rendre une fiche non identifiable.
