# Contexte

Pour représenter un parcours entre plusieurs salles, on veut tracer avec Turtle un rectangle de `120 × 60` pixels.

# Consigne

Dans l'interface Vittascience, assemble les blocs fournis pour tracer le rectangle.

Le programme doit contenir exactement **8 instructions** : quatre avances et quatre quarts de tour.

# Feedback essai 1

Repère l'alternance entre un déplacement et un changement de direction.

# Feedback essai 2

Les longueurs des côtés alternent : 120, 60, 120, 60. Après chaque côté, place un quart de tour.

# Feedback

Un rectangle de 120 × 60 pixels se trace en alternant les quatre longueurs `120, 60, 120, 60` avec quatre rotations de 90°.
