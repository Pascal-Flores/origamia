# Contexte

Sur le plan d'un musée, quatre salles rondes sont disposées autour d'un même hall. Vues ensemble, elles forment un **trèfle à quatre feuilles**.

On veut reproduire ce symbole avec Turtle : quatre cercles de même taille se rejoignent au centre, un dans chaque direction.

# Consigne

Dans l'interface Vittascience, assemble les **8 blocs fournis** pour tracer le trèfle à quatre feuilles.

Tous les paramètres sont déjà corrects. Tu dois uniquement placer les blocs dans le bon ordre, sans modifier leurs valeurs.

# Feedback essai 1

Chaque feuille du trèfle est un cercle complet. Après avoir tracé une feuille, Turtle doit changer de direction avant de tracer la suivante.

# Feedback essai 2

Le programme alterne toujours les deux mêmes actions : tracer un cercle de rayon 50, puis tourner à droite de 90°.

# Feedback

Le bon programme alterne quatre fois `cercle de rayon 50` puis `tourner à droite de 90°`. Les quatre cercles partent du même point dans quatre directions différentes et forment un trèfle à quatre feuilles.
