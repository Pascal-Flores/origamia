# Contexte

Un crayon numérique part orienté vers la droite. On veut tracer un rectangle de 80 pixels sur 40 pixels.

# Consigne

Remets les huit blocs dans l'ordre pour fermer le rectangle.

# Réponses

1. `move: AVANCER de (80) pixels`
2. `move: TOURNER à droite de (90) degrés`
3. `move: AVANCER de (40) pixels`
4. `move: TOURNER à droite de (90) degrés`
5. `move: AVANCER de (80) pixels`
6. `move: TOURNER à droite de (90) degrés`
7. `move: AVANCER de (40) pixels`
8. `move: TOURNER à droite de (90) degrés`

# Solution

1, 2, 3, 4, 5, 6, 7, 8

# Feedback essai 1

Les longueurs doivent alterner : grand côté, petit côté, grand côté, petit côté.

# Feedback essai 2

Un quart de tour doit suivre chaque côté.

# Feedback

Le rectangle alterne 80 pixels et 40 pixels, avec un quart de tour après chaque côté. Les huit blocs doivent donc suivre ce motif jusqu'au retour à l'orientation de départ.
