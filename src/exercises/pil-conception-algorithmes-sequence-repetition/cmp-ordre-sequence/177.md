# Contexte

Pour représenter un parcours de visite, on veut tracer avec Turtle trois salles rondes autour d'un même point, puis un couloir de sortie.

# Consigne

Dans l'interface Vittascience, assemble les **8 blocs fournis** pour reproduire le tracé demandé.

Les paramètres restent ceux proposés par défaut dans les blocs : `cercle 50`, `tourner à droite de 90°` et `avancer de 50`.

Tu dois uniquement assembler les blocs, sans modifier leurs paramètres.

# Feedback essai 1

Commence par les trois salles rondes. Entre deux salles, le tracé change d'orientation d'un quart de tour.

# Feedback essai 2

Après la troisième salle et le troisième quart de tour, les deux avances de 50 pixels se suivent pour former le couloir.

# Feedback

La solution enchaîne trois fois `cercle 50` puis `tourner à droite de 90°`, puis deux blocs `avancer de 50`.
