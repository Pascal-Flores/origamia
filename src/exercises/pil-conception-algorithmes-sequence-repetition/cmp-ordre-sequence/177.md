# Contexte

Pour représenter un parcours entre plusieurs salles, on veut tracer avec Turtle une spirale carrée composée de quatre segments de plus en plus courts.

# Consigne

Dans l'interface Vittascience, assemble les **8 blocs fournis** pour reproduire la forme demandée.

Tous les blocs sont déjà paramétrés : tu dois uniquement les placer dans le bon ordre.

# Feedback essai 1

Observe les longueurs des quatre déplacements : le tracé commence par le plus long segment puis se resserre progressivement.

# Feedback essai 2

Après chaque déplacement, le tracé effectue un quart de tour vers la droite. Les longueurs utilisées sont `120`, `90`, `60` puis `30` pixels.

# Feedback

Le programme correct alterne une avance et un quart de tour vers la droite, avec des déplacements de plus en plus courts : `120`, `90`, `60` puis `30` pixels. Le tracé forme ainsi une spirale carrée.
