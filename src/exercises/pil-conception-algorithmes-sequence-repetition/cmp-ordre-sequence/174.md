# Contexte

Tu bloques sur une consigne pendant que l'enseignante parle à un autre élève. Tu veux demander de l'aide sans déranger.

# Consigne

Remets les trois actions dans l'ordre.

# Réponses

1. `move: LEVER la main`
2. `move: ATTENDRE que l'enseignante donne la parole`
3. `move: POSER sa question à voix basse`

# Solution

1, 2, 3

# Feedback essai 1

La question ne doit pas être posée avant d'avoir obtenu la parole.

# Feedback essai 2

Le premier signal est de lever la main.

# Feedback

Lever la main permet de signaler la demande, attendre évite d'interrompre, puis la question peut être posée.
