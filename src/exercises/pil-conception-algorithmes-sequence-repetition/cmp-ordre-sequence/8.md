# Énoncé

En utilisant les blocs fournis, tu dois tracer une piste d’athlétisme, c’est-à-dire une forme composée de deux lignes droites reliées par deux demi-cercles. Chaque ligne droite doit mesurer 100 pixels.

Construis le programme avec les 8 instructions fournies. Leurs paramètres sont déjà corrects : ton travail consiste à placer les blocs dans le bon ordre.

# Feedback

Pour tracer la piste avec Turtle, il faut enchaîner une ligne droite, un demi-cercle, la seconde ligne droite puis le second demi-cercle. Cet ordre relie correctement les quatre parties et ferme la forme sans modifier les paramètres des blocs.
