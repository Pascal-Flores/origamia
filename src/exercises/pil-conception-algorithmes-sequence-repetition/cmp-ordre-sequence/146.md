# Contexte

Tu bloques sur une consigne pendant que l’enseignante aide déjà un autre élève. Dans cette classe, on lève la main même si l’enseignante est occupée.

# Consigne

Remets les trois actions dans l'ordre pour demander de l'aide sans interrompre.

# Réponses

1. `move: LEVER la main`
2. `move: ATTENDRE que l’enseignante te donne la parole`
3. `move: POSER sa question`

# Solution

1, 2, 3

# Feedback essai 1

L’enseignante parle déjà à quelqu’un. Comment lui faire signe sans lui couper la parole ?

# Feedback essai 2

Moi, j’attendrais un signe après avoir levé la main. Comment on sait que c’est le bon moment pour poser la question ?

# Feedback

On a trouvé comment se faire entendre sans interrompre. On lève la main, on attend d’avoir la parole, puis on pose la question.
