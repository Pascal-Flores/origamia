# Contexte

Tu bloques sur une consigne pendant que l'enseignante aide déjà un autre élève.

# Consigne

Remets les trois actions dans l'ordre pour demander de l'aide sans interrompre.

# Réponses

1. `move: LEVER la main`
2. `move: ATTENDRE que l'enseignante soit disponible`
3. `move: POSER sa question`

# Solution

1, 2, 3

# Feedback essai 1

La question ne doit pas être posée pendant que l'enseignante aide quelqu'un d'autre.

# Feedback essai 2

Le signal vient avant l'attente, puis la question est posée quand l'enseignante est disponible.

# Feedback

On lève d'abord la main, on attend que l'enseignante soit disponible, puis on pose sa question.
