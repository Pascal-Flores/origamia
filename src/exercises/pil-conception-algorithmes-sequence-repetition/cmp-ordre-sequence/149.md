# Contexte

La classe prépare une affiche pour présenter une exposition. Pour décorer l'affiche, on veut ajouter un **motif géométrique en forme de rosace**, composé de quatre cercles identiques.

Chaque cercle doit partir du même point, mais être orienté dans une direction différente.

# Consigne

Dans l'interface Vittascience, assemble les **8 blocs fournis** pour tracer la rosace à quatre cercles.

Tous les paramètres sont déjà corrects. Tu dois uniquement placer les blocs dans le bon ordre, sans modifier leurs valeurs.

# Feedback essai 1

Un cercle complet ramène Turtle exactement à son point de départ. Il faut ensuite changer sa direction avant de tracer le cercle suivant.

# Feedback essai 2

Le programme alterne toujours les deux mêmes actions : tracer un cercle de rayon 50, puis tourner à droite de 90°.

# Feedback

Le bon programme alterne quatre fois `cercle de rayon 50` puis `tourner à droite de 90°`.

Après chaque cercle complet, Turtle revient au même point. Le quart de tour change seulement son orientation : les quatre cercles partent donc du même point dans quatre directions différentes et forment la rosace utilisée pour décorer l'affiche.
