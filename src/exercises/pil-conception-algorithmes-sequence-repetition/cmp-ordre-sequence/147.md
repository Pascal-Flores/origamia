# Contexte

Tu dois quitter ta table pour rejoindre l'îlot B avec ton cahier et ta trousse. À la fin, le cahier et la trousse doivent être posés sur l'îlot B.

# Consigne

Parmi les 3 programmes, coche ceux qui donnent le résultat attendu.

# Réponses

1.
```
event: DÉBUT
move: PRENDRE le cahier
move: PRENDRE la trousse
move: ALLER à l'îlot B
move: POSER le cahier
move: POSER la trousse
end: FIN
```

2.
```
event: DÉBUT
move: PRENDRE la trousse
move: PRENDRE le cahier
move: ALLER à l'îlot B
move: POSER la trousse
move: POSER le cahier
end: FIN
```

3.
```
event: DÉBUT
move: PRENDRE la trousse
move: ALLER à l'îlot B
move: POSER la trousse
move: PRENDRE le cahier
move: POSER le cahier
end: FIN
```

# Solution

1, 2

# Feedback essai 1

On fait comme si on changeait vraiment de table ? Qu’est-ce qu’on voudrait avoir en main avant de quitter notre place ?

# Feedback essai 2

Ça m’arrive de partir avec la trousse et de laisser le cahier. Dans chaque programme, est-ce qu’on a les deux au moment de partir ?

# Feedback

Une trousse sans cahier, ça nous embête ! On peut prendre l’un ou l’autre en premier, du moment qu’on a les deux avant de partir.
