# Contexte

Tu dois quitter ta table pour rejoindre l'îlot B avec ton cahier et ta trousse. À la fin, le cahier et la trousse doivent être posés sur l'îlot B.

# Consigne

Parmi les 3 programmes, coche ceux qui donnent le résultat attendu.

# Réponses

1.
```
event: DÉBUT
move: PRENDRE le cahier
move: PRENDRE la trousse
move: ALLER à l'îlot B
move: POSER le cahier
move: POSER la trousse
end: FIN
```

2.
```
event: DÉBUT
move: PRENDRE la trousse
move: PRENDRE le cahier
move: ALLER à l'îlot B
move: POSER la trousse
move: POSER le cahier
end: FIN
```

3.
```
event: DÉBUT
move: PRENDRE la trousse
move: ALLER à l'îlot B
move: POSER la trousse
move: PRENDRE le cahier
move: POSER le cahier
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Certaines actions indépendantes peuvent être inversées. Vérifie surtout que les deux objets sont pris avant de quitter la table.

# Feedback essai 2

Prendre le cahier et la trousse peut se faire dans les deux ordres. Après être allé à l'îlot B, on ne peut plus prendre le cahier resté sur la table de départ.

# Feedback

Les programmes 1 et 2 fonctionnent : le cahier et la trousse sont tous les deux pris avant le déplacement. Le programme 3 quitte la table avant de prendre le cahier.
