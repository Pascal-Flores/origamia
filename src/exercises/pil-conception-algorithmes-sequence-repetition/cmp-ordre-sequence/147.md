# Contexte

Tu dois quitter ta table pour rejoindre l'îlot B avec ton cahier et ta trousse. À la fin, le cahier et la trousse doivent être posés sur l'îlot B.

# Consigne

Parmi les 3 programmes, coche ceux qui donnent le résultat attendu.

# Réponses

1.
```
event: DÉBUT
move: PRENDRE le cahier
move: PRENDRE la trousse
move: ALLER à l'îlot B
move: POSER le cahier
move: POSER la trousse
end: FIN
```

2.
```
event: DÉBUT
move: PRENDRE la trousse
move: PRENDRE le cahier
move: ALLER à l'îlot B
move: POSER la trousse
move: POSER le cahier
end: FIN
```

3.
```
event: DÉBUT
move: PRENDRE la trousse
move: ALLER à l'îlot B
move: POSER la trousse
move: PRENDRE le cahier
move: POSER le cahier
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Imaginons qu’on change de table. Est-ce qu’on a tout ce qu’il nous faut dans les mains au moment de partir ?

# Feedback essai 2

On peut prendre la trousse avant le cahier ou l’inverse. Qu’est-ce qui manque si on quitte la table trop tôt ?

# Feedback

On peut prendre le cahier et la trousse dans l’ordre qu’on veut. L’important est d’avoir les deux avant de changer de table.
