# Contexte

Lors d'une relecture en binôme, ton camarade classe les remarques faites sur ta copie :

- `2` remarques d'orthographe ;
- `1` remarque de ponctuation ;
- `2` remarques de présentation.

Ces trois nombres sont les **entrées** du programme qui prépare le bilan de relecture.

On veut que le programme affiche le nombre total d'éléments à corriger :

`5 ÉLÉMENTS À CORRIGER`

C'est la **sortie attendue**.

Trois programmes ont été proposés.

### Programme 1

```
event: DÉBUT
move: LIRE les trois nombres de remarques
move: ADDITIONNER seulement les remarques d'orthographe et de ponctuation
say: AFFICHER le résultat suivi de "ÉLÉMENTS À CORRIGER"
end: FIN
```

### Programme 2

```
event: DÉBUT
move: LIRE les trois nombres de remarques
move: COMPTER le nombre de catégories de remarques
say: AFFICHER le résultat suivi de "ÉLÉMENTS À CORRIGER"
end: FIN
```

### Programme 3

```
event: DÉBUT
move: LIRE les trois nombres de remarques
move: ADDITIONNER les trois nombres
say: AFFICHER le résultat suivi de "ÉLÉMENTS À CORRIGER"
end: FIN
```

# Consigne

Quel programme transforme correctement les trois entrées en la sortie attendue ?

# Réponses

1. Programme 1
2. Programme 2
3. Programme 3

# Solution

3

# Feedback essai 1

La sortie doit donner le nombre total de remarques, pas le nombre de catégories. Vérifie quelles valeurs chaque programme additionne.

# Feedback essai 2

Il faut prendre en compte les trois catégories : `2 + 1 + 2 = 5`.

# Feedback

Le programme 3 est correct : il additionne les trois nombres de remarques et obtient `5`. Le programme 1 oublie les `2` remarques de présentation et obtient `3`. Le programme 2 compte seulement les trois catégories et obtient également `3`.
