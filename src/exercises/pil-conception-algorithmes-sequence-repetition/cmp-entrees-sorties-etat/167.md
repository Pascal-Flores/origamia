# Contexte

Avant de rendre une copie, tu vérifies que ton prénom est bien indiqué. Pour représenter cette vérification, on imagine un formulaire numérique qui reprend le prénom saisi et prépare l'étiquette associée à la copie.

Le prénom saisi est : `Nora`. C'est l'**entrée** du programme.

On veut obtenir l'affichage :

`PRÉNOM : NORA`

C'est la **sortie attendue**.

Trois programmes ont été proposés.

### Programme 1

```
event: DÉBUT
move: LIRE le prénom saisi
say: AFFICHER "NOM : " suivi du prénom lu
end: FIN
```

### Programme 2

```
event: DÉBUT
move: LIRE le prénom saisi
say: AFFICHER "PRÉNOM : " suivi du prénom lu
end: FIN
```

### Programme 3

```
event: DÉBUT
move: LIRE le prénom saisi
say: AFFICHER "PRÉNOM : LINA"
end: FIN
```

# Consigne

Quel programme transforme correctement l'entrée `Nora` en la sortie attendue ?

# Réponses

1. Programme 1
2. Programme 2
3. Programme 3

# Solution

2

# Feedback essai 1

Vérifie que le programme utilise bien le prénom fourni en entrée et que le texte affiché correspond exactement à la sortie attendue.

# Feedback essai 2

La sortie doit commencer par `PRÉNOM :` et reprendre le prénom `Nora` reçu au départ.

# Feedback

Le programme 2 est correct : il lit le prénom saisi puis l'affiche après `PRÉNOM :`, ce qui produit `PRÉNOM : NORA`. Le programme 1 affiche `NOM :` et le programme 3 ignore la valeur reçue en affichant un autre prénom.
