# Contexte

Un programme multiplie le nombre reçu par 3 puis affiche le résultat.

# Consigne

Quelle entrée faut-il donner pour obtenir la sortie 18 ? Écris uniquement le nombre.

# Solution

6

# Feedback essai 1

Quel nombre multiplié par 3 donne 18 ?

# Feedback

6 × 3 = 18. L'entrée recherchée est 6.
