# Contexte

Le programme compte une bouchée supplémentaire :

```
SORTIE = ENTRÉE + 1
```

La sortie attendue est `4`.

# Consigne

Quelle valeur d'entrée faut-il donner ?

# Réponses

1. 2
2. 3
3. 4

# Solution

2

# Feedback essai 1

Quel nombre donne 4 quand on lui ajoute 1 ?

# Feedback

L'entrée 3 devient 4 après l'ajout de 1.
