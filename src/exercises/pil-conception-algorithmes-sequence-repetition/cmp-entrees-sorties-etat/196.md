# Contexte

Un programme reçoit le nombre de tours à effectuer. Une variable `tour_actuel` commence à 0 et augmente pendant l'exécution. À la fin, le programme affiche « terminé ».

# Consigne

Classe les trois éléments selon leur rôle.

# Items

1. le nombre de tours demandé
2. la variable `tour_actuel`
3. le message « terminé » affiché à la fin

# Catégories

## Entrée
1

## État intermédiaire
2

## Sortie
3

# Feedback essai 1

Repère ce qui est connu avant l'exécution, ce qui change pendant et ce qui est produit à la fin.

# Feedback

Le nombre de tours est l'entrée. `tour_actuel` est conservé et mis à jour pendant l'exécution : c'est l'état intermédiaire. Le message final est la sortie.
