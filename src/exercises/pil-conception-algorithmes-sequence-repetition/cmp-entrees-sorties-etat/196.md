# Contexte

Lors d'une relecture en binôme, un programme reçoit le nombre de remarques faites par le camarade, conserve le total pendant le traitement, puis affiche le bilan.

# Consigne

Classe chaque étiquette dans `Entrée`, `État intermédiaire` ou `Sortie`.

# Catégories

1. Entrée
2. État intermédiaire
3. Sortie

# Étiquettes

1. Le nombre `3` fourni par le camarade.
2. Les remarques comptées au départ.
3. La variable `a_corriger = 3`.
4. Le total conservé pendant la préparation du bilan.
5. L'affichage `3 éléments à corriger`.
6. Le bilan visible à la fin.

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback essai 1

Repère ce qui est reçu, ce qui est conservé pendant l'exécution et ce qui est affiché à la fin.

# Feedback essai 2

Le nombre fourni arrive avant le traitement ; la variable sert pendant le traitement ; le bilan est produit après.

# Feedback

Les données initiales sont les entrées, la variable est l'état intermédiaire et le bilan affiché est la sortie.
