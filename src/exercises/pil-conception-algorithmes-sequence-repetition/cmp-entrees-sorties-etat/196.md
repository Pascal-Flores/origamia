# Contexte

Lors d'une relecture en binôme, ton camarade signale `3` éléments à corriger sur ta copie.

Le nombre `3` est l'**entrée** du programme qui prépare le bilan de relecture.

On veut obtenir l'affichage :

`3 ÉLÉMENTS À CORRIGER`

C'est la **sortie attendue**.

Trois programmes ont été proposés.

### Programme 1

```
event: DÉBUT
move: LIRE le nombre d'éléments à corriger
move: AJOUTER 1 à ce nombre
say: AFFICHER le résultat suivi de "ÉLÉMENTS À CORRIGER"
end: FIN
```

### Programme 2

```
event: DÉBUT
move: LIRE le nombre d'éléments à corriger
say: AFFICHER ce nombre suivi de "ÉLÉMENTS RELUS"
end: FIN
```

### Programme 3

```
event: DÉBUT
move: LIRE le nombre d'éléments à corriger
say: AFFICHER ce nombre suivi de "ÉLÉMENTS À CORRIGER"
end: FIN
```

# Consigne

Quel programme transforme correctement l'entrée `3` en la sortie attendue ?

# Réponses

1. Programme 1
2. Programme 2
3. Programme 3

# Solution

3

# Feedback essai 1

Suis la valeur `3` dans chaque programme et compare le message obtenu avec la sortie attendue.

# Feedback essai 2

La valeur reçue ne doit pas être modifiée et le message final doit indiquer des éléments `À CORRIGER`.

# Feedback

Le programme 3 est correct : il reprend directement le nombre `3` fourni en entrée et affiche `3 ÉLÉMENTS À CORRIGER`. Le programme 1 transforme `3` en `4` et le programme 2 affiche un autre message.
