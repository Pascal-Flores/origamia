# Contexte

Lors d'une relecture en binôme, ton camarade signale `3` éléments à corriger sur ta copie.

Pour représenter la préparation du bilan de relecture, le programme ci-dessous reçoit ce nombre, le garde pendant le traitement, puis affiche le bilan final.

```
event: DÉBUT
move: LIRE le nombre de remarques (3)
move: GARDER le total (3) pendant la préparation du bilan
say: AFFICHER "3 ÉLÉMENTS À CORRIGER"
end: FIN
```

# Consigne

Lis le programme puis classe chaque étiquette dans `Entrée`, `État intermédiaire` ou `Sortie`.

# Catégories

1. Entrée
2. État intermédiaire
3. Sortie

# Étiquettes

1. Le nombre `3` fourni à partir de la relecture.
2. Le nombre de remarques lu au début du programme.
3. Pendant la préparation du bilan, le total conservé est `3`.
4. Avant l'affichage, le programme garde encore le nombre `3`.
5. L'affichage `3 ÉLÉMENTS À CORRIGER`.
6. Le bilan visible à la fin du programme.

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback essai 1

Suis le nombre `3` dans le programme : il est d'abord reçu, puis gardé pendant le traitement, puis utilisé dans l'affichage final.

# Feedback essai 2

La ligne `LIRE` correspond à l'entrée. La ligne `GARDER` correspond à l'information conservée pendant le traitement. Le message affiché à la fin correspond à la sortie.

# Feedback

Le nombre `3` fourni par la relecture et lu par le programme constitue l'entrée. Pendant la préparation du bilan, cette valeur est gardée temporairement : c'est l'état intermédiaire. Enfin, le message `3 ÉLÉMENTS À CORRIGER` et le bilan visible à l'écran constituent la sortie.
