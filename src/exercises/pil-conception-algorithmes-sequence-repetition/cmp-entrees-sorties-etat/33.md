# Contexte

Voici un programme qui calcule un nombre à partir d’une entrée.

# Consigne

Quel nombre faut-il donner au programme pour que le résultat soit `15` ?

```
event: DÉBUT
move: AJOUTER 4 à l'entrée
move: MULTIPLIER le résultat par 3
move: RETIRER 6
say: AFFICHER le résultat
end: FIN
```

# Solution

3

# Feedback essai 1

Remonte les étapes depuis 15, en ordre inverse, avec l'opération contraire à chaque fois.

# Feedback essai 2

Annule successivement la soustraction de 6, la multiplication par 3, puis l'ajout de 4.

# Feedback

Pour retrouver l’entrée, il faut remonter les étapes dans l’ordre inverse : à partir de `15`, on ajoute `6`, on obtient `21`, puis on divise par `3`, on obtient `7`, puis on enlève `4`, ce qui donne `3`.
