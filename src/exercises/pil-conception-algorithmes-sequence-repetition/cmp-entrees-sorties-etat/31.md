# Contexte

Voici un programme qui calcule un nombre à partir d’une entrée.

# Consigne

Quel nombre faut-il donner au programme pour que le résultat soit `21` ?

```
event: DÉBUT
move: MULTIPLIER l'entrée par 4
move: AJOUTER 1
say: AFFICHER le résultat
end: FIN
```

# Solution

5

# Feedback essai 1

Et si on remontait le programme depuis le nombre affiché ? Quelle action arrive juste avant le résultat ?

# Feedback essai 2

On peut annuler une addition par une soustraction. Une fois revenu au nombre d’avant l’ajout, comment annule-t-on la multiplication ?

# Feedback

À partir de 21, on enlève 1, puis on divise 20 par 4. On retrouve 5 ! On peut vérifier en repartant dans l’autre sens.
