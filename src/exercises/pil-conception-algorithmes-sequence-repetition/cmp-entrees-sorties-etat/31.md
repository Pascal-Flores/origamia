# Énoncé

Voici un programme qui calcule un nombre à partir d’une entrée. Quel nombre faut-il donner au programme pour que le résultat soit `21` ?

```
event: DÉBUT
move: MULTIPLIER l'entrée par 4
move: AJOUTER 1
say: AFFICHER le résultat
end: FIN
```

# Solution

5

# Feedback

Pour retrouver l’entrée, il faut défaire le programme en partant de la sortie : si le résultat est `21`, on enlève d’abord `1`, ce qui donne `20`, puis on divise par `4`, ce qui donne `5`.
