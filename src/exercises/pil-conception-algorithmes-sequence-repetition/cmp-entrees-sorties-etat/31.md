# Contexte

Voici un programme qui calcule un nombre à partir d’une entrée.

# Consigne

Quel nombre faut-il donner au programme pour que le résultat soit `21` ?

```
event: DÉBUT
move: MULTIPLIER l'entrée par 4
move: AJOUTER 1
say: AFFICHER le résultat
end: FIN
```

# Solution

5

# Feedback essai 1

Mince, le nombre est toujours caché ! Si on repartait de 21, quel bloc aurait-on à défaire en premier ?

# Feedback essai 2

Pour défaire une addition, je soustrais. Une fois cette étape passée, comment est-ce qu’on défait la multiplication ?

# Feedback

On a remonté le calcul ! De 21, on enlève 1, puis on divise 20 par 4. Ça nous ramène à 5.
