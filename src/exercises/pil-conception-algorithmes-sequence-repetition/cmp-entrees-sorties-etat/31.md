# Contexte

Voici un programme qui calcule un nombre à partir d’une entrée.

# Consigne

Quel nombre faut-il donner au programme pour que le résultat soit `21` ?

```
event: DÉBUT
move: MULTIPLIER l'entrée par 4
move: AJOUTER 1
say: AFFICHER le résultat
end: FIN
```

# Solution

5

# Feedback essai 1

Pars du résultat et défais les opérations dans l'ordre inverse.

# Feedback essai 2

À partir de 21, annule d'abord l'ajout de 1, puis annule la multiplication par 4.

# Feedback

Pour retrouver l’entrée, il faut défaire le programme en partant de la sortie : si le résultat est `21`, on enlève d’abord `1`, ce qui donne `20`, puis on divise par `4`, ce qui donne `5`.
