# Contexte

Un service prépare un trajet en transports à partir d'un lieu de départ et d'une destination.

Les informations saisies sont :

- départ : `École` ;
- destination : `Piscine`.

Ce sont les **entrées** du programme.

Pour ce trajet, le service connaît l'itinéraire disponible suivant : **Bus 12 puis métro A**.

On veut que le programme affiche :

`ÉCOLE -> BUS 12 -> MÉTRO A -> PISCINE`

C'est la **sortie attendue**.

Trois programmes ont été proposés.

### Programme 1

```
event: DÉBUT
move: LIRE le lieu de départ et la destination
move: RECHERCHER un trajet de la destination vers le départ
say: AFFICHER la destination, les transports trouvés puis le départ
end: FIN
```

### Programme 2

```
event: DÉBUT
move: LIRE le lieu de départ et la destination
move: RECHERCHER un trajet du départ vers la destination
say: AFFICHER seulement les transports trouvés
end: FIN
```

### Programme 3

```
event: DÉBUT
move: LIRE le lieu de départ et la destination
move: RECHERCHER un trajet du départ vers la destination
say: AFFICHER le départ, les transports trouvés puis la destination
end: FIN
```

# Consigne

Quel programme transforme correctement les deux entrées en la sortie attendue ?

# Réponses

1. Programme 1
2. Programme 2
3. Programme 3

# Solution

3

# Feedback essai 1

Compare le sens du trajet recherché et les informations affichées à la sortie attendue.

# Feedback essai 2

La sortie doit partir de l'`École`, arriver à la `Piscine` et afficher aussi les transports empruntés.

# Feedback

Le programme 3 est correct : il cherche le trajet dans le bon sens puis affiche le départ, la correspondance **Bus 12 puis métro A** et la destination. Le programme 1 inverse le trajet et le programme 2 n'affiche pas le départ ni la destination.
