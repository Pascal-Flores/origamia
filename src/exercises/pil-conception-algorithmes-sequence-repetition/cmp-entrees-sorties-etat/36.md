# Contexte

Un service prépare des itinéraires à partir d'une petite table de trajets déjà enregistrés :

- `École` → `Piscine` : `Bus 12`, puis `Métro A` ;
- `École` → `Médiathèque` : `Bus 7` ;
- `Mairie` → `Piscine` : `Tram B`.

Les informations saisies sont :

- départ : `École` ;
- destination : `Piscine`.

Ce sont les **entrées** du programme.

On veut obtenir l'affichage :

`ÉCOLE -> BUS 12 -> MÉTRO A -> PISCINE`

C'est la **sortie attendue**.

Trois programmes ont été proposés.

### Programme 1

```
event: DÉBUT
move: LIRE le départ et la destination
move: RECHERCHER dans la table le trajet de la destination vers le départ
say: AFFICHER le trajet trouvé
end: FIN
```

### Programme 2

```
event: DÉBUT
move: LIRE le départ et la destination
move: RECHERCHER dans la table le trajet du départ vers la destination
say: AFFICHER le départ, les transports dans l'ordre inverse, puis la destination
end: FIN
```

### Programme 3

```
event: DÉBUT
move: LIRE le départ et la destination
move: RECHERCHER dans la table le trajet du départ vers la destination
say: AFFICHER le départ, les transports dans l'ordre indiqué, puis la destination
end: FIN
```

# Consigne

Quel programme transforme correctement les deux entrées en la sortie attendue ?

# Réponses

1. Programme 1
2. Programme 2
3. Programme 3

# Solution

3

# Feedback essai 1

Repère d'abord la ligne de la table qui correspond exactement au départ `École` et à la destination `Piscine`, puis vérifie l'ordre dans lequel le programme affiche le trajet.

# Feedback essai 2

La bonne ligne indique `Bus 12` puis `Métro A`. Le programme doit chercher dans le sens École → Piscine et conserver cet ordre dans l'affichage.

# Feedback

Le programme 3 est correct : il sélectionne la ligne `École` → `Piscine` puis affiche `Bus 12` avant `Métro A`, comme dans la table. Le programme 1 cherche le trajet dans le sens inverse et le programme 2 inverse l'ordre des deux transports.
