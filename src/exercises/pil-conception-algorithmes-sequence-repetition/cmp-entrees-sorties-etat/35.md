# Énoncé

À la bibliothèque, une borne aide à retrouver un livre. Elle reçoit un mot-clé, recherche les livres correspondants, puis affiche le rayon du livre retenu.

Lis le programme puis classe chaque étiquette dans `Entrée`, `État intermédiaire` ou `Sortie`.

```
event: DÉBUT
move: LIRE le mot-clé ("volcans")
move: CHERCHER les livres associés au mot-clé
move: CONSERVER le livre ("Volcans du monde")
move: TROUVER son emplacement ("Sciences - rayon 4")
say: AFFICHER "VOLCANS DU MONDE : RAYON 4"
end: FIN
```

# Catégories

1. Entrée
2. État intermédiaire
3. Sortie

# Étiquettes

1. Le mot-clé `volcans` est saisi sur la borne.
2. Le programme reçoit le sujet du livre recherché.
3. La borne conserve le résultat `Volcans du monde`.
4. La borne associe ce livre à l'emplacement `Sciences - rayon 4`.
5. L'écran affiche `VOLCANS DU MONDE : RAYON 4`.
6. L'utilisateur obtient l'indication du rayon où chercher le livre.

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback

Le mot-clé fourni est l'entrée. Le livre retenu et son emplacement sont des informations conservées pendant la recherche. L'indication affichée à l'utilisateur est la sortie du programme.
