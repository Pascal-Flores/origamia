# Contexte

À la bibliothèque, une borne permet de retrouver l'emplacement d'un livre à partir de son titre exact.

Dans le catalogue, on trouve notamment :

- `Volcans du monde` → `Sciences - rayon 4` ;
- `Le Petit Prince` → `Romans - rayon 2` ;
- `Atlas des océans` → `Géographie - rayon 6`.

Un utilisateur saisit :

`Volcans du monde`

Ce titre est l'**entrée** du programme.

On veut que la borne affiche :

`SCIENCES - RAYON 4`

C'est la **sortie attendue**.

Trois programmes ont été proposés.

### Programme 1

```
event: DÉBUT
move: LIRE le titre saisi
move: RECHERCHER ce titre dans le catalogue
say: AFFICHER le titre trouvé
end: FIN
```

### Programme 2

```
event: DÉBUT
move: LIRE le titre saisi
move: RECHERCHER ce titre dans le catalogue
say: AFFICHER l'emplacement du livre trouvé
end: FIN
```

### Programme 3

```
event: DÉBUT
move: LIRE le titre saisi
move: RECHERCHER ce titre dans le catalogue
say: AFFICHER l'emplacement du livre placé juste après dans le catalogue
end: FIN
```

# Consigne

Quel programme transforme correctement le titre saisi en la sortie attendue ?

# Réponses

1. Programme 1
2. Programme 2
3. Programme 3

# Solution

2

# Feedback essai 1

Pars du titre donné en entrée et regarde précisément quelle information chaque programme affiche après la recherche.

# Feedback essai 2

Le catalogue indique que `Volcans du monde` se trouve en `Sciences - rayon 4`. La sortie attendue est cet emplacement, pas le titre du livre ni l'emplacement d'un autre ouvrage.

# Feedback

Le programme 2 est correct : il recherche exactement `Volcans du monde` puis affiche l'emplacement associé dans le catalogue, `SCIENCES - RAYON 4`. Le programme 1 réaffiche seulement le titre et le programme 3 utilise l'emplacement d'un autre livre.
