# Contexte

Au départ, les lettres `XF` sont écrites sur une feuille. Cette suite est l’entrée du programme.

Quand le programme écrit une lettre, il la place après toutes les autres lettres.

# Consigne

Observe le programme ci-dessous, puis indique la sortie obtenue à la fin.

```
event: DÉBUT
move: ÉCRIRE la lettre "R"
move: ÉCRIRE la lettre "Q"
end: FIN
```

# Réponses

1. XFQR
2. XFRQ
3. RXFQ

# Solution

2

# Feedback essai 1

Garde les lettres d'entrée dans leur ordre, puis ajoute les nouvelles lettres une par une à droite.

# Feedback essai 2

Commence par XF. Ajoute ensuite R, puis Q, dans l'ordre du programme.

# Feedback

Pour trouver la bonne sortie, il faut partir de la suite d’entrée `XF`. Le programme écrit d’abord `R`, puis `Q` après toutes les autres lettres : la suite obtenue est donc `XFRQ`.
