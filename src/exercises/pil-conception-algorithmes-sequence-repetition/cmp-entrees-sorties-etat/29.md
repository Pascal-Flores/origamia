# Énoncé

Un programme écrit des lettres dans l’ordre où les instructions sont lues.

Observe le programme ci-dessous, puis indique la sortie obtenue à la fin.

```
event: DÉBUT
say: ÉCRIRE "C"
say: ÉCRIRE "O"
say: ÉCRIRE "D"
say: ÉCRIRE "E"
end: FIN
```

# Réponses

1. COED
2. CODE
3. DOCE

# Solution

2

# Feedback

Pour trouver la bonne sortie, il faut lire les instructions dans l’ordre : le programme écrit d’abord `C`, puis `O`, puis `D`, puis `E`, donc la sortie obtenue est `CODE`.
