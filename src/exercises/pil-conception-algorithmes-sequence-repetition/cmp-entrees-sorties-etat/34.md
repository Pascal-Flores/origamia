# Contexte

Lors d'un défi sportif, trois essais ont été chronométrés :

- essai 1 : `42 s` ;
- essai 2 : `39 s` ;
- essai 3 : `41 s`.

Ces trois temps sont les **entrées** du programme. On veut que le programme affiche à la fin :

`MEILLEUR TEMPS : 39 s`

Cette phrase est la **sortie attendue**.

Trois programmes ont été proposés.

### Programme 1

```
event: DÉBUT
move: LIRE les trois temps
move: CHOISIR le plus petit temps
say: AFFICHER "MEILLEUR TEMPS : " suivi du temps choisi
end: FIN
```

### Programme 2

```
event: DÉBUT
move: LIRE les trois temps
move: CHOISIR le plus grand temps
say: AFFICHER "MEILLEUR TEMPS : " suivi du temps choisi
end: FIN
```

### Programme 3

```
event: DÉBUT
move: LIRE les trois temps
move: CHOISIR le temps du dernier essai
say: AFFICHER "MEILLEUR TEMPS : " suivi du temps choisi
end: FIN
```

# Consigne

Quel programme transforme correctement les trois temps d'entrée en la sortie attendue ?

# Réponses

1. Programme 1
2. Programme 2
3. Programme 3

# Solution

1

# Feedback essai 1

Pars des entrées `42 s`, `39 s` et `41 s`, puis vérifie ce que chaque programme décide d'afficher.

# Feedback essai 2

La sortie attendue contient `39 s`. Parmi les trois temps fournis, `39 s` est le plus petit.

# Feedback

Le programme 1 est correct : il reçoit les trois temps, choisit le plus petit (`39 s`) puis l'affiche comme meilleur temps. Le programme 2 choisirait `42 s` et le programme 3 choisirait `41 s` ; ils ne produisent donc pas la sortie attendue.
