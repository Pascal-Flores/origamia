# Contexte

Lors d'un défi sportif, un programme reçoit les temps de trois essais et affiche le meilleur temps, c'est-à-dire le plus petit.

# Consigne

Lis le programme puis classe chaque étiquette dans `Entrée`, `État intermédiaire` ou `Sortie`.

```
event: DÉBUT
move: LIRE le temps de l'essai 1 (42 s)
move: LIRE le temps de l'essai 2 (39 s)
move: CONSERVER le plus petit temps (39 s)
move: LIRE le temps de l'essai 3 (41 s)
move: CONSERVER le plus petit temps (39 s)
say: AFFICHER "MEILLEUR TEMPS : 39 s"
end: FIN
```

# Catégories

1. Entrée
2. État intermédiaire
3. Sortie

# Étiquettes

1. Les temps `42 s`, `39 s` et `41 s` sont fournis au programme.
2. Le programme reçoit trois mesures issues des essais du sportif.
3. Après les deux premiers essais, la meilleure valeur conservée est `39 s`.
4. Après le troisième essai, la valeur conservée reste `39 s`.
5. L'écran affiche `MEILLEUR TEMPS : 39 s`.
6. Le sportif peut lire son meilleur temps final : `39 s`.

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback

Les trois temps sont les entrées du programme. Pendant l'exécution, le meilleur temps conservé constitue l'état intermédiaire. L'affichage final de `39 s` est la sortie communiquée au sportif.
