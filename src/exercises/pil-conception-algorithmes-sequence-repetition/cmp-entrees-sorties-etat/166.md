# Contexte

Tu prépares une carte d'anniversaire numérique. Pour éviter de réécrire le même message à chaque fois, un petit programme le personnalise automatiquement.

Le programme reçoit le **prénom du destinataire** en entrée et l'insère dans la phrase :

`Joyeux anniversaire, [prénom] !`

La carte obtenue affiche :

`Joyeux anniversaire, Inès !`

# Consigne

Quel prénom a été donné au programme en entrée ?

Écris uniquement le prénom.

# Solution

Inès

# Feedback essai 1

Une partie du message est toujours la même. Cherche quelle partie change selon la personne à qui la carte est destinée.

# Feedback essai 2

Le programme ajoute les mots `Joyeux anniversaire,` et le point d'exclamation autour du prénom reçu en entrée. Repère le texte placé entre les deux.

# Feedback

Le message affiché est `Joyeux anniversaire, Inès !`. Les mots `Joyeux anniversaire,` et le point d'exclamation sont ajoutés automatiquement par le programme. Le prénom inséré au milieu vient de l'entrée : l'entrée était donc `Inès`.
