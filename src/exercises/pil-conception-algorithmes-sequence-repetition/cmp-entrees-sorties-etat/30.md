# Contexte

Au départ, les lettres `NQ` sont écrites sur une feuille. Cette suite est l’entrée du programme.

Quand le programme écrit des lettres, il les place après toutes les autres lettres.

# Consigne

Observe le programme ci-dessous, puis indique la sortie obtenue à la fin.

```
event: DÉBUT
move: ÉCRIRE les lettres "ZA"
move: ÉCRIRE la lettre "L"
end: FIN
```

# Réponses

1. NQAZL
2. NQZAL
3. NQLAZ

# Solution

2

# Feedback

Pour trouver la bonne sortie, il faut partir de la suite d’entrée `NQ`. Le programme écrit d’abord `ZA`, puis `L` après toutes les autres lettres : la suite obtenue est donc `NQZAL`.
