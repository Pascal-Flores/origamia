# Énoncé

Dans ce programme, certaines instructions écrivent plusieurs lettres d’un coup.

Observe le programme ci-dessous, puis indique la sortie obtenue à la fin.

```
event: DÉBUT
say: ÉCRIRE "BO"
say: ÉCRIRE "N"
say: ÉCRIRE "JOU"
say: ÉCRIRE "R"
end: FIN
```

# Réponses

1. BOJNOUR
2. BONJOUR
3. BONROUJ

# Solution

2

# Feedback

Pour trouver la bonne sortie, il faut assembler ce que chaque instruction écrit, dans le bon ordre : `BO`, puis `N`, puis `JOU`, puis `R`. On obtient donc `BONJOUR`.
