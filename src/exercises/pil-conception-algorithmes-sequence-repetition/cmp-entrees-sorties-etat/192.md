# Contexte

L'entrée du programme est le nombre de morceaux de pain demandés : `1`.

```
ENTRÉE = 1
SORTIE = ENTRÉE
```

# Consigne

Quelle valeur est envoyée en sortie ?

# Réponses

1. 0
2. 1
3. 2

# Solution

2

# Feedback essai 1

La valeur n'est pas modifiée.

# Feedback

L'entrée vaut 1 et elle est recopiée telle quelle : la sortie vaut 1.
