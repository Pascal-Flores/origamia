# Contexte

Le programme reçoit le nombre 6, ajoute 3, puis affiche le résultat.

# Consigne

Quelle valeur est la sortie du programme ?

# Réponses

1. 3
2. 6
3. 9

# Solution

3

# Feedback essai 1

Suis l'unique transformation entre l'entrée et l'affichage.

# Feedback

Le programme part de 6, ajoute 3 et affiche 9. La sortie est donc 9.
