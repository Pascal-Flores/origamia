# Contexte

Avant de rendre une copie, tu vérifies que ton prénom est bien indiqué. Pour représenter cette vérification, on utilise le programme ci-dessous avec le prénom `Nora`.

Le programme lit le prénom saisi, garde cette information pendant la vérification, puis affiche le prénom qui sera associé à la copie.

```
event: DÉBUT
move: LIRE le prénom saisi ("Nora")
move: GARDER le prénom lu ("Nora") pendant la vérification
say: AFFICHER "PRÉNOM : NORA"
end: FIN
```

# Consigne

Lis le programme puis classe chaque étiquette dans `Entrée`, `État intermédiaire` ou `Sortie`.

# Catégories

1. Entrée
2. État intermédiaire
3. Sortie

# Étiquettes

1. Le prénom `Nora` saisi au départ.
2. La donnée reçue depuis le champ « prénom ».
3. Pendant la vérification, l'information conservée est `Nora`.
4. Avant l'affichage, le programme garde encore le prénom `Nora`.
5. Le message final `PRÉNOM : NORA`.
6. Le prénom visible à l'écran après la vérification.

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback essai 1

Repère le parcours de l'information dans le programme : elle est d'abord reçue, puis gardée pendant le traitement, puis affichée à la fin.

# Feedback essai 2

La ligne `LIRE` reçoit le prénom : c'est l'entrée. La ligne `GARDER` correspond à l'information conservée pendant le traitement. La ligne `AFFICHER` produit le résultat visible.

# Feedback

Le prénom `Nora` saisi et la donnée reçue depuis le champ sont les entrées. Pendant la vérification, le programme garde temporairement cette information : c'est l'état intermédiaire. Enfin, le message `PRÉNOM : NORA` affiché à l'écran constitue la sortie du programme.
