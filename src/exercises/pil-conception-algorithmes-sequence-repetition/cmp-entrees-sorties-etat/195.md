# Contexte

Un programme vérifie le prénom avant de rendre une copie. Il reçoit le prénom saisi, le conserve pendant la vérification, puis affiche le résultat final.

# Consigne

Classe chaque étiquette dans `Entrée`, `État intermédiaire` ou `Sortie`.

# Catégories

1. Entrée
2. État intermédiaire
3. Sortie

# Étiquettes

1. Le prénom `Nora` saisi au départ.
2. La donnée reçue depuis le champ « prénom ».
3. La variable `prenom_verifie` pendant l'exécution.
4. La valeur `Nora` conservée avant l'affichage.
5. Le message final `Prénom : Nora`.
6. Le texte visible à l'écran après la vérification.

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback essai 1

Une entrée arrive au programme, un état intermédiaire est conservé pendant l'exécution et une sortie est produite à la fin.

# Feedback essai 2

Le champ saisi est reçu au départ ; la variable existe pendant le traitement ; l'affichage est final.

# Feedback

Le prénom fourni est l'entrée, la valeur conservée est l'état intermédiaire et l'affichage est la sortie.
