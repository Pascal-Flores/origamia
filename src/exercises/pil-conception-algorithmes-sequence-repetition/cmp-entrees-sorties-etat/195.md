# Contexte

Avant de rendre une copie, un programme reçoit le prénom saisi, le conserve dans une variable `nom_verifie`, puis affiche ce prénom sur l'écran de contrôle.

# Consigne

Classe les trois éléments selon leur rôle.

# Catégories

1. Entrée
2. État intermédiaire
3. Sortie

# Étiquettes

1. prénom saisi
2. variable `nom_verifie`
3. prénom affiché

# Solution

1: 1
2: 2
3: 3

# Feedback essai 1

Repère ce qui arrive au programme, ce qu'il conserve pendant l'exécution et ce qu'il produit à la fin.

# Feedback

Le prénom saisi est l'entrée, `nom_verifie` est l'état intermédiaire et le prénom affiché est la sortie.
