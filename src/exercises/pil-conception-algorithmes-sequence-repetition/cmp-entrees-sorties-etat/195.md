# Contexte

Le programme reçoit un nombre, calcule son double dans une variable `résultat`, puis affiche cette variable.

# Consigne

Classe chaque élément selon son rôle.

# Items

1. le nombre reçu au départ
2. la variable `résultat` après le calcul du double
3. la valeur affichée à l'écran

# Catégories

## Entrée
1

## État intermédiaire
2

## Sortie
3

# Feedback essai 1

Demande-toi ce qui est fourni au départ, ce qui existe pendant le calcul et ce qui est produit à la fin.

# Feedback

Le nombre reçu est l'entrée. La variable mise à jour pendant le calcul est un état intermédiaire. La valeur affichée est la sortie.
