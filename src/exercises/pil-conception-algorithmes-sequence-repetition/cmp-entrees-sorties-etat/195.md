# Contexte

Avant de rendre une copie, tu vérifies que ton prénom est bien indiqué. Pour représenter cette vérification, on utilise le programme ci-dessous avec le prénom `Nora`.

Le programme lit le prénom saisi, le conserve pendant la vérification, puis affiche le prénom qui sera associé à la copie.

```
event: DÉBUT
move: LIRE le prénom saisi ("Nora")
move: CONSERVER le prénom ("Nora") dans prenom_verifie
say: AFFICHER "PRÉNOM : NORA"
end: FIN
```

# Consigne

Lis le programme puis classe chaque étiquette dans `Entrée`, `État intermédiaire` ou `Sortie`.

# Catégories

1. Entrée
2. État intermédiaire
3. Sortie

# Étiquettes

1. Le prénom `Nora` saisi au départ.
2. La donnée reçue depuis le champ « prénom ».
3. La variable `prenom_verifie` contient `Nora` pendant l'exécution.
4. La valeur `Nora` est conservée avant l'affichage.
5. Le message final `PRÉNOM : NORA`.
6. Le prénom visible à l'écran après la vérification.

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback essai 1

Repère le parcours de l'information dans le programme : elle est d'abord reçue, puis conservée pendant l'exécution, puis affichée à la fin.

# Feedback essai 2

La ligne `LIRE` reçoit le prénom : c'est l'entrée. La ligne `CONSERVER` garde une valeur pendant le traitement. La ligne `AFFICHER` produit le résultat visible.

# Feedback

Le prénom `Nora` saisi et la donnée reçue depuis le champ sont les entrées. Pendant l'exécution, `Nora` est conservé dans `prenom_verifie` : ce sont les éléments d'état intermédiaire. Enfin, le message `PRÉNOM : NORA` affiché à l'écran constitue la sortie du programme.
