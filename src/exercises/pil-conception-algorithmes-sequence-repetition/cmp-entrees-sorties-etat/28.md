# Énoncé

Un petit programme écrit des lettres les unes après les autres.

Observe le programme ci-dessous, puis indique la sortie obtenue à la fin.

```
event: DÉBUT
say: ÉCRIRE "B"
say: ÉCRIRE "A"
say: ÉCRIRE "B"
end: FIN
```

# Réponses

1. BAB
2. BBA
3. ABB

# Solution

1

# Feedback

Pour trouver la bonne sortie, il faut lire les instructions dans l’ordre : le programme écrit d’abord `B`, puis `A`, puis `B`, donc la sortie obtenue est `BAB`.
