# Contexte

Au départ, les lettres `PZ` sont écrites sur une feuille. Cette suite est l’entrée du programme.

Quand le programme écrit une lettre, il la place après toutes les autres lettres.

# Consigne

Observe le programme ci-dessous, puis indique la sortie obtenue à la fin.

```
event: DÉBUT
move: ÉCRIRE la lettre "Q"
end: FIN
```

# Réponses

1. PZQ
2. PQZ
3. ZPQ

# Solution

1

# Feedback essai 1

Recopie d'abord l'entrée sans la modifier, puis ajoute à droite chaque lettre écrite par le programme.

# Feedback essai 2

Commence par PZ, puis ajoute Q après ces deux lettres sans les déplacer.

# Feedback

Pour trouver la bonne sortie, il faut partir de la suite d’entrée `PZ`. Le programme écrit la lettre `Q` après toutes les autres lettres : la suite obtenue est donc `PZQ`.
