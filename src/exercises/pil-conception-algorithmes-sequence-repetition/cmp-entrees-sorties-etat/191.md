# Contexte

Le programme reçoit le nombre 4, le multiplie par 2, puis affiche le résultat.

# Consigne

Quelle est la sortie affichée ?

# Réponses

1. 2
2. 4
3. 8

# Solution

3

# Feedback essai 1

La sortie est ce que le programme affiche à la fin.

# Feedback

L'entrée est 4. Après multiplication par 2, le résultat affiché, donc la sortie, est 8.
