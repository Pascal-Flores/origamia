# Contexte

À la cantine, le programme reçoit comme entrée le choix `salade`.

```
ENTRÉE = salade
SORTIE = ENTRÉE
```

# Consigne

Quelle sortie est produite ?

# Réponses

1. salade
2. soupe
3. aucune sortie

# Solution

1

# Feedback essai 1

Le programme recopie directement l'entrée en sortie.

# Feedback

L'entrée vaut « salade » et aucune transformation n'est faite : la sortie vaut donc « salade ».
