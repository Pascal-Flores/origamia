# Contexte

Pour compléter le dessin simplifié d'un sous-marin, un programme Turtle trace **plusieurs hublots ronds alignés**, sans tracer de trait entre eux.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

3

# Feedback essai 1

Le stylo de Turtle ne dessine pas tout le temps. Quels blocs tracent un hublot et quels blocs la déplacent ?

# Feedback essai 2

Une fois qu’on a repéré le premier hublot, à quels endroits retrouve-t-on le même groupe de blocs ?

# Feedback

Après le premier hublot, on retrouve trois fois le même groupe pour les trois suivants. On compte les reprises du groupe entier.
