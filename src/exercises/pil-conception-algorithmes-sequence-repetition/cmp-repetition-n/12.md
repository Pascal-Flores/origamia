# Contexte

Pour préparer un itinéraire simplifié, un programme Turtle trace un chemin en escalier. Il est écrit sans utiliser de boucle.

Un même petit morceau d'instructions revient plusieurs fois dans le programme.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

5

# Feedback essai 1

Repère un groupe complet qui fait avancer, monter d'un petit segment puis remet Turtle dans sa direction de départ. Compte combien de fois ce groupe réapparaît.

# Feedback

Le même morceau de quatre instructions apparaît 5 fois dans le programme.
