# Contexte

Pour préparer une étiquette de rangement, un programme Turtle trace un **peigne simplifié avec cinq dents**.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de cinq instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

5

# Feedback essai 1

Repère le morceau qui avance sur le dos du peigne, descend pour tracer une dent, revient au dos puis se remet dans la direction de départ.

# Feedback

Le morceau `avancer 50` → `tourner à droite de 90°` → `avancer 50` → `reculer 50` → `tourner à gauche de 90°` apparaît **5 fois**. Chaque répétition ajoute une dent au peigne.
