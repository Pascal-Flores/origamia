# Contexte

Pour préparer une étiquette de rangement, un programme Turtle trace un **peigne simplifié avec cinq dents**.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

5

# Feedback essai 1

Et si on suivait une dent du peigne depuis son dos jusqu’au moment où Turtle retrouve sa direction ?

# Feedback essai 2

Quand Turtle revient sur le dos du peigne et tourne à gauche, un groupe se termine. Combien de groupes voit-on ?

# Feedback

Le groupe qui avance, descend pour tracer une dent puis revient se répète cinq fois. Une dent par groupe !
