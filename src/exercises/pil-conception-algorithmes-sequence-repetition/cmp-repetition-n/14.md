# Contexte

Le programme ci-dessous indique comment mettre 3 feuilles dans le casier “à rendre”. On remarque que dans le programme, certaines instructions sont répétées.

# Consigne

Parmi les 4 programmes avec boucle, choisis celui qui est équivalent (mêmes actions, même ordre).

```
event: DÉBUT
move: PRENDRE une feuille
move: METTRE la feuille dans le casier “à rendre”
move: PRENDRE une feuille
move: METTRE la feuille dans le casier “à rendre”
move: PRENDRE une feuille
move: METTRE la feuille dans le casier “à rendre”
end: FIN
```

# Réponses

1. ```
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: PRENDRE une feuille
  move: METTRE la feuille dans le casier “à rendre”
end: FIN
```
2. ```
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: PRENDRE une feuille
  move: METTRE la feuille dans le casier “à rendre”
end: FIN
```
3. ```
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: METTRE la feuille dans le casier “à rendre”
  move: PRENDRE une feuille
end: FIN
```
4. ```
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: PRENDRE une feuille
  move: METTRE la feuille dans le casier “brouillon”
end: FIN
```

# Solution

1

# Feedback essai 1

Repère les deux actions effectuées pour chaque feuille, puis vérifie le nombre de feuilles.

# Feedback essai 2

La boucle doit contenir « prendre une feuille » puis « la mettre dans le casier À rendre ». Rien d'autre ne doit être répété.

# Feedback

Le bon programme est le 1, car la boucle répète exactement 3 fois le bon groupe d’actions : prendre une feuille puis la mettre dans le casier “à rendre”. Les autres programmes ne gardent pas le bon nombre de répétitions, le bon ordre, ou le bon casier.
