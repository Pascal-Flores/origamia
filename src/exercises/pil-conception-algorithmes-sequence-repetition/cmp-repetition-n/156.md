# Contexte

Huit cahiers doivent être rangés un par un dans un casier. Le casier est ouvert une seule fois au début et refermé une seule fois à la fin.

# Consigne

Remets les étiquettes dans l'ordre pour créer le programme.

# Réponses

1. `event: DÉBUT`
2. `move: OUVRIR le casier`
3. `move: OUVRIR (8) casiers`
4. `controla: RÉPÉTER (8) FOIS`
5. `controla: RÉPÉTER (7) FOIS`
6. `move: RANGER un cahier dans le casier`
7. `move: FERMER le casier`
8. `controla: FIN RÉPÉTER`
9. `end: FIN`

# Solution

1, 2, 4, 6, 8, 7, 9

# Feedback essai 1

Seul le rangement d'un cahier doit être effectué huit fois.

# Feedback essai 2

L'ouverture vient avant la boucle et la fermeture après la boucle.

# Feedback

Le casier est ouvert une fois, le rangement d'un cahier est répété 8 fois, puis le casier est fermé une fois.
