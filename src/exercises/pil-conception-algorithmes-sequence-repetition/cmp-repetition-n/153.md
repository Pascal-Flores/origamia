# Contexte

Pour trois groupes, le programme distribue un paquet de feutres à chaque groupe, puis récupère les paquets à la fin de la séance.

```
event: DÉBUT
move: PRENDRE un paquet de feutres
move: DONNER le paquet à un groupe
move: PRENDRE un paquet de feutres
move: DONNER le paquet à un groupe
move: PRENDRE un paquet de feutres
move: DONNER le paquet à un groupe
wait : ATTENDRE la fin de la séance
move: RÉCUPÉRER les paquets de feutres
end: FIN
```


# Consigne

Parmi les 4 programmes, choisis celui qui donne exactement le même résultat.

# Réponses

1.
```
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: PRENDRE un paquet de feutres
  move: DONNER le paquet à un groupe
wait: ATTENDRE la fin de la séance
move: RÉCUPÉRER les paquets de feutres
end: FIN
```
2.
```
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: PRENDRE un paquet de feutres
  move: DONNER le paquet à un groupe
wait: ATTENDRE la fin de la séance
move: RÉCUPÉRER les paquets de feutres
end: FIN
```
3.
```
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: DONNER le paquet à un groupe
  move: PRENDRE un paquet de feutres
wait: ATTENDRE la fin de la séance
move: RÉCUPÉRER les paquets de feutres
end: FIN
```
4.
```
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: PRENDRE un paquet de feutres
move: DONNER le paquet à un groupe
wait: ATTENDRE la fin de la séance
move: RÉCUPÉRER les paquets de feutres
end: FIN
```

# Solution

1

# Feedback essai 1

Avant `ATTENDRE`, repère la plus petite suite d'actions qui revient exactement de la même façon. C'est cette suite entière que la boucle doit remplacer.

# Feedback essai 2

Vérifie trois choses dans la boucle : elle contient bien `PRENDRE` puis `DONNER`, ces deux actions restent dans cet ordre, et la boucle se répète autant de fois qu'il y a de groupes.

# Feedback

La réponse 1 est correcte : pour chacun des trois groupes, le programme doit d'abord `PRENDRE` un paquet puis le `DONNER`. Ce couple d'actions est donc placé dans une boucle répétée 3 fois. `ATTENDRE` et `RÉCUPÉRER` restent après la boucle car ces actions ne font pas partie du motif répété.
