# Contexte

Un robot doit répéter trois fois le même motif : avancer de deux cases puis tourner à gauche et avancer d'une case puis tourner à droite. Ensuite seulement, il s'arrête.

# Consigne

Remets les blocs dans l'ordre en plaçant correctement la boucle et l'arrêt.

# Réponses

1. `event: DÉBUT`
2. `controla: RÉPÉTER (3) FOIS`
3. `move: AVANCER de (2) cases`
4. `move: TOURNER à gauche`
5. `move: AVANCER de (1) case`
6. `move: TOURNER à droite`
7. `controla: FIN RÉPÉTER`
8. `move: S'ARRÊTER`
9. `end: FIN`

# Solution

1, 2, 3, 4, 5, 6, 7, 8, 9

# Feedback essai 1

Tout le motif de déplacement doit être dans la boucle.

# Feedback essai 2

L'arrêt doit se produire une seule fois, après les trois répétitions.

# Feedback

Les quatre commandes de déplacement forment le motif répété trois fois. L'arrêt reste hors de la boucle pour n'être exécuté qu'à la fin.
