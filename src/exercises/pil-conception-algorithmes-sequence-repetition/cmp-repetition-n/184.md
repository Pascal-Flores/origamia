# Contexte

Un casier contient trois piles à ranger. Pour chaque pile, le programme prend la pile puis la place dans la zone indiquée. Après les trois piles, il ferme le casier une seule fois.

# Consigne

Remets les blocs dans l'ordre.

# Réponses

1. `event: DÉBUT`
2. `repeat: RÉPÉTER (3) FOIS`
3. `move: PRENDRE la pile suivante`
4. `move: PLACER la pile dans la zone indiquée`
5. `controla: FIN RÉPÉTER`
6. `move: FERMER le casier`
7. `end: FIN`

# Solution

1, 2, 3, 4, 5, 6, 7

# Feedback essai 1

Le rangement d'une pile constitue le motif répété.

# Feedback essai 2

Fermer le casier ne doit pas être répété trois fois.

# Feedback

Les deux actions de rangement sont dans la boucle de trois répétitions ; la fermeture est placée après la boucle.
