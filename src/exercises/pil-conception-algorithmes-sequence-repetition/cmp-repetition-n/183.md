# Contexte

Trois déchets doivent être traités un par un. Pour chacun, le programme doit lire son étiquette puis le déposer dans le bac indiqué. Une fois les trois déchets triés, il affiche « TRI TERMINÉ » une seule fois.

# Consigne

Remets les blocs dans l'ordre en plaçant correctement la boucle et l'action finale.

# Réponses

1. `event: DÉBUT`
2. `repeat: RÉPÉTER (3) FOIS`
3. `move: LIRE l'étiquette du déchet`
4. `move: DÉPOSER le déchet dans le bac indiqué`
5. `controla: FIN RÉPÉTER`
6. `say: AFFICHER "TRI TERMINÉ"`
7. `end: FIN`

# Solution

1, 2, 3, 4, 5, 6, 7

# Feedback essai 1

Les deux actions concernant un déchet doivent être dans la boucle.

# Feedback essai 2

Le message final ne doit apparaître qu'après les trois répétitions.

# Feedback

La lecture et le dépôt sont répétés trois fois. Le message de fin reste hors de la boucle pour n'être affiché qu'une seule fois.
