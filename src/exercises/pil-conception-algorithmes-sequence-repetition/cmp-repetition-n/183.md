# Contexte

Un crayon numérique doit tracer un carré, puis écrire une étoile une seule fois après le carré.

# Consigne

Remets les blocs dans l'ordre. L'étoile ne doit pas être répétée.

# Réponses

1. `event: DÉBUT`
2. `controla: RÉPÉTER (4) FOIS`
3. `move: AVANCER de (50) pixels`
4. `move: TOURNER à droite de (90) degrés`
5. `controla: FIN RÉPÉTER`
6. `move: ÉCRIRE une étoile`
7. `end: FIN`

# Solution

1, 2, 3, 4, 5, 6, 7

# Feedback essai 1

Le côté et le quart de tour se répètent quatre fois. L'étoile vient seulement après.

# Feedback essai 2

Place la fin de boucle avant l'instruction qui ne doit être exécutée qu'une fois.

# Feedback

La boucle contient uniquement le tracé d'un côté et le quart de tour. Après ses quatre répétitions, l'étoile est écrite une seule fois.
