# Contexte

On veut créer un programme qui distribue une feuille à chaque élève d’une classe de 20 élèves.

# Consigne

Remets les étiquettes dans l’ordre pour créer un programme qui distribue une feuille à chaque élève d’une classe de 20 élèves.
# Réponses

1. `event: DÉBUT`
2. `controla: RÉPÉTER (20) FOIS`
3. `controla: RÉPÉTER (15) FOIS`
4. `move: PRENDRE (20) feuilles dans l'armoire`
5. `move: PRENDRE (15) feuilles dans l'armoire`
6. `move: DONNER (1) feuille à un élève`
7. `move: DONNER (2) feuille à un élève`
8. `end: FIN`
9. `controla: FIN RÉPÉTER`

# Solution

1, 4, 2, 6, 9, 8

# Feedback essai 1

Cherche l'action faite une fois pour chaque élève. C'est elle qui doit se trouver dans la boucle.

# Feedback essai 2

Les feuilles sont prises avant la boucle. Seule l'action de donner une feuille est répétée 20 fois.

# Feedback

Le bon programme commence par prendre 20 feuilles, puis il répète 20 fois l’action de donner 1 feuille à un élève. La boucle doit contenir uniquement l’action répétée, avec le bon nombre de répétitions, avant de se terminer par `FIN RÉPÉTER` puis `FIN`.
