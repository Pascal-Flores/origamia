# Contexte

Pour montrer un chemin à découper sur une affiche, un programme Turtle trace une **ligne pointillée** composée de quatre traits séparés par des espaces identiques.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

4

# Feedback essai 1

Tiens, Turtle avance même quand elle ne trace rien. À quel moment commence et finit un pointillé avec son espace ?

# Feedback essai 2

Quand le stylo touche de nouveau la feuille, Turtle peut repartir. Où est-ce que ça recommence dans le programme ?

# Feedback

Tac, un trait, un espace ! Ce groupe revient quatre fois. On a bien suivi le stylo jusqu’au bout.
