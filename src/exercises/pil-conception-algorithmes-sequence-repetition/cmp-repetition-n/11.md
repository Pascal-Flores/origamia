# Contexte

Pour montrer un chemin à découper sur une affiche, un programme Turtle trace une **ligne pointillée** composée de quatre traits séparés par des espaces identiques.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

4

# Feedback essai 1

Un trait et un espace, c’est un pointillé. Où voit-on le début et la fin de ce groupe dans le programme ?

# Feedback essai 2

Quand le stylo redescend, Turtle est prête à recommencer. Combien de fois retrouve-t-on ce même groupe ?

# Feedback

Le groupe qui trace un trait puis laisse un espace apparaît quatre fois. C’est ce qui donne nos pointillés.
