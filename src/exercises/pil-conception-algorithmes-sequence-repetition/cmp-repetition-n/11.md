# Contexte

Le programme ci-dessous trace un carré, mais il est écrit sans boucle. On remarque qu’un même “petit morceau” de programme se répète.

# Consigne

Combien de fois ce morceau est-il répété ?
# Solution

4

# Feedback

Le bon nombre est 4, car le même morceau de programme sert à tracer un côté du carré puis à tourner : comme un carré a 4 côtés, ce morceau doit être répété 4 fois.
