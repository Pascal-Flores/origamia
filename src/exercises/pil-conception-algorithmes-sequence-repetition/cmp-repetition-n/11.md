# Contexte

Sur un schéma de bassin, un programme Turtle trace une petite frise ondulée. Il est écrit sans utiliser de boucle.

Un même petit morceau d'instructions revient plusieurs fois dans le programme.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

4

# Feedback essai 1

Repère le groupe `tracer un demi-cercle` puis `tourner à droite`. Compte ses apparitions complètes.

# Feedback

Le même morceau de deux instructions apparaît 4 fois dans le programme.
