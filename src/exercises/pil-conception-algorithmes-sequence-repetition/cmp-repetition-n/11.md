# Contexte

Pour montrer un chemin à découper sur une affiche, un programme Turtle trace une **ligne pointillée** composée de quatre traits séparés par des espaces identiques.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

4

# Feedback essai 1

Repère le morceau qui trace un trait puis laisse un espace : `avancer`, `lever le stylo`, `avancer`, `baisser le stylo`. Cherche chaque fois où ces quatre actions reviennent dans le même ordre.

# Feedback

Le morceau `avancer 10` → `lever le stylo` → `avancer 10` → `baisser le stylo` apparaît **4 fois**. Chaque répétition ajoute un trait et l'espace qui le suit.
