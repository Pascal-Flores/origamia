# Contexte

Quatre déchets sont à ramasser avant de quitter le parc.

```
event: DÉBUT
move: PRENDRE un déchet
move: METTRE le déchet dans le sac
move: PRENDRE un déchet
move: METTRE le déchet dans le sac
move: PRENDRE un déchet
move: METTRE le déchet dans le sac
move: PRENDRE un déchet
move: METTRE le déchet dans le sac
move: FERMER le sac
end: FIN
```

# Consigne

Parmi les 4 programmes, choisis celui qui donne exactement le même résultat.

event: DÉBUT
repeat: RÉPÉTER (4) FOIS
