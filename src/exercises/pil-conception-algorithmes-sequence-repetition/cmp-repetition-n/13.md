# Contexte

Le programme ci-dessous indique comment prendre 2 crayons et les tailler à l’aide d’un taille-crayon, puis nettoyer les pelures. On remarque que dans le programme, certaines instructions sont répétées.

# Consigne

Parmi les 4 programmes proposés, choisis celui qui donne exactement le même résultat.

```
event: DÉBUT
move: PRENDRE un crayon
move: TAILLER le crayon
move: PRENDRE un crayon
move: TAILLER le crayon
move: JETER les pelures
end: FIN
```

# Réponses

1. ```
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: PRENDRE un crayon
  move: TAILLER le crayon
move: JETER les pelures
end: FIN
```
2. ```
event: DÉBUT
repeat: RÉPÉTER (1) FOIS
  move: PRENDRE un crayon
  move: TAILLER le crayon
move: JETER les pelures
end: FIN
```
3. ```
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: PRENDRE un crayon
move: TAILLER le crayon
move: JETER les pelures
end: FIN
```
4. ```
event: DÉBUT
move: PRENDRE un crayon
repeat: RÉPÉTER (2) FOIS
  move: JETER les pelures
move: TAILLER le crayon
end: FIN
```

1

# Feedback essai 1

Cherche d'abord le petit groupe d'actions qui se répète dans le programme sans boucle.

# Feedback essai 2

La boucle doit contenir « prendre un crayon » puis « tailler le crayon ». Le nettoyage des pelures reste après la boucle.

# Feedback

Le bon programme est le 1, car la boucle répète exactement 2 fois le bon groupe d’actions : prendre un crayon puis le tailler, avant de jeter les pelures à la fin. Dans les autres programmes, le nombre de répétitions ou l’ordre des actions n’est pas correct.
