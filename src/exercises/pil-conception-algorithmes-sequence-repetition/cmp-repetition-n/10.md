# Contexte

Le programme ci-dessous trace un triangle, mais il est écrit sans boucle. On remarque qu’un même “petit morceau” de programme se répète.

# Consigne

Combien de fois ce morceau est-il répété ?

# Solution

3

# Feedback

Le bon nombre est 3, car le même morceau de programme permet de tracer un côté du triangle, puis de tourner : comme un triangle a 3 côtés, ce morceau doit être répété 3 fois.
