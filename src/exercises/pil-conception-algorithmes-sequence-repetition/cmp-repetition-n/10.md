# Contexte

Un programme Turtle dessine une rangée de petites perforations sur le bord d'un billet. Il est écrit sans utiliser de boucle.

Un même petit morceau d'instructions revient plusieurs fois dans le programme.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

3

# Feedback essai 1

Repère le groupe `dessiner un cercle` puis `avancer`. Compte combien de fois ce groupe complet apparaît.

# Feedback

Le même morceau de deux instructions apparaît 3 fois dans le programme.
