# Contexte

Pour indiquer l'accès à l'étage sur une affiche, un programme Turtle trace un **petit escalier de trois marches**.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

3

# Feedback essai 1

On dirait que les mêmes gestes reviennent. Est-ce qu’on peut suivre le dessin jusqu’à la fin d’une seule marche ?

# Feedback essai 2

Après une marche, Turtle regarde de nouveau comme au départ. On voit le même groupe de blocs revenir combien de fois ?

# Feedback

On a grimpé une marche à la fois. Le groupe avance, gauche, avance, droite revient trois fois. C’est trois marches, pas trois blocs !
