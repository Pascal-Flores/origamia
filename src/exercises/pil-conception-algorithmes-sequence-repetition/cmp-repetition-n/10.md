# Contexte

Pour indiquer l'accès à l'étage sur une affiche, un programme Turtle trace un **petit escalier de trois marches**.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

3

# Feedback essai 1

Repère le morceau qui trace une marche complète : `avancer`, `tourner à gauche`, `avancer`, `tourner à droite`. Cherche ensuite chaque fois où ces quatre actions reviennent dans le même ordre.

# Feedback

Le morceau `avancer 50` → `tourner à gauche de 90°` → `avancer 50` → `tourner à droite de 90°` apparaît **3 fois**. Chaque répétition ajoute une marche à l'escalier.
