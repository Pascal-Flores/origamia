# Contexte

Pour trois groupes, le programme distribue un paquet de feutres à chaque groupe, puis récupère les paquets à la fin.

```
event: DÉBUT
move: PRENDRE un paquet de feutres
move: DONNER le paquet à un groupe
move: PRENDRE un paquet de feutres
move: DONNER le paquet à un groupe
move: PRENDRE un paquet de feutres
move: DONNER le paquet à un groupe
move: RÉCUPÉRER les paquets à la fin
end: FIN
```

# Consigne

Parmi les 4 programmes, choisis celui qui donne exactement le même résultat.

event: DÉBUT
repeat: RÉPÉTER (3) FOIS

# Feedback essai 1

Cherche le groupe de deux actions qui apparaît trois fois dans le programme initial.

# Feedback essai 2

La récupération finale ne doit pas être répétée pour chaque groupe.

# Feedback

La boucle doit répéter 3 fois « prendre un paquet » puis « donner le paquet ». La récupération reste après la boucle.
