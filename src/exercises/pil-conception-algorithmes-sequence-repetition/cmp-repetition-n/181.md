# Contexte

Un programme contient cinq fois de suite : `AVANCER d'une case`, puis `POSER un jeton`.

# Consigne

Quel programme avec une boucle produit exactement le même résultat ?

# Réponses

1. ```
repeat: RÉPÉTER (5) FOIS
move: AVANCER d'une case
move: POSER un jeton
controla: FIN RÉPÉTER
```
2. ```
repeat: RÉPÉTER (5) FOIS
move: AVANCER d'une case
controla: FIN RÉPÉTER
move: POSER un jeton
```
3. ```
repeat: RÉPÉTER (4) FOIS
move: AVANCER d'une case
move: POSER un jeton
controla: FIN RÉPÉTER
```
