# Contexte

Pour ranger trois documents dans un porte-vues, le programme répète trois fois :

```
PRENDRE un document
GLISSER le document dans la rubrique indiquée
```

# Consigne

Choisis le programme avec boucle exactement équivalent.

# Réponses

1. `repeat: RÉPÉTER (3) FOIS` puis `move: PRENDRE un document` puis `move: GLISSER le document dans la rubrique`
2. `repeat: RÉPÉTER (2) FOIS` puis les deux mêmes actions
3. `move: PRENDRE trois documents` puis `repeat: RÉPÉTER (3) FOIS` `move: GLISSER tous les documents`
