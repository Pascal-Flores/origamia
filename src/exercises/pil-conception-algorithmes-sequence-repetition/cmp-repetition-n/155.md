# Contexte

Six déchets doivent être déposés un par un dans le bac indiqué. Le sac de collecte est pris une seule fois au début puis fermé une seule fois à la fin.

# Consigne

Remets les étiquettes dans l'ordre pour créer le programme.

# Réponses

1. `event: DÉBUT`
2. `move: PRENDRE le sac de collecte`
3. `move: PRENDRE (6) sacs de collecte`
4. `controla: RÉPÉTER (6) FOIS`
5. `controla: RÉPÉTER (5) FOIS`
6. `move: DÉPOSER un déchet dans le bac indiqué`
7. `move: FERMER le sac de collecte`
8. `controla: FIN RÉPÉTER`
9. `end: FIN`

# Solution

1, 2, 4, 6, 8, 7, 9

# Feedback essai 1

Un seul sac pour tous les déchets. Si on refaisait chaque geste dans notre tête, lesquels ne se font qu’une fois ?

# Feedback essai 2

Si je ferme le sac au milieu du tri, on a encore des déchets à déposer. Qu’est-ce qui devrait rester dans la boucle ?

# Feedback

Zut, notre tri s’arrête là. On prend le sac, on trie un déchet à chacun des six tours, puis on ferme le sac. On a bien cherché !
