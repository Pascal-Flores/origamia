# Contexte

Six déchets doivent être déposés un par un dans le bac indiqué. Le sac de collecte est pris une seule fois au début puis fermé une seule fois à la fin.

# Consigne

Remets les étiquettes dans l'ordre pour créer le programme.

# Réponses

1. `event: DÉBUT`
2. `move: PRENDRE le sac de collecte`
3. `move: PRENDRE (6) sacs de collecte`
4. `controla: RÉPÉTER (6) FOIS`
5. `controla: RÉPÉTER (5) FOIS`
6. `move: DÉPOSER un déchet dans le bac indiqué`
7. `move: FERMER le sac de collecte`
8. `controla: FIN RÉPÉTER`
9. `end: FIN`

# Solution

1, 2, 4, 6, 8, 7, 9

# Feedback essai 1

L'action répétée est celle réalisée pour chacun des six déchets.

# Feedback essai 2

Le sac est pris avant la boucle et fermé après la boucle.

# Feedback

Le bon programme prépare le sac une fois, répète 6 fois le tri d'un déchet, termine la boucle, puis ferme le sac.
