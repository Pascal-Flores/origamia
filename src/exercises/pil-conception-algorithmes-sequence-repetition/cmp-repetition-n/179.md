# Contexte

Un programme place trois marques identiques sur une feuille.

# Consigne

Combien de fois le petit morceau `POSER une marque` puis `AVANCER d'une case` est-il répété ? Écris uniquement le nombre.

```
POSER une marque
AVANCER d'une case
POSER une marque
AVANCER d'une case
POSER une marque
AVANCER d'une case
```

# Solution

3

# Feedback essai 1

Regroupe les instructions deux par deux.

# Feedback

Le même groupe de deux instructions apparaît trois fois. On pourrait donc écrire « répéter 3 fois » autour de ce groupe.
