# Contexte

Pendant une activité de géométrie, un programme Turtle dessine une rosace composée de plusieurs cercles. Il est écrit sans utiliser de boucle.

Un même petit morceau d'instructions revient plusieurs fois dans le programme.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

6

# Feedback essai 1

Repère le groupe `dessiner un cercle` puis `tourner`. Compte combien de fois ce groupe complet apparaît.

# Feedback

Le même morceau de deux instructions apparaît 6 fois dans le programme.
