# Contexte

Pendant une activité de géométrie, le programme Turtle affiché trace un pentagone sans utiliser de boucle.

Le même petit morceau « avancer puis tourner » apparaît plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

5

# Feedback essai 1

Compte le nombre de fois où la paire « avancer puis tourner » apparaît.

# Feedback

Le même morceau est répété 5 fois : une fois pour chacun des cinq côtés du pentagone.
