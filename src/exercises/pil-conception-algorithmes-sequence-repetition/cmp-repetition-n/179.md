# Contexte

Pour trois élèves, le même petit programme prépare le matériel de géométrie :

```
PRENDRE une règle
POSER la règle sur la table
PRENDRE une règle
POSER la règle sur la table
PRENDRE une règle
POSER la règle sur la table
```

# Consigne

Combien de fois le motif « PRENDRE une règle ; POSER la règle sur la table » est-il répété ?

# Réponses

1. 2 fois
2. 3 fois
3. 6 fois

# Solution

2

# Feedback essai 1

Compte les groupes complets de deux lignes identiques.

# Feedback

Le groupe de deux instructions apparaît trois fois : le nombre de répétitions est donc 3.
