# Contexte

Pour compléter le dessin simplifié d'un sous-marin, un programme Turtle trace **quatre hublots ronds alignés**, sans tracer de trait entre eux.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de cinq instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

4

# Feedback essai 1

Repère le morceau qui dessine un hublot, lève le stylo, avance jusqu'à la place du suivant puis rebaisse le stylo.

# Feedback

Le morceau `cercle de rayon 50` → `lever le stylo` → `avancer 50` → `avancer 50` → `baisser le stylo` apparaît **4 fois**. Chaque répétition trace un hublot puis place Turtle au point de départ du suivant.
