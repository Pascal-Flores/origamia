# Contexte

Pour préparer le schéma simplifié d'une petite plaque LEGO, un programme Turtle dessine ses tenons. Il est écrit sans utiliser de boucle.

Un même petit morceau d'instructions revient plusieurs fois dans le programme.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

4

# Feedback essai 1

Repère le groupe qui dessine un cercle, avance jusqu'au tenon suivant puis tourne. Compte combien de fois ce groupe complet apparaît.

# Feedback

Le même morceau de trois instructions apparaît 4 fois dans le programme.
