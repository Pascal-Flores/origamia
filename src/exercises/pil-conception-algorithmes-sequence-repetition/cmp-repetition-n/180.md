# Contexte

Pour une affiche représentant une cabane en hauteur, un programme Turtle trace une **échelle simplifiée à six barreaux**.

Le programme est écrit entièrement, sans utiliser de boucle. Le même morceau `avancer 50` puis `reculer 50` revient plusieurs fois. Entre deux occurrences, une instruction `aller à la position x, y` place Turtle à la hauteur du barreau suivant et trace le montant gauche.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

6

# Feedback essai 1

Repère chaque fois où `avancer 50` est immédiatement suivi de `reculer 50`. Ce couple trace un barreau puis ramène Turtle au montant gauche.

# Feedback

Le morceau `avancer 50` → `reculer 50` apparaît **6 fois** : une fois pour chacun des six barreaux. Les blocs `aller à la position x, y` servent à monter au niveau suivant. Les deux derniers déplacements terminent le haut puis le montant droit de l'échelle.
