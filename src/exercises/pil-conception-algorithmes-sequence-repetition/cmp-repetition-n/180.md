# Contexte

Pour une affiche représentant une cabane en hauteur, un programme Turtle trace une **échelle simplifiée avec plusieurs barreaux**.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions y revient plusieurs fois avant les dernières instructions qui terminent le montant droit.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

6

# Feedback essai 1

Repère le morceau qui trace un barreau, revient au montant de gauche, monte d'un niveau puis se remet face au prochain barreau.

# Feedback

Le morceau `avancer 50` → `reculer 50` → `tourner à gauche de 90°` → `avancer 50` → `tourner à droite de 90°` apparaît **6 fois**. Chaque répétition ajoute exactement un barreau. Ensuite Turtle lève le stylo pour rejoindre le haut du montant droit sans tracer de barreau supplémentaire, puis redescend pour terminer l'échelle.
