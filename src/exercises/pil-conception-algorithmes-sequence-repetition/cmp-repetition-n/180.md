# Contexte

Un crayon numérique colore quatre cases alignées.

# Consigne

Combien de fois le groupe `COLORIER la case` puis `AVANCER d'une case` est-il répété ? Écris uniquement le nombre.

```
COLORIER la case
AVANCER d'une case
COLORIER la case
AVANCER d'une case
COLORIER la case
AVANCER d'une case
COLORIER la case
AVANCER d'une case
```

# Solution

4

# Feedback essai 1

Cherche le même groupe de deux lignes.

# Feedback

Le groupe apparaît quatre fois : une boucle « répéter 4 fois » serait équivalente.
