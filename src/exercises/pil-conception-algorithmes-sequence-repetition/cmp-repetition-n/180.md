# Contexte

À la fin de la séance, un responsable vérifie quatre tables. Pour chaque table, il exécute toujours :

```
REGARDER la table
SIGNALER si elle est rangée
```

Ce groupe apparaît quatre fois de suite dans le programme.

# Consigne

Quel nombre doit remplacer N dans « RÉPÉTER N FOIS » ?

# Réponses

1. 2
2. 4
3. 8

# Solution

2

# Feedback essai 1

Une répétition correspond au groupe complet de deux instructions, pas au nombre total de lignes.

# Feedback

Le groupe « regarder ; signaler » est exécuté pour quatre tables : N vaut 4.
