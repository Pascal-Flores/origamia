# Contexte

Pour préparer un modèle de séance LEGO, un programme Turtle trace le contour octogonal d'une pièce. Il est écrit sans boucle.

Le même morceau « avancer puis tourner » est répété.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

8

# Feedback essai 1

Repère et compte chaque occurrence de la paire « avancer puis tourner ».

# Feedback

Le morceau apparaît 8 fois dans le programme.
