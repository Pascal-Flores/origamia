# Contexte

Pour décorer une affiche, un programme Turtle trace une **guirlande de perles rondes alignées le long d'un fil**.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de deux instructions y revient plusieurs fois.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

6

# Feedback essai 1

Repère le morceau qui dessine une perle ronde puis avance jusqu'à la position de la suivante.

# Feedback

Le morceau `cercle de rayon 20` → `avancer 50` apparaît **6 fois**. Chaque répétition dessine une perle puis déplace Turtle jusqu'au point de départ de la suivante.
