# Contexte

Pour une affiche représentant une cabane en hauteur, un programme Turtle trace une **échelle simplifiée** avec deux montants et plusieurs barreaux.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de cinq instructions y revient plusieurs fois avant les dernières instructions qui terminent l'échelle.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

4

# Feedback essai 1

Repère le morceau qui trace un barreau, revient au montant de gauche, monte d'un niveau puis se remet face au prochain barreau.

# Feedback

Le morceau `avancer 50` → `reculer 50` → `tourner à gauche de 90°` → `avancer 50` → `tourner à droite de 90°` apparaît **4 fois**. Chaque répétition ajoute un barreau et fait monter Turtle d'un niveau. Les dernières instructions dessinent le haut puis le montant droit de l'échelle.
