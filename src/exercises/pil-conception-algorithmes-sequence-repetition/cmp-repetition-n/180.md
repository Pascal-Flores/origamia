# Contexte

Pour une affiche représentant une cabane en hauteur, un programme Turtle trace une **échelle**.

Le programme est écrit entièrement, sans utiliser de boucle. Il commence par tracer les deux montants de l'échelle. Ensuite, le même morceau `avancer 80` puis `reculer 80` revient plusieurs fois pour tracer les barreaux. Entre deux barreaux, Turtle se déplace avec le stylo levé.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

6

# Feedback essai 1

Dans la partie du programme qui trace les barreaux, repère chaque fois où `avancer 80` est immédiatement suivi de `reculer 80`.

# Feedback

Le morceau `avancer 80` → `reculer 80` apparaît **6 fois** : une fois pour chacun des six barreaux. Les déplacements effectués avec le stylo levé servent seulement à placer Turtle au niveau du barreau suivant.
