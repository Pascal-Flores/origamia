# Contexte

Pour une affiche représentant une cabane en hauteur, un programme Turtle trace une **échelle simplifiée à six barreaux**.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de cinq instructions y revient plusieurs fois. Après ces répétitions, quelques instructions terminent le second montant de l'échelle.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

6

# Feedback essai 1

Repère le morceau qui trace un barreau, revient au montant de gauche, monte d'un niveau puis remet Turtle face au barreau suivant.

# Feedback

Le morceau `avancer 50` → `reculer 50` → `tourner à gauche de 90°` → `avancer 30` → `tourner à droite de 90°` apparaît **6 fois**. Chaque répétition ajoute un barreau et un morceau du montant gauche. Ensuite Turtle lève le stylo, rejoint le haut du montant droit, rebaisse le stylo et trace ce montant d'un seul trait de 180.
