# Contexte

Pendant un atelier de dessin, Turtle trace un **serpent stylisé** dont le corps forme une ligne ondulée régulière.

Le programme est écrit entièrement, sans utiliser de boucle. Un même morceau de plusieurs instructions revient plusieurs fois au milieu du programme.

# Consigne

Combien de fois ce morceau est-il répété ? Écris uniquement le nombre.

# Solution

5

# Feedback essai 1

Je vois le serpent onduler. Est-ce qu’on peut repérer les deux gestes qui font une vague entière avant de les compter ?

# Feedback essai 2

Les avances du début et de la fin sont toutes droites. Quand est-ce qu’une ondulation commence et finit dans les autres blocs ?

# Feedback

Oh, je vois le serpent ! Deux arcs font une ondulation. On en compte cinq paires, sans les avances droites du début et de la fin.
