# Contexte

Deux mots importants ont été repérés dans une consigne. Pour chacun, le programme fait :

```
REPÉRER le mot suivant
SOULIGNER ce mot
```

# Consigne

Choisis la boucle équivalente aux quatre lignes obtenues.

# Réponses

1. `repeat: RÉPÉTER (2) FOIS` avec les deux instructions dans la boucle
2. `repeat: RÉPÉTER (4) FOIS` avec les deux instructions dans la boucle
3. `repeat: RÉPÉTER (2) FOIS` avec seulement `SOULIGNER ce mot`

# Solution

1

# Feedback essai 1

Deux mots sont traités, et les deux actions doivent être répétées pour chacun.

# Feedback

Le motif complet comporte deux instructions et doit être exécuté deux fois.
