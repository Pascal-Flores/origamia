# Contexte

Dans un programme, le robot exécute six fois `AVANCER d'un pas` puis `JOUER un son`.

# Consigne

Quelle boucle remplace exactement ces douze lignes ?

# Réponses

1. ```
repeat: RÉPÉTER (6) FOIS
move: AVANCER d'un pas
move: JOUER un son
controla: FIN RÉPÉTER
```
2. ```
repeat: RÉPÉTER (12) FOIS
move: AVANCER d'un pas
move: JOUER un son
controla: FIN RÉPÉTER
```
3. ```
repeat: RÉPÉTER (6) FOIS
move: AVANCER d'un pas
controla: FIN RÉPÉTER
move: JOUER un son
```

# Feedback essai 1

Compte les groupes d'actions, pas le nombre total de lignes.

# Feedback

Il y a six groupes identiques de deux instructions. La boucle doit donc répéter six fois les deux actions ensemble.
