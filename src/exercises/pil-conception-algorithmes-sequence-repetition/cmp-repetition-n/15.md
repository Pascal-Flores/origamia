# Contexte

Le programme ci-dessous indique comment coller 2 fiches dans le cahier. On remarque que dans le programme, certaines instructions sont répétées.

# Consigne

Parmi les 4 programmes avec boucle, choisis celui qui est équivalent (mêmes actions, même ordre).

```
event: DÉBUT
move: METTRE de la colle sur une fiche
move: COLLER la fiche dans le cahier
move: METTRE de la colle sur une fiche
move: COLLER la fiche dans le cahier
end: FIN
```

# Réponses

1. ```
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: METTRE de la colle sur une fiche
  move: COLLER la fiche dans le cahier
end: FIN
```
2. ```
event: DÉBUT
repeat: RÉPÉTER (1) FOIS
  move: METTRE de la colle sur une fiche
  move: COLLER la fiche dans le cahier
end: FIN
```
3. ```
event: DÉBUT
move: METTRE de la colle sur une fiche
repeat: RÉPÉTER (2) FOIS
  move: COLLER la fiche dans le cahier
end: FIN
```
4. ```
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: METTRE de la colle sur une fiche
move: COLLER la fiche dans le cahier
end: FIN
```

1

# Feedback essai 1

Repère les deux actions effectuées pour chaque fiche, puis vérifie combien de fiches sont traitées.

# Feedback essai 2

Dans la boucle, il faut mettre de la colle sur une fiche puis la coller. Ces deux actions doivent être répétées ensemble.

# Feedback

Le bon programme est le 1, car la boucle répète exactement 2 fois le bon groupe d’actions : mettre de la colle sur une fiche puis la coller dans le cahier. Dans les autres programmes, soit on ne répète pas assez, soit on ne répète pas le bon morceau du programme.
