# Contexte

La classe prépare le décollage d'une maquette de fusée. Son haut-parleur doit jouer un bruit de décollage lorsque le programme démarre.

Le volume peut aller de 0, quand le haut-parleur est silencieux, à 255, son volume maximal. Pour le spectacle, la fiche de la maquette demande un volume de 160.

Dans le projet, le volume est encore réglé à 255. Le son utilisé est déjà le bon.

# Consigne

Dans l'interface, corrige le programme pour que le bruit de décollage soit joué au volume demandé par la fiche.

Modifie uniquement le volume du haut-parleur, puis valide le programme.

# Feedback essai 1

Le bloc qui joue le son est déjà correct. Cherche le bloc qui règle le volume et remplace sa valeur maximale par celle indiquée sur la fiche.

# Feedback

La fiche demande un volume de 160. Il fallait conserver le son de décollage et remplacer le volume 255 par 160.
