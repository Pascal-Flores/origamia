# Contexte

Un casque d'entraînement possède un voyant de test. La consigne demande d'éteindre ce voyant avant le départ.

# Consigne

Quelle commande faut-il utiliser ?

# Réponses

1. `move: ALLUMER le voyant`
2. `move: ÉTEINDRE le voyant`
3. `move: MESURER le voyant`

# Solution

2

# Feedback essai 1

Le résultat demandé est un état marche/arrêt très simple.

# Feedback

Pour obtenir un voyant éteint, il faut utiliser la commande `ÉTEINDRE`.
