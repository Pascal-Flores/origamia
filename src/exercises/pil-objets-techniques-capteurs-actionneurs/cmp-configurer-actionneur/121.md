# Contexte

La classe prépare un automate pour une exposition. Un servomoteur, c'est-à-dire un moteur qui peut placer le bras à un angle précis, est branché sur P2.

La fiche de l'automate indique :

- avec un angle de 20°, le bras reste le long du corps ;
- avec un angle de 120°, le bras se lève pour saluer.

Au démarrage, l'automate doit lever le bras pour saluer. Dans le projet, le bloc du servomoteur contient encore la valeur provisoire 0°.

# Consigne

Dans l'interface, corrige le programme pour que l'automate lève le bras et salue au démarrage.

Modifie uniquement l'angle du servomoteur, puis valide le programme.

# Feedback essai 1

Le bloc du servomoteur est déjà placé au bon endroit et utilise la bonne broche. Cherche sur la fiche l'angle qui correspond au bras levé.

# Feedback

La fiche indique que le bras se lève pour saluer à 120°. Il fallait conserver le bloc du servomoteur sur P2 et remplacer son angle de 0° par 120°.
