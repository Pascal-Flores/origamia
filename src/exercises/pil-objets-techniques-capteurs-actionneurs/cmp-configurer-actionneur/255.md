# Contexte

Un valideur de démonstration doit émettre un son de fréquence `800` pendant `2` secondes lorsqu'on prépare le titre de transport. Les deux paramètres sont fournis.

# Consigne

Quelle commande convient ?

# Réponses

1. `move: JOUER un son fréquence (800) pendant (2) secondes`
2. `move: JOUER un son fréquence (200) pendant (8) secondes`
3. `say: AFFICHER "800" pendant (2) secondes`

# Solution

1

# Feedback essai 1

Vérifie les deux paramètres, pas seulement le type d'actionneur.

# Feedback essai 2

Il faut un son, de fréquence 800, pendant 2 secondes.

# Feedback

La première commande satisfait simultanément le choix de l'actionneur et les deux paramètres.
