# Contexte

Un moteur doit tourner vers l'avant à la vitesse 70.

# Consigne

Quelle combinaison de paramètres est correcte ?

# Réponses

1. sens avant, vitesse 70
2. sens arrière, vitesse 70
3. sens avant, vitesse 30
4. sens arrière, vitesse 30

# Solution

1

# Feedback essai 1

Vérifie séparément le sens puis la vitesse.

# Feedback essai 2

Une commande n'est correcte que si ses deux paramètres correspondent à la consigne.

# Feedback
