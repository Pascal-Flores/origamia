# Contexte

Pour ouvrir une séance de jeu, la classe fabrique une roue des défis. Son animation de lancement est entraînée par un moteur pas à pas, capable d'effectuer un nombre précis de tours avant de s'arrêter.

Pour lancer la roue, la fiche de montage demande au moteur A :

- de tourner dans le sens anti-horaire ;
- d'effectuer exactement 1 rotation.

Dans le projet, le moteur tourne actuellement dans le sens horaire et fait 3 rotations. Son branchement est déjà correct.

# Consigne

Dans l'interface, corrige le programme pour que la roue tourne comme indiqué sur la fiche de montage.

Conserve le moteur A et son branchement. Modifie le sens et le nombre de rotations dans le bloc de commande, puis valide le programme.

# Feedback essai 1

Deux réglages de la commande doivent correspondre à la fiche : le sens dans lequel la roue tourne et le nombre de tours qu'elle effectue.

# Feedback essai 2

Le bloc d'initialisation et le moteur A sont déjà corrects. Dans le bloc suivant, remplace le sens horaire par le sens anti-horaire et vérifie le nombre de rotations demandé.

# Feedback

Il fallait conserver le moteur A et son branchement, choisir le sens anti-horaire et régler le déplacement à 3 rotations.
