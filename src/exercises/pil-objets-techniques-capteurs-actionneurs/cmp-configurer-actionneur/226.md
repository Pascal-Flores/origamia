# Contexte

Un scanner pédagogique possède un écran. Après lecture d'une date, la consigne demande d'afficher le message `Date lue` pendant 3 secondes.

# Consigne

Quelle commande est correcte ?

# Réponses

1. `say: AFFICHER "Date lue" pendant (3) secondes`
2. `say: AFFICHER "Date lue" pendant (1) seconde`
3. `move: FAIRE TOURNER un moteur pendant (3) secondes`

# Solution

1

# Feedback essai 1

L'effet attendu concerne l'écran et la durée est donnée.

# Feedback

La première commande utilise le bon actionneur d'affichage et le paramètre 3 secondes.
