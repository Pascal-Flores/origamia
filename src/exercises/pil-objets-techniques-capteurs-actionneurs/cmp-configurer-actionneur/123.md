# Contexte

La classe construit une machine à bulles. Un ventilateur branché sur P2 souffle sur un anneau recouvert d'eau savonneuse.

La puissance du ventilateur peut aller de 0, lorsqu'il est arrêté, à 1023, sa puissance maximale. La fiche de montage demande une puissance de 650 pour former correctement les bulles.

Dans le projet, le ventilateur est encore réglé à 1023.

# Consigne

Dans l'interface, corrige le programme pour que le ventilateur souffle à la puissance demandée par la fiche de montage.

Modifie uniquement la puissance du ventilateur, puis valide le programme.

# Feedback essai 1

Le ventilateur est déjà branché sur la bonne broche et son bloc est au bon endroit. Modifie seulement le nombre qui règle sa puissance.

# Feedback

La fiche de montage demande une puissance de 650. Il fallait conserver le ventilateur sur P2 et remplacer la puissance 1023 par 650.
