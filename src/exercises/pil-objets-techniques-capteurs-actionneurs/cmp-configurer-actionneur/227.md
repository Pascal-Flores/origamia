# Contexte

Une maquette de chambre possède un store miniature entraîné par un servomoteur continu branché sur P2.

Sur cette maquette :

- le `sens horaire` ouvre le store ;
- le `sens anti-horaire` le ferme ;
- pour l'ouverture du matin, la fiche demande une vitesse de `35`.

Le store est fermé et doit s'ouvrir. Dans le projet, le servomoteur est pourtant réglé en `sens anti-horaire` à la vitesse `100`.

# Consigne

Dans l'interface, corrige le programme pour ouvrir le store à la vitesse demandée.

Conserve le servomoteur sur P2. Modifie son sens de rotation et sa vitesse, puis valide le programme.

# Feedback essai 1

La mission impose deux réglages : le store doit aller dans le bon sens et respecter la vitesse indiquée. Vérifie les deux champs du bloc.

# Feedback essai 2

Le sens anti-horaire ferme le store sur cette maquette. Pour l'ouvrir, il faut changer le sens et remplacer la vitesse maximale par celle donnée dans la fiche.

# Feedback

Il fallait conserver le servomoteur sur P2, choisir le `sens horaire` pour ouvrir le store et régler la vitesse à `35`.
