# Contexte

Un antivol pédagogique possède une petite LED. Pour signaler que le vélo est attaché, la consigne demande simplement d'allumer la LED.

# Consigne

Quelle commande produit l'effet demandé ?

# Réponses

1. `move: ALLUMER la LED`
2. `move: ÉTEINDRE la LED`
3. `move: LIRE la LED`

# Solution

1

# Feedback essai 1

L'effet attendu est explicitement « LED allumée ».

# Feedback

La commande `ALLUMER la LED` correspond directement à l'effet demandé.
