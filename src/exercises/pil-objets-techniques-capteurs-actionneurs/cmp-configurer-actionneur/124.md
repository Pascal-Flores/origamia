# Contexte

La classe construit un téléphérique miniature. Un servomoteur continu branché sur P2 tire le câble qui déplace la cabine.

Sur cette maquette :

- lorsqu'il tourne dans le sens horaire, la cabine monte ;
- lorsqu'il tourne dans le sens anti-horaire, la cabine descend ;
- pour un retour sans secousse, la vitesse doit être réglée à 40.

La cabine se trouve en haut et doit revenir à la station basse. Dans le projet, le servomoteur tourne encore dans le sens horaire à la vitesse 100.

# Consigne

Dans l'interface, corrige le programme pour que la cabine redescende à la vitesse demandée.

Modifie le sens de rotation et la vitesse dans le bloc du servomoteur continu, puis valide le programme.

# Feedback essai 1

La mission impose deux réglages : la cabine doit aller vers la station basse et respecter la vitesse de retour. Vérifie le sens de rotation et la vitesse dans le bloc du servomoteur.

# Feedback essai 2

Sur cette maquette, le sens horaire fait monter la cabine. Pour la faire descendre, il faut choisir le sens anti-horaire et remplacer la vitesse maximale par la valeur donnée dans le contexte.

# Feedback

Il fallait conserver le servomoteur sur P2, choisir le sens anti-horaire pour faire descendre la cabine et régler sa vitesse à 40.
