# Contexte

Lors d'un festival scientifique, trois installations transforment des mesures en actions :

- **Montage 1** : un capteur fournit un indice de pollution de 0 à 1023 : plus la valeur est élevée, plus l'air est dégradé. Le ventilateur qui renouvelle l'air utilise directement cette valeur comme puissance, de 0 à 1023 ;
- **Montage 2** : un anémomètre mesure la vitesse du vent de 0 à 100 m/s. Le servomoteur continu d'une éolienne miniature utilise directement cette valeur comme vitesse, de 0 à 100 ;
- **Montage 3** : un détecteur de pluie fournit 0 lorsqu'il est sec et 1 lorsqu'il reçoit de l'eau. Le relais d'un voyant d'alerte utilise 0 pour éteindre le voyant et 1 pour l'allumer.

Les blocs capteurs, les blocs actionneurs et les effets obtenus ont été mélangés.

Dans chaque montage, la donnée fournie par le capteur doit pouvoir être placée directement dans le réglage vide de l'actionneur, sans calcul ni condition.

# Consigne

Pour chaque montage, place le bloc capteur, le bloc actionneur et la phrase qui décrit l'effet produit.

# Feedback essai 1

Relis la description de chaque montage. Distingue ensuite le bloc qui fournit une donnée du bloc qui utilise cette donnée pour produire une action.

# Feedback essai 2

Deux montages transmettent une valeur qui augmente : l'une règle une puissance et l'autre une vitesse. Le troisième transmet seulement 0 ou 1 pour éteindre ou allumer un voyant.

# Feedback

Dans le montage 1, la qualité de l'air commande la puissance du ventilateur. Dans le montage 2, la vitesse du vent commande la vitesse du servomoteur continu de l'éolienne miniature. Dans le montage 3, la détection de pluie commande le relais du voyant d'alerte. Dans chaque montage, la donnée du capteur règle directement l'actionneur, sans calcul ni condition.
