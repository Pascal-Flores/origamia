# Contexte

Pour une exposition scientifique, la classe prépare trois montages :

- **Montage 1** : un thermomètre possède un cadran gradué de 0 à 40. L'angle de son aiguille reprend directement la température mesurée ;
- **Montage 2** : un capteur mesure de 0 à 1023 la quantité d'eau contenue dans un objet placé dans une boîte de séchage. La puissance du ventilateur utilise la même échelle ;
- **Montage 3** : dans un atelier bruyant, un bracelet avertit son porteur lorsqu'une alarme retentit. Le microphone fournit la donnée « vrai » lorsqu'il détecte ce son fort, et le moteur vibrant utilise une donnée « vrai ou faux ».

Les blocs capteurs, les blocs actionneurs et les effets obtenus ont été mélangés.

Dans chaque montage, la donnée fournie par le capteur doit pouvoir être placée directement dans le réglage vide de l'actionneur, sans calcul ni condition.

# Consigne

Pour chaque montage, place le bloc capteur, le bloc actionneur et la phrase qui décrit l'effet produit.

# Feedback essai 1

Relis la description de chaque montage. Distingue ensuite le bloc qui fournit une donnée du bloc qui utilise cette donnée pour produire une action.

# Feedback essai 2

Deux montages utilisent des nombres : une valeur règle un angle et l'autre une puissance. Le troisième utilise une donnée « vrai ou faux » pour activer ou arrêter une vibration.

# Feedback

Dans le montage 1, le capteur de température commande l'angle du servomoteur qui déplace l'aiguille. Dans le montage 2, la quantité d'eau commande la puissance du ventilateur de la boîte de séchage. Dans le montage 3, la détection d'un son fort commande le moteur vibrant du bracelet. Dans chaque montage, la donnée du capteur règle directement l'actionneur, sans calcul ni condition.
