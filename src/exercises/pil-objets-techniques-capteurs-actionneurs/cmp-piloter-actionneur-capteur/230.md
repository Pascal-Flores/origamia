# Contexte

La classe teste une petite boîte de séchage. Un capteur branché sur P1 mesure la quantité d'eau présente sur une zone test, et un ventilateur branché sur P2 souffle sur l'objet à sécher.

Le capteur fournit une valeur de `0` à `1023`. La puissance du ventilateur utilise la même échelle de `0` à `1023`. La mesure peut donc être utilisée directement : plus le capteur détecte d'eau, plus le ventilateur doit souffler fort.

Dans le projet, la boucle, le ventilateur et la pause sont déjà placés. Le réglage de la puissance possède un emplacement vide, et le bloc « quantité d'eau » est fourni à côté du programme.

# Consigne

Dans l'interface, complète le programme pour que la boîte de séchage fonctionne comme décrit, puis valide-le.

# Feedback essai 1

La puissance du ventilateur doit suivre directement la quantité d'eau mesurée, sans valeur fixe ni calcul.

# Feedback essai 2

Le bloc « quantité d'eau » doit être placé dans l'emplacement vide qui règle la puissance du ventilateur.

# Feedback

Il fallait utiliser directement la quantité d'eau comme puissance du ventilateur. Quand la valeur mesurée augmente, la puissance du ventilateur augmente elle aussi.
