# Contexte

Une balise de rendez-vous possède un capteur de lumière `lumiere` et une LED dont la luminosité accepte directement la même échelle 0–100.

# Consigne

Quelle proposition réalise une liaison directe et décrit correctement ce qui se passe si `lumiere` augmente ?

# Réponses

1. `RÉGLER LED avec lumiere` ; si `lumiere` augmente, la LED augmente aussi.
2. `RÉGLER LED avec 50` ; si `lumiere` augmente, la LED augmente.
3. `RÉGLER LED avec lumiere` ; si `lumiere` augmente, la LED reste forcément fixe.

# Solution

1

# Feedback essai 1

Une liaison directe n'utilise pas une valeur fixe.

# Feedback essai 2

Si le réglage reçoit directement une valeur plus grande, le réglage devient lui aussi plus grand.

# Feedback

La première proposition transmet directement la mesure et décrit correctement la variation.
