# Contexte

Un potentiomètre et un moteur utilisent tous les deux une échelle de 0 à 100.

# Consigne

Quel programme établit une liaison directe et quelle conséquence est correcte ?

# Réponses

1. `vitesse moteur = valeur potentiomètre` ; si la valeur augmente, la vitesse augmente.
2. `vitesse moteur = 50` ; si la valeur augmente, la vitesse augmente.
3. `afficher valeur potentiomètre` ; si la valeur augmente, le moteur accélère.
