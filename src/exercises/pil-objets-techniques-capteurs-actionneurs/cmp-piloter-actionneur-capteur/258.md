# Contexte

Un potentiomètre fournit une valeur de 0 à 100. Cette valeur doit régler directement la vitesse d'un moteur utilisant la même échelle.

# Consigne

Quel réglage du moteur faut-il choisir ?

# Réponses

1. vitesse = valeur du potentiomètre
2. vitesse = 100 en permanence
3. vitesse = température

# Solution

1

# Feedback essai 1

Aucune transformation n'est demandée entre la mesure et l'action.

# Feedback

La liaison directe consiste à utiliser la valeur du potentiomètre comme valeur de vitesse du moteur.
