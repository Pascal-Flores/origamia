# Contexte

On veut que la valeur du capteur de lumière règle directement la luminosité d'une LED, sans calcul ni condition.

# Consigne

Quelle expression doit être placée dans le réglage de la LED ?

# Réponses

1. valeur du capteur de lumière
2. nombre fixe 50
3. température mesurée

# Solution

1

# Feedback essai 1

La relation doit être directe : la mesure devient le réglage.

# Feedback

Il faut placer la valeur du capteur de lumière directement dans le paramètre de luminosité de la LED.
