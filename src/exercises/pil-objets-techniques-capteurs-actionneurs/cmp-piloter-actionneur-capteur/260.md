# Contexte

Un capteur fournit directement un angle de 0 à 180 degrés. Un servomoteur accepte un angle sur la même échelle.

# Consigne

Quelle proposition réalise une liaison directe ?

# Réponses

1. angle du servo = angle mesuré ; si la mesure augmente, le servo prend un angle plus grand
2. angle du servo = 90 ; si la mesure augmente, le servo prend un angle plus grand
3. afficher l'angle mesuré ; si la mesure augmente, le servo change automatiquement

1
