# Contexte

Sur une maquette d'alerte, un potentiomètre fournit `niveau` de 0 à 100 et le volume du buzzer accepte directement une valeur de 0 à 100.

# Consigne

Quelle proposition est correcte ?

# Réponses

1. `RÉGLER volume buzzer avec niveau` ; quand `niveau` augmente, le volume augmente.
2. `RÉGLER volume buzzer avec 20` ; quand `niveau` augmente, le volume augmente automatiquement.
3. `RÉGLER niveau avec volume buzzer` ; le buzzer devient le capteur.
