# Contexte

Un musée des sciences prépare trois montages interactifs :

- **Montage 1** : un capteur mesure de 0 à 100 % l'humidité de l'air. Le moteur d'un tambour de séchage utilise directement ce pourcentage comme vitesse, de 0 à 100 ;
- **Montage 2** : un capteur mesure la concentration de CO₂ dans l'air en parties par million. Le buzzer d'un avertisseur utilise directement cette valeur comme fréquence : plus la fréquence est élevée, plus le son est aigu ;
- **Montage 3** : un capteur fixé sur l'avant-bras d'une personne mesure son inclinaison de 0 à 90°. Le servomoteur d'un petit bras robotisé utilise directement cette valeur pour reproduire le même angle.

Les blocs capteurs, les blocs actionneurs et les effets obtenus ont été mélangés.

Dans chaque montage, la donnée fournie par le capteur doit pouvoir être placée directement dans le réglage vide de l'actionneur, sans calcul ni condition.

# Consigne

Pour chaque montage, place le bloc capteur, le bloc actionneur et la phrase qui décrit l'effet produit.

# Feedback essai 1

Relis la description de chaque montage. Distingue ensuite le bloc qui fournit une donnée du bloc qui utilise cette donnée pour produire une action.

# Feedback essai 2

Les trois montages utilisent des nombres. Repère celui qui règle une vitesse, celui qui règle une fréquence et celui qui règle un angle.

# Feedback

Dans le montage 1, l'humidité commande la vitesse du moteur qui entraîne le tambour de séchage. Dans le montage 2, la concentration de CO₂ commande la fréquence de l'avertisseur. Dans le montage 3, l'inclinaison de l'avant-bras règle l'angle du servomoteur pour que le bras robotisé reproduise le mouvement. Dans chaque montage, la donnée du capteur règle directement l'actionneur, sans calcul ni condition.
