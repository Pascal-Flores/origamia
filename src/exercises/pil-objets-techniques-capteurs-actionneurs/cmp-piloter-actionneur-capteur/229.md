# Contexte

Une borne d'inscription fournit la valeur `carte_presentee` : `0` ou `1`. Une LED accepte directement la même valeur `0` ou `1` pour son état. Aucun calcul ni condition n'est utilisé.

# Consigne

Quel bloc réalise la liaison directe ?

# Réponses

1. `move: RÉGLER LED avec (carte_presentee)`
2. `move: RÉGLER LED avec (1)`
3. `move: LIRE LED dans (carte_presentee)`

# Solution

1

# Feedback essai 1

La valeur du capteur doit être placée directement dans le réglage de l'actionneur.

# Feedback

La proposition 1 transmet `carte_presentee` directement à la LED.
