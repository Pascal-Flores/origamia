# Contexte

La classe construit un petit mobile léger entraîné par un ventilateur branché sur P2. Un capteur de lumière Grove branché sur P1 mesure l'éclairage de la pièce.

Le capteur fournit une valeur de `0` à `1023`. La puissance du ventilateur utilise elle aussi une valeur de `0` à `1023`. La mesure peut donc régler directement le ventilateur : plus la lumière mesurée augmente, plus le ventilateur doit tourner vite.

Dans le projet, la boucle, le ventilateur et la pause sont déjà placés. Le réglage de la puissance possède un emplacement vide, et le bloc de mesure de la lumière est fourni à côté du programme.

# Consigne

Dans l'interface, complète le programme pour que le mobile fonctionne comme décrit, puis valide-le.

# Feedback essai 1

La puissance du ventilateur ne doit pas garder une valeur fixe : elle doit recevoir la mesure qui change avec la lumière.

# Feedback essai 2

Le bloc qui mesure la lumière doit être placé dans l'emplacement vide qui règle la puissance du ventilateur.

# Feedback

Il fallait utiliser directement la mesure de lumière comme puissance du ventilateur. Quand la valeur mesurée augmente, la puissance augmente aussi et le mobile tourne plus vite.
