# Contexte

La classe fabrique un grand cadran pour indiquer la température de la salle. Son aiguille est déplacée par un servomoteur branché sur P2.

Le cadran est gradué de 0 à 40. Il est construit pour qu'une température de 20 °C corresponde à un angle de 20°, une température de 25 °C à un angle de 25°, et ainsi de suite. La température mesurée peut donc régler directement l'angle de l'aiguille.

Dans le projet, la boucle, le servomoteur et la pause sont déjà placés. Le réglage de l'angle possède un emplacement vide, et le bloc « température » est fourni à côté du programme.

# Consigne

Dans l'interface, complète le programme pour que le cadran fonctionne comme décrit, puis valide-le.

# Feedback essai 1

L'angle de l'aiguille ne doit pas garder une valeur fixe : il doit recevoir la mesure qui change avec la température.

# Feedback essai 2

Le bloc « température » doit être placé dans l'emplacement vide qui règle l'angle du servomoteur.

# Feedback

Il fallait utiliser directement la température comme angle du servomoteur. Quand la température augmente, l'angle augmente aussi et l'aiguille avance sur le cadran.
