# Contexte

La classe construit un petit aérateur pour une maquette de pièce humide. Un capteur branché sur P1 mesure l'humidité de l'air. Un servomoteur continu branché sur P2 fait tourner l'aérateur dans le sens horaire.

Le capteur fournit un pourcentage d'humidité compris entre 0 et 100. La vitesse du servomoteur se règle elle aussi avec une valeur comprise entre 0 et 100. La maquette doit utiliser directement la mesure du capteur pour régler cette vitesse. Le sens de rotation est réglé séparément dans le bloc du servomoteur.

Trois programmes utilisant le même capteur et le même servomoteur sont proposés.

# Consigne

Sélectionne le programme qui relie directement l'humidité à la vitesse du servomoteur, puis la phrase qui décrit ce qui se passe lorsque l'humidité augmente. Deux réponses sont attendues.

# Feedback essai 1

Tu dois sélectionner un programme et une phrase. Observe les trois programmes proposés, repère où la mesure d'humidité est utilisée, puis distingue le réglage de la vitesse de celui du sens de rotation.

# Feedback essai 2

La mesure d'humidité doit être placée dans le réglage de la vitesse du servomoteur, et non dans la console ou dans la pause. Le choix « sens horaire » reste identique lorsque l'humidité varie.

# Feedback

Il fallait sélectionner la capture où l'humidité règle directement la vitesse du servomoteur et la phrase indiquant que l'aérateur tourne plus vite dans le même sens. Quand la mesure augmente, la vitesse augmente aussi, tandis que le sens horaire reste fixé. Dans les deux autres captures, l'humidité est seulement écrite dans la console ou modifie la durée de la pause.
