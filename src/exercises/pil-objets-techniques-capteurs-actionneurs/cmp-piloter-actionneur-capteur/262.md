# Contexte

Un capteur d'angle fournit une valeur de 0 à 180°. Un servomoteur accepte directement une consigne de 0 à 180°.

# Consigne

Quelle relation est une liaison directe cohérente ?

# Réponses

1. angle servo = angle capteur ; lorsque la mesure augmente de 20°, la consigne du servo augmente aussi de 20°
2. angle servo = 90° ; la valeur du capteur est seulement affichée
3. angle servo = température ; le capteur d'angle n'est pas utilisé

# Solution

1

# Feedback essai 1

La valeur lue doit devenir sans transformation le paramètre du servo.

# Feedback essai 2

Un paramètre fixe ne constitue pas une liaison capteur-actionneur.

# Feedback

La première relation transmet directement l'angle du capteur au servo ; toute variation de mesure entraîne la même variation de consigne.
