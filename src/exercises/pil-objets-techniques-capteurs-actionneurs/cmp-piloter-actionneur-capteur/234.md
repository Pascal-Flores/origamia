# Contexte

Une maquette de retour de plateau possède :

- un capteur de position de curseur, valeur 0–100 ;
- un moteur dont la vitesse se règle de 0–100 ;
- une LED qui accepte seulement `0` ou `1`.

Aucune conversion n'est autorisée.

# Consigne

Quelle liaison directe est cohérente ?

# Réponses

1. Curseur 0–100 → vitesse moteur 0–100 ; une valeur plus grande donne une vitesse plus grande.
2. Curseur 0–100 → LED 0/1 ; toutes les valeurs sont directement compatibles.
3. LED 0/1 → capteur de position ; l'actionneur fournit la mesure.
