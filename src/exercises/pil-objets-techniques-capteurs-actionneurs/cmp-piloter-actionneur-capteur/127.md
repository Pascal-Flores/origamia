# Contexte

La classe prépare une installation sonore interactive. Quand la pièce devient plus lumineuse, le son doit devenir plus fort. Quand elle s'assombrit, le son doit diminuer.

Le capteur de luminosité de la micro:bit fournit une valeur comprise entre 0 et 255. Le volume du haut-parleur se règle lui aussi avec une valeur comprise entre 0 et 255. La luminosité peut donc régler directement le volume.

Dans le projet, la boucle, le son et la pause sont déjà placés. Le bloc qui règle le volume possède un emplacement vide, et le bloc « luminosité » est fourni à côté du programme.

# Consigne

Dans l'interface, complète le programme pour que l'installation sonore fonctionne comme décrit, puis valide-le.

# Feedback essai 1

Le volume ne doit pas garder une valeur fixe : il doit recevoir la mesure qui change avec la lumière.

# Feedback essai 2

Le bloc « luminosité » doit être placé à l'intérieur du bloc qui règle le volume, dans son emplacement vide.

# Feedback

Il fallait utiliser directement la luminosité comme valeur du volume. Quand la luminosité augmente, la valeur envoyée au haut-parleur augmente aussi et le son devient plus fort.
