# Contexte

Un distributeur pédagogique utilise des valeurs de 0 à 100. Trois couples sont proposés :

- molette 0–100 → vitesse du convoyeur 0–100 ;
- bouton oui/non → angle de moteur 0–180 ;
- thermomètre en °C → texte libre à afficher.

La liaison doit être directe, sans conversion.

# Consigne

Quel couple convient, et comment évolue l'action ?

# Réponses

1. Molette → vitesse du convoyeur ; si la valeur augmente, la vitesse augmente.
2. Bouton → angle ; `oui` devient automatiquement 180 sans conversion.
3. Thermomètre → texte ; un nombre devient automatiquement une phrase.
