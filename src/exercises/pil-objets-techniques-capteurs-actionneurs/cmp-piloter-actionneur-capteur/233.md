# Contexte

Un atelier présente trois montages indépendants :

- **Montage 1** : un capteur mesure l'humidité de l'air de `0` à `100 %`. La vitesse d'un servomoteur continu utilise la même échelle de `0` à `100` ;
- **Montage 2** : un support peut s'incliner de `0°` à `90°`. Sur cette plage, la valeur mesurée par le capteur d'inclinaison est utilisée directement comme angle d'un servomoteur ;
- **Montage 3** : un détecteur de pluie fournit `0` ou `1`. Un relais commandant un voyant d'alerte utilise lui aussi `0` ou `1`.

Les blocs capteurs, les blocs actionneurs et les effets obtenus ont été mélangés. Dans chaque montage, la donnée du capteur doit pouvoir régler directement l'actionneur, sans calcul ni condition.

# Consigne

Pour chaque montage, place le bloc capteur, le bloc actionneur et la phrase qui décrit l'effet produit.

# Feedback essai 1

Relis ce que mesure chaque montage et ce que doit régler son actionneur. Cherche d'abord les couples qui utilisent la même nature de donnée.

# Feedback essai 2

Un montage relie une humidité de `0` à `100` à une vitesse de `0` à `100`. Un autre relie directement un angle mesuré à un angle de servomoteur. Le dernier utilise une donnée `0/1` pour commander un relais.

# Feedback

Dans le montage 1, l'humidité règle directement la vitesse du servomoteur continu. Dans le montage 2, l'inclinaison mesurée règle directement l'angle du servomoteur. Dans le montage 3, la détection de pluie commande directement le relais du voyant. Chaque relation transmet la donnée du capteur sans calcul ni condition.
