# Contexte

Un atelier présente trois montages indépendants :

- **Montage 1** : un capteur mesure l'humidité de l'air de `0` à `100 %`. Un servomoteur continu fait tourner une petite hélice d'aération ; sa vitesse utilise la même échelle de `0` à `100` ;
- **Montage 2** : un support peut s'incliner de `0°` à `90°`. Sur cette plage, la valeur mesurée par le capteur d'inclinaison est utilisée directement comme angle d'un servomoteur qui déplace un bras indicateur ;
- **Montage 3** : un détecteur de pluie fournit `0` ou `1`. Un relais commandant un voyant d'alerte utilise lui aussi `0` ou `1`.

Les blocs capteurs, les blocs actionneurs et les effets obtenus ont été mélangés. Dans chaque montage, la donnée du capteur doit pouvoir régler directement l'actionneur, sans calcul ni condition.

# Consigne

Pour chaque montage, place le bloc capteur, le bloc actionneur et la phrase qui décrit l'effet produit.

# Feedback essai 1

Relis la description de chaque montage. Distingue ensuite le bloc qui fournit la donnée, le bloc qui l'utilise et l'effet observable obtenu.

# Feedback essai 2

Un montage transmet une valeur de `0` à `100` à une vitesse. Un autre transmet directement un angle mesuré à un angle de commande. Le dernier utilise une donnée `0/1` pour éteindre ou allumer un voyant.

# Feedback

Dans le montage 1, l'humidité règle directement la vitesse du servomoteur continu qui entraîne l'hélice. Dans le montage 2, l'inclinaison mesurée règle directement l'angle du servomoteur qui déplace le bras indicateur. Dans le montage 3, la détection de pluie commande directement le relais du voyant. Chaque relation transmet la donnée du capteur sans calcul ni condition.
