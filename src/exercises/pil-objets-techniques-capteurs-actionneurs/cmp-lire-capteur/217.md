# Contexte

Une carte micro:bit est placée dans un casier de démonstration pour observer la quantité de lumière à l'intérieur.

Dans l'interface Vittascience, le programme doit écrire régulièrement dans la console la luminosité réellement mesurée. L'emplacement où placer la donnée est encore vide et trois blocs sont proposés à côté du programme.

# Consigne

Que faut-il placer dans l'emplacement vide pour afficher la luminosité réellement mesurée ?

# Réponses

1. Le bloc qui lit la luminosité mesurée par le capteur.
2. Le nombre 100.
3. Le texte « Lumière ».

1

# Feedback essai 1

La lumière dans le casier peut changer. Cherche la réponse qui fournit une nouvelle mesure pendant que le programme fonctionne.

# Feedback

Il faut utiliser le bloc qui lit la luminosité : sa valeur vient du capteur au moment où le programme fonctionne. Le nombre 100 afficherait toujours la même valeur et le texte « Lumière » afficherait seulement un mot.
