# Contexte

Un portillon de bus doit détecter uniquement si une carte de transport est présentée. Deux capteurs sont disponibles :

- lecteur de carte : indique `carte_presentee` ;
- capteur de lumière : indique `niveau_lumiere`.

# Consigne

Quel capteur répond directement au besoin ?

# Réponses

1. Le lecteur de carte, car il indique si la carte est présentée.
2. Le capteur de lumière, car il mesure l'éclairage.

# Solution

1

# Feedback essai 1

La donnée recherchée est « carte présentée », pas la luminosité.

# Feedback

Le lecteur de carte fournit directement l'information nécessaire.
