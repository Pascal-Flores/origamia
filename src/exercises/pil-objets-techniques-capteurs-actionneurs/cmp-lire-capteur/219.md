# Contexte

Un portillon de démonstration doit savoir si une carte de transport est présentée devant lui.

Deux capteurs sont proposés pour fournir l'information au programme :

- un lecteur de carte, qui détecte la présence d'une carte compatible ;
- un capteur de proximité, qui indique seulement si un objet se trouve près du portillon.

# Consigne

Sélectionne le capteur à utiliser et la phrase qui justifie ce choix. Deux réponses sont attendues.

# Réponses

1. Bloc : lecteur de carte.
2. Bloc : capteur de proximité.
3. Justification : il faut savoir si une carte de transport compatible est présentée.
4. Justification : il suffit de savoir si n'importe quel objet est proche du portillon.

# Solution

1, 3

# Feedback essai 1

Tu dois sélectionner une réponse « Bloc » et une réponse « Justification ». Compare précisément l'information recherchée avec ce que détecte chacun des deux capteurs.

# Feedback

Il faut choisir le lecteur de carte et la justification sur la détection d'une carte compatible. Le capteur de proximité peut signaler qu'un objet est proche, mais il ne permet pas de savoir qu'il s'agit bien d'une carte de transport.
