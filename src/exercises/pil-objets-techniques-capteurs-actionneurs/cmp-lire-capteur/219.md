# Contexte

Avant une projection, la classe veut savoir si la salle est suffisamment sombre pour bien voir l'image.

Dans l'interface Vittascience, le programme doit écrire régulièrement dans la console une mesure de la quantité de lumière présente dans la salle. L'emplacement de lecture est encore vide et deux blocs de capteurs sont proposés à côté du programme :

- un bloc qui lit la luminosité ;
- un bloc qui lit le niveau sonore du microphone.

# Consigne

Sélectionne le bloc à placer dans l'emplacement vide et la phrase qui justifie ce choix. Deux réponses sont attendues.

# Réponses

1. Bloc : luminosité.
2. Bloc : niveau sonore du microphone.
3. Justification : il faut mesurer la quantité de lumière présente dans la salle.
4. Justification : il faut mesurer si la salle est silencieuse ou bruyante.

# Solution

1, 3

# Feedback essai 1

Tu dois sélectionner une réponse « Bloc » et une réponse « Justification ». Repère précisément ce que la classe veut mesurer avant la projection.

# Feedback

Il faut choisir le bloc de luminosité et la justification sur la quantité de lumière. Le microphone mesure le niveau sonore : il peut indiquer si la salle est bruyante, mais pas si elle est sombre ou éclairée.
