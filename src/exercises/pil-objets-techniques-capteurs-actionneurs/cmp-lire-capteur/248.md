# Contexte

Dans un bus, le système doit savoir si le bouton « arrêt demandé » a été pressé. Deux capteurs sont proposés :

- capteur de bouton : fournit `arret_demande` ;
- thermomètre : fournit `temperature`.

# Consigne

Quel capteur faut-il choisir ?

# Réponses

1. Le capteur de bouton
2. Le thermomètre

# Solution

1

# Feedback essai 1

Choisis le capteur qui mesure directement l'événement demandé.

# Feedback

Le capteur du bouton fournit précisément l'information `arret_demande`.
