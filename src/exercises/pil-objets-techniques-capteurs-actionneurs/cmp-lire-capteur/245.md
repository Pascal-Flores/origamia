# Contexte

Le programme doit utiliser la valeur fournie par le capteur de lumière de la carte.

# Consigne

Quel bloc faut-il utiliser pour récupérer cette donnée ?

# Réponses

1. `lire la luminosité`
2. `allumer les LED`
3. `jouer un son`

# Solution

1

# Feedback essai 1

Cherche le bloc qui lit une information, pas celui qui produit une action.

# Feedback

Le bloc `lire la luminosité` récupère la valeur du capteur de lumière. Les autres blocs commandent des actionneurs.
