# Contexte

Dans une maquette de bus, le programme doit savoir si le bouton « arrêt demandé » a été pressé.

Deux capteurs sont proposés :

- un capteur de bouton, qui indique si le bouton est pressé ;
- un microphone, qui mesure le niveau sonore autour de la maquette.

# Consigne

Sélectionne le capteur à utiliser et la phrase qui justifie ce choix. Deux réponses sont attendues.

# Réponses

1. Bloc : état du bouton « arrêt demandé ».
2. Bloc : niveau sonore du microphone.
3. Justification : le programme doit savoir si le bouton a été pressé.
4. Justification : le programme doit mesurer si les passagers font du bruit.

# Solution

1, 3

# Feedback essai 1

Tu dois sélectionner une réponse « Bloc » et une réponse « Justification ». Cherche l'information qui correspond directement à l'appui sur le bouton.

# Feedback

Il faut choisir le bloc qui lit l'état du bouton et la justification sur l'appui. Le microphone mesure le bruit ambiant : cette mesure ne permet pas de savoir de façon fiable si le bouton « arrêt demandé » a été pressé.
