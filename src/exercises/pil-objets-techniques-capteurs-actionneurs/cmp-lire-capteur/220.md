# Contexte

Dans une maquette de bus, le **bouton A de la carte micro:bit** représente le bouton « arrêt demandé ».

Dans l'interface Vittascience, le programme doit écrire régulièrement dans la console si ce bouton est pressé. L'emplacement de lecture est encore vide et deux blocs sont proposés à côté du programme :

- un bloc qui indique si le bouton A est pressé ;
- un bloc qui lit le niveau sonore du microphone.

# Consigne

Sélectionne le bloc à placer dans l'emplacement vide et la phrase qui justifie ce choix. Deux réponses sont attendues.

# Réponses

1. Bloc : état du bouton A.
2. Bloc : niveau sonore du microphone.
3. Justification : le programme doit savoir si le bouton « arrêt demandé » a été pressé.
4. Justification : le programme doit mesurer le bruit à l'intérieur du bus.

# Solution

1, 3

# Feedback essai 1

Tu dois sélectionner une réponse « Bloc » et une réponse « Justification ». Cherche l'information qui correspond directement à l'appui sur le bouton.

# Feedback

Il faut choisir le bloc qui lit l'état du bouton A et la justification sur l'appui. Le microphone mesure le bruit ambiant : cette mesure ne permet pas de savoir de façon fiable si le bouton « arrêt demandé » a été pressé.
