# Contexte

La bibliothèque de l'école utilise une carte micro:bit pour surveiller le bruit.

Le microphone de la carte mesure le niveau sonore. Dans le programme affiché, un bloc manque pour écrire cette mesure dans la console.

# Consigne

Que faut-il placer dans l'emplacement vide pour afficher le niveau sonore réellement mesuré ?

# Réponses

1. Le bloc qui lit le niveau sonore mesuré par le microphone.
2. Le nombre 50.
3. Le texte « Bruit ».

# Solution

1

# Feedback essai 1

Le bruit dans la bibliothèque peut changer. Cherche la réponse qui fournit une nouvelle mesure pendant que le programme fonctionne.

# Feedback

Il faut utiliser le bloc qui lit le niveau sonore : sa valeur vient du microphone au moment où le programme fonctionne. Le nombre 50 afficherait toujours la même valeur et le texte « Bruit » afficherait seulement un mot.
