# Contexte

Le programme affiché écrit une information dans la console.

# Consigne

Dans ce programme, quel capteur est utilisé ?

# Réponses

1. Le thermomètre.
2. Le microphone.
3. Le bouton A.
4. La boussole.

# Solution

2

# Feedback

Le programme écrit dans la console une information liée au son. Il utilise donc le microphone, c'est-à-dire le capteur qui mesure le niveau sonore autour de la carte micro:bit.
