# Contexte

Un siège d'essai doit savoir uniquement si la boucle de ceinture est fermée. Les capteurs proposés sont :

- contacteur de boucle : `boucle_fermee` ;
- capteur de vitesse : `vitesse` ;
- thermomètre : `temperature`.

# Consigne

Quel capteur convient et pourquoi ?

# Réponses

1. Le contacteur de boucle, car il indique directement si la boucle est fermée.
2. Le capteur de vitesse, car il mesure le déplacement.
3. Le thermomètre, car il mesure la température.

1

# Feedback essai 1

Le besoin est un état ouvert/fermé de la boucle.

# Feedback essai 2

Choisis la donnée qui correspond exactement à cet état.

# Feedback

`boucle_fermee` répond directement au besoin ; les autres capteurs mesurent des grandeurs sans lien avec la fermeture.
