# Contexte

Le jardin de l'école suit l'humidité du sol d'un pot de basilic avec une carte micro:bit.

Une sonde est placée dans la terre. Le programme doit écrire régulièrement dans la console une mesure qui permet de savoir si la terre se dessèche.

Dans l'interface, deux blocs de capteurs sont proposés à côté du programme incomplet.

# Consigne

Sélectionne le bloc à placer dans l'emplacement vide et la phrase qui justifie ce choix. Deux réponses sont attendues.

# Réponses

1. Bloc : humidité du sol sur la broche P1.
2. Bloc : quantité d'eau sur la broche P1.
3. Justification : la sonde doit mesurer l'eau présente dans la terre.
4. Justification : la sonde doit mesurer la quantité d'eau qui la recouvre.

# Solution

1, 3

# Feedback essai 1

Tu dois sélectionner une réponse « Bloc » et une réponse « Justification ». Repère l'information qui permet de savoir si la terre se dessèche, puis compare ce que mesurent les deux capteurs.

# Feedback

Il faut choisir le bloc d'humidité du sol et la justification sur l'eau présente dans la terre. Ce capteur mesure l'humidité autour des racines. Le bloc de quantité d'eau mesure l'eau qui recouvre directement son capteur, pas l'humidité retenue dans la terre.
