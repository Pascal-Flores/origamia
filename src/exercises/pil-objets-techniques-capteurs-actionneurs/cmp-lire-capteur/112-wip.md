## Competence et attendu

- Competence : `cmp-lire-capteur`
- Intitule : Lire une information de capteur et la rendre exploitable dans le programme.
- Attendu : `att-lire-capteur-cm2`
- Niveau : CM2
- Exercices : `112.md`, `113.md`, `114.md`

Attendu du referentiel :

> Choisir le bon capteur parmi 2 (guide) et justifier rapidement.

Indicateurs :

- acquis : bon capteur et justification liee au besoin ;
- en cours : bon capteur avec justification faible ;
- non acquis : mauvais capteur malgre le guidage.

## Diagnostic des exercices actuels

Les exercices actuels ne correspondent plus suffisamment a l'attendu :

- ils proposent quatre capteurs au lieu de deux ;
- ils ne demandent pas de justification a l'eleve ;
- ils utilisent des jauges, LED ou afficheurs qui attirent l'attention vers les actionneurs ;
- leurs reponses reposent sur d'anciennes captures ou sur des SVG reconstruits ;
- leurs noms, descriptions, essais et feedbacks ne suivent pas les nouvelles regles.

Ils doivent etre remplaces apres validation du present cadrage.

## Progression depuis le CM1

Dans `109-111`, le capteur est annonce et l'eleve distingue sa mesure d'un nombre ou d'un texte fixe.

Dans `112-114`, le besoin est annonce mais deux blocs de capteurs sont proposes. L'eleve doit :

1. choisir le bloc qui lit la grandeur demandee ;
2. choisir la phrase qui explique pourquoi ce bloc convient.

La difficulte augmente donc sans passer a plusieurs capteurs non guides, qui restent reserves a la 6e.

## Forme exacte proposee

- Type : `qcm`.
- Media : `interface`.
- Projet Vittascience :
  - bloc `Au demarrage` vide ;
  - bloc `Repeter indefiniment` ;
  - bloc `ecrire dans la console` avec entree vide ;
  - pause d'une seconde apres l'ecriture ;
  - exactement deux blocs de capteurs non connectes, visibles a droite.
- Contexte : une situation concrete indique clairement l'information a mesurer.
- Consigne commune : `Selectionne le bloc a placer dans l'emplacement vide et la phrase qui justifie ce choix. Deux reponses sont attendues.`
- Reponses :
  - deux reponses commencent par `Bloc :` ;
  - deux reponses commencent par `Justification :` ;
  - une reponse de chaque nature est correcte.
- Solution : deux identifiants, un bloc et une justification.
- Essais : `2`.
- Feedback essai 1 : rappeler de selectionner un bloc et une justification, puis de comparer la grandeur demandee avec ce que mesure chaque capteur.
- Feedback final : nommer le bon bloc et expliquer la difference avec l'autre mesure.

Les reponses restent en langage naturel. Elles ne sont pas entourees de backticks afin que le build ne tente pas de produire de faux blocs. Les vrais blocs sont visibles dans le projet Vittascience.

## Variante pilote - 112.md

### Situation

Le jardin de l'ecole suit un pot de basilic. Une sonde placee dans la terre doit indiquer si celle-ci se desseche.

### Deux blocs proposes dans le projet

1. `sensors_getGroveMoisture` : humidite du sol sur la broche P1.
2. `sensors_getGroveWaterAmount` : quantite d'eau sur la broche P1.

Ces types existent dans le projet Vittascience fourni a la racine.

### Reponses prevues

1. Bloc : humidite du sol sur la broche P1.
2. Bloc : quantite d'eau sur la broche P1.
3. Justification : la sonde doit mesurer l'eau presente dans la terre.
4. Justification : la sonde doit mesurer la quantite d'eau qui la recouvre.

Solution : `1, 3`.

### Metadonnees envisagees

- Nom : `Basilic sous surveillance`
- Situation : `obj-jardin-basilic-humidite-sol`
- Description : le programme doit suivre l'humidite de la terre ; l'eleve choisit entre deux blocs de capteurs et selectionne la justification adaptee.

## Declinaison envisagee - 114.md

### Deux blocs proposes dans le projet

### Reponses prevues

2. Bloc : niveau sonore mesure par le microphone.
3. Justification : la temperature indique si l'interieur de la glaciere est froid ou chaud.
4. Justification : le microphone indique si l'environnement est silencieux ou bruyant.

Solution : `1, 3`.

### Metadonnees envisagees

- Situation : `obj-pique-nique-glaciere-temperature`
- Description : pour un pique-nique, l'eleve choisit entre la temperature et le niveau sonore afin de savoir si les aliments restent au frais, puis justifie son choix.

## Garde-fous didactiques

- Le programme n'utilise la donnee que dans la console : aucun actionneur n'est evalue.
- La boucle et la pause sont deja fournies et ne font l'objet d'aucune question.
- Deux blocs de capteurs seulement sont proposes.
- Les deux mesures sont plausibles dans la meme situation, mais une seule repond au besoin formule.
- La justification porte sur la grandeur mesuree, pas sur la couleur ou la forme du bloc.
- Les trois situations ne sont pas deja utilisees dans le corpus actuel.
- Le pilote `112.md` a ete valide avant la redaction de `113.md` et `114.md`.
