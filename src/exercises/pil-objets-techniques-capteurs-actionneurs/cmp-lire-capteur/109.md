# Contexte

La classe prépare une station météo avec une carte micro:bit.

Le thermomètre de la carte mesure la température de la pièce. Dans le programme affiché, un bloc manque pour écrire cette mesure dans la console.

# Consigne

Que faut-il placer dans l'emplacement vide pour afficher la température réellement mesurée ?

# Réponses

1. Le bloc qui lit la température en degrés Celsius.
2. Le nombre 20.
3. Le texte « Température ».

# Solution

1

# Feedback essai 1

La température de la pièce peut changer. Cherche la réponse qui fournit une nouvelle mesure pendant que le programme fonctionne.

# Feedback

Il faut utiliser le bloc qui lit la température en degrés Celsius : sa valeur vient du thermomètre au moment où le programme fonctionne. Le nombre 20 afficherait toujours la même valeur et le texte « Température » afficherait seulement un mot.
