# Contexte

Le programme affiché écrit une information dans la console.

# Consigne

Dans ce programme, quel capteur est utilisé ?

# Réponses

# Solution

1

# Feedback

Le programme écrit dans la console la température en degrés Celsius. Il utilise donc le thermomètre, c'est-à-dire le capteur de température de la carte micro:bit.
