# Contexte

On veut préparer un programme pour une carte micro:bit.

Le programme doit afficher sur un afficheur 4 chiffres la force exercée sur un détecteur branché sur la broche P1.

# Consigne

Quel programme respecte la consigne ?

# Réponses

1. Programme à capturer : au démarrage, faire défiler `Force`. Dans la boucle, afficher sur l'afficheur 4-digit le nombre entier fourni par le bloc `[Détecteur de force] valeur sur la broche P1`, puis attendre 1 seconde.
2. Programme à capturer : au démarrage, faire défiler `Force`. Dans la boucle, afficher sur l'afficheur 4-digit le nombre entier fourni par le bloc `[Micro] intensité du son`, puis attendre 1 seconde.
3. Programme à capturer : au démarrage, faire défiler `Force`. Dans la boucle, afficher sur l'afficheur 4-digit le nombre entier fourni par le bloc `[Capteur à ultrasons Grove] distance (cm) sur la broche P1`, puis attendre 1 seconde.
4. Programme à capturer : au démarrage, faire défiler `Force`. Dans la boucle, écrire dans la console la valeur fournie par le bloc `[Capteur de gestes] type de geste`, puis attendre 1 seconde.

# Solution

1

# Feedback

Le programme correct lit la valeur du détecteur de force branché sur P1 et l'affiche sur l'afficheur 4 chiffres. Les autres programmes utilisent le même contexte d'affichage ou une étiquette proche, mais ils lisent une intensité sonore, une distance ou un type de geste.
