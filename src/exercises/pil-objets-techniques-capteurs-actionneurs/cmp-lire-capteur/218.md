# Contexte

Un boîtier d'appel de démonstration possède un bouton d'urgence relié à une carte programmable.

Le programme doit écrire dans la console l'état réellement lu sur ce bouton afin de voir s'il est pressé ou non. L'information à écrire est encore manquante.

# Consigne

Que faut-il placer dans l'emplacement vide pour afficher l'état réellement lu sur le bouton ?

# Réponses

1. Le bloc qui lit si le bouton d'urgence est pressé.
2. Le nombre 1.
3. Le texte « Urgence ».

# Solution

1

# Feedback essai 1

L'état du bouton peut changer pendant l'utilisation. Cherche la réponse qui lit cet état au moment où le programme fonctionne.

# Feedback

Il faut utiliser le bloc qui lit l'état du bouton. Le nombre 1 resterait toujours identique et le texte « Urgence » afficherait seulement un mot : ni l'un ni l'autre ne permet de connaître l'état réellement lu.
