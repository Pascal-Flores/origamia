# Contexte

Un boîtier d'appel de démonstration utilise le **bouton A de la carte micro:bit** comme bouton d'urgence.

Dans l'interface Vittascience, le programme doit écrire régulièrement dans la console si ce bouton est réellement pressé ou non. L'emplacement où placer la donnée est encore vide et trois blocs sont proposés à côté du programme.

# Consigne

Que faut-il placer dans l'emplacement vide pour afficher l'état réellement lu sur le bouton A ?

# Réponses

1. Le bloc qui indique si le bouton A est pressé.
2. Le nombre 1.
3. Le texte « Urgence ».

# Solution

1

# Feedback essai 1

L'état du bouton peut changer pendant l'utilisation. Cherche la réponse qui lit cet état au moment où le programme fonctionne.

# Feedback

Il faut utiliser le bloc qui indique si le bouton A est pressé. Sa valeur dépend de l'état réel du bouton. Le nombre 1 resterait toujours identique et le texte « Urgence » afficherait seulement un mot.
