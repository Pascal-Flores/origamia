# Contexte

Un boîtier d'appel possède un bouton d'urgence. Le capteur fournit la donnée `bouton_urgence`. Le programme doit lire cette donnée pour savoir si l'utilisateur a appuyé.

# Consigne

Quelle donnée correspond à l'entrée du capteur ?

# Réponses

1. `bouton_urgence`
2. `sonnerie`
3. `luminosite`

# Solution

1

# Feedback essai 1

Cherche la valeur qui vient directement du bouton.

# Feedback

`bouton_urgence` est la donnée produite par le capteur ; les deux autres propositions décrivent autre chose.
