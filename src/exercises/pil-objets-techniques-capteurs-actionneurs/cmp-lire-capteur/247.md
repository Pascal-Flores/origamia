# Contexte

On veut connaître la température de la pièce. Deux capteurs sont disponibles : un capteur de température et un capteur de lumière.

# Consigne

Quelle réponse est correcte ?

# Réponses

1. Le capteur de température, car il mesure la grandeur recherchée.
2. Le capteur de lumière, car il produit aussi un nombre.
3. N'importe lequel, car tous les capteurs mesurent la même chose.

# Solution

1

# Feedback essai 1

Le type de nombre ne suffit pas : regarde ce que chaque capteur mesure réellement.

# Feedback

Le capteur de température est adapté parce que la grandeur recherchée est précisément la température.
