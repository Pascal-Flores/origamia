## Reference pedagogique

> Choisir parmi plusieurs capteurs et justifier l'adequation au besoin.

Indicateurs :

- acquis : choix pertinent + justification liee a la mesure attendue ;
- en cours : choix correct mais justification superficielle ;
- non acquis : choix non pertinent ou justification hors sujet.

## Forme retenue

Type : `qcu`.

Structure commune :

1. Une consigne de programme precise ce qui doit etre mesure ou affiche.
2. Quatre programmes courts sont proposes.
3. Chaque proposition est decrite textuellement dans le draft.
4. Les propositions seront ensuite remplacees par des captures d'ecran de programmes.
5. Un seul programme respecte la consigne.

## Critere de choix

L'eleve ne choisit pas seulement un bloc capteur isole. Il doit identifier le programme qui :

- lit le bon capteur ;
- lit la bonne grandeur ou le bon etat ;
- utilise cette donnee dans le bon contexte d'affichage ;
- garde une etiquette de demarrage coherente avec la mission quand elle est presente.

## Contraintes de redaction

- Les reponses doivent decrire explicitement les captures a produire.
- Les programmes proposes doivent rester courts et lisibles.
- Les distracteurs doivent etre plausibles :
  - bon contexte mais mauvais capteur ;
  - bon capteur mais mauvais contexte ;
  - capteur proche mais grandeur differente ;
  - etiquette incoherente.
- Ne pas demander a l'eleve d'ecrire un programme.
- Ne pas introduire de condition.
- Ne pas transformer l'exercice en correction d'erreur : la question reste "quel programme respecte la consigne ?"

## Plan de redaction

### `115.md`

Consigne : afficher la force exercee sur un detecteur branche sur P1 sur un afficheur 4 chiffres.

Solution : programme qui affiche le nombre entier fourni par `[Detecteur de force] valeur sur la broche P1` sur l'afficheur 4-digit.

Correction utilisateur - 2026-07-09 :

- L'ancien distracteur 3 lisait bien la force dans la console ; il restait donc acceptable si on interprete seulement "attendre la force detectee".
- Le distracteur 3 est remplace par un programme qui affiche une distance sur l'afficheur 4 chiffres.
- La solution unique reste le programme qui lit la force P1 et l'affiche sur l'afficheur 4 chiffres.

### `116.md`

Consigne : ecrire dans la console la vitesse du vent en metres par seconde pour une station meteo.

Solution : programme qui ecrit dans la console `[Weather:bit - wind] vitesse du vent en (m/s)`.

Correction utilisateur - 2026-07-09 :

- L'ancien distracteur 3 lisait bien la vitesse du vent dans la console avec une etiquette differente ; il restait donc acceptable.
- Le distracteur 3 est remplace par un programme qui ecrit l'intensite sonore dans la console.
- La solution unique reste le programme qui lit la vitesse du vent en m/s et l'ecrit dans la console.

### `117.md`

Consigne : ecrire dans la console le geste reconnu par un capteur de gestes.

Solution : programme qui ecrit dans la console `[Capteur de gestes] type de geste`.

Correction utilisateur - 2026-07-09 :

- L'ancien distracteur 4 lisait bien le type de geste dans la console avec une etiquette differente ; il restait donc acceptable.
- Le distracteur 4 est remplace par un programme qui ecrit une valeur de force dans la console.
- La solution unique reste le programme qui lit le type de geste et l'ecrit dans la console.
