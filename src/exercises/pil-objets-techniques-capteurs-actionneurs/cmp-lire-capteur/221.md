# Contexte

Un dispositif pédagogique doit mesurer la distance entre une personne et une ligne de sécurité. Les capteurs disponibles sont :

- capteur de distance ;
- microphone ;
- capteur de température ;
- capteur de lumière.

# Consigne

Quel capteur est adapté, et pourquoi ?

# Réponses

1. Le capteur de distance, car la grandeur recherchée est une distance.
2. Le microphone, car il mesure un son.
3. Le thermomètre, car il mesure une température.
4. Le capteur de lumière, car il mesure un éclairement.

1

# Feedback essai 1

# Feedback essai 2

Cherche le capteur dont le nom correspond à « distance ».

# Feedback

Seul le capteur de distance mesure directement la grandeur demandée.
