# Contexte

Le programme affiché écrit une information dans la console.

# Consigne

Dans ce programme, quel capteur est utilisé ?

# Réponses

1. Le thermomètre.
2. Le microphone.
3. La boussole.
4. Le bouton A.

# Solution

3

# Feedback

Le programme écrit dans la console une information d'orientation. Il utilise donc la boussole, c'est-à-dire le capteur qui indique la direction de la carte micro:bit.
