# Contexte

Un système doit connaître la distance qui le sépare d'un obstacle. Les capteurs disponibles sont : distance, température, lumière et microphone.

# Consigne

Quel capteur est le plus adapté ?

# Réponses

1. capteur de distance, car il mesure directement l'éloignement de l'obstacle
2. capteur de lumière, car un obstacle peut faire de l'ombre
3. thermomètre, car tous les objets ont une température
4. microphone, car certains obstacles font du bruit

# Solution

1

# Feedback essai 1

Cherche le capteur qui mesure directement l'information demandée, sans déduction supplémentaire.

# Feedback essai 2

La mission demande une distance, pas un indice indirect de présence.

# Feedback

Le capteur de distance fournit directement la grandeur utile au programme : l'éloignement de l'obstacle.
