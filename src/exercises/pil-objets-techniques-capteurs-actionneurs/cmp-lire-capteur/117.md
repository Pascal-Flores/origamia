# Contexte

On veut préparer un programme pour une carte micro:bit avec un capteur de gestes.

Le programme doit écrire dans la console le geste reconnu par le capteur.

# Consigne

Quel programme respecte la consigne ?

# Réponses

1. Programme à capturer : au démarrage, faire défiler `Geste`. Dans la boucle, écrire dans la console la valeur fournie par le bloc `[Capteur de gestes] type de geste`, puis attendre 1 seconde.
2. Programme à capturer : au démarrage, faire défiler `Geste`. Dans la boucle, écrire dans la console la valeur fournie par le bloc `[Capteur à ultrasons Grove] distance (cm) sur la broche P1`, puis attendre 1 seconde.
3. Programme à capturer : au démarrage, faire défiler `Geste`. Dans la boucle, écrire dans la console la valeur fournie par le bloc `[Micro] intensité du son`, puis attendre 1 seconde.
4. Programme à capturer : au démarrage, faire défiler `Geste`. Dans la boucle, écrire dans la console la valeur fournie par le bloc `[Détecteur de force] valeur sur la broche P1`, puis attendre 1 seconde.

1

# Feedback

Le programme correct lit le type de geste et l'écrit dans la console. Les autres programmes écrivent bien une valeur dans la console, mais ils lisent une distance, une intensité sonore ou une force.
