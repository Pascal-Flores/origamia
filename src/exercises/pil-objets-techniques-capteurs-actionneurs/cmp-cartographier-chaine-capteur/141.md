# Contexte

Un portail automatique doit détecter l’arrivée d’un véhicule puis ouvrir le passage.

# Consigne

Observe le système. Deux éléments sont remplacés par des `?`. Quels sont les deux éléments manquants ?

# Réponses

1. Capteur de distance
2. Moteur électrique
3. Capteur de température
4. Buzzer
5. Lampe LED

# Solution

1, 2

# Feedback essai 1

L’un des éléments manquants doit repérer l’arrivée du véhicule. L’autre doit produire le mouvement du portail.

# Feedback essai 2

Cherche ce qui peut détecter un objet qui s’approche, puis ce qui peut entraîner mécaniquement l’ouverture du portail.

# Feedback

Il manque le **capteur de distance** et le **moteur électrique**. Le capteur informe la carte électronique de l’arrivée du véhicule ; la carte commande ensuite le moteur pour ouvrir le portail.
