# Contexte

Un portail automatique doit détecter l’arrivée d’un véhicule puis ouvrir le passage.

# Consigne

Sur le schéma, deux éléments sont remplacés par `??? A` et `??? B`.

Classe chaque proposition dans la bonne catégorie : place le bon élément sous `??? A`, le bon élément sous `??? B`, et les autres dans « Éléments inutiles ».

# Feedback essai 1

Pour ouvrir le portail, on doit d’abord savoir qu’un véhicule approche. À quel endroit cette information entre-t-elle dans le schéma ?

# Feedback essai 2

Une flèche va vers la carte et l’autre en part. Quel rôle demande de détecter une approche ? Quel autre rôle demande de déplacer le portail ?

# Feedback

On peut ouvrir le portail ! Le capteur de distance signale l’arrivée du véhicule. La carte commande le moteur qui ouvre le portail.
