# Contexte

Sur un convoyeur, un capteur repère les colis. Le système commande ensuite le moteur pour faire avancer les colis jusqu'à la caisse.

# Consigne

Complète la chaîne dans l'ordre où l'information circule, de la détection jusqu'au mouvement.

# Texte à trous

La chaîne du convoyeur est : [[1]] → [[2]] → [[3]] → [[4]] → [[5]].

# Étiquettes

1. capteur de présence de colis
2. entrée du contrôleur
3. programme de gestion du convoyeur
4. sortie du moteur
5. moteur du convoyeur
6. capteur de lumière
7. buzzer
8. bouton de réinitialisation

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Commence par l'élément qui repère le colis. Termine par celui qui le fait avancer.

# Feedback essai 2

Entre le capteur et le moteur, l'information passe par l'entrée, le programme et la sortie commandée.

# Feedback

La chaîne correcte est **capteur de présence de colis → entrée du contrôleur → programme de gestion du convoyeur → sortie du moteur → moteur du convoyeur**. Elle relie la détection à l'action de faire avancer le colis.
