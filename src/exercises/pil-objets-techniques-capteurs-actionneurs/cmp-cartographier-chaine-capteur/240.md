# Contexte

Un distributeur automatique doit détecter qu’une carte est prête à être distribuée, puis commander un moteur qui l’entraîne vers la sortie.

Sur le schéma, le capteur est placé après le rouleau d’entraînement : il ne peut donc détecter la carte qu’une fois qu’elle a déjà été déplacée.

# Consigne

Quelle modification faut-il faire pour que la chaîne d’information et d’action fonctionne correctement ?

# Réponses

1. Placer le capteur avant le mécanisme d’entraînement, afin qu’il détecte la carte avant que la carte électronique ne commande le moteur.
2. Supprimer le capteur et faire tourner le moteur en permanence.
3. Remplacer le moteur par un buzzer.
4. Placer le capteur après la sortie du distributeur.
