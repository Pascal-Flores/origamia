# Contexte

Un distributeur de démonstration possède un capteur de carte, une entrée, un programme, une sortie moteur et un moteur. Le moteur avance une carte lorsque l'information a été traitée.

# Consigne

Remets les cinq éléments dans l'ordre du flux.

# Réponses

1. capteur de carte
2. entrée
3. programme
4. sortie moteur
5. moteur

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Commence par ce qui détecte la carte et termine par ce qui la déplace.

# Feedback essai 2

Entre le capteur et le moteur, l'information passe par l'entrée, le programme puis la sortie.

# Feedback

La chaîne est capteur de carte → entrée → programme → sortie moteur → moteur. Elle distingue clairement acquisition, traitement et action.
