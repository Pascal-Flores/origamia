# Contexte

Un dispositif mesure le niveau sonore et commande une LED. Il comporte : microphone, entrée analogique, programme, sortie LED, LED.

# Consigne

Remets les éléments dans l'ordre de la chaîne information → action.

# Réponses

1. microphone
2. entrée analogique
3. programme
4. sortie LED
5. LED

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Commence par l'élément qui mesure le son et termine par celui qui produit la lumière.

# Feedback essai 2

La donnée doit passer par l'entrée puis le programme avant qu'une commande soit envoyée à la LED.

# Feedback

Le flux est microphone → entrée analogique → programme → sortie LED → LED. Il distingue clairement acquisition, traitement et action.
