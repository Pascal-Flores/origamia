# Contexte

Un casier programmable lit un badge. Si le badge est reconnu, le système commande le verrou pour ouvrir la porte.

# Consigne

Complète la chaîne dans l'ordre où l'information circule, de la lecture du badge jusqu'à l'action.

# Texte à trous

La chaîne du casier est : [[1]] → [[2]] → [[3]] → [[4]] → [[5]].

# Étiquettes

1. lecteur de badge
2. entrée numérique
3. programme de reconnaissance
4. sortie du verrou
5. verrou électrique
6. capteur de température
7. moteur de ventilation
8. voyant de batterie

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Repère d'abord ce qui lit le badge. L'information entre ensuite dans la carte, est traitée, puis commande le mécanisme de la porte.

# Feedback essai 2

L'entrée reçoit la lecture du badge et le programme décide si le verrou doit être commandé. La sortie vient juste avant le verrou.

# Feedback

La chaîne est **lecteur de badge → entrée numérique → programme de reconnaissance → sortie du verrou → verrou électrique**. La lecture est acquise, traitée puis transformée en ouverture du casier.
