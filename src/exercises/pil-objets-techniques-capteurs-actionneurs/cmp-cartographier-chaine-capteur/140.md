# Contexte

Une station de tri doit reconnaître la couleur d’un objet puis orienter cet objet vers le bon bac.

# Consigne

Sur le schéma, deux éléments sont remplacés par `??? A` et `??? B`.

Classe chaque proposition dans la bonne catégorie : place le bon élément sous `??? A`, le bon élément sous `??? B`, et les autres dans « Éléments inutiles ».

2: 2

# Feedback essai 1

Si notre trieur envoie tout dans le même bac, on est mal partis ! Que doit-il savoir sur chaque objet avant d’agir ?

# Feedback essai 2

La carte doit recevoir un indice sur l’objet, puis commander une pièce qui bouge. Peut-on trouver qui fait chaque travail ?

# Feedback

On a suivi l’objet jusqu’au bac ! Le capteur de couleur renseigne la carte, puis le servomoteur dirige la trappe vers le bon bac.
