# Contexte

Une station de tri doit reconnaître la couleur d’un objet puis orienter cet objet vers le bon bac.

# Consigne

Observe le système. Deux éléments sont remplacés par des `?`. Quels sont les deux éléments manquants ?

# Réponses

1. Capteur de couleur
2. Servomoteur
3. Capteur de température
4. Buzzer
5. Lampe LED

# Solution

1, 2

# Feedback essai 1

L’un des éléments manquants doit récupérer une information sur l’objet. L’autre doit produire un mouvement permettant de changer sa direction.

# Feedback essai 2

Cherche ce qui peut distinguer une couleur, puis ce qui peut déplacer une trappe ou un aiguillage mécanique.

# Feedback

Il manque le **capteur de couleur** et le **servomoteur**. Le capteur transmet la couleur détectée à la carte électronique ; la carte commande ensuite le servomoteur pour orienter l’objet vers le bon bac.
