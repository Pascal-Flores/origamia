# Contexte

Une lampe de lecture mesure la lumière de la pièce. Son programme adapte ensuite la puissance de la lampe pour obtenir un éclairage confortable.

# Consigne

Complète la chaîne complète, puis vérifie que chaque élément a sa place entre la mesure et l'effet produit.

# Texte à trous

La chaîne de réglage est : [[1]] → [[2]] → [[3]] → [[4]] → [[5]] → [[6]].

# Étiquettes

1. capteur de luminosité
2. entrée analogique
3. programme de réglage
4. sortie de puissance
5. lampe de lecture
6. éclairage adapté dans la pièce
7. microphone
8. bouton marche-arrêt
9. haut-parleur

# Solution

1, 2, 3, 4, 5, 6

# Feedback essai 1

Commence par ce qui mesure la lumière. Place ensuite le traitement et la commande avant la lampe, puis termine par l'effet observé.

# Feedback essai 2

La sortie de puissance commande la lampe. L'éclairage adapté n'est pas un élément de commande : c'est l'effet final produit par la lampe.

# Feedback

La chaîne complète est **capteur de luminosité → entrée analogique → programme de réglage → sortie de puissance → lampe de lecture → éclairage adapté dans la pièce**. La mesure est acquise, traitée, transformée en commande, puis la lampe produit l'effet attendu.
