# Contexte

Un robot mesure une distance et fait tourner son moteur. Les cinq éléments sont : capteur de distance, entrée de la carte, programme, sortie de commande, moteur.

# Consigne

Ordonne les cinq éléments du flux complet.

# Réponses

1. capteur de distance
2. entrée de la carte
3. programme
4. sortie de commande
5. moteur

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Sépare le trajet en trois étapes : acquisition, traitement, action.

# Feedback essai 2

L'entrée reçoit la donnée avant le programme ; la sortie transmet la décision avant le moteur.

# Feedback

Le capteur mesure, l'entrée transmet la mesure au programme, le programme la traite, la sortie envoie la commande et le moteur produit l'action.
