# Contexte

Un meuble pédagogique possède un capteur de présence d'objet, une entrée, un programme, une sortie et une LED. Quand un objet est posé, l'information doit parvenir jusqu'à la LED.

# Consigne

Remets les cinq éléments dans l'ordre de la chaîne.

# Réponses

1. capteur de présence d'objet
2. entrée
3. programme
4. sortie LED
5. LED

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Suis l'information depuis la mesure jusqu'à l'effet lumineux.

# Feedback essai 2

Le programme se trouve entre l'entrée et la sortie.

# Feedback

Le flux complet est capteur → entrée → programme → sortie → LED : la mesure est acquise, traitée puis transformée en action.
