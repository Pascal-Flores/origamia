# Contexte

Un ventilateur intelligent mesure la température puis adapte la rotation de ses pales. Les éléments sont : sonde de température, carte programmable, commande moteur, moteur.

# Consigne

Remets les éléments dans l'ordre du trajet de l'information jusqu'à l'action.

# Réponses

1. sonde de température
2. carte programmable
3. commande moteur
4. moteur

# Solution

1, 2, 3, 4

# Feedback essai 1

Commence par l'élément qui mesure et termine par celui qui produit le mouvement.

# Feedback essai 2

La carte traite la mesure avant d'envoyer une commande au moteur.

# Feedback

La chaîne suit sonde → carte programmable → commande moteur → moteur : l'information mesurée est traitée puis transformée en action.
