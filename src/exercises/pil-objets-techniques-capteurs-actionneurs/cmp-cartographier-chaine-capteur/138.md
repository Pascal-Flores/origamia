# Contexte

Une maquette de pont-levis détecte l’approche d’un bateau puis commande un servomoteur.

# Consigne

Observe la chaîne de fonctionnement. Quel effet manque à la place du `?` ?

# Réponses

1. Le pont se lève
2. Une alarme sonore retentit
3. Une lampe s’allume

# Solution

1

# Feedback essai 1

Un bateau attend devant le pont. À la fin du schéma, on cherche le nom d’une pièce ou ce qu’on voit se passer ?

# Feedback essai 2

Le moteur fait déjà son travail. Qu’est-ce qui doit changer sur le pont pour que le bateau puisse passer dessous ?

# Feedback

On a suivi le mouvement jusqu’au bout ! Le servomoteur agit sur le mécanisme et le pont se lève. À toi de passer, petit bateau !
