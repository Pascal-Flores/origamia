# Contexte

Un store extérieur doit se déployer lorsque la lumière du soleil devient trop forte.

# Consigne

Observe le système. Deux éléments sont remplacés par des `?`. Quels sont les deux éléments manquants ?

# Réponses

1. Capteur de luminosité
2. Moteur électrique
3. Capteur de température
4. Buzzer
5. Lampe LED

# Solution

1, 2

# Feedback essai 1

L’un des éléments manquants doit mesurer la lumière. L’autre doit produire le mouvement du store.

# Feedback essai 2

Cherche ce qui permet à la carte de savoir si l’ensoleillement est fort, puis ce qui peut enrouler ou dérouler mécaniquement le store.

# Feedback

Il manque le **capteur de luminosité** et le **moteur électrique**. Le capteur transmet l’intensité lumineuse à la carte électronique ; la carte commande ensuite le moteur pour déployer le store.
