# Contexte

Un casier pédagogique vérifie qu'un badge est présenté puis allume une LED verte. La chaîne comporte quatre éléments : lecteur de badge, entrée du contrôleur, programme, LED verte.

# Consigne

Remets les quatre éléments dans l'ordre du flux d'information vers l'action.

# Réponses

1. lecteur de badge
2. entrée du contrôleur
3. programme
4. LED verte

# Solution

1, 2, 3, 4

# Feedback essai 1

Commence par l'élément qui capte l'information et termine par celui qui produit l'effet.

# Feedback essai 2

L'information doit entrer dans le contrôleur avant d'être traitée.

# Feedback

Le trajet est lecteur → entrée → programme → LED.
