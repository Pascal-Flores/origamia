## Attendu retravaillé

**Compléter une chaîne d’information et d’action en identifiant deux éléments manquants dans le fonctionnement d’un objet programmable.**

L’élève observe le système complet et doit retrouver deux maillons complémentaires, généralement un capteur et un actionneur, à partir de leur place dans le montage et de l’effet attendu.

## Forme exacte

- Type : `qcm`
- Statut : `wip`
- Media : `image`, avec `link: contexte`
- Support attendu : `contexte.png` dans le dossier de l’exercice
- Deux éléments du système sont remplacés par `?` / `???`
- 5 propositions textuelles
- Exactement 2 bonnes réponses
- 3 essais
- Feedback essai 1 : rappeler que les deux éléments n’ont pas le même rôle
- Feedback essai 2 : orienter vers la fonction précise du capteur et de l’actionneur sans donner leur nom
- Feedback final : nommer les deux éléments et expliquer le trajet information → commande → action
- Aucun classement, aucune remise en ordre, aucun paramétrage de programme

## Variantes

- 139 : casier à badge — lecteur de badge + serrure électrique
- 140 : station de tri — capteur de couleur + servomoteur
- 141 : à reprendre ultérieurement sur la même matrice
- 237 : store automatique — capteur de luminosité + moteur électrique
- 238 : chasse d’eau automatique — capteur de présence + électrovanne

## Frontières

- `cmp-lire-capteur` : il ne s’agit pas de choisir un bloc de lecture.
- `cmp-configurer-actionneur` : aucun paramètre d’actionneur n’est réglé.
- `cmp-piloter-actionneur-capteur` : aucune valeur n’est injectée directement dans l’actionneur.
- Ici, l’élève reconstitue deux rôles dans le fonctionnement global du système.
