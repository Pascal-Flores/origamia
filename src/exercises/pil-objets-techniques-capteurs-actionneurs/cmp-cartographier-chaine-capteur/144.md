# Contexte

Dans une serre, un capteur mesure la température. Quand il fait trop chaud, le programme commande un moteur qui ouvre un volet pour aérer les semis.

# Consigne

Complète la chaîne complète et vérifie le trajet de l'information jusqu'à l'effet produit.

# Texte à trous

La chaîne d'aération est : [[1]] → [[2]] → [[3]] → [[4]] → [[5]] → [[6]].

# Étiquettes

1. capteur de température
2. entrée analogique
3. programme de ventilation
4. sortie du moteur
5. moteur du volet
6. volet de la serre ouvert
7. capteur de pluie
8. buzzer
9. réserve d'eau

# Solution

1, 2, 3, 4, 5, 6

# Feedback essai 1

Repère la mesure de départ, puis suis-la dans le contrôleur. L'effet final doit être ce que le moteur fait réellement au volet.

# Feedback essai 2

Le programme traite la température avant la sortie du moteur. Le moteur est l'actionneur et le volet ouvert est l'effet obtenu.

# Feedback

Le flux est **capteur de température → entrée analogique → programme de ventilation → sortie du moteur → moteur du volet → volet de la serre ouvert**. La mesure est traitée puis transformée en action pour aérer les semis.
