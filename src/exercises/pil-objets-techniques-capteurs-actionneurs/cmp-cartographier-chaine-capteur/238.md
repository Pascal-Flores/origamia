# Contexte

Un plateau de rangement possède un bouton, une entrée numérique, un programme, une sortie et un voyant. Les cinq éléments sont déjà identifiés ; il faut seulement représenter leur chaîne.

# Consigne

Remets-les dans l'ordre.

# Réponses

1. bouton
2. entrée numérique
3. programme
4. sortie du voyant
5. voyant

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Le bouton fournit l'information et le voyant produit l'action finale.

# Feedback essai 2

Entre les deux se trouvent l'entrée, le programme puis la sortie.

# Feedback

La chaîne complète est bouton → entrée → programme → sortie → voyant.
