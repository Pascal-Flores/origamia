# Contexte

Une chasse d’eau automatique doit détecter qu’une personne s’éloigne puis laisser passer l’eau pendant quelques secondes.

# Consigne

Observe le système. Deux éléments sont remplacés par des `?`. Quels sont les deux éléments manquants ?

# Réponses

1. Capteur de présence
2. Électrovanne
3. Capteur de température
4. Buzzer
5. Lampe LED

# Solution

1, 2

# Feedback essai 1

L’un des éléments manquants doit indiquer à la carte qu’une personne est présente ou vient de partir. L’autre doit contrôler le passage de l’eau.

# Feedback essai 2

Cherche ce qui peut détecter une présence sans contact, puis ce qui peut ouvrir ou fermer automatiquement une arrivée d’eau.

# Feedback

Il manque le **capteur de présence** et l’**électrovanne**. Le capteur transmet l’information de présence à la carte électronique ; la carte commande ensuite l’électrovanne pour laisser passer l’eau.
