# Contexte

Dans un entrepôt, un robot détecte une zone de livraison. Il traite cette information, avance avec son moteur et dépose le colis dans la zone prévue.

# Consigne

Complète la chaîne complète, puis vérifie que tu peux expliquer le trajet de l'information jusqu'à l'effet produit.

# Texte à trous

Le fonctionnement complet est : [[1]] → [[2]] → [[3]] → [[4]] → [[5]] → [[6]].

# Étiquettes

2. entrée du contrôleur

4. sortie du moteur
5. moteur du robot
6. colis déposé dans la zone
7. capteur de température
8. écran de contrôle

# Solution

1, 2, 3, 4, 5, 6

# Feedback essai 1

Suis la mesure depuis le capteur. Avant l'effet final, l'information doit entrer dans le contrôleur, être traitée, puis commander l'actionneur.

# Feedback essai 2

Le moteur est l'actionneur : il vient après sa sortie de commande. Le dépôt du colis décrit l'effet produit après le mouvement du robot.

# Feedback

Le flux est **capteur de position → entrée du contrôleur → programme de déplacement → sortie du moteur → moteur du robot → colis déposé dans la zone**. Le capteur fournit une information, la commande la traite et le moteur produit l'action.
