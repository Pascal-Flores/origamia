## Attendu retravaillé

**Compléter une chaîne simple d’information et d’action en choisissant l’élément manquant parmi des propositions fournies.**

La chaîne CM1 comporte cinq maillons visibles :

`observation → capteur → carte programmable → actionneur → effet`

Un seul maillon est masqué. L’élève choisit la réponse qui rend le fonctionnement global cohérent.

## Forme exacte

- Type : `qcu`
- Media : image raster `contexte.png`
- 3 propositions
- 2 essais
- Une seule case manquante
- Aucun paramétrage de bloc et aucun choix de valeur de capteur
- Les flèches décrivent une relation fonctionnelle, pas une séquence d’instructions

## Variantes

- 136 : abreuvoir automatique — capteur manquant
- 137 : éclairage automatique — actionneur manquant
- 138 : pont-levis de maquette — effet manquant
- 235 : distributeur de savon — actionneur manquant
- 236 : lampe de placard — capteur manquant

## Frontières avec les autres compétences

- `cmp-lire-capteur` : on ne choisit pas un bloc de lecture ni une donnée de programme.
- `cmp-configurer-actionneur` : aucun réglage d’actionneur n’est demandé.
- `cmp-piloter-actionneur-capteur` : aucune valeur de capteur n’est injectée directement dans un actionneur.
- Ici, l’objectif est de comprendre **la place et le rôle d’un maillon dans le système complet**.
