# Contexte

Un casier de retrait doit reconnaître un badge autorisé puis déverrouiller sa porte.

# Consigne

Observe le système. Deux éléments sont remplacés par des `?`. Quels sont les deux éléments manquants ?

# Réponses

1. Lecteur de badge
2. Serrure électrique
3. Capteur de température
4. Lampe LED
5. Buzzer

# Solution

1, 2

# Feedback essai 1

Les deux éléments manquants n’ont pas le même rôle : l’un récupère une information, l’autre agit sur la porte.

# Feedback essai 2

Cherche ce qui peut lire l’identifiant présenté, puis ce qui peut verrouiller ou déverrouiller mécaniquement le casier.

# Feedback

Il manque le **lecteur de badge** et la **serrure électrique**. Le lecteur transmet l’identifiant à la carte électronique ; après traitement, la carte commande la serrure pour ouvrir le casier.
