# Contexte

Dans un couloir, un système automatique allume une lampe lorsqu’il fait sombre.

# Consigne

Observe la chaîne de fonctionnement. Quel élément manque à la place du `?` ?

# Réponses

1. Lampe LED
2. Capteur de température
3. Buzzer

# Solution

1

# Feedback essai 1

Le maillon manquant se trouve après la carte programmable et avant l’effet « le couloir s’éclaire ». Il doit produire de la lumière.

# Feedback

Il manque la **lampe LED**. La carte la commande pour produire l’effet visible : éclairer le couloir.
