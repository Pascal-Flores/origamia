# Contexte

Un système d'arrosage possède une sonde d'humidité, une entrée de carte, un programme de commande, une sortie de carte et une pompe.

# Consigne

Remets les cinq éléments dans l'ordre du flux.

# Réponses

1. sonde d'humidité
2. entrée de la carte
3. programme de commande
4. sortie de la carte
5. pompe

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

L'information entre dans la carte avant d'être traitée ; l'ordre d'action vient ensuite.

# Feedback essai 2

La pompe est l'élément final qui agit physiquement.

# Feedback

La sonde fournit l'information à l'entrée, le programme la traite, la sortie transmet la commande et la pompe réalise l'action.
