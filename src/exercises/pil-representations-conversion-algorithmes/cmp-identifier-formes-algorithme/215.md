# Contexte

Une fiche de retour de livre rassemble quatre extraits écrits de façons différentes.

**Extrait A**

À l'accueil, poser le livre dans la boîte de retour puis garder le ticket.

**Extrait B**

```
Algorithme : enregistrer le retour
Début
  lire le code du livre
  enregistrer le retour
Fin
```

**Extrait C**

```blockly
event: DÉBUT
move: POSER le livre dans la boîte de retour
move: PRENDRE le ticket
end: FIN
```

**Extrait D**

Avant de partir, vérifier que le retour a bien été enregistré.

# Consigne

Coche toutes les affirmations correctes sur la **forme d'écriture** des quatre extraits.

# Réponses

1. L'extrait A est en langage naturel.
2. L'extrait B est en pseudocode.
3. L'extrait C est en blocs.
4. L'extrait D est en pseudocode.
5. L'extrait B est en blocs.
6. L'extrait D est en langage naturel.

# Solution

1, 2, 3, 6

# Feedback essai 1

Classe mentalement chaque extrait dans une forme avant de juger les affirmations. Ne te sers pas du sujet du retour de livre pour décider.

# Feedback essai 2

A et D sont des phrases ordinaires. B est structuré avec `Algorithme`, `Début` et `Fin`. C est présenté en blocs.

# Feedback

Les extraits A et D sont en langage naturel. L'extrait B est en pseudocode grâce à son cadre `Algorithme` / `Début` / `Fin`. L'extrait C est en blocs. Les affirmations correctes sont donc `1`, `2`, `3` et `6`.
