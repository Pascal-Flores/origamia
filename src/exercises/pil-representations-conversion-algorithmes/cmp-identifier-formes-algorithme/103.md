# Contexte

Voici un programme :

```
Algorithme : préparer la page
Début
  ouvrir le cahier
  écrire la date
  souligner le titre
Fin
```

# Consigne

Sous quelle forme ce programme est-il écrit ?

Choisis la réponse qui donne le bon indice.

# Réponses

1. Langage naturel : le programme est une phrase.
2. Pseudocode : on voit "Algorithme", "Début" et "Fin".
3. Blocs : les instructions sont affichées en blocs.
4. Pseudocode : il y a un personnage à déplacer.

# Solution

2

# Feedback

On reconnaît le pseudocode grâce au titre "Algorithme" et aux lignes "Début" et "Fin".
