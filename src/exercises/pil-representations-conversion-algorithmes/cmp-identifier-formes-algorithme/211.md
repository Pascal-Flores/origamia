# Contexte

Voici six extraits qui décrivent des actions possibles pour débarrasser une table. Ils ne sont pas tous écrits de la même façon.

# Consigne

Classe chaque extrait dans la bonne catégorie en observant sa **forme d'écriture**, pas l'action qu'il décrit.

# Catégories

1. Langage naturel
2. Pseudocode
3. Blocs

# Étiquettes

1. Après le repas, empile les assiettes puis pose-les près de l'évier.
2. ```
Algorithme : ranger les couverts
Début
  rassembler les couverts
  poser les couverts près de l'évier
Fin
```
3. ```blockly
event: DÉBUT
move: RAMASSER les verres
move: POSER les verres près de l'évier
end: FIN
```
4. Essuie les miettes sur la table, puis range le chiffon.
5. ```
Algorithme : ranger les verres
Début
  prendre les verres
  poser les verres près de l'évier
Fin
```
6. ```blockly
event: DÉBUT
move: EMPILER les assiettes
move: POSER les assiettes près de l'évier
end: FIN
```

# Solution

1: 1, 4
2: 2, 5
3: 3, 6

# Feedback essai 1

Regarde d'abord la présentation de chaque extrait : phrase ordinaire, texte structuré avec `Algorithme`, `Début` et `Fin`, ou blocs visuels.

# Feedback essai 2

Les extraits `2` et `5` sont encadrés comme du pseudocode. Les extraits `3` et `6` sont présentés en blocs. Les deux autres sont des phrases ordinaires.

# Feedback

Les extraits `1` et `4` sont en langage naturel. Les extraits `2` et `5` sont en pseudocode grâce au cadre `Algorithme` / `Début` / `Fin`. Les extraits `3` et `6` sont des blocs.
