# Contexte

Voici plusieurs extraits d'algorithmes.

# Consigne

Classe chaque extrait dans la bonne catégorie.

Le langage naturel utilise des phrases ordinaires. Le pseudocode écrit le programme en texte, avec une action par ligne. Les blocs sont des instructions visuelles que l'on assemble.

# Catégories

1. Langage naturel
2. Pseudocode
3. Blocs

# Étiquettes

1. Choisis un livre, note son titre, puis range-le dans le bac Romans.
2. ```blockly
event: DÉBUT
move: CHOISIR un livre
move: NOTER son titre
move: RANGER le livre dans le bac Romans
end: FIN
```
3. ```
Algorithme : emprunter un livre
Début
  choisir un livre
  noter son titre
  ranger le livre dans le bac Romans
Fin
```
4. Pour préparer la lecture, ouvre le livre et lis la première page.
5. ```
Algorithme : débuter la lecture
Début
  ouvrir le livre
  lire la première page
Fin
```
6. ```blockly
event: DÉBUT
move: OUVRIR le livre
move: LIRE la première page
end: FIN
```

# Solution

1: 1, 4
2: 3, 5
3: 2, 6
