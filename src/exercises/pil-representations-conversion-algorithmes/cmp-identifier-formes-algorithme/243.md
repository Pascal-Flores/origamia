# Contexte

Une fiche de retour de livre contient six extraits indépendants.

# Consigne

Classe-les uniquement selon leur forme d'écriture.

# Catégories

1. Langage naturel
2. Pseudo-code
3. Blocs

# Étiquettes

1. « Poser le livre dans la boîte de retour. »
2. « Vérifier le ticket. »
3. `DÉBUT\nPOSER le livre\nFIN`
4. `DÉBUT\nLIRE le ticket\nFIN`
5. `move: POSER le livre`
6. `move: LIRE le ticket`

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback essai 1

Classe d'après la présentation visible, pas d'après le sens.

# Feedback essai 2

`DÉBUT` / `FIN` indique le pseudo-code ; `move:` indique les blocs.

# Feedback

Les phrases ordinaires sont en langage naturel, les extraits encadrés sont en pseudo-code et les lignes préfixées sont des blocs.
