# Contexte

Une fiche de réparation de marque-page contient quatre extraits écrits de façons différentes.

**Extrait A**

```
Algorithme : aplatir le marque-page
Début
  poser le marque-page à plat
  maintenir le pli quelques secondes
Fin
```

**Extrait B**

Ajouter une petite bande de ruban sur la partie déchirée, puis lisser doucement.

**Extrait C**

```blockly
event: DÉBUT
move: POSER le marque-page à plat
move: AJOUTER une bande de ruban
end: FIN
```

**Extrait D**

```
Algorithme : terminer la réparation
Début
  vérifier que le ruban tient
  ranger le marque-page
Fin
```

# Consigne

Coche toutes les affirmations correctes sur la **forme d'écriture** des quatre extraits.

# Réponses

1. L'extrait A est en pseudocode.
2. L'extrait B est en blocs.
3. L'extrait C est en blocs.
4. L'extrait D est en langage naturel.
5. L'extrait B est en langage naturel.
6. L'extrait D est en pseudocode.

# Solution

1, 3, 5, 6

# Feedback essai 1

Identifie d'abord la forme de A, B, C et D séparément. Les actions décrites peuvent être proches : seule leur présentation compte.

# Feedback essai 2

A et D sont structurés avec `Algorithme`, `Début` et `Fin`. B est une phrase ordinaire. C est présenté en blocs.

# Feedback

A et D sont en pseudocode. B est en langage naturel. C est en blocs. Les affirmations correctes sont donc `1`, `3`, `5` et `6`.
