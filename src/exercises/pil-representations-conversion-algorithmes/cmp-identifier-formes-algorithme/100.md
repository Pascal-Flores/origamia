# Contexte

Voici plusieurs extraits d'algorithmes.

# Consigne

Classe chaque extrait dans la bonne catégorie.

Le langage naturel utilise des phrases ordinaires. Le pseudocode écrit le programme en texte, avec une action par ligne. Les blocs sont des instructions visuelles que l'on assemble.

# Catégories

1. Langage naturel
2. Pseudocode
3. Blocs

# Étiquettes

1. Prends ton cahier, écris la date, puis souligne le titre.
2. ```
Algorithme : préparer la page
Début
  ouvrir le cahier
  écrire la date
  souligner le titre
Fin
```
3. ```blockly
event: DÉBUT
move: PRENDRE le cahier
move: ÉCRIRE la date
move: SOULIGNER le titre
end: FIN
```
4. Pour ranger le bureau, ferme la trousse et pose le cahier dans le casier.
5. ```
Algorithme : ranger le bureau
Début
  fermer la trousse
  poser le cahier dans le casier
Fin
```
6. ```blockly
event: DÉBUT
move: FERMER la trousse
move: POSER le cahier dans le casier
end: FIN
```

# Solution

1: 1, 4
2: 2, 5
3: 3, 6

# Feedback essai 1

Commence par observer la forme, pas le sujet des instructions : phrase continue, texte ligne par ligne ou blocs visuels.

# Feedback essai 2

Les extraits avec des pièces colorées vont dans Blocs. Ceux avec Début et Fin vont dans Pseudocode ; les phrases ordinaires restent en Langage naturel.

# Feedback

Les deux phrases qui commencent par « Prends ton cahier » et « Pour ranger le bureau » sont en langage naturel. Les deux textes encadrés par « Algorithme », « Début » et « Fin » sont en pseudocode. Les deux suites de pièces colorées sont en blocs.
