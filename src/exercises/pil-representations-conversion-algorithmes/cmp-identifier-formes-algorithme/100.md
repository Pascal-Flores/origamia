# Consigne

Classe chaque extrait dans la bonne catégorie.

Le langage naturel utilise des phrases ordinaires. Le pseudocode écrit le programme en texte, avec une action par ligne. Les blocs sont des instructions visuelles que l'on assemble.

# Catégories

1. Langage naturel
2. Pseudocode
3. Blocs

# Étiquettes

1. Prends ton cahier, écris la date, puis souligne le titre.
2. ```
Algorithme : préparer la page
Début
  ouvrir le cahier
  écrire la date
  souligner le titre
Fin
```
3. ```blockly
event: DÉBUT
move: PRENDRE le cahier
move: ÉCRIRE la date
move: SOULIGNER le titre

```
4. Pour ranger le bureau, ferme la trousse et pose le cahier dans le casier.
5. ```
Algorithme : ranger le bureau
Début
  fermer la trousse
  poser le cahier dans le casier
Fin
```
6. ```blockly
