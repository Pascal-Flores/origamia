# Contexte

Voici plusieurs extraits d'algorithmes écrits sous des formes différentes.

# Consigne

Classe chaque extrait dans la bonne catégorie.

Le langage naturel utilise des phrases ordinaires. Le pseudocode écrit le programme en texte, avec une action par ligne. Les blocs sont des instructions visuelles que l'on assemble.

# Catégories

1. Langage naturel
2. Pseudocode
3. Blocs

# Étiquettes

1. ```blockly
event: DÉBUT
move: POSER la feuille sur la table
move: PRENDRE le crayon gris
end: FIN
```
2. Pour préparer le dessin, pose la feuille sur la table et prends le crayon gris.
3. ```
Algorithme : préparer le dessin
Début
  poser la feuille sur la table
  prendre le crayon gris
Fin
```
4. Mélange la peinture bleue, puis nettoie le pinceau.
5. ```blockly
event: DÉBUT
move: MÉLANGER la peinture bleue
move: NETTOYER le pinceau
end: FIN
```
6. ```
Algorithme : peinture
Début
  mélanger la peinture bleue
  nettoyer le pinceau
Fin
```

# Solution

1: 2, 4
2: 3, 6
3: 1, 5

# Feedback essai 1

Le dessin ou la peinture racontés ne déterminent pas la catégorie. Observe seulement la manière dont chaque instruction est écrite.

# Feedback essai 2

Les éléments colorés emboîtés sont des blocs. Début et Fin signalent le pseudocode ; une phrase complète signale le langage naturel.

# Feedback

Les phrases « Pour préparer le dessin » et « Mélange la peinture bleue » sont en langage naturel. Les deux textes avec « Algorithme », « Début » et « Fin » sont en pseudocode. Les deux suites de pièces colorées sont en blocs.
