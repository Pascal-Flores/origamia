# Contexte

Voici un programme :

Avant de partir, vérifie ton agenda, range la trousse, puis ferme le cartable.

# Consigne

Sous quelle forme ce programme est-il écrit ?

Choisis la réponse qui donne le bon indice.

# Réponses

1. Pseudocode : le programme commence par "Algorithme".
2. Blocs : les instructions sont dans une image.
3. Langage naturel : le programme est une phrase de consigne.
4. Langage naturel : il contient les lignes "Début" et "Fin".

# Solution

3

# Feedback

Ce programme est une phrase de consigne : c'est du langage naturel.
