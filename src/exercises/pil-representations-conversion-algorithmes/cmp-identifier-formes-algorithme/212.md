# Contexte

Voici six extraits qui décrivent des actions de pliage ou de rangement de vêtements. Ils utilisent trois formes d'écriture différentes.

# Consigne

Classe chaque extrait dans la bonne catégorie en observant uniquement sa forme d'écriture.

# Catégories

1. Langage naturel
2. Pseudocode
3. Blocs

# Étiquettes

1. Plie le tee-shirt puis pose-le dans le tiroir du haut.
2. ```blockly
event: DÉBUT
move: PLIER le pantalon
move: RANGER le pantalon dans le tiroir
end: FIN
```
3. ```
Algorithme : ranger les chaussettes
Début
  rassembler les chaussettes par paire
  mettre les paires dans le tiroir
Fin
```
4. Range le pull sur l'étagère de l'armoire.
5. ```blockly
event: DÉBUT
move: PLIER le pull
move: POSER le pull sur l'étagère
end: FIN
```
6. ```
Algorithme : plier le tee-shirt
Début
  plier le tee-shirt
  poser le tee-shirt dans le tiroir
Fin
```

# Solution

1: 1, 4
2: 3, 6
3: 2, 5
