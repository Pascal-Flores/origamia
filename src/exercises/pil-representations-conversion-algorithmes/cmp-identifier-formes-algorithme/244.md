# Contexte

Une fiche de réparation de marque-page mélange plusieurs écritures.

# Consigne

Classe chaque extrait selon sa forme.

# Catégories

1. Langage naturel
2. Pseudo-code
3. Blocs

# Étiquettes

1. « Poser le marque-page à plat. »
2. « Ajouter une bande de ruban. »
3. `DÉBUT\nPOSER le marque-page\nFIN`
4. `DÉBUT\nAJOUTER le ruban\nFIN`
5. `move: POSER le marque-page`
6. `move: AJOUTER le ruban`

# Solution

1: 1, 2
2: 3, 4
3: 5, 6

# Feedback essai 1

Cherche les indices de forme : phrases, cadre de pseudo-code, préfixes de blocs.

# Feedback essai 2

Ne cherche pas si les actions sont bonnes ; seule leur écriture est évaluée.

# Feedback

Les six extraits se répartissent en deux phrases, deux pseudo-codes et deux blocs.
