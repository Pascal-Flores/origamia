# Contexte

Le document contient six extraits indépendants.

# Consigne

Classe-les uniquement d'après leur forme d'écriture.

# Items

1. « Attendre une seconde puis afficher une étoile. »
2. `move: ATTENDRE (1) seconde`
3. ```
DÉBUT
AFFICHER une étoile
FIN
```
4. « Tourner à droite. »
5. `move: TOURNER à droite`
6. ```
DÉBUT
AVANCER de 4 cases
FIN
```
