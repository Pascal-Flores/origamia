# Contexte

Voici quatre extraits.

**Extrait A**

```
Algorithme : ranger le matériel
Début
  fermer la boîte de feutres
  poser la boîte sur l'étagère
Fin
```

**Extrait B**

Ferme la boîte de feutres, puis pose-la sur l'étagère.

**Extrait C**

```blockly
event: DÉBUT
move: FERMER la boîte de feutres
move: POSER la boîte sur l'étagère
end: FIN
```

**Extrait D**

```
Algorithme : nettoyer la table
Début
  jeter les papiers
  essuyer la table
Fin
```

# Consigne

Coche toutes les affirmations correctes.

# Réponses

1. L'extrait A est en pseudocode.
2. L'extrait B est en langage naturel.
3. L'extrait C est en blocs.
4. L'extrait D est en pseudocode.
5. L'extrait A est en langage naturel.
6. L'extrait B est en blocs.

# Solution

1, 2, 3, 4

# Feedback
