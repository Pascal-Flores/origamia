# Contexte

On veut convertir ce pseudo-code en langage naturel.

**Pseudo-code**

```
Algorithme : ranger le document
Début
  placer la feuille d'activité dans le classeur d'histoire
  fermer le classeur
  remettre le classeur dans le casier
Fin
```

**Conversion commencée**

Pour ranger le document, mettre la feuille d'activité dans le classeur d'histoire, ..., puis déposer le classeur dans le casier.

# Consigne

Quelle partie faut-il choisir pour compléter la phrase ?

# Réponses

1. fermer le classeur
2. ouvrir le classeur
3. poser la feuille dans le casier
4. ranger le classeur d'histoire dans la trousse

# Solution

1

# Feedback essai 1

La partie manquante correspond à l'action placée entre le rangement de la feuille et le retour du classeur dans le casier.

# Feedback

La conversion doit garder les trois actions dans le même ordre. Après avoir mis la feuille dans le classeur, il faut le fermer avant de le déposer dans le casier.
