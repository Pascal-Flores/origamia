# Contexte

Source :

```
RÉPÉTER 2 FOIS
  LIRE une page
FIN RÉPÉTER
ÉTEINDRE la lumière
```

Une conversion indique par erreur « lire une page trois fois puis éteindre la lumière ».

# Consigne

Complète la correction.

# Texte à trous

La conversion conserve bien l'action [[1]], mais le nombre de répétitions doit être [[2]] et non 3. L'action [[3]] reste placée après la répétition.

# Étiquettes

1. lire une page
2. 2
3. éteindre la lumière
4. 3
5. allumer la lumière

# Solution

1, 2, 3

# Feedback essai 1

Compare précisément le nombre de répétitions et l'action placée hors de la boucle.

# Feedback essai 2

La source répète la lecture deux fois seulement.

# Feedback

La correction doit rétablir 2 répétitions et conserver l'extinction de la lumière après la boucle.
