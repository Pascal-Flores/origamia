# Contexte

On veut convertir cette phrase en blocs.

**Langage naturel**

Marquer trois cartes atelier avec le tampon, puis remettre le tampon à sa place.

**Conversion proposée**

```blockly
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: TAMPONNER une carte atelier
move: RANGER le tampon
end: FIN
```

La conversion contient une erreur sur le nombre de répétitions.

# Consigne

Complète le texte qui corrige la conversion.

# Texte à trous

Pour obtenir une conversion correcte en blocs, le bloc de répétition doit indiquer [[1]]. Le bloc placé dans la répétition doit représenter [[2]]. Le bloc placé après la répétition doit représenter [[3]].

# Étiquettes

1. répéter 3 fois
2. marquer une carte atelier avec le tampon
3. remettre le tampon à sa place
4. répéter 2 fois
5. marquer trois cartes en une seule action
6. remettre trois tampons à leur place

# Solution

1, 2, 3

# Feedback

La phrase demande trois cartes : la répétition doit donc être de 3. L'action répétée concerne une carte atelier, puis le tampon est rangé après la répétition.
