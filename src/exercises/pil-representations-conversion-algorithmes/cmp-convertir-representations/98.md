# Contexte

On veut convertir ce pseudo-code en langage naturel.

**Pseudo-code**

```
Algorithme : laver les pinceaux
Début
  répéter 4 fois
    rincer un pinceau
  essuyer le pot
Fin
```

**Conversion proposée**

Passer quatre pinceaux sous l'eau, puis ranger le pot.

La conversion contient une erreur sur l'action finale.

# Consigne

Complète le texte qui corrige la conversion.

# Texte à trous

La conversion correcte en langage naturel doit dire : [[1]], puis [[2]]. L'action répétée concerne [[3]], tandis que l'action faite après la répétition concerne [[4]].

# Étiquettes

1. passer quatre pinceaux sous l'eau
2. sécher le pot
3. les pinceaux
4. le pot
5. ranger le pot
6. passer trois pinceaux sous l'eau
7. les cahiers

# Solution

1, 2, 3, 4

# Feedback

Le pseudo-code répète quatre fois le rinçage d'un pinceau, puis demande d'essuyer le pot. La conversion corrigée doit donc parler de quatre pinceaux rincés, puis du pot essuyé.
