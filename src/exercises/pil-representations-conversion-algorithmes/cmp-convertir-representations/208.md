# Contexte

On veut convertir ces blocs en langage naturel.

**Blocs**

```blockly
event: DÉBUT
move: POSER le tee-shirt sur la chaise
move: POSER le pantalon sur la chaise
move: PLACER les chaussettes sur le pantalon
end: FIN
```

**Conversion commencée**

Pour préparer les vêtements du lendemain, poser le tee-shirt sur la chaise, ..., puis placer les chaussettes sur le pantalon.

# Consigne

Quelle partie faut-il choisir pour compléter la phrase ?

# Réponses

1. poser le pantalon sur la chaise
2. ranger le pantalon dans l'armoire
3. poser le pyjama sur la chaise
4. placer le pantalon sur le tee-shirt

1

# Feedback essai 1

Cherche l'action située entre le tee-shirt et les chaussettes dans les blocs. La phrase doit conserver l'objet, l'action et le lieu.

# Feedback

La partie manquante doit traduire le deuxième bloc : **poser le pantalon sur la chaise**. Les autres propositions changent l'objet, l'action ou sa destination.
