# Contexte

On veut convertir ces blocs en pseudo-code.

**Blocs**

```blockly
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  say: DIRE "Bienvenue"
move: SALUER le groupe
end: FIN
```

**Conversion proposée**

```
Algorithme : répéter une phrase
Début
  répéter 3 fois
    annoncer "Bienvenue"
    faire un salut au groupe
Fin
```

La conversion contient une erreur : le salut au groupe est placé dans la répétition.

# Consigne

Complète le texte qui corrige la conversion.

# Texte à trous

Dans la conversion corrigée, la répétition doit être [[1]]. À l'intérieur de cette répétition, on place seulement [[2]]. Après la répétition, on place [[3]].

# Étiquettes

1. répéter 3 fois
2. annoncer "Bienvenue"
3. faire un salut au groupe
4. répéter 2 fois
5. annoncer "Bienvenue" et faire un salut au groupe
6. supprimer le salut au groupe

# Solution

1, 2, 3

# Feedback essai 1

Si je salue à chaque fois que je dis « Bienvenue », je vais faire beaucoup de saluts ! Est-ce que les blocs disent ça ?

# Feedback essai 2

Moi, je cherche où s’arrête la répétition dans les blocs. Dans le texte, est-ce qu’on a mis le salut du même côté ?

# Feedback

On a trouvé où la boucle s’arrête. On dit « Bienvenue » trois fois et on salue une seule fois après. Un seul salut suffit !
