# Contexte

On veut convertir ces blocs en pseudo-code.

**Blocs**

```blockly
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  say: DIRE "Bienvenue"
move: SALUER le groupe
end: FIN
```

**Conversion proposée**

```
Algorithme : répéter une phrase
Début
  répéter 3 fois
    annoncer "Bienvenue"
    faire un salut au groupe
Fin
```

La conversion contient une erreur : le salut au groupe est placé dans la répétition.

# Consigne

Complète le texte qui corrige la conversion.

# Texte à trous

Dans la conversion corrigée, la répétition doit être [[1]]. À l'intérieur de cette répétition, on place seulement [[2]]. Après la répétition, on place [[3]].

# Étiquettes

1. répéter 3 fois
2. annoncer "Bienvenue"
3. faire un salut au groupe
4. répéter 2 fois
5. annoncer "Bienvenue" et faire un salut au groupe
6. supprimer le salut au groupe

# Solution

1, 2, 3

# Feedback essai 1

Observe les limites de la répétition dans les blocs : tout ce qui vient après sa fermeture ne doit pas être répété.

# Feedback essai 2

La phrase « Bienvenue » est répétée trois fois. Le salut n'a lieu qu'une fois, après la répétition.

# Feedback

Dans les blocs, seule la phrase "Bienvenue" est répétée trois fois. Le salut au groupe vient après la répétition, donc il doit rester en dehors de la répétition dans la conversion.
