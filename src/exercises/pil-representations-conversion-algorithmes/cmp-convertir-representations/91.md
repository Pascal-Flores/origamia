# Contexte

On veut convertir cette instruction en blocs : Fixer sur le cahier de lecture l'étiquette qui porte le prénom.

# Consigne

Choisis la suite de blocs qui représente exactement la même instruction.

# Réponses

1. ```blockly
event: DÉBUT
move: COLLER l'étiquette prénom sur le cahier de lecture
end: FIN
```
2. ```blockly
event: DÉBUT
move: COLLER l'étiquette prénom sur le carnet de liaison
end: FIN
```
3. ```blockly
event: DÉBUT
move: COLLER l'étiquette lecture sur le cahier de lecture
end: FIN
```
4. ```blockly
event: DÉBUT
move: ÉCRIRE le prénom sur le cahier de lecture
end: FIN
```
