# Contexte

On veut convertir cette instruction en blocs :

Poser le bol dans l'évier.

# Consigne

Choisis la suite de blocs qui représente exactement la même instruction.

# Réponses

1. ```blockly
event: DÉBUT
move: POSER le bol dans l'évier
end: FIN
```
2. ```blockly
event: DÉBUT
move: POSER l'assiette dans l'évier
end: FIN
```
3. ```blockly
event: DÉBUT
move: POSER le bol sur la table
end: FIN
```
4. ```blockly
event: DÉBUT
move: PRENDRE le bol dans l'évier
end: FIN
```

# Feedback essai 1

Imaginons qu’on débarrasse la table. Quel objet bouge et où va-t-il ?

# Feedback essai 2

Deux blocs peuvent parler du même bol. Est-ce que le geste et l’endroit où il finit sont aussi les mêmes ?

# Feedback

En posant le bol dans l’évier, on suit bien la phrase. Le bloc garde le même geste, le même objet et le même endroit. On garde ce repère.
