# Contexte

On veut convertir cette instruction en blocs :

Poser le bol dans l'évier.

# Consigne

Choisis la suite de blocs qui représente exactement la même instruction.

# Réponses

1. ```blockly
event: DÉBUT
move: POSER le bol dans l'évier
end: FIN
```
2. ```blockly
event: DÉBUT
move: POSER l'assiette dans l'évier
end: FIN
```
3. ```blockly
event: DÉBUT
move: POSER le bol sur la table
end: FIN
```
4. ```blockly
event: DÉBUT
move: PRENDRE le bol dans l'évier
end: FIN
```

# Solution

1

# Feedback essai 1

Compare séparément l'action, l'objet déplacé et l'endroit où il doit être posé. Aucun de ces trois éléments ne doit changer pendant la conversion.

# Feedback

La réponse `1` conserve exactement l'instruction source : il faut **poser** le **bol** dans **l'évier**. Les autres propositions changent soit l'objet, soit le lieu, soit l'action.
