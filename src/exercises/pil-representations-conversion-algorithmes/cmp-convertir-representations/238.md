# Contexte

Source : « Répéter 5 fois : afficher un point puis attendre 1 seconde. »

La conversion erronée répète 5 fois uniquement l'affichage, puis attend 1 seconde après la boucle.

# Consigne

Complète la correction.

# Texte à trous

L'instruction `ATTENDRE 1 seconde` doit être placée [[1]] la boucle, après [[2]]. Le nombre de répétitions reste [[3]].

# Étiquettes

1. dans
2. AFFICHER un point
3. 5
4. après
5. 1

# Solution

1, 2, 3

# Feedback essai 1

Dans la source, l'attente fait partie de chaque répétition.

# Feedback essai 2

Le nombre de répétitions n'est pas l'erreur ici.

# Feedback

L'attente doit être dans la boucle, après l'affichage du point, et la boucle reste répétée cinq fois.
