# Contexte

Source :

```
RÉPÉTER 4 FOIS
  PRENDRE un objet
  RANGER l'objet
FIN RÉPÉTER
FERMER la boîte
```

La conversion proposée dit « répéter 3 fois : prendre un objet ; puis fermer la boîte dans la répétition ».

# Consigne

Complète la correction.

# Texte à trous

Il faut remplacer 3 par [[1]]. L'instruction [[2]] doit aussi être répétée avec `PRENDRE un objet`. Enfin, `FERMER la boîte` doit rester [[3]] de la répétition.

# Étiquettes

1. 4
2. RANGER l'objet
3. hors
4. 2
5. dans

# Solution

1, 2, 3

# Feedback essai 1

Vérifie le nombre de répétitions, les instructions répétées et l'action finale.

# Feedback essai 2

Le rangement fait partie du motif répété ; la fermeture n'en fait pas partie.

# Feedback

La version correcte répète quatre fois « prendre ; ranger » et ferme la boîte une seule fois après la boucle.
