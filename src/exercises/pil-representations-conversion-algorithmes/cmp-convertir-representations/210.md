# Contexte

On veut convertir ce pseudo-code en langage naturel.

**Pseudo-code**

```
Algorithme : préparer l'exposition
Début
  répéter 3 fois
    accrocher une œuvre
    placer son étiquette sous l'œuvre
  ouvrir l'exposition
Fin
```

**Conversion proposée**

Répéter deux fois : accrocher une œuvre et placer son étiquette, puis ouvrir l'exposition à chaque répétition.

Cette conversion change à la fois le nombre de répétitions et la place de l'action finale.

# Consigne

Complète le texte qui rétablit exactement le sens du pseudo-code.

# Texte à trous

La conversion corrigée doit indiquer [[1]]. À l'intérieur de cette répétition, il faut d'abord [[2]], puis [[3]]. Une fois toutes les répétitions terminées, il faut [[4]].

# Étiquettes

1. répéter 3 fois
2. accrocher une œuvre
3. placer son étiquette sous l'œuvre
4. ouvrir l'exposition
5. répéter 2 fois
6. ouvrir l'exposition après chaque œuvre
7. ranger les œuvres

# Solution

1, 2, 3, 4

# Feedback essai 1

Compare quatre éléments : le nombre de répétitions, les deux actions qui composent le motif répété, puis l'action placée après la répétition.

# Feedback essai 2

Le pseudo-code répète trois fois le couple « accrocher une œuvre ; placer son étiquette ». L'ouverture de l'exposition ne fait pas partie de ce motif : elle arrive une seule fois, à la fin.

# Feedback

La conversion correcte doit dire **répéter 3 fois**, puis conserver à l'intérieur les deux actions dans leur ordre : **accrocher une œuvre**, puis **placer son étiquette**. L'action **ouvrir l'exposition** reste hors de la répétition et n'est exécutée qu'une seule fois après les trois œuvres.
