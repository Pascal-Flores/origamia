## Forme de référence

Chaque variante comporte :

1. trois instructions de référence appartenant à une même préparation ;
2. les trois instructions sont présentées sous des formes différentes ;
3. six étiquettes, soit deux représentations équivalentes pour chaque instruction ;
4. l'élève regroupe les six versions sous les trois catégories ;
5. les correspondances reposent sur le sens et non sur la copie exacte des mots ;
6. `type: ddc`, `essais: 3`, avec deux feedbacks progressifs puis un feedback final qui explicite les trois familles.

## Retour utilisateur et problème identifié

- 2026-09-03 : l'utilisateur juge 223–224 beaucoup plus simples que leurs variantes de référence.
- Le nombre de catégories et d'étiquettes était correct, mais les trois familles étaient trop éloignées : `trier / suivre / ranger` pour 223 et `film / popcorn / lumière` pour 224.
- Il était possible de réussir presque uniquement en repérant le verbe ou le champ lexical, sans comparer précisément les informations portées par les représentations.

## Nouvelle décision de difficulté

La structure reste identique à 76–78, mais les familles deviennent volontairement proches.

### 223 — LEGO

Les trois catégories portent toutes sur les **mêmes quatre briques rouges**. Il faut distinguer :

- les sortir du bac ;
- les poser sur le plateau ;
- les remettre dans le bac.

Les mots `4`, `briques` et `rouges` ne suffisent donc plus pour apparier les représentations : il faut comprendre le sens de l'action et la destination.

### 224 — soirée cinéma

Les trois catégories sont des **réglages numériques proches** :

- volume à `30 %` ;
- luminosité à `30 %` ;
- volume à `50 %`.

L'élève doit comparer conjointement la propriété réglée et la valeur. Une correspondance basée seulement sur `30 %` ou seulement sur `volume` mène à une erreur.
