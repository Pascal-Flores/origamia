# Contexte

Voici une instruction :

Placer une pièce bleue dans le coin supérieur gauche du cadre.

# Consigne

Choisis la version qui dit exactement la même chose.

# Réponses

1. Placer une pièce bleue dans le coin inférieur gauche du cadre.
2. ```blockly
event: DÉBUT
move: POSER la pièce bleue dans le coin supérieur gauche du cadre
end: FIN
```
3. ```blockly
event: DÉBUT
move: POSER la pièce rouge dans le coin supérieur gauche du cadre
end: FIN
```
4. Retirer une pièce bleue du coin supérieur gauche du cadre.

# Solution

2

# Feedback essai 1

Pour comparer deux versions, on pourrait vérifier une chose à la fois. Qu’est-ce qu’on fait, avec quelle pièce et où ?

# Feedback essai 2

Les coins se ressemblent. Est-ce que notre choix garde aussi le côté et la hauteur indiqués dans la phrase ?

# Feedback

On pose une pièce bleue dans le coin supérieur gauche. Si le geste, la pièce ou le coin change, on n’obtient plus la même chose.
