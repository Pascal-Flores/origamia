# Contexte

Voici une instruction :

Placer une pièce bleue dans le coin supérieur gauche du cadre.

# Consigne

Choisis la version qui dit exactement la même chose.

# Réponses

1. Placer une pièce bleue dans le coin inférieur gauche du cadre.
2. ```blockly
event: DÉBUT
move: POSER la pièce bleue dans le coin supérieur gauche du cadre
end: FIN
```
3. ```blockly
event: DÉBUT
move: POSER la pièce rouge dans le coin supérieur gauche du cadre
end: FIN
```
4. Retirer une pièce bleue du coin supérieur gauche du cadre.

# Solution

2

# Feedback essai 1

Je tiens une pièce et je vois quatre coins. Est-ce que notre choix me fait faire exactement le même geste que la phrase ?

# Feedback essai 2

Moi, je pourrais viser le bon côté et me tromper entre le haut et le bas. Est-ce qu’on garde aussi la bonne pièce ?

# Feedback

Ça valait le coup de suivre la pièce ! On pose une pièce bleue dans le coin supérieur gauche. Si on la retire, ce n’est plus le même geste.
