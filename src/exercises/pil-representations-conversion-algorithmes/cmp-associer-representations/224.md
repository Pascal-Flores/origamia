# Contexte

Voici trois instructions d'une même préparation de soirée cinéma. Elles ne sont pas écrites de la même façon.

# Consigne

Dépose chaque version sous l'instruction qui veut dire la même chose.

# Catégories

1. Choisir le film de la soirée.
2. ```blockly
event: DÉBUT
move: PRÉPARER un bol de popcorn
end: FIN
```
3. ```
Algorithme : tamiser la lumière
Début
  baisser la lumière du salon
Fin
```

# Étiquettes

1. ```
Algorithme : choisir le film
Début
  sélectionner le film de la soirée
Fin
```
2. Préparer un bol de popcorn.
3. ```blockly
event: DÉBUT
move: BAISSER la lumière du salon
end: FIN
```
4. ```blockly
event: DÉBUT
move: SÉLECTIONNER le film de la soirée
end: FIN
```
5. ```
Algorithme : préparer le popcorn
Début
  préparer un bol de popcorn
Fin
```
6. Diminuer la lumière du salon.

# Solution

1: 1, 4
2: 2, 5
3: 3, 6

# Feedback essai 1

Ignore la forme d'écriture et cherche ce que chaque version fait réellement : choisir, préparer ou modifier la lumière.

# Feedback essai 2

Forme trois familles : **choisir le film**, **préparer le popcorn** et **baisser la lumière**.

# Feedback

Les versions `1` et `4` choisissent le film de la soirée. Les versions `2` et `5` préparent un bol de popcorn. Les versions `3` et `6` diminuent la lumière du salon. Les mots changent parfois, mais l'action et le résultat restent les mêmes dans chaque famille.
