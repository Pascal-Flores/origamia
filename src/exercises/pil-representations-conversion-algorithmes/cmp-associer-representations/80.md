# Contexte

Voici le programme de départ :

# Consigne

```
event: DÉBUT
move: PLACER les cahiers à gauche
move: PLACER les manuels à droite
move: METTRE la trousse devant
end: FIN
```

Coche toutes les versions qui disent exactement la même chose.
# Réponses

1. Placer les cahiers à gauche, placer les manuels à droite, puis mettre la trousse devant.
2. Placer les manuels à gauche, placer les cahiers à droite, puis mettre la trousse devant.
3. ```
event: DÉBUT
move: PLACER les cahiers à gauche
move: PLACER les manuels à droite
move: METTRE la trousse derrière
end: FIN
```
4. ```
event: DÉBUT
move: PLACER les cahiers à gauche
move: PLACER les manuels à droite
move: METTRE la trousse devant
end: FIN
```

# Solution

1, 4

# Feedback

Les réponses `1` et `4` gardent les mêmes objets, les mêmes emplacements et le même ordre. La réponse `2` inverse les emplacements des cahiers et des manuels ; la réponse `3` change l’emplacement de la trousse.
