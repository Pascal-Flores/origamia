# Contexte

Voici un pseudo-code :

```
Algorithme : apprendre la poésie
Début
  Répéter 2 fois :
    lire la première strophe
  réciter sans regarder
Fin
```

# Consigne

Coche toutes les versions qui gardent exactement le même sens.

# Réponses

1. Lire la première strophe, la relire une deuxième fois, puis réciter sans regarder.
2. ```blockly
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: LIRE la première strophe
move: RÉCITER sans regarder
end: FIN
```
3. Réciter sans regarder, puis lire la première strophe deux fois.
4. ```blockly
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: LIRE la première strophe
  move: RÉCITER sans regarder
end: FIN
```

# Solution

1, 2

# Feedback

Les réponses `1` et `2` disent la même chose que le pseudo-code : la lecture est répétée deux fois, puis on récite. La réponse `3` change l'ordre, et la réponse `4` répète aussi la récitation.
