# Contexte

Référence : « Répéter 4 fois : avancer de 2 cases puis tourner à droite. »

# Consigne

Quelles représentations ont exactement le même sens ?

# Réponses

1. ```
RÉPÉTER 4 FOIS
  AVANCER de 2 cases
  TOURNER à droite
FIN RÉPÉTER
```
2. ```
RÉPÉTER 4 FOIS
  TOURNER à droite
  AVANCER de 2 cases
FIN RÉPÉTER
```
3. ```
repeat: RÉPÉTER (4) FOIS
move: AVANCER de (2) cases
move: TOURNER à droite
controla: FIN RÉPÉTER
```
4. ```
RÉPÉTER 2 FOIS
  AVANCER de 4 cases
  TOURNER à droite
FIN RÉPÉTER
```

# Solution

1, 3

# Feedback essai 1

L'équivalence exige le même nombre de répétitions, le même ordre et les mêmes paramètres.

# Feedback essai 2

Ne remplace pas une répétition par une autre simplement parce que la distance totale semble proche.

# Feedback

Les représentations 1 et 3 conservent exactement les quatre répétitions, l'avance de deux cases puis le virage à droite.
