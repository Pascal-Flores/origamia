# Contexte

L'instruction source est :

```
RÉPÉTER 3 FOIS
  PLIER le bord vers le centre
FIN RÉPÉTER
```

# Consigne

Sélectionne les représentations qui ont exactement le même sens.

# Réponses

1. « Plier le bord vers le centre trois fois. »
2. `repeat: RÉPÉTER (3) FOIS` puis `move: PLIER le bord vers le centre`
3. « Plier trois bords différents une fois chacun. »
4. `repeat: RÉPÉTER (2) FOIS` puis `move: PLIER le bord vers le centre`

# Solution

1, 2

# Feedback essai 1

Vérifie à la fois l'action répétée et le nombre de répétitions.

# Feedback essai 2

Trois fois la même action n'est pas équivalent à deux fois ni à trois actions différentes.

# Feedback

Les réponses 1 et 2 conservent exactement la répétition de la même action trois fois.
