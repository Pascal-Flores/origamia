# Contexte

On veut représenter cette action sous forme d’instruction :

Ouvrir les volets.

# Consigne

Choisis l’instruction qui dit exactement la même chose.
# Réponses

1. `move: FERMER les volets`
2. `move: OUVRIR les volets`
3. `say: ALLUMER la lumière`

# Solution

2

# Feedback

La phrase demande d’ouvrir les volets. L’instruction équivalente doit donc garder la même action et le même objet : `OUVRIR les volets`.
