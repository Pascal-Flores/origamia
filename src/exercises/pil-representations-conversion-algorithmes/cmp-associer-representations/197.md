# Contexte

Voici un pseudo-code qui représente une étape d'origami :

```
Algorithme : préparer les plis
Début
  Répéter 3 fois :
    plier le bord vers le centre
  retourner le modèle
Fin
```

# Consigne

Coche toutes les versions qui gardent exactement le même sens.

# Réponses

1. Plier le bord vers le centre trois fois, puis retourner le modèle une seule fois.
2. ```blockly
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: PLIER le bord vers le centre
move: RETOURNER le modèle
end: FIN
```
3. ```blockly
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: PLIER le bord vers le centre
  move: RETOURNER le modèle
end: FIN
```
4. ```
Algorithme : préparer les plis
Début
  Répéter 2 fois :
    plier le bord vers le centre
  retourner le modèle
Fin
```

# Solution

1, 2

# Feedback essai 1

Repère précisément **ce qui est répété**, **combien de fois**, puis l'action qui doit seulement se produire après la répétition.

# Feedback essai 2

Le pli est effectué `3` fois. Le modèle est retourné **une seule fois**, après les trois plis.

# Feedback

Les réponses `1` et `2` conservent exactement la séquence : trois plis, puis un seul retournement. La réponse `3` place le retournement dans la boucle et le répète donc trois fois. La réponse `4` ne réalise que deux plis.
