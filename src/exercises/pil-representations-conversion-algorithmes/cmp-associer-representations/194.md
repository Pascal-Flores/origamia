# Contexte

Voici une instruction :

Donner l'indice numéro 2 à l'équipe bleue.

# Consigne

Choisis la version qui dit exactement la même chose.

# Réponses

1. ```blockly
event: DÉBUT
move: DONNER l'indice (2) à l'équipe rouge
end: FIN
```
2. Donner l'indice numéro 3 à l'équipe bleue.
3. ```blockly
event: DÉBUT
move: DONNER l'indice (2) à l'équipe bleue
end: FIN
```
4. Cacher l'indice numéro 2 à l'équipe bleue.

# Solution

3

# Feedback essai 1

Compare l'action demandée, le numéro de l'indice et l'équipe qui doit le recevoir.

# Feedback

La réponse `3` garde exactement les trois informations : **donner** l'indice **2** à l'équipe **bleue**. La réponse `1` change l'équipe, la `2` change le numéro et la `4` change l'action.
