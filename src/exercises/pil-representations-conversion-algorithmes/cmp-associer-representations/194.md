# Contexte

Voici une instruction :

Donner l'indice numéro 2 à l'équipe bleue.

# Consigne

Choisis la version qui dit exactement la même chose.

# Réponses

1. ```blockly
event: DÉBUT
move: DONNER l'indice (2) à l'équipe rouge
end: FIN
```
2. Donner l'indice numéro 3 à l'équipe bleue.
3. ```blockly
event: DÉBUT
move: DONNER l'indice (2) à l'équipe bleue
end: FIN
```
4. Cacher l'indice numéro 2 à l'équipe bleue.

# Solution

3

# Feedback essai 1

J’ai un indice à distribuer. Il serait dommage qu’il arrive à la mauvaise équipe ! Qu’est-ce qu’on transmet et à qui ?

# Feedback essai 2

Moi, je peux avoir la bonne équipe et le mauvais indice. Est-ce que l’action et le numéro restent les mêmes dans notre version ?

# Feedback

Pas cette fois, mais on a bien suivi l’indice. On donne le numéro 2 à l’équipe bleue. Si le numéro ou l’équipe change, le jeu change aussi.
