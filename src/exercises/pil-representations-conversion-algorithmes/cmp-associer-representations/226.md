# Contexte

Référence : « Répéter 3 fois : afficher une étoile, attendre 1 seconde. »

# Consigne

Sélectionne toutes les représentations équivalentes.

# Réponses

1. ```
RÉPÉTER 3 FOIS
  AFFICHER une étoile
  ATTENDRE 1 seconde
FIN RÉPÉTER
```
2. ```
repeat: RÉPÉTER (3) FOIS
say: AFFICHER une étoile
move: ATTENDRE (1) seconde
controla: FIN RÉPÉTER
```
3. ```
RÉPÉTER 3 FOIS
  ATTENDRE 1 seconde
FIN RÉPÉTER
AFFICHER une étoile
```
4. ```
RÉPÉTER 1 FOIS
  AFFICHER trois étoiles
  ATTENDRE 3 secondes
FIN RÉPÉTER
```

# Solution

1, 2

# Feedback essai 1

Les deux actions doivent rester ensemble dans la boucle.

# Feedback essai 2

Le nombre 3 indique trois exécutions successives du même groupe, pas une transformation globale des paramètres.

# Feedback

Les propositions 1 et 2 décrivent exactement les trois répétitions de l'affichage puis de l'attente.
