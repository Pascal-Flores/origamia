# Contexte

Le pseudo-code source dit :

```
RÉPÉTER 3 FOIS
  ATTRIBUER le rôle suivant
FIN RÉPÉTER
```

# Consigne

Quelles propositions sont équivalentes ?

# Réponses

1. « Attribuer le rôle suivant trois fois. »
2. `repeat: RÉPÉTER (3) FOIS` puis `move: ATTRIBUER le rôle suivant`
3. `repeat: RÉPÉTER (4) FOIS` puis `move: ATTRIBUER le rôle suivant`
4. « Attribuer le même rôle une seule fois. »

# Solution

1, 2

# Feedback essai 1

Le nombre de répétitions doit rester 3.

# Feedback essai 2

L'action à l'intérieur de la répétition doit elle aussi rester identique.

# Feedback

Les réponses 1 et 2 conservent les trois répétitions de l'instruction source.
