# Contexte

Voici trois instructions d'une même préparation de séance LEGO. Elles ne sont pas écrites de la même façon.

# Consigne

Dépose chaque version sous l'instruction qui veut dire la même chose.

# Catégories

1. Trier les pièces par couleur.
2. ```blockly
event: DÉBUT
move: SUIVRE l'étape (3) du modèle
end: FIN
```
3. ```
Algorithme : ranger les pièces
Début
  mettre les pièces dans la boîte
Fin
```

# Étiquettes

1. ```blockly
event: DÉBUT
move: TRIER les pièces selon leur couleur
end: FIN
```
2. ```
Algorithme : suivre le modèle
Début
  réaliser l'étape 3 du modèle
Fin
```
3. Ranger les pièces dans la boîte.
4. ```
Algorithme : trier les pièces
Début
  regrouper les pièces par couleur
Fin
```
5. Réaliser l'étape numéro 3 du modèle.
6. ```blockly
event: DÉBUT
move: METTRE les pièces dans la boîte
end: FIN
```

# Solution

1: 1, 4
2: 2, 5
3: 3, 6

# Feedback essai 1

Ne te fie pas à la forme d'écriture. Pour chaque version, repère l'action réalisée et l'objet concerné.

# Feedback essai 2

Forme trois familles : **trier les pièces**, **suivre l'étape 3** et **ranger les pièces dans la boîte**.

# Feedback

La première famille regroupe les deux versions qui trient les pièces par couleur (`1` et `4`). La deuxième regroupe les versions qui demandent de réaliser l'étape `3` du modèle (`2` et `5`). La troisième regroupe les versions qui rangent les pièces dans la boîte (`3` et `6`).
