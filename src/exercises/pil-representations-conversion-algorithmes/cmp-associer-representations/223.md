# Contexte

Un carnet de lecture contient trois instructions en langage naturel.

# Consigne

Associe chaque phrase à son bloc équivalent.

# Catégories

1. Noter le numéro de page.
2. Écrire une phrase d'avis.
3. Ranger le carnet.

# Étiquettes

1. `move: NOTER le numéro de page`
2. `move: ÉCRIRE une phrase d'avis`
3. `move: RANGER le carnet`

# Solution

1: 1
2: 2
3: 3

# Feedback essai 1

Cherche le même verbe et le même objet dans chaque paire.

# Feedback essai 2

Aucune action ne change : seule la forme d'écriture change.

# Feedback

Les trois correspondances conservent exactement action et objet.
