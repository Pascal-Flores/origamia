# Contexte

Pendant une séance LEGO, on manipule toujours les **mêmes quatre briques rouges**, mais trois actions différentes sont prévues. Les instructions sont écrites sous plusieurs formes.

# Consigne

Dépose chaque version sous l'instruction qui veut dire exactement la même chose. Attention : toutes parlent de quatre briques rouges ; il faut donc vérifier ce qu'on en fait et où elles doivent se trouver.

# Catégories

1. Sortir quatre briques rouges du bac.
2. ```blockly
event: DÉBUT
move: POSER (4) briques rouges sur le plateau
end: FIN
```
3. ```
Algorithme : ranger les briques rouges
Début
  remettre 4 briques rouges dans le bac
Fin
```

# Étiquettes

1. ```blockly
event: DÉBUT
move: PRENDRE (4) briques rouges dans le bac
end: FIN
```
2. ```
Algorithme : installer les briques
Début
  déposer 4 briques rouges sur le plateau
Fin
```
3. Remettre les quatre briques rouges dans le bac.
4. ```
Algorithme : sortir les briques
Début
  prendre 4 briques rouges dans le bac
Fin
```
5. Placer quatre briques rouges sur le plateau.
6. ```blockly
event: DÉBUT
move: RANGER (4) briques rouges dans le bac
end: FIN
```

# Solution

1: 1, 4
2: 2, 5
3: 3, 6

# Feedback essai 1

Le nombre, la couleur et l'objet sont les mêmes partout. Pour chaque étiquette, demande-toi si les briques **quittent le bac**, **vont sur le plateau** ou **reviennent dans le bac**.

# Feedback essai 2

`PRENDRE dans le bac` et `sortir du bac` vont ensemble. `POSER`, `déposer` ou `placer sur le plateau` décrivent une deuxième action. `Remettre` ou `ranger dans le bac` décrivent la troisième.

# Feedback

La catégorie 1 correspond aux versions `1` et `4` : dans les trois cas, les quatre briques rouges sont sorties du bac. La catégorie 2 correspond aux versions `2` et `5`, qui les placent sur le plateau. La catégorie 3 correspond aux versions `3` et `6`, qui les remettent dans le bac. Ici, les mêmes mots et les mêmes objets apparaissent souvent : c'est bien la relation entre l'action et la destination qui distingue les trois sens.
