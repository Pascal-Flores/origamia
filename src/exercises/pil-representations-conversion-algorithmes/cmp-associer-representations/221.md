# Contexte

Voici une instruction :

Placer une pièce bleue dans le coin supérieur gauche du cadre.

# Consigne

Choisis la version qui dit exactement la même chose.

# Réponses

1. Placer une pièce bleue dans le coin inférieur gauche du cadre.
2. ```blockly
event: DÉBUT
move: POSER la pièce bleue dans le coin supérieur gauche du cadre
end: FIN
```
3. ```blockly
event: DÉBUT
move: POSER la pièce rouge dans le coin supérieur gauche du cadre
end: FIN
```
4. Retirer une pièce bleue du coin supérieur gauche du cadre.

# Solution

2

# Feedback essai 1

Compare séparément l'action, la couleur de la pièce et le coin indiqué.

# Feedback

La réponse `2` conserve les trois informations de l'instruction : il faut **poser** une pièce **bleue** dans le coin **supérieur gauche**. La réponse `1` change le lieu, la `3` change la pièce et la `4` change l'action.
