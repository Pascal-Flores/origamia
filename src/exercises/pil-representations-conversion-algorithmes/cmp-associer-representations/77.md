# Contexte

Voici trois instructions utilisées pour préparer le tableau. Elles ne sont pas écrites de la même façon.

# Consigne

Dépose chaque version sous l'instruction qui veut dire la même chose.

# Catégories

1. ```blockly
event: DÉBUT
move: EFFACER le tableau
end: FIN
```
2. ```
Algorithme : écrire la date
Début
  écrire la date en haut du tableau
Fin
```
3. Tracer un cadre autour de la date.

# Étiquettes

1. Nettoyer le tableau.
2. ```blockly
event: DÉBUT
move: ÉCRIRE la date en haut du tableau
end: FIN
```
3. ```
Algorithme : encadrer la date
Début
  tracer un cadre autour de la date
Fin
```
4. ```blockly
event: DÉBUT
move: DESSINER un cadre autour de la date
end: FIN
```
5. Noter la date en haut du tableau.
6. ```
Algorithme : nettoyer le tableau
Début
  effacer le tableau
Fin
```

# Solution

1: 1, 6
2: 2, 5
3: 3, 4

# Feedback essai 1

J’imagine qu’on prépare le tableau pour la classe. Est-ce que chaque étiquette change la même chose au tableau ?

# Feedback essai 2

Écrire la date et dessiner autour d’elle, est-ce que ça donne le même résultat ?

# Feedback

On peut nettoyer le tableau, écrire la date en haut ou dessiner un cadre autour. Pour chaque geste, les mots peuvent changer. Ça aide à faire le tri.
