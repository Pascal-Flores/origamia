# Contexte

Voici une instruction :

```
Instruction :
placer la feuille dans le casier À rendre
```

# Consigne

Choisis la représentation qui dit exactement la même chose.

# Réponses

1. ```blockly
event: DÉBUT
move: METTRE la feuille dans le casier (À rendre)
end: FIN
```
2. Mettre la feuille dans le casier Brouillon.
3. Garder la feuille sur la table.

# Solution

1

# Feedback

La réponse 1 garde la même action, le même objet et le même casier : À rendre. Les autres réponses changent le lieu ou ne rangent pas la feuille.
