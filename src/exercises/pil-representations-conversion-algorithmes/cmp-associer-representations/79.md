# Contexte

Voici un algorithme écrit en phrases :

Faire `3` séries. Dans chaque série, faire `10` flexions. Ensuite, boire de l'eau.

# Consigne

Coche toutes les représentations qui gardent exactement le même sens.

# Réponses

1. ```
Algorithme : pause sportive
Début
  Répéter 3 fois :
    faire 10 flexions
  boire de l'eau
Fin
```
2. ```blockly
event: DÉBUT
move: FAIRE (10) flexions
move: FAIRE (10) flexions
move: FAIRE (10) flexions
move: BOIRE de l'eau
end: FIN
```
3. ```
Algorithme : pause sportive
Début
  Répéter 10 fois :
    faire 3 flexions
  boire de l'eau
Fin
```
4. ```blockly
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: FAIRE (10) flexions
  move: BOIRE de l'eau
end: FIN
```

# Solution

1, 2

# Feedback

Les réponses `1` et `2` gardent bien `3` séries de `10` flexions, puis l'eau à la fin. La réponse `3` inverse les nombres, et la réponse `4` boit de l'eau à chaque répétition au lieu de le faire seulement à la fin.
