## Forme de référence

Chaque variante comporte :

1. une séquence source contenant une répétition simple et au moins une action placée après la répétition ;
2. quatre représentations candidates ;
3. deux représentations exactement équivalentes ;
4. un distracteur qui modifie le nombre ou le contenu répété ;
5. un distracteur qui déplace dans la répétition une action qui ne doit être exécutée qu'une fois, ou change l'ordre global ;
6. `type: qcm`, `essais: 3`, avec deux feedbacks progressifs puis un feedback final détaillant les écarts de sens.
