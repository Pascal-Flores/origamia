# Contexte

Voici une instruction :

Placer le devoir dans la pochette À rendre.

# Consigne

Choisis la version qui dit exactement la même chose.

# Réponses

1. Placer le devoir dans la pochette Brouillon.
2. ```blockly
event: DÉBUT
move: PLACER le cahier dans la pochette (À rendre)
end: FIN
```
3. ```blockly
event: DÉBUT
move: METTRE le devoir dans la pochette (À rendre)
end: FIN
```
4. Garder le devoir sur la table.

# Solution

3

# Feedback essai 1

On cherche la même action dans deux écritures. Qu’est-ce qu’on déplace et où ?

# Feedback essai 2

Plusieurs pochettes peuvent se ressembler. Est-ce que leurs noms veulent dire la même chose ?

# Feedback

Le devoir va dans la pochette « À rendre ». Même avec d’autres mots, on garde bien le même objet et la même pochette. Ça nous servira.
