# Contexte

Voici un algorithme :

```
Algorithme : préparer le tableau
Début
  Étape 1 : nettoyer le tableau
  Étape 2 : noter la date
  Étape 3 : dessiner une colonne à gauche
Fin
```

# Consigne

Choisis la représentation qui garde exactement les mêmes actions, dans le même ordre.

# Réponses

1. ```blockly
event: DÉBUT
move: EFFACER le tableau
say: ÉCRIRE la date
move: TRACER une colonne à gauche
end: FIN
```
2. Effacer le tableau, tracer une colonne à gauche, puis écrire la date.

# Solution

1

# Feedback

La réponse 1 garde les trois actions et leur ordre, même si les mots changent entre le pseudo-code simple et les blocs. La réponse 2 place la colonne avant la date.
