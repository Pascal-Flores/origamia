# Contexte

On veut représenter cette action sous forme d’instruction :

Joindre le fichier `photo.png` au message.

# Consigne

Choisis l’instruction qui dit exactement la même chose.
# Réponses

1. `move: JOINDRE le fichier (photo.png) au message`
2. `say: ENVOYER le message`
3. `move: SUPPRIMER le fichier (photo.png)`

# Solution

1

# Feedback

L’action demandée est de joindre un fichier précis au message. Envoyer le message ou supprimer le fichier sont d’autres actions : elles ne sont donc pas équivalentes.
