# Contexte

Voici une instruction :

Placer le devoir dans la pochette À rendre.

# Consigne

Choisis la version qui dit exactement la même chose.

# Réponses

1. Placer le devoir dans la pochette Brouillon.
2. ```blockly
event: DÉBUT
move: PLACER le cahier dans la pochette (À rendre)
end: FIN
```
3. ```blockly
event: DÉBUT
move: METTRE le devoir dans la pochette (À rendre)
end: FIN
```
4. Garder le devoir sur la table.

# Solution

3

# Feedback essai 1

Vérifie trois éléments dans chaque réponse : l'action, le devoir et le nom exact de la pochette.

# Feedback

La réponse 3 garde la même action, le même objet et la même pochette. Les autres réponses changent la pochette, l'objet ou l'action.
