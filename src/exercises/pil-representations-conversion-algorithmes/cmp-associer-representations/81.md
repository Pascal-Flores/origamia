# Contexte

Voici un programme en blocs :

```blockly
event: DÉBUT
repeat: RÉPÉTER (2) FOIS
  move: RELIRE la leçon
move: RÉPONDRE à (3) questions
end: FIN
```

# Consigne

Coche toutes les versions qui gardent exactement le même sens.

# Réponses

1. Relire la leçon deux fois, puis répondre à `3` questions.
2. ```
Algorithme : réviser la leçon
Début
  relire la leçon
  relire la leçon
  répondre à 3 questions
Fin
```
3. Relire la leçon, répondre à `3` questions, puis relire la leçon.
4. ```
Algorithme : réviser la leçon
Début
  Répéter 3 fois :
    relire la leçon
  répondre à 2 questions
Fin
```

# Solution

1, 2

# Feedback essai 1

Compare les nombres, l'ordre et la place de chaque action par rapport aux répétitions.

# Feedback essai 2

Le programme demande d'abord deux relectures, puis trois questions. Aucune relecture ne vient après les questions.

# Feedback

Les réponses `1` et `2` gardent le même sens : deux relectures, puis trois questions. La réponse `3` place une relecture après les questions, et la réponse `4` change les nombres.
