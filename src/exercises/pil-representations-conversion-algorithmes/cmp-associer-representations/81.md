# Contexte

Voici la suite d’actions de départ :

- donner la feuille au premier groupe ;
- récupérer la feuille remplie ;
- déposer la feuille sur le bureau.

# Consigne

Coche toutes les versions qui disent exactement la même chose.
# Réponses

1. ```
event: DÉBUT
move: DONNER la feuille au premier groupe
move: RÉCUPÉRER la feuille remplie
move: DÉPOSER la feuille sur le bureau
end: FIN
```
2. Donner la feuille au premier groupe, faire signer la feuille, puis la déposer sur le bureau.
3. ```
event: DÉBUT
move: DONNER la feuille au premier groupe
move: DÉPOSER la feuille sur le bureau
move: RÉCUPÉRER la feuille remplie
end: FIN
```
4. Donner la feuille au premier groupe, récupérer la feuille remplie, puis déposer la feuille sur le bureau.

# Solution

1, 4

# Feedback

Les réponses `1` et `4` gardent les trois mêmes étapes dans le même ordre. La réponse `2` remplace la récupération par une signature, et la réponse `3` dépose la feuille avant de la récupérer.
