# Contexte

Voici trois instructions pour préparer un bol de céréales. Elles ne sont pas écrites de la même façon.

# Consigne

Dépose chaque version sous l'instruction qui veut dire la même chose.

# Catégories

1. ```
Algorithme : ajouter les céréales
Début
  mettre les céréales dans le bol
Fin
```
2. Ajouter le lait dans le bol.
3. ```blockly
event: DÉBUT
move: RANGER la boîte de céréales
end: FIN
```

# Étiquettes

1. Verser les céréales dans le bol.
2. ```blockly
event: DÉBUT
move: VERSER le lait dans le bol
end: FIN
```
3. Remettre la boîte de céréales à sa place.
4. ```
Algorithme : ranger la boîte
Début
  ranger la boîte de céréales
Fin
```
5. ```blockly
event: DÉBUT
move: AJOUTER les céréales dans le bol
end: FIN
```
6. ```
Algorithme : ajouter le lait
Début
  verser le lait dans le bol
Fin
```

# Solution

1: 1, 5
2: 2, 6
3: 3, 4

# Feedback essai 1

Deux versions vont ensemble si elles produisent exactement la même action sur le même objet.

# Feedback essai 2

Forme trois familles : verser les céréales, ajouter le lait et ranger le paquet.

# Feedback

Le pseudo-code qui met les céréales dans le bol va avec la phrase et le bloc qui versent les céréales. « Ajouter le lait » va avec le bloc et le pseudo-code qui versent le lait. Le bloc qui range la boîte va avec la phrase et le pseudo-code qui remettent la boîte à sa place.
