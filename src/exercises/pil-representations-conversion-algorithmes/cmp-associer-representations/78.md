# Énoncé

Après une activité de peinture, une même action peut être écrite de plusieurs façons.

Dépose chaque écriture sous l’action qui veut dire la même chose.

# Catégories

1. Rincer les pinceaux à l’eau claire.
2. Sécher les pinceaux avec un chiffon.
3. Ranger les pinceaux dans le pot bleu.

# Étiquettes

1. `move: PASSER les pinceaux sous l’eau claire`
2. RANGER les pinceaux dans le pot bleu
3. `move: ESSUYER les pinceaux avec un chiffon`
4. RINCER les pinceaux à l’eau claire
5. SECHER les pinceaux avec un chiffon
6. `move: DÉPOSER les pinceaux dans le pot bleu`

# Solution

1: 1, 4
2: 3, 5
3: 2, 6

# Feedback

Les écritures ne se lisent pas toutes pareil, mais elles peuvent décrire la même action. Pour garder l’équivalence, il faut conserver le geste et le détail utile : eau claire pour rincer, chiffon pour sécher, pot bleu pour ranger.
