# Contexte

Pour répartir le travail, trois rôles ont été préparés dans une liste. La procédure est représentée par ces blocs :

```blockly
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: ATTRIBUER le rôle suivant
move: NOTER les rôles sur la feuille du groupe
end: FIN
```

# Consigne

Coche toutes les versions qui gardent exactement le même sens.

# Réponses

1. Attribuer successivement les trois rôles, puis noter les rôles sur la feuille du groupe une seule fois.
2. ```
Algorithme : répartir les rôles
Début
  Répéter 3 fois :
    attribuer le rôle suivant
  noter les rôles sur la feuille du groupe
Fin
```
3. ```blockly
event: DÉBUT
repeat: RÉPÉTER (3) FOIS
  move: ATTRIBUER le rôle suivant
  move: NOTER les rôles sur la feuille du groupe
end: FIN
```
4. ```blockly
event: DÉBUT
repeat: RÉPÉTER (4) FOIS
  move: ATTRIBUER le rôle suivant
move: NOTER les rôles sur la feuille du groupe
end: FIN
```

# Solution

1, 2

# Feedback essai 1

Sépare les deux parties de la séquence : l'attribution répétée des rôles et l'action qui ne doit avoir lieu qu'après cette répétition.

# Feedback essai 2

Il faut attribuer exactement `3` rôles. La feuille du groupe n'est complétée qu'une seule fois, après les trois attributions.

# Feedback

Les réponses `1` et `2` gardent exactement le fonctionnement des blocs : trois attributions successives, puis une seule écriture sur la feuille. La réponse `3` répète aussi l'écriture sur la feuille, tandis que la `4` attribue quatre rôles au lieu de trois.
