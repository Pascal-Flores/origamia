# Contexte

Pour préparer une pâte, une même action peut être écrite de plusieurs façons.

# Consigne

Dépose chaque écriture sous l’action qui veut dire la même chose.
# Catégories

1. Ajouter la farine dans le saladier.
2. Mélanger la pâte pendant `2 min`.
3. Attendre `10 min`.

# Étiquettes

1. `move: METTRE la farine dans le saladier`
2. MELANGER la pâte pendant (2 min)
3. `move: LAISSER reposer pendant (10 min)`
4. AJOUTER la farine dans le saladier
5. `move: REMUER la pâte pendant (2 min)`
6. ATTENDRE pendant (10 min)

# Solution

1: 1, 4
2: 2, 5
3: 3, 6

# Feedback

Une même action peut changer de forme sans changer de sens. `METTRE la farine dans le saladier` et `AJOUTER la farine dans le saladier` donnent le même résultat. Il faut aussi conserver les durées : `2 min` pour mélanger et `10 min` pour attendre.
