# Contexte

Voici une instruction :

Joindre le fichier photo.png au message.

# Consigne

Choisis la représentation qui dit exactement la même chose.

# Réponses

1. ```
Instruction :
joindre le fichier photo.png au message
```
2. ```blockly
event: DÉBUT
move: SUPPRIMER le fichier (photo.png)
end: FIN
```
3. Envoyer le message sans fichier joint.

1

# Feedback

La réponse 1 garde la même action et le même fichier. Les autres réponses changent l'action : supprimer un fichier ou envoyer sans pièce jointe ne veut pas dire joindre photo.png.
