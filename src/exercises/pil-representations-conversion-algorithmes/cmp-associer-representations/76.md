# Contexte

Voici trois instructions d'une même préparation. Elles ne sont pas écrites de la même façon.

# Consigne

Dépose chaque version sous l'instruction qui veut dire la même chose.

# Catégories

1. Sortir la gourde du cartable.
2. ```blockly
event: DÉBUT
move: REMPLIR la gourde au point d'eau
end: FIN
```
3. ```
Algorithme : ranger la collation
Début
  mettre la collation dans le sac
Fin
```

# Étiquettes

1. ```blockly
event: DÉBUT
move: PRENDRE la gourde dans le cartable
end: FIN
```
2. ```
Algorithme : remplir la gourde
Début
  remplir la gourde au robinet
Fin
```
3. Ranger le goûter dans le sac.
4. ```
Algorithme : sortir la gourde
Début
  prendre la gourde dans le cartable
Fin
```
5. Remplir la gourde au point d'eau.
6. ```blockly
event: DÉBUT
move: METTRE la collation dans le sac
end: FIN
```

# Solution

1: 1, 4
2: 2, 5
3: 3, 6

# Feedback essai 1

Ne te fie pas à la forme. Compare pour chaque version l'action, l'objet concerné et le résultat obtenu.

# Feedback essai 2

Commence par regrouper toutes les versions qui parlent de remplir la gourde, puis fais de même pour préparer et ranger le goûter.

# Feedback

Avec « Sortir la gourde du cartable », il faut placer le bloc qui prend la gourde et le pseudo-code qui la sort du cartable. Avec « Remplir la gourde », il faut placer le pseudo-code qui la remplit au robinet et la phrase qui la remplit au point d'eau. Les deux versions restantes rangent la collation dans le sac.
