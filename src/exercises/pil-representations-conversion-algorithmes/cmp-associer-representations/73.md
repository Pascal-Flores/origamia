# Énoncé

On veut représenter cette action sous forme d’instruction :

Créer un dossier nommé `Lina`.

Choisis l’instruction qui dit exactement la même chose.

# Réponses

1. `move: CRÉER un dossier nommé (Lina)`
2. `move: OUVRIR le dossier nommé (Lina)`
3. `move: CRÉER un fichier nommé (Lina)`

# Solution

1

# Feedback

La bonne représentation est `CRÉER un dossier nommé (Lina)`. Les autres propositions changent l’action ou l’objet : ouvrir un dossier n’est pas le créer, et créer un fichier n’est pas créer un dossier.
