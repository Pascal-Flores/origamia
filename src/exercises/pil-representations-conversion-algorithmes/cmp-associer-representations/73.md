# Contexte

Voici une instruction :

Joindre le fichier photo.png au message.

# Consigne

Choisis la version qui dit exactement la même chose.

# Réponses

1. Joindre le fichier photo.png au dossier Images.
2. ```blockly
event: DÉBUT
move: JOINDRE le fichier (photo.png) au message
end: FIN
```
3. ```blockly
event: DÉBUT
move: JOINDRE le fichier (dessin.png) au message
end: FIN
```
4. Envoyer le message sans fichier joint.

# Solution

2

# Feedback essai 1

Compare séparément l'action, le nom du fichier et l'endroit où il doit être placé.

# Feedback

La réponse 2 garde la même action, le même fichier et le même endroit : le message. Les autres réponses changent le lieu, le fichier ou l'action.
