# Contexte

La séquence doit être entièrement écrite en pseudo-code simple.

```
DÉBUT
AVANCER de 2 cases
move: TOURNER à droite
ATTENDRE
FIN
```

# Consigne

Quels problèmes de forme faut-il corriger ?

# Réponses

1. La ligne `move: TOURNER à droite` est dans une autre représentation.
2. `ATTENDRE` est incomplet car la durée manque.
3. `DÉBUT` et `FIN` sont interdits en pseudo-code.
4. `AVANCER de 2 cases` est une ligne complète.

# Solution

1, 2

# Feedback essai 1

Cherche d'abord une rupture de représentation, puis une instruction qui manque d'information.

# Feedback essai 2

`DÉBUT` et `FIN` font partie de la forme de pseudo-code utilisée dans le projet.

# Feedback

La séquence mélange un bloc textuel avec le pseudo-code et contient une attente sans durée. Ce sont les deux problèmes à corriger.
