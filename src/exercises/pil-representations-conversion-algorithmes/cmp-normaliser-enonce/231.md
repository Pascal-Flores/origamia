# Contexte

La séquence doit être entièrement écrite en pseudo-code simple :

```
DÉBUT
LIRE la compétence
move: CHOISIR "je sais / j'hésite / à revoir"
ÉCRIRE
FIN
```

# Consigne

Sélectionne tous les problèmes de forme.

# Réponses

1. La ligne `move: CHOISIR ...` n'est pas dans la même représentation que le reste.
2. La ligne `ÉCRIRE` est incomplète : elle ne précise pas quoi écrire.
3. `DÉBUT` est interdit en pseudo-code.
4. `LIRE la compétence` est forcément un bloc.

# Solution

1, 2

# Feedback essai 1

Cherche d'abord une rupture de représentation, puis une instruction incomplète.

# Feedback essai 2

Les lignes `DÉBUT` et `FIN` sont compatibles avec le pseudo-code du projet.

# Feedback

Une ligne introduit un bloc au milieu du pseudo-code et `ÉCRIRE` ne possède pas son complément.
