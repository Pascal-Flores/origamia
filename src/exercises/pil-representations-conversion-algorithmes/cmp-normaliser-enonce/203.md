# Contexte

Pour décrire comment remplir une fiche d'auto-évaluation, la procédure a été écrite sous forme de petit algorithme. Elle doit rester homogène et chaque instruction doit être suffisamment précise pour être exécutée.

La séquence contient plusieurs problèmes de forme.

```
Algorithme : remplir l'auto-évaluation
Début
  lire l'intitulé de la compétence
  choisir une réponse parmi « je sais / j'hésite / à revoir »
  move: COCHER la case choisie
  écrire
  ranger la fiche dans le classeur
Fin
```

# Consigne

Coche tous les problèmes de forme présents dans cette séquence.

# Réponses

1. Une ligne utilise une autre représentation que le reste de la séquence.
2. Une instruction est incomplète car elle ne précise pas ce qu'il faut écrire.
3. Il manque la ligne `Début`.
4. Il manque la ligne `Fin`.
5. La ligne qui propose les trois réponses est mal formée parce qu'une instruction ne peut pas contenir plusieurs choix.

# Solution

1, 2

# Feedback essai 1

Contrôle séparément trois points : la forme utilisée par chaque ligne, la présence du cadre `Début` / `Fin`, puis la complétude des instructions.

# Feedback essai 2

La ligne qui commence par `move:` n'a pas la même forme que le reste du petit algorithme. Une autre ligne donne seulement l'action `écrire` sans préciser son contenu.

# Feedback

Deux problèmes sont réellement présents. `move: COCHER la case choisie` introduit une ligne de blocs au milieu d'un pseudo-code. La ligne `écrire` est incomplète parce qu'elle ne dit pas ce qui doit être écrit. Les lignes `Début` et `Fin` sont bien présentes, et proposer plusieurs choix dans une instruction n'est pas en soi un problème de forme.
