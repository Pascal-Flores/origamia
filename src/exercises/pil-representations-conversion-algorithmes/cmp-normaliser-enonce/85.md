# Contexte

Voici une courte séquence en blocs pour renommer un fichier.

Une instruction est mal formée : elle indique une action, mais il manque les informations nécessaires pour l'exécuter correctement.

```blockly
event: DÉBUT
move: OUVRIR le dossier Français
move: SÉLECTIONNER le fichier brouillon.odt
move: RENOMMER
move: DÉPLACER le fichier poesie_finale.odt vers À rendre
end: FIN
```

# Consigne

Choisis la réponse qui repère l'instruction à corriger et propose une correction avec la même forme que le reste.

# Réponses

1. Le bloc RENOMMER doit devenir :
```blockly
move: RENOMMER le fichier brouillon.odt en poesie_finale.odt
```
2. Le bloc RENOMMER doit devenir :
```blockly
move: RENOMMER
```
3. Le bloc DÉPLACER doit devenir :
```blockly
move: DÉPLACER le fichier brouillon.odt vers À corriger
```
4. Le bloc RENOMMER doit devenir : Renommer le fichier brouillon.odt en poesie_finale.odt.

# Solution

1

# Feedback essai 1

Repère d'abord l'information manquante dans le bloc incomplet, puis choisis une correction qui reste écrite en blocs.

# Feedback

Le bloc RENOMMER est incomplet : il ne dit pas quel fichier renommer ni quel nouveau nom utiliser. La bonne correction garde la forme en blocs et ajoute les paramètres nécessaires.
