# Contexte

Pour préparer une page de cahier, certaines propositions sont écrites avec des phrases et d'autres avec des blocs.

Une instruction est bien formée si elle indique clairement l'action et ce qu'il faut utiliser ou modifier.

# Consigne

Classe chaque proposition dans la bonne colonne.

# Catégories

1. Instructions valides
2. Instructions invalides

# Étiquettes

1. Écrire la date en haut de la page.
2. ```blockly
move: ÉCRIRE le titre sous la date
```
3. Souligner le titre avec la règle.
4. ```blockly
move: OUVRIR le cahier à la bonne page
```
5. Écrire.
6. ```blockly
move: SOULIGNER
```
7. Le titre sous la date.
8. ```blockly
move: FAIRE la page
```

# Solution

1: 1, 2, 3, 4
2: 5, 6, 7, 8

# Feedback essai 1

On a la page de cahier devant nous. Est-ce qu’on pourrait suivre chaque proposition telle qu’elle est écrite ?

# Feedback essai 2

Pour souligner sur la page, saurait-on quoi souligner ? Pour écrire, aurait-on tous les détails utiles ?

# Feedback

Avec « Écrire la date en haut de la page », on sait quoi écrire et où. Le seul verbe « écrire » nous laisse deviner. On y voit mieux.
