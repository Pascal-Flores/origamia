# Énoncé

On veut réécrire une consigne sous forme d'une liste d'actions simples.

Une action simple indique une seule chose à faire.

Consigne de départ :

Ouvre l’application de lecture, lis le texte, puis ferme l’application.

Choisis la liste qui garde le même sens et le bon ordre.

# Réponses

1. Lire le texte ; ouvrir l’application de lecture ; fermer l’application
2. Ouvrir l’application de lecture ; lire le texte ; fermer l’application
3. Ouvrir l’application de lecture ; fermer l’application ; lire le texte

# Solution

2

# Feedback

La version correcte garde les trois actions dans l'ordre : ouvrir l'application, lire le texte, puis fermer l'application.
