# Contexte

Voici une séquence écrite comme un petit algorithme pour vérifier une feuille avant de la rendre.

Elle contient plusieurs problèmes de forme.

```
Algorithme : vérifier la feuille
Début
  lire la première question
  cocher
  3. Ranger la feuille dans la pochette à rendre.
Fin
```

# Consigne

Coche tous les problèmes de forme présents dans cette séquence.

# Réponses

1. Une instruction est incomplète.
2. Une ligne utilise une autre forme que le reste.
3. Il manque la ligne Début.
4. Il manque la ligne Fin.
5. La séquence est homogène et complète.

# Solution

1, 2

# Feedback

La ligne "cocher" est incomplète : elle ne dit pas quoi cocher. La ligne numérotée "3. Ranger la feuille..." ne garde pas la même forme que les autres lignes du petit algorithme. Les lignes Début et Fin sont bien présentes.
