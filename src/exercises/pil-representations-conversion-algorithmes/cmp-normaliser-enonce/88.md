# Contexte

Consigne de départ :

Fais 3 séries de 10 flexions, puis bois de l'eau.

# Consigne

Complète la forme compacte avec répétition.

# Texte à trous

Algorithme : pause sportive
Début
  Répéter [[1]] fois :
    faire [[2]] flexions
  boire [[3]]
Fin

# Étiquettes

1. 3
2. 10
3. de l'eau
4. 30
5. avant les flexions

# Solution

1, 2, 3

# Feedback

La répétition porte sur les séries : on répète 3 fois l'action de faire 10 flexions. Boire de l'eau arrive après la répétition.
