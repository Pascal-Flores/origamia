# Énoncé

Consigne de départ :

Fais `3` séries de `10` flexions, puis bois de l’eau.

Coche toutes les écritures qui gardent exactement le même sens.

# Réponses

1. RÉPÉTER (3 fois) : FAIRE (10) flexions / BOIRE de l’eau
2. FAIRE (10) flexions / FAIRE (10) flexions / FAIRE (10) flexions / BOIRE de l’eau
3. RÉPÉTER (10 fois) : FAIRE (3) flexions / BOIRE de l’eau
4. FAIRE (3) flexions / BOIRE de l’eau

# Solution

1, 2

# Feedback

Les réponses `1` et `2` gardent bien `3` séries de `10` flexions, puis l’eau à la fin. La réponse `3` inverse les nombres, et la réponse `4` perd la répétition.
