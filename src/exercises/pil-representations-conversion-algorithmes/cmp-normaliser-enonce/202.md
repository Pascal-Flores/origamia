# Contexte

Pour préparer un plan de travail, la fiche indique de placer `mathématiques` dans la zone `Maintenant`, `lecture` dans la zone `Ensuite`, puis de commencer la tâche placée dans `Maintenant`.

Voici la séquence écrite sous forme de blocs. Une instruction est mal formée : elle indique qu'il faut commencer, mais ne précise pas quelle tâche.

```blockly
event: DÉBUT
move: NOTER (mathématiques) dans la zone Maintenant
move: NOTER (lecture) dans la zone Ensuite
move: COMMENCER
end: FIN
```

# Consigne

Choisis la réponse qui corrige le bloc incomplet tout en conservant la même représentation et le résultat attendu.

# Réponses

1. ```blockly
move: COMMENCER la tâche (mathématiques)
```
2. ```blockly
move: COMMENCER
```
3. ```blockly
move: COMMENCER la tâche (lecture)
```
4. Commencer la tâche mathématiques.

# Solution

1

# Feedback essai 1

Le bloc à corriger est celui qui ne dit pas quelle tâche commencer. La correction doit à la fois rester écrite en blocs et respecter ce qui a été placé dans la zone `Maintenant`.

# Feedback

Le bloc `COMMENCER` est incomplet. La tâche placée dans `Maintenant` est `mathématiques`, donc la correction doit préciser `COMMENCER la tâche mathématiques`. La réponse 3 désigne la mauvaise tâche et la réponse 4 change de représentation.
