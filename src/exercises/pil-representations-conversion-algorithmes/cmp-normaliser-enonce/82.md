# Contexte

Pour décrire ce qu'il faut faire en arrivant en classe, on peut utiliser des phrases ou des blocs.

Une instruction est bien formée si elle indique clairement l'action et ce sur quoi porte l'action.

# Consigne

Classe chaque proposition dans la bonne colonne.

# Catégories

1. Instructions valides
2. Instructions invalides

# Étiquettes

1. Accrocher le manteau au portemanteau.
2. ```blockly
move: POSER le cartable sous la table
```
3. S'asseoir à sa place.
4. ```blockly
move: RANGER la trousse dans le cartable
```
5. Accrocher.
6. ```blockly
move: POSER
```
7. Le cartable sous la table.
8. ```blockly
move: FAIRE les affaires
```

# Solution

1: 1, 2, 3, 4
2: 5, 6, 7, 8

# Feedback essai 1

Si j’arrive en classe et qu’on me dit juste « le cartable », qu’est-ce qu’on ferait à ton avis ?

# Feedback essai 2

Est-ce qu’on pourrait mimer chaque étiquette sans inventer un geste ou un objet ? Moi, « poser » tout seul me laisse les mains vides.

# Feedback

Ça nous donne une piste pour la suite. « Poser le cartable sous la table », on peut le faire. Si on doit deviner le geste ou l’objet, ça coince.
