# Contexte

Pour décrire ce qu'il faut faire en arrivant en classe, on peut utiliser des phrases ou des blocs.

Une instruction est bien formée si elle indique clairement l'action et ce sur quoi porte l'action.

# Consigne

Classe chaque proposition dans la bonne colonne.

# Catégories

1. Instructions valides
2. Instructions invalides

# Étiquettes

1. Accrocher le manteau au portemanteau.
2. ```blockly
move: POSER le cartable sous la table
```
3. S'asseoir à sa place.
4. ```blockly
move: RANGER la trousse dans le cartable
```
5. Accrocher.
6. ```blockly
move: POSER
```
7. Le cartable sous la table.
8. ```blockly
move: FAIRE les affaires
```

# Solution

1: 1, 2, 3, 4
2: 5, 6, 7, 8

# Feedback essai 1

Une instruction complète doit contenir un verbe d'action précis et indiquer sur quel objet porte cette action.

# Feedback essai 2

Commence par repérer les propositions où l'on sait exactement quoi faire. Classe comme invalides celles où il manque l'action ou l'objet.

# Feedback

Une instruction valide donne une action précise et l'objet concerné : accrocher le manteau, poser le cartable, s'asseoir, ranger la trousse. Les propositions invalides sont incomplètes ou trop vagues : on ne sait pas exactement quoi faire, ou sur quel objet agir.
