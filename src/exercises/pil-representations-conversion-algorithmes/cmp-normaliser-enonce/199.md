# Contexte

Pour passer du travail individuel au travail en binôme, certaines consignes sont écrites sous forme de phrases et d'autres sous forme de blocs.

Une instruction est bien formée si elle indique clairement l'action à réaliser et les informations nécessaires pour savoir sur quoi ou où agir.

# Consigne

Classe chaque proposition dans la bonne colonne.

# Catégories

1. Instructions valides
2. Instructions invalides

# Étiquettes

1. Tourner sa chaise vers son binôme.
2. Poser le cahier entre les deux élèves.
3. ```blockly
move: OUVRIR le cahier à la page demandée
```
4. ```blockly
move: PLACER le crayon au centre de la table
```
5. Commencer la première question avec son binôme.
6. Tourner.
7. ```blockly
move: POSER
```
8. Le cahier entre les deux élèves.

# Solution

1: 1, 2, 3, 4, 5
2: 6, 7, 8

# Feedback essai 1

Pour chaque proposition, demande-toi si un autre élève pourrait l'exécuter immédiatement sans avoir besoin de demander ce qu'il faut tourner, poser, ouvrir ou utiliser.

# Feedback essai 2

Une instruction complète contient une action claire et, lorsque c'est nécessaire, l'objet ou le lieu concerné. Une action seule ou un groupe de mots sans verbe ne suffit pas.

# Feedback

Les propositions `1` à `5` donnent toutes une action précise et les informations nécessaires pour la réaliser. `Tourner` ne précise pas ce qu'il faut tourner, le bloc `POSER` ne précise pas quoi poser, et `Le cahier entre les deux élèves` indique un objet et un lieu sans donner d'action.
