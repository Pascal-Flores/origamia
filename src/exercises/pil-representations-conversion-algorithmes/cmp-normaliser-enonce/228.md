# Contexte

Pour une pause active, les instructions sont écrites sous forme de blocs.

# Consigne

Classe les blocs selon qu'ils sont complets ou incomplets.

# Catégories

1. Blocs valides
2. Blocs invalides

# Étiquettes

1. `move: SE LEVER de la chaise`
2. `move: ÉTIRER les bras`
3. `move: SE LEVER`
4. `move: ÉTIRER`

# Solution

1: 1, 2
2: 3, 4

# Feedback essai 1

Un bloc valide précise l'action et ce sur quoi elle porte quand cette précision est nécessaire.

# Feedback essai 2

Compare les blocs deux à deux : certains ont perdu leur complément.

# Feedback

Les blocs 1 et 2 sont complets ; les blocs 3 et 4 sont trop incomplets pour la forme attendue dans cet exercice.
