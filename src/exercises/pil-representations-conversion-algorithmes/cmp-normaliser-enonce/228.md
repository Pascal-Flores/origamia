# Contexte

Pour décrire une courte pause active, certaines consignes sont écrites sous forme de phrases et d'autres sous forme de blocs.

Une instruction est bien formée si elle dit clairement quelle action réaliser et, lorsque c'est nécessaire, sur quelle partie du corps ou quel objet elle porte.

# Consigne

Classe chaque proposition dans la bonne colonne.

# Catégories

1. Instructions valides
2. Instructions invalides

# Étiquettes

1. ```blockly
move: ÉTIRER les bras au-dessus de la tête
```
2. Poser les deux pieds au sol.
3. ```blockly
move: TOURNER les épaules vers l'arrière
```
4. ```blockly
move: ÉTIRER
```
5. ```blockly
move: POSER au sol
```
6. Les bras au-dessus de la tête.
7. Faire le mouvement.
8. ```blockly
move: BOUGER le truc
```

# Solution

1: 1, 2, 3
2: 4, 5, 6, 7, 8

# Feedback essai 1

Lis chaque proposition comme si tu devais l'exécuter sans autre explication. Vérifie que tu sais exactement quelle action faire et sur quoi elle porte.

# Feedback essai 2

Une instruction peut être invalide parce qu'il manque l'objet de l'action, parce qu'il manque le verbe, ou parce que les mots employés restent trop vagues pour savoir quoi faire.

# Feedback

Les propositions `1`, `2` et `3` indiquent précisément l'action à réaliser et la partie du corps concernée. `ÉTIRER` ne dit pas quoi étirer, `POSER au sol` ne dit pas quoi poser, `Les bras au-dessus de la tête` ne contient aucune action, et `Faire le mouvement` comme `BOUGER le truc` restent trop vagues pour être exécutés sans information supplémentaire.
