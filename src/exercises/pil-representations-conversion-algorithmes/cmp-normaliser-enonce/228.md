# Contexte

On veut décrire des actions de rangement avec des blocs fournis.

# Consigne

Classe les blocs selon qu'ils forment une instruction complète ou non.

# Items

1. `move: RANGER les livres sur l'étagère`
2. `move: METTRE les vêtements dans le panier`
3. `move: RANGER`
4. `move: les jouets dans la boîte`
5. `move: POSER le jeu dans le tiroir`
6. `move: FAIRE les choses`

# Catégories

## Valides
1, 2, 5

## Invalides
3, 4, 6

# Feedback essai 1

On doit comprendre précisément l'action et son objet.

# Feedback essai 2

« Faire les choses » contient un verbe mais reste trop vague pour être exécuté sans interprétation.

# Feedback

Les blocs 1, 2 et 5 sont précis et complets. Les autres manquent d'action, d'objet ou de précision.
