# Contexte

Pour ranger une trousse, certaines propositions sont écrites avec des phrases et d'autres avec des blocs.

Une instruction est bien formée si elle indique clairement l'action et l'objet concerné.

# Consigne

Classe chaque proposition dans la bonne colonne.

# Catégories

1. Instructions valides
2. Instructions invalides

# Étiquettes

1. Ranger le crayon dans la trousse.
2. ```blockly
move: METTRE la gomme dans la trousse
```
3. Fermer la trousse.
4. ```blockly
move: POSER la règle dans la trousse
```
5. Ranger.
6. ```blockly
move: METTRE
```
7. La gomme dans la trousse.
8. ```blockly
move: FAIRE la trousse
```

# Solution

1: 1, 2, 3, 4
2: 5, 6, 7, 8

# Feedback essai 1

Et si on se passait les consignes à voix haute ? Est-ce qu’on pourrait suivre chacune sans demander de détail ?

# Feedback essai 2

Si un bloc dit juste « mettre », saurait-on quoi prendre dans la trousse ?

# Feedback

On peut suivre « poser la règle » parce qu’on connaît le geste et l’objet. Avec le seul verbe, il nous manque un détail. On garde ce repère.
