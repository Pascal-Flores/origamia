# Contexte

On veut réécrire une consigne sous forme d'une liste d'actions simples.

Une action simple indique une seule chose à faire.

Consigne de départ :

Range ton crayon, ta gomme et ta règle dans la trousse.

# Consigne

Choisis la liste qui garde le même sens, avec une action par objet à ranger.
# Réponses

1. Ranger le crayon dans la trousse ; ranger la gomme dans la trousse ; ranger la règle dans la trousse
2. Ranger la trousse dans le cartable ; ranger le crayon
3. Ranger le crayon, la gomme et la règle

# Solution

1

# Feedback

La bonne version sépare les trois objets à ranger : le crayon, la gomme et la règle. La réponse 3 garde le sens global, mais elle ne fait pas encore une action simple par objet.
