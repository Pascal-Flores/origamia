# Contexte

Pour ranger une trousse, certaines propositions sont écrites avec des phrases et d'autres avec des blocs.

Une instruction est bien formée si elle indique clairement l'action et l'objet concerné.

# Consigne

Classe chaque proposition dans la bonne colonne.

# Catégories

1. Instructions valides
2. Instructions invalides

# Étiquettes

1. Ranger le crayon dans la trousse.
2. ```blockly
move: METTRE la gomme dans la trousse
```
3. Fermer la trousse.
4. ```blockly
move: POSER la règle dans la trousse
```
5. Ranger.
6. ```blockly
move: METTRE
```
7. La gomme dans la trousse.
8. ```blockly
move: FAIRE la trousse
```

# Solution

1: 1, 2, 3, 4
2: 5, 6, 7, 8

# Feedback essai 1

J’ouvre ma trousse. Si on lit chaque étiquette à voix haute, est-ce qu’on saurait quoi faire sans demander de détail ?

# Feedback essai 2

Avec juste « mettre », mes mains ne savent pas quoi attraper ! Est-ce qu’on voit l’objet et le geste dans nos choix ?

# Feedback

Mince, mais on a bien fouillé la trousse ! « Poser la règle dans la trousse » indique quoi faire et avec quoi. « Mettre » seul ne suffit pas.
