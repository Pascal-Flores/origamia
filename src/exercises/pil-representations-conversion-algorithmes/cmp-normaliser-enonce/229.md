# Contexte

Toutes les lignes doivent être écrites en pseudo-code simple :

```
DÉBUT
RELIRE la phrase
ponctuation
CORRIGER la phrase
FIN
```

# Consigne

Quelle correction remplace la ligne mal formée sans changer de représentation ?

# Réponses

1. `VÉRIFIER la ponctuation`
2. `move: VÉRIFIER la ponctuation`
3. « La ponctuation est vérifiée. »
