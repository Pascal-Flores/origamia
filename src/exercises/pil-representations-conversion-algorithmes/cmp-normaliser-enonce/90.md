# Contexte

Voici une séquence écrite comme un petit programme pour préparer la classe.

Elle contient plusieurs problèmes de forme.

```
Programme : préparer la classe
Début
  ouvrir les volets
  éteindre
  fermer la porte
```

# Consigne

Coche tous les problèmes de forme présents dans cette séquence.

# Réponses

1. Il manque la ligne Fin.
2. Une instruction est incomplète.
3. Une ligne n'a pas la même forme que les autres.
4. Il manque la ligne Début.
5. La séquence est homogène et complète.

# Solution

1, 2

# Feedback essai 1

Et si on regardait d’abord ce qui ouvre et ferme le petit programme ? Après, on pourra vérifier si chaque geste est précis.

# Feedback essai 2

Quand on lit « éteindre », est-ce qu’on sait quoi éteindre ? On peut aussi comparer les deux bouts de la séquence.

# Feedback

On voit qu’il manque la ligne « Fin ». Et avec « éteindre », on ne sait toujours pas quoi éteindre. On a de quoi repérer ça.
