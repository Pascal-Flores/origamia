# Contexte

Voici une séquence écrite comme un petit programme pour préparer la classe.

Elle contient plusieurs problèmes de forme.

```
Programme : préparer la classe
Début
  ouvrir les volets
  éteindre
  fermer la porte
```

# Consigne

Coche tous les problèmes de forme présents dans cette séquence.

# Réponses

1. Il manque la ligne Fin.
2. Une instruction est incomplète.
3. Une ligne n'a pas la même forme que les autres.
4. Il manque la ligne Début.
5. La séquence est homogène et complète.

# Solution

1, 2

# Feedback essai 1

Contrôle l'encadrement du programme, puis vérifie que chaque verbe possède les informations nécessaires.

# Feedback essai 2

Le programme commence par Début mais n'a pas de ligne Fin. L'action « éteindre » ne précise pas ce qui doit être éteint.

# Feedback

La ligne Fin manque : le programme n'est pas correctement encadré. L'instruction "éteindre" est incomplète, car elle ne précise pas ce qu'il faut éteindre. Les autres lignes gardent la même forme et la ligne Début est présente.
