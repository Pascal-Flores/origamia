# Contexte

Consigne de départ :

Range 4 ballons dans le sac, puis ferme le sac de sport.

# Consigne

Complète la forme compacte avec répétition.

# Texte à trous

Algorithme : ranger le matériel
Début
  Répéter [[1]] fois :
    mettre [[2]] ballon dans le sac
  fermer [[3]]
Fin

# Étiquettes

1. 4
2. 1
3. le sac de sport
4. 2
5. la trousse

# Solution

1, 2, 3

# Feedback

La répétition permet de représenter les 4 ballons : on répète 4 fois l'action de mettre 1 ballon dans le sac, puis on ferme le sac de sport.
