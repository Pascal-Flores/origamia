# Contexte

Consigne de départ :

Pendant la révision, relis la leçon `2` fois puis réponds à `3` questions.

# Consigne

Coche toutes les écritures qui gardent exactement le même sens.
# Réponses

1. RÉPÉTER (2 fois) : RELIRE la leçon / RÉPONDRE à (3) questions
2. RELIRE la leçon / RELIRE la leçon / RÉPONDRE à (3) questions
3. RELIRE la leçon / RÉPONDRE à (3) questions / RELIRE la leçon
4. RÉPÉTER (3 fois) : RELIRE la leçon / RÉPONDRE à (2) questions

# Solution

1, 2

# Feedback

Les réponses `1` et `2` gardent le même sens : deux relectures, puis trois questions. La réponse `3` déplace une relecture après les questions, et la réponse `4` échange les nombres.
