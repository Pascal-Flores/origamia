# Contexte

Pour passer du travail individuel au travail en binôme, une instruction est valide si elle contient une action claire et l'objet ou le lieu nécessaire.

# Consigne

Classe les propositions.

# Catégories

1. Instructions valides
2. Instructions invalides

# Étiquettes

1. « Tourner sa chaise vers son binôme. »
2. « Poser le cahier entre les deux élèves. »
3. « Tourner. »
4. « Le cahier entre les deux. »

# Solution

1: 1, 2
2: 3, 4

# Feedback essai 1

Une instruction doit dire clairement quoi faire.

# Feedback essai 2

Les propositions 3 et 4 sont incomplètes : il manque soit l'objet, soit l'action.

# Feedback

Les deux premières phrases donnent une action précise et ce sur quoi elle porte.
