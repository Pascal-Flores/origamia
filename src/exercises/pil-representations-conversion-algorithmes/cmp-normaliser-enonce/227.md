# Contexte

Une instruction est complète quand elle indique clairement l'action et ce sur quoi elle porte.

# Consigne

Classe les propositions.

# Items

1. Prendre le cahier rouge.
2. Ranger la règle dans la trousse.
3. Prendre.
4. Le cahier sur la table.
5. `move: OUVRIR le manuel page 12`
6. `move: RANGER`

# Catégories

## Instructions valides
1, 2, 5

## Instructions invalides
3, 4, 6

# Feedback essai 1

Une instruction doit permettre de savoir quoi faire sans deviner.

# Feedback essai 2

Cherche un verbe d'action précis et l'objet concerné.

# Feedback

Les propositions 1, 2 et 5 indiquent une action complète. Les autres sont incomplètes ou ne disent pas clairement sur quoi agir.
