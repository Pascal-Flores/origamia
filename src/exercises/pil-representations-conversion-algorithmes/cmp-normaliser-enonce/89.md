# Énoncé

Consigne de départ :

Lis la première strophe `2` fois, puis récite-la sans regarder.

Coche toutes les écritures qui gardent exactement le même sens.

# Réponses

1. LIRE la première strophe / LIRE la première strophe / RÉCITER sans regarder
2. RÉPÉTER (2 fois) : LIRE la première strophe / RÉCITER sans regarder
3. RÉPÉTER (2 fois) : RÉCITER sans regarder / LIRE la première strophe
4. LIRE la première strophe / RÉCITER sans regarder

# Solution

1, 2

# Feedback

Les réponses `1` et `2` disent la même chose que la consigne : la lecture de la première strophe est faite deux fois, puis on récite sans regarder. Les autres réponses changent l’ordre ou oublient une lecture.
