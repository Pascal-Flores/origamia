# Contexte

Voici une séquence écrite en étapes numérotées pour faire signer un agenda.

Elle contient plusieurs problèmes de forme.

```
1. Ouvrir l'agenda à la bonne semaine.
2. Écrire "signature" dans la case du vendredi.
- Faire signer l'agenda.
4. Vérifier.
5. Ranger l'agenda dans le cartable.
```

# Consigne

Coche tous les problèmes de forme présents dans cette séquence.

# Réponses

1. Une ligne n'a pas la forme d'une étape numérotée.
2. Une étape est trop vague.
3. Les étapes sont toutes dans la même forme.
4. Il manque la ligne Début.
5. Il manque la ligne Fin.

# Solution

1, 2

# Feedback

La ligne "- Faire signer l'agenda." casse la forme des étapes numérotées. L'étape "4. Vérifier." est trop vague : elle ne précise pas ce qu'il faut vérifier. Dans une liste d'étapes numérotées, les lignes Début et Fin ne sont pas nécessaires.
