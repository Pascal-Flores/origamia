# Contexte

Voici un programme écrit en blocs.

```blockly
event: DÉBUT
move: OUVRIR le classeur d'histoire
move: RANGER la feuille dans l'intercalaire Révolution
move: FERMER le classeur
end: FIN
```

# Consigne

On veut réécrire ce programme en pseudocode. Coche toutes les informations qui doivent rester identiques pour garder le même fond.

# Réponses

1. Les actions ouvrir, ranger et fermer.
2. Le classeur concerné : le classeur d'histoire.
3. L'endroit où ranger la feuille : l'intercalaire Révolution.
4. La couleur et la forme des blocs.
5. La manière dont les blocs sont assemblés à l'écran.

# Solution

1, 2, 3

# Feedback

Le fond du programme demande d'ouvrir le classeur d'histoire, de ranger la feuille dans le bon intercalaire, puis de fermer le classeur. La couleur, la forme et l'assemblage visuel des blocs appartiennent au support d'écriture.
