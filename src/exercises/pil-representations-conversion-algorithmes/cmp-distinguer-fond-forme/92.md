# Contexte

Voici une instruction écrite comme un petit algorithme.

Le fond du programme, c'est ce qu'il demande de faire. La forme, c'est la manière de l'écrire ou de le présenter.

```
Algorithme : ranger l'autorisation
Début
  glisser l'autorisation signée dans la pochette rouge
Fin
```

# Consigne

Classe chaque élément dans la bonne colonne.

# Catégories

1. Informations sur ce que le programme fait
2. Éléments de forme ou de présentation

# Étiquettes

1. L'action : glisser.
2. Le document : l'autorisation signée.
3. L'endroit : dans la pochette rouge.
4. Le titre Algorithme : ranger l'autorisation.
5. Le retrait avant la ligne d'instruction.
6. Les lignes Début et Fin.

# Solution

1: 1, 2, 3
2: 4, 5, 6

# Feedback

Le fond indique l'action, le document concerné et l'endroit où le mettre. Le titre, le retrait et les lignes Début et Fin servent à présenter le petit algorithme.
