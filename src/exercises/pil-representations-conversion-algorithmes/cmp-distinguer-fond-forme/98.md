# Contexte

Voici un programme écrit en pseudocode.

```
Algorithme : nettoyer les pinceaux
Début
  Répéter 2 fois :
    rincer le pinceau
    l'essuyer sur le chiffon
  fermer le pot d'eau
Fin
```

# Consigne

Complète le texte pour expliquer ce qui appartient au fond du programme et ce qui appartient à sa forme d'écriture.

# Texte à trous

Pour garder le même programme en blocs, il faut conserver les deux actions répétées : [[1]] et [[2]]. Il faut aussi conserver le nombre de répétitions : [[3]]. La ligne Début, la ligne Fin et le retrait des lignes aident surtout à [[4]].

# Étiquettes

1. rincer le pinceau
2. l'essuyer sur le chiffon
3. deux fois
4. présenter le programme clairement
5. changer le sens du programme
6. cinq fois
7. mettre le titre en majuscules

# Solution

1, 2, 3, 4

# Feedback

Le fond comprend les actions répétées, leur nombre de répétitions et l'action qui reste hors de la répétition. Les lignes Début et Fin ainsi que le retrait servent surtout à rendre le pseudocode lisible.
