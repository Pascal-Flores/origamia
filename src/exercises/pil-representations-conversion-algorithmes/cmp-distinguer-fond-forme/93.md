# Contexte

Voici une instruction écrite en blocs.

Le fond du programme, c'est ce qu'il demande de faire. La forme, c'est la manière de l'écrire ou de le présenter.

```blockly
event: DÉBUT
say: ÉCRIRE "Réunion jeudi" sur l'affiche
end: FIN
```

# Consigne

Classe chaque élément dans la bonne colonne.

# Catégories

1. Informations sur ce que le programme fait
2. Éléments de forme ou de présentation

# Étiquettes

1. L'action : écrire.
2. Le texte : Réunion jeudi.
3. Le support : l'affiche.
4. Les guillemets autour du texte.
5. La couleur du bloc.
6. L'assemblage vertical des blocs.

# Solution

1: 1, 2, 3
2: 4, 5, 6

# Feedback

Écrire, le texte à écrire et l'affiche donnent le sens de l'instruction. Les guillemets, la couleur du bloc et l'assemblage des blocs appartiennent à la manière de présenter le programme.
