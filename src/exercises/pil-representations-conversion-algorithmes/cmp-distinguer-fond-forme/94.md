# Contexte

Voici un programme écrit en langage naturel.

Pour démarrer l'atelier lecture, prendre la tablette dans le chariot, ouvrir l'application Lecture, puis régler le minuteur sur 5 minutes.

# Consigne

On veut réécrire ce programme en blocs. Coche toutes les informations qui doivent rester identiques pour garder le même fond.

# Réponses

1. L'ordre des trois actions.
2. L'action de prendre la tablette dans le chariot.
3. Le réglage du minuteur sur 5 minutes.
4. Le fait que la phrase soit écrite sur une seule ligne.
5. Les mots de liaison comme pour et puis.

# Solution

1, 2, 3

# Feedback

Quand on change de forme d'écriture, il faut garder les actions, leurs informations utiles et leur ordre. La longueur de la phrase et les mots de liaison peuvent changer sans changer le fond du programme.
