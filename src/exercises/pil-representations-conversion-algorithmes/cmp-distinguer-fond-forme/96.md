# Contexte

Voici un programme écrit en pseudocode.

```
Algorithme : préparer l'annonce
Début
  écrire "Réunion vendredi" sur l'affiche
  afficher l'affiche sur le panneau du couloir
  prévenir la classe
Fin
```

# Consigne

On veut réécrire ce programme en langage naturel. Coche toutes les informations qui doivent rester identiques pour garder le même fond.

# Réponses

1. Le message à écrire : Réunion vendredi.
2. Le lieu d'affichage : le panneau du couloir.
3. L'ordre : écrire l'annonce avant de l'afficher.
4. Le titre exact Algorithme : préparer l'annonce.
5. Le retrait des lignes entre Début et Fin.

# Solution

1, 2, 3

# Feedback

Le message, le lieu d'affichage et l'ordre des actions donnent le fond du programme. Le titre et les retraits aident à présenter le pseudocode, mais ils peuvent changer quand on écrit le même programme autrement.
