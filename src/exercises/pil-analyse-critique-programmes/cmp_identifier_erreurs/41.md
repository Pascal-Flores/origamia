# Énoncé

Le programme de cet exercice décrit comment ranger une trousse dans un casier.

Le code du casier est `5312`.

Après avoir exécuté le programme, on se rend compte que le casier ne s'ouvre pas et que la trousse n'est pas rangée.

Choisis la ou les réponses qui expliquent pourquoi le programme comporte une erreur.

```
event: DÉBUT
move: ENTRER le code (2580)
move: OUVRIR le casier
move: RANGER la trousse dans le casier
move: FERMER le casier
end: FIN
```

# Réponses

1. L'instruction `ENTRER le code (2580)` est incorrecte.
2. Le casier ne peut pas s'ouvrir, car le code entré n'est pas le bon.
3. L'instruction `RANGER la trousse dans le casier` est incorrecte.
4. L'instruction `FERMER le casier` devrait se trouver au début du programme.

# Solution

1, 2

# Feedback

Les réponses `1` et `2` sont correctes : le programme entre `2580` au lieu de `5312`, donc le casier ne peut pas s'ouvrir et la trousse ne peut pas être rangée. Les réponses `3` et `4` sont fausses, car le problème ne vient ni de l'action de ranger la trousse ni de la place de `FERMER le casier`.
