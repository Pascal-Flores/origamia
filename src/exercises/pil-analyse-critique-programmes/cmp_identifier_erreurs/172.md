# Contexte

La mission est de mettre son manteau, prendre ses clés, dire au revoir puis sortir.

```
METTRE le manteau
SORTIR
PRENDRE les clés
DIRE au revoir
```

# Consigne

Quelles affirmations expliquent pourquoi la mission n'est pas accomplie correctement ?

# Réponses

1. Les clés sont prises après être sorti.
2. Le manteau est mis avant de sortir.
3. Le « au revoir » arrive après la sortie.
4. Il faudrait enlever le manteau avant de sortir.

# Solution

1, 3

# Feedback essai 1

Clac, imaginons que la porte se referme ! Avec ce programme, est-ce qu’on a fait tout ce qu’il faut avant de sortir ?

# Feedback essai 2

On a bien pris le manteau. Mais moi, je me demande ce que le programme essaie encore de faire une fois qu’on est dehors.

# Feedback

On a repéré les deux oublis avant la porte. Il faut prendre les clés et dire au revoir avant de sortir, sinon c’est trop tard.
