# Contexte

La mission est de mettre son manteau, prendre ses clés, dire au revoir puis sortir.

```
METTRE le manteau
SORTIR
PRENDRE les clés
DIRE au revoir
```

# Consigne

Quelles affirmations expliquent pourquoi la mission n'est pas accomplie correctement ?

# Réponses

1. Les clés sont prises après être sorti.
2. Le manteau est mis avant de sortir.
3. Le « au revoir » arrive après la sortie.
4. Il faudrait enlever le manteau avant de sortir.

# Solution

1, 3

# Feedback essai 1

Et si on jouait la scène jusqu’au moment où la porte se referme ? Qu’est-ce qui doit déjà être fait ?

# Feedback essai 2

Le manteau est bien mis à temps. Qu’est-ce que le programme essaie encore de faire une fois dehors ?

# Feedback

On voit ce qui coince : les clés sont prises trop tard et le « au revoir » arrive aussi après la sortie. Les deux doivent venir avant.
