# Contexte

La mission est de mettre son manteau, prendre ses clés, dire au revoir puis sortir.

```
METTRE le manteau
SORTIR
PRENDRE les clés
DIRE au revoir
```

# Consigne

Quelles affirmations expliquent pourquoi la mission n'est pas accomplie correctement ?

# Réponses

1. Les clés sont prises après être sorti.
2. Le manteau est mis avant de sortir.
3. Le « au revoir » arrive après la sortie.
4. Il faudrait enlever le manteau avant de sortir.

# Solution

1, 3

# Feedback essai 1

Repère les actions qui devraient forcément avoir lieu avant `SORTIR`.

# Feedback

Prendre les clés et dire au revoir doivent se faire avant de sortir. Leur position explique l'échec.
