# Contexte

Le professeur pose une question. Écris le résultat sur l’ardoise. Il doit rester visible quand tu lui montres l’ardoise.

# Consigne

Observe le programme ci-dessous. Quelle instruction faut-il retirer pour que le programme fonctionne ?

```
event: DÉBUT
move: PRENDRE l’ardoise
move: ATTENDRE la question du professeur
move: ÉCRIRE le résultat
move: EFFACER l’ardoise
move: MONTRER le résultat
end: FIN
```

# Réponses

1. `move: PRENDRE l’ardoise`
2. `move: ÉCRIRE le résultat`
3. `move: EFFACER l’ardoise`
4. `move: MONTRER le résultat`

# Solution

3

# Feedback essai 1

Tiens, ça ne marche pas encore. Et si on jouait le programme dans notre tête ? Au moment de montrer l’ardoise, qu’est-ce qu’il y a dessus ?

# Feedback essai 2

Moi, j’ai l’impression qu’une action fait disparaître notre réponse avant qu’on la montre… Laquelle pourrait bien faire ça ?

# Feedback

Pas de chance cette fois ! On a quand même bien cherché. Si on retire le bloc qui efface, le résultat est encore là quand on montre l’ardoise.
