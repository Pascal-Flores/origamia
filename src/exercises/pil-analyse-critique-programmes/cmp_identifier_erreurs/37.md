# Contexte

Quand le professeur pose une question et que tu dois répondre avec l’ardoise, il faut faire certaines actions dans le bon ordre.

# Consigne

Observe le programme ci-dessous. Quelle instruction rend le programme faux ?

```
event: DÉBUT
move: PRENDRE l'ardoise
move: ATTENDRE la question de l'enseignant
move: ÉCRIRE le résultat
move: EFFACER l'ardoise
move: MONTRER le résultat
end: FIN
```

# Réponses

1. `move: PRENDRE l'ardoise`
2. `move: ÉCRIRE le résultat`
3. `move: EFFACER l'ardoise`
4. `move: MONTRER le résultat`

# Solution

3

# Feedback

L’instruction fautive est `EFFACER l'ardoise`, car elle arrive avant `MONTRER le résultat`. Si on efface l’ardoise trop tôt, on ne peut plus lire la réponse. `PRENDRE l'ardoise` est correct au début, `ÉCRIRE le résultat` est bien nécessaire, et `MONTRER le résultat` doit justement se faire avant d’effacer.
