# Contexte

La règle est simple : vérifier l'heure, puis préparer ce qui manque, puis partir. Trois programmes sont proposés.

# Consigne

Sélectionne les programmes qui contiennent une erreur empêchant de respecter cette règle.

# Réponses

1. ```
VÉRIFIER l'heure
PRÉPARER ce qui manque
PARTIR
```
2. ```
PARTIR
VÉRIFIER l'heure
PRÉPARER ce qui manque
```
3. ```
VÉRIFIER l'heure
PARTIR
PRÉPARER ce qui manque
```

# Solution

2, 3

# Feedback essai 1

Dans chaque programme, cherche si une action nécessaire est placée après le départ.

# Feedback essai 2

Le départ doit être la dernière des trois actions.

# Feedback

Les programmes 2 et 3 placent une action nécessaire après `PARTIR`. Seul le programme 1 respecte la mission.
