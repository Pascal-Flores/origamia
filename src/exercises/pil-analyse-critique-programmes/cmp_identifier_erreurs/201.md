# Contexte

Pendant la récréation, deux fenêtres de la classe sont ouvertes pour aérer. Avant le retour des élèves, les deux fenêtres doivent être refermées.

Trois programmes décrivent la procédure.

# Consigne

Sélectionne les programmes qui contiennent une erreur et ne permettent pas de terminer avec les deux fenêtres fermées.

# Réponses

1. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
FERMER la fenêtre droite
```
2. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
```
3. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
FERMER la fenêtre droite
OUVRIR la fenêtre gauche
```

# Solution

2, 3

# Feedback essai 1

Regarde l'état de chaque fenêtre à la toute fin de chaque programme.

# Feedback essai 2

Le programme est correct uniquement si la fenêtre gauche et la fenêtre droite sont toutes les deux fermées à la fin.

# Feedback

Le programme 2 laisse la fenêtre droite ouverte. Le programme 3 referme d'abord les deux fenêtres, mais rouvre ensuite la fenêtre gauche. Seul le programme 1 se termine avec les deux fenêtres fermées.
