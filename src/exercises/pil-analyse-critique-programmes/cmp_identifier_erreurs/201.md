# Contexte

Un robot doit avancer de 3 cases, tourner à droite, puis avancer de 2 cases.

# Consigne

Quels programmes contiennent une erreur empêchant d'obtenir ce déplacement ?

# Réponses

1. ```
AVANCER de 3 cases
TOURNER à droite
AVANCER de 2 cases
```
2. ```
AVANCER de 2 cases
TOURNER à droite
AVANCER de 3 cases
```
3. ```
AVANCER de 3 cases
TOURNER à gauche
AVANCER de 2 cases
```
4. ```
AVANCER de 3 cases
TOURNER à droite
AVANCER de 1 case
AVANCER de 1 case
```

# Solution

2, 3

# Feedback essai 1

Compare chaque programme avec les trois effets demandés, sans juger seulement le nombre de lignes.

# Feedback essai 2

Le programme 4 découpe seulement la dernière avance en deux instructions équivalentes.

# Feedback

Les programmes 2 et 3 modifient respectivement les distances et le sens du virage. Les programmes 1 et 4 produisent le déplacement demandé.
