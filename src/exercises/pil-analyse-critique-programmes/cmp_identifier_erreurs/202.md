# Contexte

Pendant dix minutes, tu ranges ta chambre. À la fin, on veut obtenir exactement ce résultat :

- les livres sont sur l'étagère ;
- les jeux sont dans la boîte à jeux ;
- les vêtements sales sont dans le panier à linge.

# Consigne

Parmi les programmes suivants, sélectionne ceux qui contiennent une erreur empêchant d'obtenir ce résultat.

# Réponses

1. `RANGER les livres sur l'étagère → RANGER les jeux dans la boîte à jeux → METTRE les vêtements sales dans le panier à linge`
2. `RANGER les livres dans la boîte à jeux → RANGER les jeux sur l'étagère → METTRE les vêtements sales dans le panier à linge`
3. `RANGER les livres sur l'étagère → RANGER les jeux dans la boîte à jeux → POSER les vêtements sales sur le lit`
4. `METTRE les vêtements sales dans le panier à linge → RANGER les jeux dans la boîte à jeux → RANGER les livres sur l'étagère`

# Solution

2, 3

# Feedback essai 1

Pour chaque programme, compare l'endroit où finit chaque type d'objet avec le résultat demandé.

# Feedback essai 2

L'ordre entre les trois rangements peut changer. Ce qui compte ici est que les livres, les jeux et les vêtements terminent chacun au bon endroit.

# Feedback

Le programme 2 échange la place des livres et des jeux. Le programme 3 laisse les vêtements sur le lit au lieu de les mettre dans le panier à linge. Les programmes 1 et 4 aboutissent tous deux au résultat demandé.
