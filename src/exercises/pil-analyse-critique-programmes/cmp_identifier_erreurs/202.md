# Contexte

Le programme doit afficher « prêt », attendre 2 secondes puis effacer l'écran.

# Consigne

Quels programmes contiennent une erreur qui empêche d'obtenir ce comportement ?

# Réponses

1. ```
AFFICHER « prêt »
ATTENDRE 2 secondes
EFFACER l'écran
```
2. ```
ATTENDRE 2 secondes
AFFICHER « prêt »
EFFACER l'écran
```
3. ```
AFFICHER « prêt »
EFFACER l'écran
ATTENDRE 2 secondes
```
4. ```
AFFICHER « prêt »
ATTENDRE 1 seconde
ATTENDRE 1 seconde
EFFACER l'écran
```

# Solution

2, 3

# Feedback essai 1

Le message doit être visible pendant les deux secondes.

# Feedback essai 2

Deux attentes successives d'une seconde ont le même effet temporel qu'une attente de deux secondes.

# Feedback

Les programmes 2 et 3 déplacent l'attente ou l'effacement au mauvais endroit. Les programmes 1 et 4 gardent le message visible pendant deux secondes avant l'effacement.
