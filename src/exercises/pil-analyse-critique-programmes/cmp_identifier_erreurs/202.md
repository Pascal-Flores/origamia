# Contexte

Après le goûter, la table doit finir propre : manger, mettre la vaisselle de côté, essuyer la table, puis ranger la vaisselle.

# Consigne

Parmi les programmes suivants, sélectionne ceux qui contiennent une erreur empêchant d'obtenir ce résultat.

# Réponses

1. `MANGER → METTRE la vaisselle de côté → ESSUYER la table → RANGER la vaisselle`
2. `ESSUYER la table → MANGER → METTRE la vaisselle de côté → RANGER la vaisselle`
3. `MANGER → RANGER la vaisselle → ESSUYER la table → METTRE la vaisselle de côté`
4. `MANGER → METTRE la vaisselle de côté → RANGER la vaisselle → ESSUYER la table`

# Solution

2, 3

# Feedback essai 1

Vérifie si une action rend impossible ou inutile une action qui vient ensuite.

# Feedback essai 2

Essuyer avant de manger ne garantit pas une table propre à la fin ; ranger avant de mettre la vaisselle de côté est incohérent.

# Feedback

Les programmes 2 et 3 contiennent une inversion qui casse la mission. Les programmes 1 et 4 aboutissent tous deux à une table propre et à la vaisselle rangée.
