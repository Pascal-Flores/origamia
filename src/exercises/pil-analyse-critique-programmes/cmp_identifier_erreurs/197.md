# Contexte

Pendant un temps libre, tu veux choisir un livre, le lire puis le ranger.

# Consigne

Quelle instruction rend ce programme incohérent ?

```
event: DÉBUT
move: PRENDRE un livre
move: RANGER le livre
move: LIRE le livre
end: FIN
```

# Réponses

1. `PRENDRE un livre`
2. `RANGER le livre`
3. `LIRE le livre`

# Solution

2

# Feedback essai 1

Observe où se trouve le livre au moment où tu dois le lire.

# Feedback

Le livre est rangé avant la lecture. L'instruction `RANGER le livre` est donc placée trop tôt et empêche le résultat attendu.
