# Contexte

Pour vérifier les affaires de sport, le programme devrait regarder les chaussures puis la tenue, puis annoncer que le sac est prêt.

```
event: DÉBUT
move: VÉRIFIER les chaussures
say: AFFICHER "Sac prêt"
move: VÉRIFIER la tenue
end: FIN
```

# Consigne

Quelle instruction rend le programme incohérent avec le résultat attendu ?

# Réponses

1. `VÉRIFIER les chaussures`
2. `AFFICHER "Sac prêt"`
3. `VÉRIFIER la tenue`

# Solution

2

# Feedback essai 1

Le message « Sac prêt » ne doit apparaître qu'une fois toutes les vérifications terminées.

# Feedback

Le programme annonce que le sac est prêt avant d'avoir vérifié la tenue. C'est cette instruction qui arrive trop tôt.
