# Contexte

Le cartable doit contenir l'agenda et la trousse avant d'être fermé.

# Consigne

Quelle instruction rend le programme faux ?

```
event: DÉBUT
move: METTRE l'agenda dans le cartable
move: FERMER le cartable
move: METTRE la trousse dans le cartable
end: FIN
```

# Réponses

1. `METTRE l'agenda dans le cartable`
2. `FERMER le cartable`
3. `METTRE la trousse dans le cartable`

# Solution

2

# Feedback essai 1

Une action empêche l'action suivante d'être réalisée normalement.

# Feedback

Le cartable est fermé avant l'ajout de la trousse. C'est cette instruction qui rend le programme incohérent avec la mission.
