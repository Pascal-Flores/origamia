# Contexte

La routine attendue est : prendre la brosse, se brosser les dents, rincer la brosse, puis la ranger.

```
event: DÉBUT
move: PRENDRE la brosse
move: RANGER la brosse
move: SE BROSSER les dents
move: RINCER la brosse
end: FIN
```

# Consigne

Quelle instruction rend ce programme incohérent ?

# Réponses

1. `PRENDRE la brosse`
2. `RANGER la brosse`
3. `SE BROSSER les dents`
4. `RINCER la brosse`

# Solution

2

# Feedback essai 1

Cherche l'action qui empêche d'utiliser ensuite l'objet.

# Feedback

La brosse est rangée avant le brossage et le rinçage. `RANGER la brosse` est donc placée au mauvais moment.
