# Contexte

On veut mettre une tablette en charge, attendre qu’elle soit chargée, puis la ranger au bon endroit.

À la fin, la tablette doit avoir été chargée correctement et posée sur l’étagère prévue.

Critères de réussite :

- le chargeur est branché à une prise ;
- la tablette est reliée au chargeur avant le temps d’attente ;
- la tablette est rangée seulement après le chargement.

# Consigne

Parmi les 3 programmes donnés, coche ceux qui comportent une erreur qui empêche d’obtenir le résultat attendu.
# Réponses

1. ```blockly
event: DÉBUT
move: BRANCHER le chargeur à une prise
move: BRANCHER le chargeur à la tablette
move: ATTENDRE que la tablette soit chargée
move: DÉBRANCHER le chargeur et le ranger
move: RANGER la tablette sur l'étagère
end: FIN
```
2. ```blockly
event: DÉBUT
move: BRANCHER le chargeur à une prise
move: BRANCHER le chargeur à la tablette
move: DÉBRANCHER le chargeur et le ranger
move: ATTENDRE que la tablette soit chargée
move: RANGER la tablette sur l'étagère
end: FIN
```
3. ```blockly
event: DÉBUT
move: BRANCHER le chargeur à la tablette
move: ATTENDRE que la tablette soit chargée
move: DÉBRANCHER le chargeur et le ranger
move: RANGER la tablette sur l'étagère
end: FIN
```

# Solution

2, 3

# Feedback

Les programmes `2` et `3` comportent une erreur. Dans le programme `2`, on débranche et on range le chargeur avant d’attendre que la tablette soit chargée : le chargement ne peut donc pas se faire correctement. Dans le programme `3`, le chargeur n’est jamais branché à une prise, donc la tablette ne peut pas charger. Le programme `1` est le seul qui respecte les trois critères.
