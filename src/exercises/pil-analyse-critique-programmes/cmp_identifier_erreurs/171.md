# Contexte

La classe prépare trois ateliers en rotation :

- table 1 : lecture, avec les fiches de lecture ;
- table 2 : géométrie, avec les équerres ;
- table 3 : dessin, avec les feutres.

Pour représenter la mise en place prévue, un élève a écrit le programme suivant :

```
METTRE les fiches de lecture sur la table 1
METTRE les équerres sur la table 3
METTRE les feutres sur la table 2
ANNONCER "Ateliers prêts"
```

# Consigne

Sélectionne les affirmations qui expliquent pourquoi les ateliers ne sont pas correctement préparés.

# Réponses

1. Les équerres sont placées sur la table 3 au lieu de la table 2.
2. Les fiches de lecture sont placées sur la table 1.
3. Les feutres sont placés sur la table 2 au lieu de la table 3.
4. La table de lecture est préparée avant la table de géométrie.

# Solution

1, 3

# Feedback essai 1

Compare pour chaque table le matériel prévu dans la consigne avec celui placé par le programme.

# Feedback

La table 2 doit recevoir les équerres et la table 3 les feutres. Le programme inverse ces deux matériels. Les fiches de lecture sont, elles, correctement placées sur la table 1.
