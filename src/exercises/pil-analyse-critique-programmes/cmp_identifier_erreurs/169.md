# Contexte

La couverture d'un cahier est déchirée. Pour représenter la procédure de réparation, on a écrit le programme ci-dessous.

Pour réparer la couverture, il faut poser le cahier à plat, prendre le rouleau de scotch, tirer une bande de scotch, la coller sur la déchirure, puis ranger le rouleau.

```
event: DÉBUT
move: POSER le cahier à plat
move: PRENDRE le rouleau de scotch
move: RANGER le rouleau de scotch
move: TIRER une bande de scotch
move: COLLER la bande sur la déchirure
end: FIN
```

# Consigne

Quelle instruction rend le programme incohérent avec la procédure attendue ?

# Réponses

1. `POSER le cahier à plat`
2. `PRENDRE le rouleau de scotch`
3. `RANGER le rouleau de scotch`
4. `COLLER la bande sur la déchirure`

# Solution

3

# Feedback essai 1

Cherche l'action qui empêche d'utiliser ensuite le rouleau de scotch.

# Feedback

Le rouleau est rangé avant que la bande de scotch soit tirée. `RANGER le rouleau de scotch` arrive donc trop tôt et empêche de poursuivre la réparation comme prévu.
