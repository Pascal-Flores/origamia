# Contexte

Pendant la récréation, deux fenêtres de la classe sont ouvertes pour aérer. Avant le retour des élèves, les deux fenêtres doivent être refermées.

Trois programmes décrivent la procédure.

# Consigne

Sélectionne les programmes qui contiennent une erreur et ne permettent pas de terminer avec les deux fenêtres fermées.

# Réponses

1. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
FERMER la fenêtre droite
```
2. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
```
3. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
FERMER la fenêtre droite
OUVRIR la fenêtre gauche
```

# Solution

2, 3

# Feedback essai 1

On pourrait noter l’état des deux fenêtres à la fin de chaque programme. Est-ce qu’elles restent toutes les deux fermées ?

# Feedback essai 2

Même si une fenêtre est fermée au milieu du programme, une action plus tard peut la rouvrir. Que voit-on à la toute fin ?

# Feedback

On voit deux pièges : un programme laisse la fenêtre droite ouverte. Un autre referme les deux, puis rouvre celle de gauche.
