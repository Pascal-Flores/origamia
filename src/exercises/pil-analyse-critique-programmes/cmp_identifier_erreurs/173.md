# Contexte

Pendant la récréation, deux fenêtres de la classe sont ouvertes pour aérer. Avant le retour des élèves, les deux fenêtres doivent être refermées.

Trois programmes décrivent la procédure.

# Consigne

Sélectionne les programmes qui contiennent une erreur et ne permettent pas de terminer avec les deux fenêtres fermées.

# Réponses

1. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
FERMER la fenêtre droite
```
2. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
```
3. ```
OUVRIR la fenêtre gauche
OUVRIR la fenêtre droite
FERMER la fenêtre gauche
FERMER la fenêtre droite
OUVRIR la fenêtre gauche
```

# Solution

2, 3

# Feedback essai 1

Je sens presque un courant d’air ! On pourrait regarder chacune des deux fenêtres une fois que le programme a fini. Dans quel état est-elle ?

# Feedback essai 2

Fermer une fenêtre au milieu ne suffit pas si on la rouvre ensuite. Si on attend la fin, est-ce que les deux sont vraiment fermées ?

# Feedback

Ah, voilà d’où vient le courant d’air ! Un programme laisse la fenêtre droite ouverte. Un autre ferme les deux, puis rouvre celle de gauche.
