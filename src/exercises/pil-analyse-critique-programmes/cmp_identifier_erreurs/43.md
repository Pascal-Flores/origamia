# Contexte

Pour une sortie scolaire, on veut préparer une petite trousse de secours.

À la fin, la trousse doit contenir un pansement, une compresse et un petit flacon de désinfectant.

Critères de réussite :

- la trousse est ouverte avant qu’on y range le matériel ;
- les trois éléments demandés sont bien placés dans la trousse ;
- la trousse est refermée à la fin.

# Consigne

Parmi les 3 programmes donnés, coche ceux qui comportent une erreur qui empêche d’obtenir le résultat attendu.

move: OUVRIR la trousse

move: METTRE (1) flacon de désinfectant dans la trousse

# Solution

2, 3

# Feedback essai 1

Contrôle chaque programme avec les trois critères, un par un : ouverture, contenu complet, puis fermeture.

# Feedback essai 2

Un programme agit avant d'ouvrir la trousse ; un autre oublie la compresse. Le programme restant respecte les trois critères.

# Feedback

Les programmes `2` et `3` comportent une erreur. Dans le programme `2`, on essaie de mettre un pansement dans la trousse avant de l’ouvrir : l’ordre des actions n’est donc pas correct. Dans le programme `3`, la compresse n’est jamais ajoutée, donc la trousse n’est pas complète à la fin. Le programme `1` est le seul qui respecte tous les critères.
