# Contexte

Le programme de cet exercice décrit comment noter les devoirs dans un agenda.

Après avoir exécuté le programme, on se rend compte que les devoirs n'ont pas été notés dans l'agenda.

# Consigne

Choisis la ou les réponses qui expliquent pourquoi le programme comporte une erreur.

```
event: DÉBUT
move: OUVRIR l'agenda
move: CHERCHER la date du jour
move: FERMER l'agenda
end: FIN
```

# Réponses

1. Le programme ne contient pas d'instruction pour écrire les devoirs.
2. L'agenda devrait déjà être ouvert au début du programme.
3. L'instruction `OUVRIR l'agenda` est incorrecte.
4. Il faudrait ajouter une instruction pour écrire les devoirs avant de fermer l'agenda.

# Solution

1, 4

# Feedback essai 1

Cherche l'instruction qui devrait réellement inscrire les devoirs, pas seulement ouvrir l'agenda ou trouver la date.

# Feedback essai 2

Le programme atteint la bonne date, mais aucune action n'écrit les devoirs. Plusieurs affirmations peuvent décrire ce même manque.

# Feedback

Les réponses `1` et `4` sont correctes : le programme cherche bien la date du jour, mais il ne contient aucune instruction pour écrire les devoirs. Les réponses `2` et `3` sont fausses, car le problème ne vient pas de l'ouverture de l'agenda, mais de l'absence d'une instruction pour noter les devoirs.
