# Énoncé

Avant de commencer une partie, on veut installer un jeu de l’oie pour 4 joueurs.

À la fin, le plateau doit être au centre, chaque joueur doit avoir un pion placé sur la case de départ, et le dé doit être prêt à être lancé.

Critères de réussite :

- le plateau est installé avant la mise en place du reste du matériel ;
- les pions sont placés au bon endroit avant le début de la partie ;
- le dé est préparé à la fin.

Parmi les 3 programmes donnés, coche ceux qui comportent une erreur qui empêche d’obtenir le résultat attendu.

# Réponses

1. ```event: DÉBUT
move: METTRE le plateau sur la table
move: PLACER les pions sur la case départ
move: DONNER le dé au premier joueur
end: FIN
```
2. ```event: DÉBUT
move: PLACER les pions sur la case départ
move: METTRE le plateau sur la table
move: DONNER le dé au premier joueur
end: FIN
```
3. ```event: DÉBUT
move: METTRE le plateau sur la table
move: DONNER le dé au premier joueur
end: FIN
```

# Solution

2, 3

# Feedback

Les programmes `2` et `3` comportent une erreur. Dans le programme `2`, on place les pions avant d’avoir mis le plateau sur la table : les actions ne sont donc pas dans le bon ordre. Dans le programme `3`, les pions ne sont jamais placés sur la case de départ, donc le jeu n’est pas complètement installé. Le programme `1` est le seul qui prépare correctement la partie.
