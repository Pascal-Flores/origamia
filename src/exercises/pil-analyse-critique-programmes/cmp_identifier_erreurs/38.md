# Contexte

Lors du cours d'arts plastiques, il est demandé de sortir un crayon gris, du papier canson et une gomme.

# Consigne

Observe le programme ci-dessous. Quelle instruction rend le programme faux ?

```
event: DÉBUT
move: OUVRIR le cartable
move: SORTIR (1) crayon gris
move: SORTIR (1) cahier
move: SORTIR (1) gomme
end: FIN
```

# Réponses

1. `move: OUVRIR le cartable`
2. `move: SORTIR (1) crayon gris`
3. `move: SORTIR (1) cahier`
4. `move: SORTIR (1) gomme`

# Solution

3

# Feedback essai 1

Compare la liste du matériel demandé avec chaque instruction. Un objet du programme n'apparaît pas dans la consigne.

# Feedback

L’instruction fautive est `move: SORTIR (1) cahier`, car ce n’est pas le matériel demandé. Il faut sortir du papier canson, pas un cahier.
