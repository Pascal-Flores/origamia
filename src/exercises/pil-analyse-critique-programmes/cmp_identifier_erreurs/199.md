# Contexte

Le sac doit contenir l'agenda, la trousse et le cahier du jour avant d'être fermé.

```
PRENDRE l'agenda
PRENDRE la trousse
FERMER le sac
PRENDRE le cahier du jour
ANNONCER "Sac prêt"
```

# Consigne

Sélectionne les affirmations qui expliquent l'échec du programme.

# Réponses

1. Le sac est fermé avant que le cahier du jour soit pris.
2. L'agenda est pris avant la trousse.
3. Le message « Sac prêt » est annoncé alors que le cahier n'a pas pu être rangé.
4. La trousse est inutile.

# Solution

1, 3

# Feedback essai 1

Compare la mission avec l'état du sac au moment où il est fermé.

# Feedback

Le cahier est demandé après la fermeture : il ne peut pas être ajouté. Le message final affirme donc à tort que le sac est prêt.
