# Contexte

Avant une sortie, chaque élève doit avoir un binôme et le professeur doit vérifier que tous les binômes sont complets avant le départ.

# Consigne

Pourquoi le programme suivant ne permet-il pas d'obtenir le résultat attendu ? Sélectionne toutes les bonnes raisons.

```
event: DÉBUT
move: PARTIR vers le point de rendez-vous
move: CHOISIR un binôme
move: VÉRIFIER que le binôme est présent
end: FIN
```

# Réponses

1. Le départ est placé avant le choix du binôme.
2. Le programme vérifie bien la présence du binôme.
3. Le choix du binôme devrait avoir lieu avant le départ.
4. Il faut supprimer toute vérification.

# Solution

1, 3

# Feedback essai 1

Compare l'ordre du programme avec la condition « avant le départ ».

# Feedback

La mission exige que le binôme soit constitué avant de partir. Le programme commence pourtant par le départ : les réponses 1 et 3 décrivent cette erreur.
