# Contexte

Après s'être brossé les dents, il faut rincer la brosse avant de la ranger. Pour représenter cette routine sous forme de programme, on veut donc décrire les actions suivantes : prendre la brosse, se brosser les dents, rincer la brosse, puis la ranger.

Le programme ci-dessous est censé décrire cette procédure, mais une instruction est placée au mauvais moment.

```
event: DÉBUT
move: PRENDRE la brosse
move: RANGER la brosse
move: SE BROSSER les dents
move: RINCER la brosse
end: FIN
```

# Consigne

Observe l'ordre des actions. Quelle instruction rend le programme incohérent avec la procédure attendue ?

# Réponses

1. `PRENDRE la brosse`
2. `RANGER la brosse`
3. `SE BROSSER les dents`
4. `RINCER la brosse`

# Solution

2

# Feedback essai 1

Après avoir pris la brosse, vérifie qu'elle reste disponible pour les actions qui doivent encore être réalisées.

# Feedback

`RANGER la brosse` arrive trop tôt. Une fois la brosse rangée, le programme demande encore de se brosser les dents puis de la rincer, sans prévoir de la reprendre. Cette instruction devrait donc arriver après le brossage et le rinçage.
