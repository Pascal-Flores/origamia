# Contexte

Pendant dix minutes, tu ranges ta chambre.

À la fin, la chambre doit respecter trois critères :

- les livres sont rangés sur l'étagère ;
- les jeux sont rangés dans la boîte à jeux ;
- les vêtements sales sont placés dans le panier à linge.

# Consigne

Parmi les 3 programmes donnés, coche ceux qui comportent une erreur qui empêche d'obtenir le résultat attendu.

# Réponses

1. ```blockly
event: DÉBUT
move: RANGER les livres sur l'étagère
move: RANGER les jeux dans la boîte à jeux
move: METTRE les vêtements sales dans le panier à linge
end: FIN
```
2. ```blockly
event: DÉBUT
move: RANGER les livres dans la boîte à jeux
move: RANGER les jeux sur l'étagère
move: METTRE les vêtements sales dans le panier à linge
end: FIN
```
3. ```blockly
event: DÉBUT
move: RANGER les livres sur l'étagère
move: RANGER les jeux dans la boîte à jeux
move: POSER les vêtements sales sur le lit
end: FIN
```

# Solution

2, 3

# Feedback essai 1

Contrôle chaque programme avec les trois critères, un par un : emplacement des livres, emplacement des jeux, puis emplacement des vêtements sales.

# Feedback essai 2

Un programme échange les emplacements des livres et des jeux ; un autre ne met pas les vêtements sales dans le panier à linge.

# Feedback

Les programmes `2` et `3` comportent une erreur. Dans le programme `2`, les livres sont rangés dans la boîte à jeux et les jeux sur l'étagère : deux critères ne sont donc pas respectés. Dans le programme `3`, les vêtements sales sont posés sur le lit au lieu d'être placés dans le panier à linge. Le programme `1` est le seul qui respecte les trois critères.
