# Contexte

Le programme de cet exercice décrit comment préparer son cartable pour le lendemain, où il y aura cours de maths et d'histoire.

Après avoir exécuté le programme, on se rend compte que le manuel d'histoire est dans le cartable, mais pas le manuel de maths.

# Consigne

Choisis la ou les réponses qui expliquent pourquoi le programme comporte une erreur.

```
event: DÉBUT
move: OUVRIR le cartable
move: METTRE le manuel d'histoire dans le cartable
move: FERMER le cartable
move: METTRE le manuel de maths dans le cartable
end: FIN
```

# Réponses

1. L'instruction `FERMER le cartable` arrive trop tôt.
2. Le manuel de maths ne peut pas être mis dans le cartable, car le cartable est déjà fermé.
3. L'instruction `METTRE le manuel d'histoire dans le cartable` est incorrecte.
4. Il faudrait fermer le cartable seulement après avoir mis les deux manuels.

# Solution

1, 2, 4

# Feedback essai 1

Compare le programme au résultat observé : le manuel d'histoire est rangé, mais celui de maths ne l'est pas.

# Feedback essai 2

Repère le moment où le cartable est fermé. Toute action qui essaie d'ajouter un manuel après ce moment explique l'échec.

# Feedback

Les réponses `1`, `2` et `4` sont correctes : le programme ferme le cartable trop tôt, donc le manuel de maths ne peut pas être ajouté ensuite. La réponse `3` est fausse, car mettre le manuel d'histoire dans le cartable est bien une action attendue.
