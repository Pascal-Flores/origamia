# Contexte

Pour expliquer un jeu, il faut annoncer l'objectif avant de donner le signal de départ. Le programme actuel fait l'inverse.

```
DIRE "Départ"
EXPLIQUER l'objectif
```

# Consigne

Complète la correction.

# Texte à trous

Il faut déplacer l'instruction [[1]] avant l'instruction [[2]]. Ainsi, les joueurs connaissent [[3]] avant que la partie commence.

# Étiquettes

1. `EXPLIQUER l'objectif`
2. `DIRE "Départ"`
3. l'objectif du jeu
4. `DIRE "Départ"`
5. le score final

# Solution

1, 2, 3

# Feedback essai 1

La correction porte uniquement sur l'ordre des deux instructions.

# Feedback

Expliquer l'objectif avant le signal de départ permet aux joueurs de savoir ce qu'ils doivent faire avant de commencer.
