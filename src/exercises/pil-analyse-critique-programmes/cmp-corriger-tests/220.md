# Contexte

Un robot doit avancer exactement 6 cases. Le programme contient :

```
RÉPÉTER 2 FOIS
  AVANCER de 2 cases
FIN RÉPÉTER
```

# Consigne

Complète la correction.

# Texte à trous

Le programme avance actuellement de [[1]] cases. Pour atteindre 6 cases sans changer l'instruction d'avance, il faut remplacer le nombre de répétitions 2 par [[2]]. Le robot avancera alors de [[3]] cases.

# Étiquettes

1. 4
2. 3
3. 6
4. 2
5. 8

# Solution

1, 2, 3

# Feedback essai 1

Deux répétitions de deux cases donnent quatre cases. Cherche ensuite combien de groupes de deux sont nécessaires pour obtenir six.

# Feedback

Le programme actuel produit 4 cases. Avec 3 répétitions de 2 cases, il produit bien 6 cases.
