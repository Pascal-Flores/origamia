# Contexte

Une lampe programmable doit rester allumée en lumière chaude pour permettre la lecture. Le programme produit brièvement la bonne lumière, puis l’éteint.

# Consigne

```
event: DÉBUT
say: ALLUMER la lampe
say: RÉGLER la couleur (chaude)
say: ÉTEINDRE la lampe
end: FIN
```

Chaque étiquette montre le programme après une correction. Classe-la selon qu’elle permet ou non d’obtenir l’éclairage attendu.
# Catégories

1. Corrige la mission
2. Ne corrige pas la mission

# Étiquettes

1.

```blockly
event: DÉBUT
say: ALLUMER la lampe
say: RÉGLER la couleur (chaude)
end: FIN
```

2.

```blockly
event: DÉBUT
say: ALLUMER la lampe
say: RÉGLER la couleur (chaude)
say: MAINTENIR la lampe allumée
end: FIN
```

3.

```blockly
event: DÉBUT
say: ALLUMER la lampe
say: RÉGLER la couleur (froide)
say: ÉTEINDRE la lampe
end: FIN
```

4.

```blockly
event: DÉBUT
say: FAIRE CLIGNOTER la lampe
say: RÉGLER la couleur (chaude)
say: ÉTEINDRE la lampe
end: FIN
```

5.

```blockly
event: DÉBUT
say: ALLUMER la lampe
say: RÉGLER la couleur (chaude)
say: RÉGLER l’intensité (lecture)
end: FIN
```

# Solution

1: 1, 2, 5
2: 3, 4

# Feedback essai 1

Compare l'état final produit par chaque correction avec les deux critères : lumière chaude et lampe encore allumée.

# Feedback essai 2

La couleur est déjà correcte. La correction doit empêcher l'extinction finale sans remplacer la lumière chaude par une autre.

# Feedback

La couleur chaude est déjà correcte. Supprimer l’extinction ou la remplacer par une instruction qui laisse la lampe allumée permet d’obtenir l’éclairage demandé. Les deux autres modifications changent le résultat attendu.
