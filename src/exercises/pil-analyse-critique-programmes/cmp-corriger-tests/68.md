# Contexte

Une lampe programmable doit préparer un éclairage de lecture. À la fin de la mission :

- la lampe doit être **allumée** ;
- la couleur doit être **chaude** ;
- l'intensité doit être exactement de `70 %`.

Le programme utilisé est le suivant :

```blockly
event: DÉBUT
say: AUGMENTER l'intensité de (20 points)
say: RÉGLER la couleur (chaude)
say: ALLUMER la lampe
end: FIN
```

Ce programme a été testé dans deux situations.

**Test 1 — réussi**  
Au départ, l'intensité est de `50 %`. Le programme ajoute `20 points` : elle atteint `70 %`. La couleur devient chaude et la lampe est allumée. La mission réussit.

**Test 2 — en échec**  
Au départ, l'intensité est déjà de `70 %`. Le même programme ajoute encore `20 points` : elle atteint `90 %`. La lampe est bien allumée en lumière chaude, mais l'intensité est trop forte. La mission échoue.

On cherche une correction qui répare le test 2 **sans casser le test 1**.

# Consigne

Classe chaque correction proposée selon son effet sur les deux tests.

# Catégories

1. Corrige le test 2 sans casser le test 1
2. Corrige le test 2 mais casse le test 1
3. Ne corrige pas le test 2

# Étiquettes

1. Remplacer `AUGMENTER l'intensité de 20 points` par `RÉGLER l'intensité à 70 %`.
2. Remplacer l'augmentation par `DIMINUER l'intensité de 20 points`.
3. Supprimer l'instruction qui modifie l'intensité.
4. Remplacer l'augmentation par deux instructions successives : `AUGMENTER de 20 points`, puis `DIMINUER de 20 points`.
5. Conserver `AUGMENTER l'intensité de 20 points` sans modification.

# Solution

1: 1
2: 3, 4
3: 2, 5

# Feedback essai 1

Teste chaque correction deux fois : une fois à partir de `50 %`, puis une fois à partir de `70 %`. Une correction robuste doit terminer à `70 %` dans les deux cas.

# Feedback essai 2

Certaines corrections laissent simplement l'intensité à sa valeur de départ. Elles peuvent donc faire réussir le test 2, qui commence déjà à `70 %`, tout en faisant régresser le test 1, qui commence à `50 %`.

# Feedback

La correction `1` est la seule qui réussit les deux tests : régler directement l'intensité à `70 %` donne la valeur attendue quelle que soit la valeur de départ.

Supprimer la modification (`3`) ou augmenter puis diminuer de la même quantité (`4`) laisse finalement l'intensité à sa valeur initiale : le test 2 réussit alors à `70 %`, mais le test 1 reste à `50 %`. Ces corrections provoquent donc une régression.

Diminuer de `20 points` (`2`) fait passer le test 2 à `50 %`, et conserver l'augmentation (`5`) le fait monter à `90 %` : ces deux propositions ne corrigent pas le test en échec.
