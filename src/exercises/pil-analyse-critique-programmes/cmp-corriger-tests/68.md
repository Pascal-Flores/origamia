# Contexte

Une lampe programmable doit rester allumée en lumière chaude pour permettre la lecture. Le programme produit brièvement la bonne lumière, puis l’éteint.

# Consigne

```
event: DÉBUT
say: ALLUMER la lampe
say: RÉGLER la couleur (chaude)
say: ÉTEINDRE la lampe
end: FIN
```

Chaque étiquette propose une seule correction. Classe-la selon qu’elle permet ou non d’obtenir l’éclairage attendu.
# Catégories

1. Corrige la mission
2. Ne corrige pas la mission

# Étiquettes

1. Supprimer cette instruction :

```blockly
say: ÉTEINDRE la lampe
```

2. Remplacer l’extinction par :

```blockly
say: MAINTENIR la lampe allumée
```

3. Remplacer le réglage de la couleur par :

```blockly
say: RÉGLER la couleur (froide)
```

4. Remplacer l’allumage de la lampe par :

```blockly
say: FAIRE CLIGNOTER la lampe
```

5. Remplacer l’extinction par :

```blockly
say: RÉGLER l’intensité (lecture)
```

# Solution

1: 1, 2, 5
2: 3, 4

# Feedback

La couleur chaude est déjà correcte. Supprimer l’extinction ou la remplacer par une instruction qui laisse la lampe allumée permet d’obtenir l’éclairage demandé. Les deux autres modifications changent le résultat attendu.
