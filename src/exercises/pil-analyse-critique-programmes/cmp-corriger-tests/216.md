# Contexte

```
METTRE la tenue dans le sac
FERMER le sac
METTRE les chaussures dans le sac
```

Le sac doit contenir la tenue et les chaussures puis être fermé.

# Consigne

Quelle correction permet d'obtenir ce résultat ?

# Réponses

1. Déplacer `FERMER le sac` après `METTRE les chaussures dans le sac`.
2. Supprimer `METTRE les chaussures dans le sac`.
3. Fermer le sac avant toute autre action.

# Solution

1

# Feedback essai 1

La fermeture doit être la dernière action concernant le contenu du sac.

# Feedback

En déplaçant la fermeture après l'ajout des chaussures, les deux objets sont présents avant que le sac soit fermé.
