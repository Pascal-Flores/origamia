# Contexte

Un petit robot de démonstration prépare un sac de piscine. À la fin de la mission :

- la serviette doit être dans le sac ;
- les lunettes doivent être dans le sac ;
- le sac doit être **fermé** ;
- le voyant doit être **vert**.

Le programme utilisé est le suivant :

```blockly
event: DÉBUT
move: DÉPOSER la serviette dans le sac
move: DÉPOSER les lunettes dans le sac
move: FERMER le sac
say: INVERSER la couleur du voyant (rouge / vert)
end: FIN
```

Ce programme a été testé dans deux situations.

**Test 1 — réussi**  
Au départ, le voyant est **rouge**. Le programme place les deux objets, ferme le sac puis inverse le voyant : il devient vert. La mission réussit.

**Test 2 — en échec**  
Au départ, le voyant est déjà **vert**. Le même programme l'inverse : il devient rouge. Le sac contient bien les deux objets et il est fermé, mais le voyant final n'est pas celui attendu. La mission échoue.

On cherche une correction qui répare le test 2 **sans casser le test 1**.

# Consigne

Classe chaque correction proposée selon son effet sur les deux tests.

# Catégories

1. Corrige le test 2 sans casser le test 1
2. Corrige le test 2 mais casse le test 1
3. Ne corrige pas le test 2

# Étiquettes

1. Remplacer `INVERSER la couleur du voyant` par `ALLUMER le voyant vert`.
2. Remplacer l'inversion par `ALLUMER le voyant rouge`.
3. Supprimer l'instruction qui modifie le voyant.
4. Remplacer l'inversion par deux inversions successives du voyant.
5. Conserver l'inversion du voyant sans modification.

# Solution

1: 1
2: 3, 4
3: 2, 5

# Feedback essai 1

Pour chaque correction, repars une fois avec un voyant rouge et une fois avec un voyant vert. Vérifie ensuite la couleur finale dans les deux tests.

# Feedback essai 2

Une correction robuste doit terminer avec un voyant vert **quel que soit son état initial**. Certaines propositions ne font que conserver la couleur de départ : elles peuvent réparer le test 2 mais faire régresser le test 1.

# Feedback

La correction `1` est la seule qui réussit les deux tests : demander explicitement un voyant vert produit le bon état qu'il soit rouge ou vert au départ.

Supprimer l'instruction (`3`) laisse le voyant à sa couleur initiale. Deux inversions successives (`4`) le ramènent également à sa couleur initiale. Dans les deux cas, le test 2 réussit puisqu'il commence en vert, mais le test 1 reste rouge : ces corrections provoquent une régression.

Allumer le rouge (`2`) ou conserver une seule inversion (`5`) laisse le test 2 avec un voyant rouge et ne corrige donc pas l'échec.
