# Contexte

Le programme oublie de ranger la serviette dans le sac avant de le fermer. Plusieurs corrections sont proposées.

# Consigne

Classe les corrections selon qu'elles permettent ou non d'obtenir un sac fermé contenant la serviette.

# Catégories

1. Correction efficace
2. Correction inefficace

# Étiquettes

1. Ajouter `RANGER la serviette dans le sac` juste avant `FERMER le sac`
2. Ajouter `RANGER la serviette dans le sac` après `FERMER le sac`
3. Déplacer `FERMER le sac` après le rangement de la serviette
4. Supprimer le rangement de la serviette

# Solution

1: 1, 3
2: 2, 4

# Feedback essai 1

La serviette doit être dans le sac avant sa fermeture.

# Feedback

Les corrections 1 et 3 garantissent cet ordre ; les deux autres laissent le problème intact.
