# Contexte

À la piscine, un casier automatique doit ranger une serviette dans le compartiment `3`, verrouiller le compartiment puis allumer un voyant vert. À la fin, la serviette doit donc être **dans le casier**, la porte **verrouillée** et le voyant **vert**.

Lors de l'essai, la serviette est bien déposée dans le casier, mais le programme la retire juste avant de verrouiller la porte.

# Consigne

Voici le programme utilisé lors de l'essai raté.

```
event: DÉBUT
move: DÉVERROUILLER le compartiment (3)
move: DÉPOSER la serviette dans le compartiment (3)
move: RETIRER la serviette du compartiment (3)
move: VERROUILLER le compartiment (3)
say: ALLUMER le voyant (vert)
end: FIN
```

Chaque étiquette montre le programme après une correction. Classe-la selon qu'elle permet ou non d'obtenir les trois états attendus à la fin.

# Catégories

1. Corrige la mission
2. Ne corrige pas la mission

# Solution

1: 1, 2, 5
2: 3, 4

# Feedback essai 1

Teste chaque programme séparément. À la fin, vérifie toujours les trois critères : où se trouve la serviette, si le compartiment est verrouillé et quelle couleur est affichée.

# Feedback essai 2

Le défaut du programme initial est le retrait de la serviette. Une correction peut soit supprimer ce retrait, soit faire en sorte que la serviette soit replacée avant le verrouillage, sans dégrader les deux autres critères.

# Feedback

Les programmes `1`, `2` et `5` corrigent la mission. Dans `1`, le retrait disparaît ; dans `2`, l'attente ne change pas la position de la serviette ; dans `5`, la serviette est redéposée après avoir été retirée. Les programmes `3` et `4` échouent encore : l'un laisse le casier ouvert et vide, l'autre conserve la serviette hors du casier et affiche en plus la mauvaise couleur.
