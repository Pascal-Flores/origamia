# Contexte

Le programme doit avancer de 4 cases, mais il contient `AVANCER de 2 cases`.

# Consigne

Classe les corrections proposées selon qu'elles permettent ou non d'obtenir le déplacement de 4 cases.

# Items

1. remplacer 2 par 4
2. ajouter une deuxième instruction `AVANCER de 2 cases`
3. remplacer 2 par 1
4. supprimer l'instruction d'avance

# Catégories

## Corrige le programme
1, 2

## Ne corrige pas le programme
3, 4

# Feedback essai 1

Pour chaque correction, calcule la distance totale obtenue.

# Feedback

Remplacer 2 par 4 ou avancer deux fois de 2 cases produit bien 4 cases. Les deux autres propositions ne permettent pas d'atteindre la distance demandée.
