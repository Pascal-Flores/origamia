# Contexte

Pour préparer un sac de piscine, un petit robot de démonstration doit y placer une serviette et des lunettes, fermer le sac puis allumer un voyant vert. À la fin, les **deux objets** doivent donc être dans le sac, le sac doit être **fermé** et le voyant **vert**.

Lors de l'essai, le robot place bien la serviette et les lunettes dans le sac, mais retire ensuite la serviette avant de fermer le sac.

# Consigne

Voici le programme utilisé lors de l'essai raté.

```
event: DÉBUT
move: OUVRIR le sac
move: DÉPOSER la serviette dans le sac
move: DÉPOSER les lunettes dans le sac
move: RETIRER la serviette du sac
move: FERMER le sac
say: ALLUMER le voyant (vert)
end: FIN
```

Chaque étiquette montre le programme après une correction. Classe-la selon qu'elle permet ou non d'obtenir les quatre éléments attendus à la fin : serviette dans le sac, lunettes dans le sac, sac fermé et voyant vert.

# Catégories

1. Corrige la mission
2. Ne corrige pas la mission

# Solution

1: 1, 2, 5

# Feedback essai 1

Teste chaque programme séparément. Après sa dernière instruction, vérifie le contenu du sac, sa fermeture et la couleur du voyant.

# Feedback essai 2

Le défaut du programme initial est le retrait de la serviette. Une correction peut supprimer ce retrait, le remplacer par une action qui ne change pas le contenu, ou remettre la serviette dans le sac avant la fermeture.

# Feedback

Les programmes `1`, `2` et `5` corrigent la mission : dans chacun d'eux, la serviette et les lunettes sont encore dans le sac lorsqu'il est fermé, et le voyant est vert. Le programme `3` conserve exactement le défaut initial. Le `4` laisse lui aussi la serviette hors du sac et ajoute en plus un voyant rouge.
