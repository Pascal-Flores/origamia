# Contexte

Dans une maquette de centre aquatique, une douche automatique représente le passage sous la douche avant l'entrée dans le bassin. Elle doit faire couler l'eau pendant exactement `20 secondes`, puis couper l'eau et allumer un voyant vert pour signaler que le cycle est terminé.

Lors de l'essai, le voyant vert s'allume bien après `20 secondes`, mais l'eau continue de couler.

# Consigne

Voici le programme utilisé lors de l'essai raté.

```
event: DÉBUT
move: OUVRIR l'eau
move: ATTENDRE (20 secondes)
say: ALLUMER le voyant (vert)
end: FIN
```

Choisis le programme corrigé qui respecte les trois critères : durée de `20 secondes`, eau coupée à la fin et voyant vert.

La durée et la couleur du voyant sont déjà correctes dans le programme initial. Cherche la modification qui corrige uniquement ce qui reste faux à la fin du cycle.

# Feedback

Le problème vient de l'instruction `MAINTENIR l'eau ouverte` : elle laisse la douche fonctionner alors que le cycle doit être terminé. Le programme `1` la remplace par `COUPER l'eau` tout en conservant les `20 secondes` et le voyant vert. Il est donc le seul à respecter toute la mission.
