# Contexte

Dans un musée, une borne numérique affiche les informations d'un cartel. À la fin de la mission :

- le titre, l'auteur et la date doivent être affichés ;
- la taille du texte doit être exactement de `18 points` ;
- l'écran doit afficher `FICHE COMPLÈTE`.

Le programme utilisé est le suivant :

```blockly
event: DÉBUT
say: AJOUTER la ligne (titre)
say: AJOUTER la ligne (auteur)
say: AJOUTER la ligne (date)
say: AUGMENTER la taille du texte de (2 points)
say: AFFICHER l'état (FICHE COMPLÈTE)
end: FIN
```

Ce programme a été testé dans deux situations.

**Test 1 — réussi**  
Au départ, la taille du texte est de `16 points`. Le programme ajoute `2 points` : le texte atteint `18 points`. Les trois informations sont affichées et l'état final est `FICHE COMPLÈTE`. La mission réussit.

**Test 2 — en échec**  
Au départ, la taille du texte est déjà de `18 points`. Le même programme ajoute encore `2 points` : le texte atteint `20 points`. Les informations et le message final sont corrects, mais la taille n'est plus celle demandée. La mission échoue.

On cherche une correction qui répare le test 2 **sans casser le test 1**.

# Consigne

Classe chaque correction proposée selon son effet sur les deux tests.

# Catégories

1. Corrige le test 2 sans casser le test 1
2. Corrige le test 2 mais casse le test 1
3. Ne corrige pas le test 2

# Étiquettes

1. Remplacer `AUGMENTER la taille du texte de 2 points` par `RÉGLER la taille du texte à 18 points`.
2. Remplacer l'augmentation par `DIMINUER la taille du texte de 2 points`.
3. Supprimer l'instruction qui modifie la taille du texte.
4. Remplacer l'augmentation par deux instructions successives : `AUGMENTER de 2 points`, puis `DIMINUER de 2 points`.
5. Conserver l'augmentation de `2 points` sans modification.

# Solution

1: 1
2: 3, 4
3: 2, 5

# Feedback essai 1

Teste chaque correction à partir de `16 points`, puis à partir de `18 points`. La bonne correction doit terminer à `18 points` dans les deux situations.

# Feedback essai 2

Une correction qui laisse finalement la taille du texte inchangée peut faire réussir le test 2, puisqu'il commence déjà à `18 points`, mais elle fait régresser le test 1, qui commence à `16 points`.

# Feedback

La correction `1` est la seule qui réussit les deux tests : régler directement la taille à `18 points` produit la valeur attendue quelle que soit la taille de départ.

Supprimer la modification (`3`) ou augmenter puis diminuer de la même quantité (`4`) laisse finalement la taille à sa valeur initiale. Le test 2 réussit alors à `18 points`, mais le test 1 reste à `16 points` : ces corrections provoquent une régression.

Diminuer de `2 points` (`2`) fait passer le test 2 à `16 points`, tandis que conserver l'augmentation (`5`) le fait monter à `20 points` : ces deux propositions ne corrigent pas le test en échec.
