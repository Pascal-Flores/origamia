# Contexte

Un robot d’atelier doit déposer un outil sur la case marquée d’un triangle. La flèche indique son point de départ et sa direction. Avec le programme ci-dessous, il arrive sur la case marquée d’un cercle.

# Consigne

```robot-grid
grid: 4x4
start: B4 nord
target: A2 triangle
target: C2 cercle
```

Voici le programme utilisé.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (1) case
move: DÉPOSER l’outil
end: FIN
```

Choisis le programme qui mène à la case marquée d’un triangle.
