# Contexte

Un robot d’atelier doit déposer un outil sur la case verte. La flèche indique sa position de départ et son orientation. Lors du premier essai, il arrive sur la case bleue.

# Consigne

```robot-grid
grid: 4x4
start: B4 nord
target: A2 vert
target: C2 bleu
target: B1 orange
```

Voici le programme utilisé.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (1) case
move: DÉPOSER l’outil
end: FIN
```

Choisis le programme corrigé qui permet au robot d’arriver sur la case verte.
# Réponses

1.

```blockly
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (1) case
move: DÉPOSER l’outil
end: FIN
```

2.

```blockly
event: DÉBUT
move: AVANCER de (3) cases
move: TOURNER à droite
move: AVANCER de (1) case
move: DÉPOSER l’outil
end: FIN
```

3.

```blockly
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (2) cases
move: DÉPOSER l’outil
end: FIN
```

# Feedback essai 1

Compare la case atteinte avec la case attendue et cherche la plus petite modification qui change la direction au bon moment.

# Feedback

Après deux avancées, le robot est en face des cases colorées. En tournant à gauche plutôt qu’à droite, il avance vers la case verte et peut y déposer l’outil.
