# Contexte

Un convoyeur programmable prépare une caisse pour l'expédition. À la fin de la mission :

- la caisse doit contenir exactement `6 colis` ;
- la caisse doit être **fermée** ;
- le voyant vert doit être allumé.

Le programme utilisé est le suivant :

```blockly
event: DÉBUT
move: AJOUTER (2) colis dans la caisse
move: FERMER la caisse
say: ALLUMER le voyant (vert)
end: FIN
```

Ce programme a été testé dans deux situations.

**Test 1 — réussi**  
Au départ, la caisse contient `4 colis`. Le convoyeur en ajoute `2` : elle en contient alors exactement `6`. La caisse est fermée et le voyant vert s'allume. La mission réussit.

**Test 2 — en échec**  
Au départ, la caisse contient déjà `6 colis`. Le même programme en ajoute encore `2` : elle en contient alors `8`. La caisse est bien fermée et le voyant est vert, mais elle contient trop de colis. La mission échoue.

On cherche une correction qui répare le test 2 **sans casser le test 1**.

# Consigne

Classe chaque correction proposée selon son effet sur les deux tests.

# Catégories

1. Corrige le test 2 sans casser le test 1
2. Corrige le test 2 mais casse le test 1
3. Ne corrige pas le test 2

# Étiquettes

1. Remplacer `AJOUTER 2 colis` par `COMPLÉTER la caisse jusqu'à 6 colis`.
2. Remplacer l'ajout par `RETIRER 2 colis de la caisse`.
3. Supprimer l'instruction qui ajoute des colis.
4. Remplacer l'ajout par deux instructions successives : `AJOUTER 2 colis`, puis `RETIRER 2 colis`.
5. Conserver `AJOUTER 2 colis` sans modification.

# Solution

1: 1
2: 3, 4
3: 2, 5

# Feedback essai 1

Teste chaque correction à partir de `4 colis`, puis à partir de `6 colis`. La bonne correction doit terminer avec exactement `6 colis` dans les deux situations.

# Feedback essai 2

Une correction qui ne change finalement pas le nombre de colis peut faire réussir le test 2, puisqu'il commence déjà à `6`, mais elle laisse le test 1 à `4 colis`.

# Feedback

La correction `1` est la seule qui réussit les deux tests : compléter **jusqu'à** `6 colis` ajoute les deux colis manquants dans le test 1 et n'en ajoute aucun dans le test 2, qui est déjà au niveau attendu.

Supprimer l'ajout (`3`) ou ajouter puis retirer deux colis (`4`) laisse finalement la caisse à sa quantité initiale. Le test 2 réussit donc avec `6 colis`, mais le test 1 reste à `4 colis` : il y a régression.

Retirer deux colis (`2`) fait passer le test 2 à `4`, tandis que conserver l'ajout (`5`) le fait monter à `8` : ces deux propositions ne corrigent pas le test en échec.
