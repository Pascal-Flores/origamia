# Contexte

Un robot d'usine doit placer un colis dans une caisse, fermer la caisse, puis allumer le voyant vert. Avec le programme actuel, le colis est retiré de la caisse avant la fin.

# Consigne

```
event: DÉBUT
move: SAISIR le colis
move: DÉPOSER le colis dans la caisse
move: RETIRER le colis de la caisse
move: FERMER la caisse
say: ALLUMER le voyant (vert)
end: FIN
```

Chaque étiquette propose une seule correction. Classe-la selon qu’elle permet ou non d’accomplir la mission.
# Catégories

1. Corrige la mission
2. Ne corrige pas la mission

# Étiquettes

1. Supprimer cette instruction :

```blockly
move: RETIRER le colis de la caisse
```

2. Remplacer le retrait par :

```blockly
move: MAINTENIR le colis dans la caisse
```

3. Remplacer la fermeture de la caisse par :

```blockly
move: OUVRIR la caisse
```

4. Remplacer l’instruction du voyant par :

```blockly
say: ALLUMER le voyant (rouge)
```

5. Ajouter après l’instruction qui retire le colis :

```blockly
move: DÉPOSER le colis dans la caisse
```

# Solution

1: 1, 2, 5
2: 3, 4

# Feedback essai 1

Pour chaque correction, vérifie à la fin le contenu de la caisse, sa fermeture et la couleur du voyant.

# Feedback essai 2

Le problème vient du retrait du colis. Une correction est valable si elle supprime ce retrait ou remet ensuite le colis dans la caisse.

# Feedback

La caisse doit rester fermée avec le colis à l’intérieur et le voyant vert. Supprimer le retrait, le remplacer par un maintien, ou redéposer le colis après son retrait corrige le contenu final de la caisse sans dégrader les autres états attendus.
