# Énoncé

Une fontaine programmable doit remplir un flacon avec exactement `50 cL` d’eau, puis le laisser prêt à emporter. Après l’exécution du programme, le flacon est vide.

```
event: DÉBUT
move: PLACER le flacon sous la fontaine
move: VERSER (25 cL) d’eau
move: VERSER (25 cL) d’eau
move: VIDER le flacon
move: ARRÊTER la fontaine
end: FIN
```

Choisis la modification qui permet d’obtenir le résultat attendu.

# Réponses

1. Remplacer l’instruction qui vide le flacon par :

```blockly
move: FERMER le bouchon du flacon
```

2. Remplacer le second versement par :

```blockly
move: RINCER le flacon
```

3. Remplacer l’arrêt de la fontaine par :

```blockly
move: VIDER le flacon
```

# Feedback

Les deux versements fournissent déjà `50 cL`. C’est l’instruction `VIDER le flacon` qui annule le résultat ; la remplacer par la fermeture du bouchon laisse le flacon rempli et prêt.
