# Énoncé

Un casier programmable doit ranger un badge dans le compartiment `4`, le verrouiller, puis afficher `PRÊT`. Lors de l’essai, le badge est rangé dans le compartiment `2` et l’écran affiche `VIDE`.

```
event: DÉBUT
move: DÉVERROUILLER le compartiment (2)
move: DÉPOSER le badge dans le compartiment (2)
move: VERROUILLER le compartiment (2)
say: AFFICHER le message (VIDE)
end: FIN
```

Complète la correction du programme avec les fragments adaptés.

# Texte à trous

Il faut remplacer les trois instructions utilisant le compartiment `2` par des instructions qui permettent de [[1]]. Il faut aussi remplacer le message affiché pour que l’écran indique [[2]]. Ces modifications permettent de [[3]].

# Étiquettes

1. déverrouiller le compartiment 4, y déposer le badge puis le verrouiller
2. le message `PRÊT`
3. ranger le badge au bon endroit, sécuriser le retrait et afficher l’état attendu
4. déverrouiller le compartiment 3, y déposer le badge puis le verrouiller
5. que le casier est vide
6. ouvrir le compartiment 4 sans le verrouiller

# Solution

1, 2, 3

# Feedback

La correction doit concerner à la fois le compartiment utilisé et le message final. Le badge est déposé puis verrouillé dans le compartiment `4`, et l’affichage `PRÊT` signale que le retrait peut avoir lieu.
