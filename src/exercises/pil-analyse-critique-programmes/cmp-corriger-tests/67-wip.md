## Forme de référence

Les variantes 67–69 utilisent toutes :

1. une mission concrète réalisée par un dispositif programmable ;
2. un programme fautif complet ;
3. cinq propositions montrant chacune le programme après une correction ;
4. un classement en deux catégories : correction efficace / inefficace ;
5. plusieurs corrections possibles ;
6. `type: ddu`, `essais: 3` et deux feedbacks progressifs avant le feedback final.

## Reprise prévue

- 217 : casier automatique de piscine qui doit conserver une serviette dans le compartiment fermé et signaler la réussite.
- 218 : borne de musée qui doit afficher les informations d'un cartel dans l'ordre attendu et signaler que la fiche est complète.

Les anciennes corrections textuelles sont remplacées par des programmes complets, afin que l'élève teste réellement l'effet de chaque correction.
