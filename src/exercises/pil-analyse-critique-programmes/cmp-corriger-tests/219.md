# Contexte

La mission demande 4 répétitions de l'exercice d'échauffement, puis une pause unique.

Programme actuel :

```
RÉPÉTER 3 FOIS
  FAIRE l'exercice
FIN RÉPÉTER
FAIRE une pause
```

# Consigne

Complète la correction.

# Texte à trous

Le problème vient du nombre de [[1]]. Il faut remplacer `3` par [[2]]. La pause doit rester [[3]] de la boucle pour n'être effectuée qu'une fois.

# Étiquettes

1. répétitions
2. 4
3. hors
4. déplacements
5. 2
6. dans

# Solution

1, 2, 3

# Feedback essai 1

Compare le nombre demandé au nombre programmé, puis vérifie ce qui ne doit pas être répété.

# Feedback

La boucle doit comporter 4 répétitions et la pause reste après la boucle.
