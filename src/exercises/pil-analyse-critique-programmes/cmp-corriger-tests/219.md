# Contexte

Le robot doit avancer de 3 cases puis tourner à droite. Le programme actuel fait l'inverse :

```
TOURNER à droite
AVANCER de 3 cases
```

# Consigne

Complète la proposition de correction.

# Texte à trous

Il faut [[1]] les deux instructions. Ainsi, le robot [[2]] avant de [[3]], ce qui correspond à la mission.

# Étiquettes

1. inverser
2. avance de 3 cases
3. tourner à droite
4. supprimer
5. tourne à gauche

# Solution

1, 2, 3

# Feedback essai 1

La correction doit changer l'ordre, pas la valeur des paramètres.

# Feedback

Il faut inverser les deux instructions : le robot avance d'abord de trois cases, puis tourne à droite, comme demandé.
