# Contexte

Un minuteur programmable accompagne un échauffement avant une activité sportive. Il doit lancer un compte à rebours de `5 minutes`, puis afficher `PRÊT` et allumer un voyant bleu pour signaler que l'échauffement est terminé.

Lors de l'essai, le voyant bleu s'allume bien, mais le minuteur ne dure que `3 minutes` et l'écran affiche `STOP`.

# Consigne

Voici le programme utilisé lors de l'essai raté.

```
event: DÉBUT
move: DÉMARRER le minuteur pour (3 minutes)
say: AFFICHER le message (STOP)
say: ALLUMER le voyant (bleu)
end: FIN
```

Complète le texte pour expliquer les deux corrections nécessaires et le résultat obtenu après modification du programme.

# Texte à trous

Le voyant bleu est déjà correct. Il faut remplacer la durée de `3 minutes` par [[1]] et remplacer le message `STOP` par [[2]]. Après ces deux modifications, le minuteur peut [[3]].

# Étiquettes

1. une durée de 5 minutes
2. le message `PRÊT`
3. faire durer l'échauffement 5 minutes puis signaler qu'il est terminé avec le message et le voyant attendus
4. une durée de 2 minutes
5. le message `STOP`
6. un voyant rouge

# Solution

1, 2, 3

# Feedback essai 1

Compare séparément les trois critères de la mission avec ce que produit le programme : durée, message affiché et couleur du voyant. L'un des trois est déjà correct.

# Feedback essai 2

Le voyant bleu peut rester inchangé. Il reste à corriger la durée du minuteur et le texte affiché lorsqu'il se termine.

# Feedback

Le programme doit utiliser une durée de `5 minutes` au lieu de `3`, et afficher `PRÊT` au lieu de `STOP`. Le voyant bleu est déjà conforme. Avec ces deux corrections, le dispositif réalise donc l'échauffement pendant la durée demandée puis signale correctement sa fin.
