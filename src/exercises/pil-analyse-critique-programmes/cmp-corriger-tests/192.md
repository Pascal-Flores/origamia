# Contexte

Une tablette de démonstration utilise un petit script pour présenter une application pendant quelques secondes. Le script doit :

- ouvrir l'application `Dessin` ;
- la laisser affichée pendant `10 secondes` ;
- fermer l'application ;
- afficher le message `DÉMONSTRATION TERMINÉE`.

Lors de l'essai, la durée de `10 secondes` et la fermeture fonctionnent correctement. En revanche, le script ouvre l'application `Calculatrice` au lieu de `Dessin` et affiche `RECOMMENCER` à la fin.

# Consigne

Voici le programme utilisé lors de l'essai raté.

```blockly
event: DÉBUT
move: OUVRIR l'application (Calculatrice)
move: ATTENDRE (10 secondes)
move: FERMER l'application
say: AFFICHER le message (RECOMMENCER)
end: FIN
```

Complète le texte pour expliquer les deux corrections nécessaires et le résultat obtenu après modification du programme.

# Texte à trous

La durée de `10 secondes` et la fermeture de l'application sont déjà correctes. Il faut remplacer l'application `Calculatrice` par [[1]] et remplacer le message `RECOMMENCER` par [[2]]. Après ces deux modifications, le script peut [[3]].

# Étiquettes

1. l'application `Dessin`
2. le message `DÉMONSTRATION TERMINÉE`
3. ouvrir l'application demandée pendant 10 secondes, la fermer puis signaler correctement la fin de la démonstration
4. l'application `Calculatrice`
5. le message `RECOMMENCER`
6. une attente de 20 secondes

# Solution

1, 2, 3

# Feedback essai 1

Compare séparément les quatre critères de la mission avec ce que produit le programme : application ouverte, durée d'affichage, fermeture et message final. Deux éléments sont déjà corrects.

# Feedback essai 2

L'attente de `10 secondes` et la fermeture peuvent rester telles quelles. Il reste à corriger le nom de l'application ouverte et le message affiché à la fin.

# Feedback

Le programme doit ouvrir `Dessin` au lieu de `Calculatrice` et afficher `DÉMONSTRATION TERMINÉE` au lieu de `RECOMMENCER`. La durée de `10 secondes` et la fermeture sont déjà conformes. Avec ces deux corrections, le script réalise donc toute la démonstration demandée dans le bon état final.
