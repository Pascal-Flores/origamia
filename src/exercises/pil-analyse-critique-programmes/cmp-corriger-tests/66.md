# Énoncé

Un volet motorisé doit aérer des plantes pendant `5 minutes`, puis se refermer et allumer un voyant vert. Lors de l’essai, le voyant s’allume mais le volet reste ouvert.

```
event: DÉBUT
move: OUVRIR le volet
move: ATTENDRE (5 minutes)
move: MAINTENIR le volet ouvert
say: ALLUMER le voyant (vert)
end: FIN
```

Choisis la modification qui corrige le programme.

# Réponses

1. Remplacer l’instruction qui laisse le volet ouvert par :

```blockly
move: FERMER le volet
```

2. Remplacer l’instruction d’attente par :

```blockly
move: ATTENDRE (10 minutes)
```

3. Remplacer l’instruction du voyant par :

```blockly
say: ALLUMER le voyant (rouge)
```

La durée d’aération et le voyant sont déjà adaptés. La mission échoue parce que le volet reste ouvert ; il faut donc le fermer après l’attente.
