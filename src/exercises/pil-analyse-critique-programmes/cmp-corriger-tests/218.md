# Contexte

Dans un musée, une borne numérique doit afficher les trois informations principales d'un cartel dans cet ordre : **titre**, **auteur**, puis **date**. Une fois les trois lignes affichées, elle doit indiquer `FICHE COMPLÈTE`.

Lors de l'essai, le titre et la date apparaissent bien, mais la ligne de l'auteur manque.

# Consigne

Voici le programme utilisé lors de l'essai raté.

```
event: DÉBUT
say: AJOUTER la ligne (titre)
say: AJOUTER la ligne (date)
say: AFFICHER l'état (FICHE COMPLÈTE)
end: FIN
```

Chaque étiquette montre la borne après une correction du programme. Classe-la selon qu'elle permet ou non d'afficher le titre, l'auteur et la date dans l'ordre attendu, avec l'état `FICHE COMPLÈTE`.

# Catégories

1. Corrige la mission
2. Ne corrige pas la mission

# Solution

1: 1, 2
2: 3, 4, 5

# Feedback essai 1

Pour chaque correction, vérifie quatre éléments : présence du titre, présence de l'auteur, présence de la date, puis message final. L'ordre des trois lignes fait aussi partie de la mission.

# Feedback essai 2

La correction doit insérer l'auteur **entre** le titre et la date. Une instruction supplémentaire qui ne modifie pas ces informations peut être acceptable, mais une ligne manquante, un ordre différent ou un mauvais message final fait échouer la mission.

# Feedback

Les programmes `1` et `2` sont corrects : ils affichent `titre → auteur → date`, puis `FICHE COMPLÈTE`. L'attente ajoutée dans le programme `2` ne change pas ce résultat. Le programme `3` place l'auteur après la date, le `4` oublie le titre et le `5` affiche un état final incorrect.
