# Contexte

Le programme doit lire successivement le titre, l'auteur et la date d'un cartel, mais il saute l'auteur.

# Consigne

Classe les corrections.

# Catégories

1. Permet d'obtenir le résultat attendu
2. Ne permet pas d'obtenir le résultat attendu

# Étiquettes

1. Ajouter `LIRE l'auteur` entre le titre et la date
2. Ajouter `LIRE l'auteur` après la fin du programme
3. Remplacer `LIRE la date` par `LIRE l'auteur` puis ajouter `LIRE la date`
4. Supprimer `LIRE le titre`

# Solution

1: 1, 3
2: 2, 4

# Feedback essai 1

La correction doit permettre de lire les trois informations avant la fin.

# Feedback

Les propositions 1 et 3 rétablissent les trois lectures ; les autres laissent une information absente.
