# Contexte

Le programme affiche un message puis l'efface tout de suite. Il doit au contraire garder ce message visible pendant 3 secondes avant de l'effacer.

# Consigne

Classe les corrections.

# Items

1. ajouter `ATTENDRE 3 secondes` entre l'affichage et l'effacement
2. ajouter trois fois `ATTENDRE 1 seconde` entre l'affichage et l'effacement
3. ajouter `ATTENDRE 3 secondes` après l'effacement
4. supprimer l'affichage

# Catégories

## Corrige le programme
1, 2

## Ne corrige pas le programme
3, 4

# Feedback essai 1

L'attente doit avoir lieu pendant que le message est encore visible.

# Feedback

Les corrections 1 et 2 maintiennent l'affichage pendant trois secondes. Une attente après l'effacement arrive trop tard.
