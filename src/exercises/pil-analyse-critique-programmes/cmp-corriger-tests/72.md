# Contexte

Pour le début d’un spectacle, un dispositif programmable doit ouvrir le rideau, allumer un projecteur bleu et afficher `SCÈNE PRÊTE`. Lors de l’essai, le rideau se ferme et le projecteur devient rouge.

# Consigne

```
event: DÉBUT
move: FERMER le rideau
say: ALLUMER le projecteur (rouge)
say: AFFICHER le message (SCÈNE PRÊTE)
end: FIN
```

Complète la correction du programme avec les instructions adaptées.
# Texte à trous

Le message final est déjà correct. Pour réussir la mission, le programme corrigé doit [[1]] et [[2]]. Il produit alors [[3]].

# Étiquettes

1. ouvrir le rideau
2. allumer le projecteur bleu
3. un rideau ouvert, un projecteur bleu et le message attendu
4. fermer le rideau
5. allumer le projecteur rouge
6. éteindre le projecteur

# Solution

1, 2, 3

# Feedback

Le message `SCÈNE PRÊTE` peut rester inchangé. Les deux modifications nécessaires sont l’ouverture du rideau et l’allumage du projecteur bleu.
