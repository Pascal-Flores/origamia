# Contexte

Un robot de recyclage dépose une batterie usagée dans un bac. À la fin de sa mission :

- la batterie doit être dans le bac ;
- la trappe du bac doit être **fermée** ;
- le voyant vert doit être allumé.

Le programme utilisé est le suivant :

```blockly
event: DÉBUT
move: DÉPOSER la batterie dans le bac
move: INVERSER l'état de la trappe
say: ALLUMER le voyant (vert)
end: FIN
```

Ce programme a été testé dans deux situations.

**Test 1 — réussi**  
Au départ, la trappe est **ouverte**. Le programme l'inverse : elle se ferme. La batterie est dans le bac et le voyant est vert. La mission réussit.

**Test 2 — en échec**  
Au départ, la trappe est déjà **fermée**. Le programme l'inverse : elle s'ouvre. La batterie est bien dans le bac et le voyant devient vert, mais la trappe reste ouverte à la fin. La mission échoue.

On cherche maintenant une correction qui répare le test 2 **sans casser le test 1**.

# Consigne

Classe chaque correction proposée selon son effet sur les deux tests.

# Catégories

1. Corrige le test 2 sans casser le test 1
2. Corrige le test 2 mais casse le test 1
3. Ne corrige pas le test 2

# Étiquettes

1. Remplacer `INVERSER l'état de la trappe` par `FERMER la trappe`.
2. Remplacer `INVERSER l'état de la trappe` par `OUVRIR la trappe`.
3. Supprimer l'instruction qui modifie la trappe.
4. Remplacer l'instruction par deux inversions successives de l'état de la trappe.
5. Conserver `INVERSER l'état de la trappe` sans modification.

# Solution

1: 1
2: 3, 4
3: 2, 5

# Feedback essai 1

Ne regarde pas seulement le test qui échoue. Pour chaque correction, repars une fois avec la trappe ouverte et une fois avec la trappe fermée, puis vérifie son état final.

# Feedback essai 2

Une correction robuste doit terminer avec une trappe fermée dans **les deux** situations. Certaines propositions réparent le test 2 uniquement parce que la trappe y est déjà fermée au départ : vérifie alors ce qu'elles font au test 1.

# Feedback

La correction `1` est la seule qui réussit les deux tests : `FERMER la trappe` donne une trappe fermée qu'elle soit ouverte ou fermée au départ.

Supprimer l'instruction (`3`) laisse la trappe fermée dans le test 2, mais elle reste ouverte dans le test 1. Deux inversions successives (`4`) font également réussir le test 2 mais ramènent la trappe à son état ouvert dans le test 1 : ces deux corrections provoquent donc une régression.

`OUVRIR la trappe` (`2`) ne corrige pas le test 2, et conserver l'inversion actuelle (`5`) reproduit exactement l'échec observé.
