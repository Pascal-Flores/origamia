# Contexte

Un robot doit déposer une batterie usagée sur la case verte. Avec le programme actuel, il la dépose sur la case orange.

# Consigne

```robot-grid
grid: 4x3
start: B3 nord
target: B1 vert
target: A2 orange
target: C2 bleu
```

```
event: DÉBUT
move: AVANCER de (1) case
move: TOURNER à gauche
move: AVANCER de (1) case
move: DÉPOSER la batterie
end: FIN
```

Chaque étiquette propose une seule correction du programme. Classe-la selon qu’elle permet ou non de déposer la batterie sur la case verte.
# Catégories

1. Corrige la mission
2. Ne corrige pas la mission

# Étiquettes

1.

```blockly
move: AVANCER de (2) cases
```

2.

```blockly
move: AVANCER de (1) case
move: TOURNER à droite
move: AVANCER de (1) case
```

3.

```blockly
move: AVANCER de (1) case
move: TOURNER à gauche
move: AVANCER de (2) cases
```

4.

```blockly
move: AVANCER de (1) case
move: AVANCER de (1) case
```

5.

```blockly
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (1) case
```

# Solution

1: 1, 4
2: 2, 3, 5

# Feedback essai 1

Teste chaque correction séparément depuis la position de départ. Une proposition est valable seulement si le dépôt se fait sur la case verte.

# Feedback essai 2

La case verte est deux cases devant le robot. Écarte les corrections qui changent inutilement de direction ou parcourent une mauvaise distance.

# Feedback

La case verte est située deux cases devant le robot. Les corrections `1` et `4` l’y conduisent directement avant le dépôt. Les autres propositions le dirigent vers une autre case.
