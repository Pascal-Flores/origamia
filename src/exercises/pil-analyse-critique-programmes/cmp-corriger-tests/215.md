# Contexte

Le programme doit afficher « bonjour » pendant 2 secondes, mais il efface immédiatement l'écran.

```
AFFICHER « bonjour »
EFFACER l'écran
ATTENDRE 2 secondes
```

# Consigne

Quelle modification permet d'obtenir le comportement attendu ?

# Réponses

1. Placer `ATTENDRE 2 secondes` avant `EFFACER l'écran`.
2. Supprimer `AFFICHER « bonjour »`.
3. Remplacer 2 secondes par 0 seconde.

# Solution

1

# Feedback essai 1

Le message doit rester affiché pendant l'attente.

# Feedback

Il faut attendre deux secondes après l'affichage et seulement ensuite effacer l'écran.
