# Contexte

Après un entraînement, un robot doit rapporter un ballon jusqu'au râtelier représenté par la **case verte**. La flèche indique sa position de départ et son orientation.

Lors du premier essai, le robot suit le programme ci-dessous et dépose le ballon sur la **case bleue** au lieu de la case verte.

# Consigne

```robot-grid
grid: 5x4
start: C4 nord
target: E2 vert
target: A2 bleu
target: C1 orange
```

Voici le programme utilisé lors de l'essai raté.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (2) cases
move: DÉPOSER le ballon
end: FIN
```

Choisis le programme corrigé qui permet au robot de déposer le ballon sur la case verte.

# Réponses

1.

```blockly
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (2) cases
move: DÉPOSER le ballon
end: FIN
```

2.

```blockly
event: DÉBUT
move: AVANCER de (3) cases
move: TOURNER à droite
move: AVANCER de (2) cases
move: DÉPOSER le ballon
end: FIN
```

3.

```blockly
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (1) case
move: DÉPOSER le ballon
end: FIN
```

# Solution

1

# Feedback essai 1

Après les deux premières cases parcourues, le robot se trouve en `C2`. Compare alors la direction de la case bleue et celle de la case verte par rapport au robot.

# Feedback

Après avoir avancé de deux cases vers le nord, le robot arrive en `C2`. Le programme initial le fait tourner à gauche vers la case bleue. En tournant **à droite** à la place, il avance vers l'est et atteint la case verte `E2`. Le programme `1` corrige donc le trajet sans modifier les autres étapes.
