# Contexte

Après un entraînement, un robot doit rapporter un ballon au râtelier, repéré par un carré. La flèche indique son point de départ et sa direction.

Avec le programme ci-dessous, le robot dépose le ballon sur la case marquée d’un cercle.

# Consigne

```robot-grid
grid: 5x4
start: C4 nord
target: E2 carre
target: A2 cercle
```

Voici le programme de départ.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (2) cases
move: DÉPOSER le ballon
end: FIN
```

Choisis le programme qui mène à la case du râtelier, marquée d’un carré.

# Réponses

1.

```blockly
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (2) cases

end: FIN
```

2.

```blockly
event: DÉBUT
move: AVANCER de (3) cases
move: TOURNER à droite
move: AVANCER de (2) cases
move: DÉPOSER le ballon
end: FIN
```

3.

```blockly
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (1) case
move: DÉPOSER le ballon
end: FIN
```
