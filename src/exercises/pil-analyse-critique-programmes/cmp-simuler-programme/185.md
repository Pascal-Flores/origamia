# Contexte

Une maquette de passage piéton comporte :

- un feu pour les voitures ;
- un feu pour les piétons ;
- un signal sonore pour les personnes qui ne voient pas le feu.

Pour que le passage soit autorisé en sécurité à la fin du programme :

- le feu des voitures doit être rouge ;
- le feu des piétons doit être vert ;
- le signal sonore doit être activé.

# Consigne

Le même programme est lancé dans plusieurs états initiaux. Coche tous les tests où le passage est autorisé en sécurité à la fin.

```
event: DÉBUT
say: ALLUMER le feu (voitures rouge)
say: ALLUMER le feu (piétons vert)
end: FIN
```

# Réponses

1. Au départ : feu voitures vert ; feu piétons rouge ; signal sonore activé.
2. Au départ : feu voitures rouge ; feu piétons vert ; signal sonore désactivé.
3. Au départ : feu voitures vert ; feu piétons vert ; signal sonore désactivé.
4. Au départ : feu voitures rouge ; feu piétons rouge ; signal sonore activé.

# Solution

1, 4

# Feedback essai 1

Pour chaque test, regarde quels états sont modifiés par le programme et quel état n'est jamais modifié.

# Feedback essai 2

Le programme met toujours le feu des voitures au rouge et le feu des piétons au vert. Il ne change pas le signal sonore : celui-ci doit donc être activé dès le départ.

# Feedback

Dans tous les tests, le programme termine avec le feu des voitures rouge et le feu des piétons vert. En revanche, il ne modifie jamais le signal sonore. Les tests `1` et `4` commencent avec ce signal déjà activé : ce sont donc les deux situations où les trois conditions de sécurité sont réunies à la fin.
