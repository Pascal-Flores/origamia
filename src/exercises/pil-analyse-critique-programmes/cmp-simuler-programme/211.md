# Contexte

Au départ : `savon = non`, `rincé = non`.

```
METTRE savon = oui
METTRE rincé = oui
METTRE savon = non
```

# Consigne

Quelles affirmations sont vraies à la fin ?

# Réponses

1. `savon = non`
2. `rincé = oui`
3. `savon = oui`
4. `rincé = non`

# Solution

1, 2

# Feedback essai 1

Note la valeur de chaque état après chaque ligne.

# Feedback

La dernière ligne remet `savon` à non, tandis que `rincé` reste à oui.
