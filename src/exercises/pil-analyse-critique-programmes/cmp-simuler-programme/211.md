# Contexte

Il reste `15 minutes` avant l'heure prévue pour se coucher.

Pour vérifier si les différentes étapes tiennent dans ce temps, on les représente dans une petite simulation. Chaque instruction utilise le nombre de minutes indiqué : cette durée est donc retirée du temps restant.

# Consigne

Exécute les trois instructions dans l'ordre. Après chaque étape, calcule combien de minutes il reste, puis classe chaque affirmation dans `Vrai` ou `Faux`.

```blockly
event: DÉBUT
move: METTRE le pyjama (temps restant - 4 minutes)
move: SE BROSSER les dents (temps restant - 3 minutes)
move: LIRE une histoire (temps restant - 6 minutes)
end: FIN
```

# Catégories

1. Vrai
2. Faux

# Étiquettes

1. Après avoir mis le pyjama, il reste 11 minutes.
2. Après le brossage des dents, il reste 8 minutes.
3. À la fin du programme, il reste 2 minutes.
4. Après le brossage des dents, il reste 12 minutes.
5. Les trois étapes utilisent plus de 15 minutes au total.

# Solution

1: 1, 2, 3
2: 4, 5

# Feedback essai 1

Commence avec `15 minutes`. Après chaque instruction, retire uniquement la durée indiquée pour cette étape.

# Feedback essai 2

Après le pyjama, il reste `11 minutes`. Retire ensuite `3 minutes`, puis encore `6 minutes`.

# Feedback

Le temps restant évolue ainsi : `15 min`, puis `11 min`, puis `8 min`, et enfin `2 min`. Les affirmations `1`, `2` et `3` sont vraies. Les affirmations `4` et `5` sont fausses.
