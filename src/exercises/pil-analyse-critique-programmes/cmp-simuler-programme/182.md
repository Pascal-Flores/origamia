# Contexte

Dans une cuisine pédagogique, un petit robot se déplace entre plusieurs zones où sont préparés les ingrédients d'une recette. La flèche montre sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: E4 ouest
target: B1 orange
target: C2 vert
target: D3 violet
```

Exécute le programme, puis indique sur quelle case colorée le robot arrive.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. La case orange
2. La case verte
3. La case violette

# Solution

2

# Feedback essai 1

Pars de la case indiquée et suis les instructions dans l'ordre. Le virage change la direction dans laquelle le robot avance ensuite.

# Feedback essai 2

Le robot avance d'abord de deux cases vers l'ouest. Il tourne ensuite à droite, puis avance encore de deux cases.

# Feedback

Le robot part de E4 vers l'ouest, avance jusqu'en C4, tourne à droite vers le nord puis avance de deux cases. Il arrive en C2, sur la case verte.
