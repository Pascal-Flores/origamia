# Contexte

Dans une cuisine pédagogique, un petit robot se déplace entre plusieurs zones où sont préparés les ingrédients d'une recette. La flèche montre sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: E4 ouest
target: B1 carre
target: C2 cercle
target: D3 triangle
```

Suis le programme pas à pas sur la grille, puis choisis le symbole de la case d’arrivée.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. Le carré
2. Le cercle
3. Le triangle

# Solution

2

# Feedback essai 1

Je pose mon doigt sur la flèche. Le robot avance d’abord tout droit. Dans quel sens mon doigt bouge-t-il sur la grille ?

# Feedback essai 2

Quand il regarde vers la gauche de la grille, de quel côté avance-t-il après avoir tourné à sa droite ?

# Feedback

On voit le trajet. Le robot avance de deux cases vers la gauche, tourne à droite puis remonte de deux cases jusqu’au cercle.
