# Contexte

Dans une cuisine pédagogique, un petit robot se déplace entre plusieurs zones où sont préparés les ingrédients d'une recette. La flèche montre sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: E4 ouest
target: B1 orange
target: C2 vert
target: D3 violet
```

Suis le programme pas à pas sur la grille, puis choisis la case d’arrivée parmi les propositions. Compte les rangées depuis le haut et les colonnes depuis la gauche.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. 1re rangée, 2e colonne
2. 2e rangée, 3e colonne
3. 3e rangée, 4e colonne

# Solution

2

# Feedback essai 1

Je pose mon doigt sur la flèche. Le robot avance d’abord tout droit. Dans quel sens mon doigt bouge-t-il sur la grille ?

# Feedback essai 2

Quand il regarde vers la gauche de la grille, de quel côté avance-t-il après avoir tourné à sa droite ?

# Feedback

On voit le trajet : deux cases vers la gauche, puis le robot tourne à droite et remonte de deux cases. Arrivée en 2e rangée, 3e colonne.
