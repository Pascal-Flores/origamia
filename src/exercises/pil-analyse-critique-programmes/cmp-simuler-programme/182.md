# Contexte

Dans une cuisine pédagogique, un petit robot se déplace entre plusieurs zones où sont préparés les ingrédients d'une recette. La flèche montre sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: E4 ouest
target: B1 carre
target: C2 cercle
target: D3 triangle
```

Suis le programme pas à pas sur la grille, puis choisis le symbole de la case d’arrivée.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. Le carré
2. Le cercle
3. Le triangle

# Solution

2

# Feedback essai 1

Oups, où est passé notre robot de cuisine ? Si je mets mon doigt sur la flèche, dans quel sens je commence à avancer ?

# Feedback essai 2

Moi, je m’imagine face au bord gauche. Quand je tourne à ma droite, est-ce que mon prochain pas monte ou descend sur la grille ?

# Feedback

On a retrouvé le chemin ! Le robot avance de deux cases à gauche, tourne à droite et remonte de deux cases jusqu’au cercle.
