# Contexte

```
MULTIPLIER n par 3
AJOUTER 1 à n
```

La mission réussit si la valeur finale est strictement inférieure à 16.

# Consigne

Avec quelles valeurs initiales la mission réussit-elle ?

# Réponses

1. n = 2
2. n = 4
3. n = 5
4. n = 6

# Solution

1, 2

# Feedback essai 1

Calcule séparément la sortie pour chaque entrée.

# Feedback essai 2

Pour n = 4, la sortie vaut 13 ; pour n = 5, elle vaut 16.

# Feedback

Les sorties sont 7, 13, 16 et 19. Seules les entrées 2 et 4 donnent une valeur strictement inférieure à 16.
