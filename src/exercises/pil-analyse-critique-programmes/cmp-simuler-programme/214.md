# Contexte

Une simulation représente une courte activité avant le départ d'un parc. La mission est réussie si, à la fin :

- l'activité est terminée ;
- il reste au moins `5 minutes` avant le départ ;
- le point de rendez-vous est repéré.

Le programme dure `3 minutes` et marque l'activité comme terminée, mais il ne change pas le fait que le point de rendez-vous soit repéré ou non.

# Consigne

Exécute le même programme pour chaque état initial, puis coche tous les tests où la mission réussit.

```blockly
event: DÉBUT
move: RÉALISER l'activité pendant (3 minutes)
say: MARQUER l'activité comme terminée
end: FIN
```

# Réponses

1. Au départ : 8 minutes restent avant le départ ; le point de rendez-vous est repéré.
2. Au départ : 7 minutes restent avant le départ ; le point de rendez-vous est repéré.
3. Au départ : 10 minutes restent avant le départ ; le point de rendez-vous n'est pas repéré.
4. Au départ : 9 minutes restent avant le départ ; le point de rendez-vous est repéré.

# Solution

1, 4

# Feedback essai 1

Pour chaque test, retire `3 minutes` au temps de départ. Vérifie ensuite séparément le temps restant, l'état de l'activité et le repérage du point de rendez-vous.

# Feedback essai 2

Le programme termine toujours l'activité, mais il ne repère jamais le point de rendez-vous. Un test ne peut donc réussir que si ce point est déjà repéré au départ et s'il reste au moins `5 minutes` après les trois minutes d'activité.

# Feedback

Le test `1` se termine avec `5 minutes` restantes et le point de rendez-vous repéré. Le test `4` se termine avec `6 minutes` restantes et le point repéré : tous deux réussissent. Le test `2` ne laisse que `4 minutes`, et le test `3` conserve un point de rendez-vous non repéré.
