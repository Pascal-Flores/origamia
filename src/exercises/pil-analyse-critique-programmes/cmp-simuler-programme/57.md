# Contexte

Un robot d’entrepôt transporte un colis. La flèche indique sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: E1 ouest
target: B2 bleu
target: D3 jaune
target: C3 rouge
```

Exécute le programme, puis indique sur quelle case colorée le robot arrive.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. La case bleue
2. La case jaune
3. La case rouge

# Solution

3

# Feedback essai 1

Pose ton doigt sur la case de départ et exécute chaque instruction sans anticiper la suivante.

# Feedback essai 2

Avance d'abord de deux cases. Après le virage à gauche, avance encore de deux cases dans la nouvelle direction.

# Feedback

Le robot avance de deux cases, tourne à gauche, puis avance de deux cases : il arrive sur la case rouge.
