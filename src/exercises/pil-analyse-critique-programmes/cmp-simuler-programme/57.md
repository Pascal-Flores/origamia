# Contexte

Un robot d’entrepôt transporte un colis. La flèche indique sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: E1 ouest
target: B2 bleu
target: D3 jaune
target: C3 rouge
```

Suis le programme pas à pas sur la grille, puis choisis la case d’arrivée parmi les propositions. Compte les rangées depuis le haut et les colonnes depuis la gauche.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. 2e rangée, 2e colonne
2. 3e rangée, 4e colonne
3. 3e rangée, 3e colonne

# Solution

3

# Feedback essai 1

On pourrait partir de la flèche et marquer chaque case parcourue. Où est le robot avant de tourner ?

# Feedback essai 2

La flèche regarde vers la gauche au départ. Quand le robot tourne à sa gauche, est-ce qu’il regarde toujours vers ce bord ?

# Feedback

On voit le trajet : deux cases vers la gauche, puis le robot tourne à sa gauche et descend de deux cases. 3e rangée, 3e colonne !
