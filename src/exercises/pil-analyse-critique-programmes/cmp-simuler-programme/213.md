# Contexte

Une simulation représente la fin d'une application de crème solaire. La mission est réussie si, à la fin, exactement `5 zones` sont couvertes et si le tube est refermé.

Le même programme est testé depuis plusieurs états initiaux.

# Consigne

Exécute le programme pour chaque test, puis coche tous les états initiaux où la mission réussit.

```blockly
event: DÉBUT
move: COUVRIR (2) zones supplémentaires
move: REFERMER le tube
end: FIN
```

# Réponses

1. Au départ : 3 zones sont couvertes ; le tube est ouvert.
2. Au départ : 2 zones sont couvertes ; le tube est fermé.
3. Au départ : 3 zones sont couvertes ; le tube est déjà fermé.
4. Au départ : 4 zones sont couvertes ; le tube est ouvert.

# Solution

1, 3

# Feedback essai 1

Le programme est identique pour tous les tests. Pour chacun, ajoute d'abord deux zones au nombre de départ, puis regarde l'état du tube à la fin.

# Feedback essai 2

Le programme referme toujours le tube. Il faut donc surtout repérer quels tests commencent avec un nombre de zones qui devient exactement `5` après l'ajout de deux zones.

# Feedback

Les tests `1` et `3` commencent avec `3 zones` couvertes. Le programme en couvre deux de plus : ils se terminent donc avec `5 zones` couvertes, et le tube est refermé dans les deux cas. Les tests `2` et `4` terminent respectivement avec `4` et `6 zones` couvertes.
