# Contexte

Le programme ajoute 2 au compteur `zones_couvertes`. La mission réussit si la valeur finale est au moins 5.

```
zones_couvertes = zones_couvertes + 2
```

# Consigne

Pour quels états initiaux la mission réussit-elle ?

# Réponses

1. `zones_couvertes = 1`
2. `zones_couvertes = 2`
3. `zones_couvertes = 3`
4. `zones_couvertes = 4`

# Solution

3, 4

# Feedback essai 1

Exécute la même addition pour chaque valeur de départ.

# Feedback essai 2

La valeur finale doit atteindre 5 ou plus.

# Feedback

3 devient 5 et 4 devient 6 : ces deux états initiaux réussissent. 1 et 2 restent sous 5.
