# Contexte

Une simulation représente l'évolution du niveau sonore pendant un temps de travail calme. La mission est réussie si, à la fin :

- le niveau sonore est inférieur ou égal à `30` ;
- le voyant `CALME` est allumé.

Le même programme est testé depuis plusieurs états initiaux.

# Consigne

Exécute le programme pour chaque test, puis coche tous les états initiaux où la mission réussit.

```blockly
event: DÉBUT
move: DIMINUER le niveau sonore de (10 points)
say: ALLUMER le voyant (CALME)
end: FIN
```

# Réponses

1. Au départ : niveau sonore = 35 ; voyant CALME éteint.
2. Au départ : niveau sonore = 45 ; voyant CALME allumé.
3. Au départ : niveau sonore = 42 ; voyant CALME éteint.
4. Au départ : niveau sonore = 40 ; voyant CALME allumé.

# Solution

1, 4

# Feedback essai 1

Le programme est identique pour tous les tests. Pour chacun, retire `10` au niveau sonore de départ puis regarde l'état du voyant à la fin.

# Feedback essai 2

Le programme allume toujours le voyant CALME. Il faut donc repérer quels niveaux de départ deviennent inférieurs ou égaux à `30` après la diminution de 10 points.

# Feedback

Le test `1` passe de `35` à `25` et le test `4` de `40` à `30` : tous deux respectent la limite finale et le voyant est allumé. Les tests `2` et `3` se terminent respectivement à `35` et `32`, donc au-dessus de la limite demandée.
