# Contexte

Un robot arrose les plantes d’une serre. La flèche indique sa case de départ et la direction qu’il regarde.

# Consigne

```robot-grid
grid: 5x4
start: A4 est
target: C1 orange
target: D2 vert
target: E3 violet
```

Suis le programme pas à pas sur la grille, puis choisis la case d’arrivée parmi les propositions. Compte les rangées depuis le haut et les colonnes depuis la gauche.

```
event: DÉBUT
move: AVANCER de (3) cases
move: TOURNER à gauche
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. 1re rangée, 3e colonne
2. 2e rangée, 4e colonne
3. 3e rangée, 5e colonne

# Solution

2

# Feedback essai 1

Et si on posait le doigt sur la flèche pour suivre le robot, une case après l’autre ?

# Feedback essai 2

Moi, quand je tourne à gauche, je change de direction. Et le robot, de quel côté regarde-t-il après avoir tourné ?
