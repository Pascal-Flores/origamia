# Énoncé

Un robot de serre doit rejoindre une plante à arroser. La flèche indique sa case de départ et son orientation.

```robot-grid
grid: 5x4
start: A4 est
target: C1 orange
target: D2 vert
target: E3 violet
```

Exécute le programme, puis indique sur quelle case colorée le robot arrive.

```
event: DÉBUT
move: AVANCER de (3) cases
move: TOURNER à gauche
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. La case orange
2. La case verte
3. La case violette

# Solution

2

# Feedback

Le robot avance de trois cases, tourne à gauche, puis avance de deux cases : il arrive sur la case verte.
