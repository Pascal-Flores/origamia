# Contexte

Un robot arrose les plantes d’une serre. La flèche indique sa case de départ et la direction qu’il regarde.

# Consigne

```robot-grid
grid: 5x4
start: A4 est
target: C1 cercle
target: D2 triangle
target: E3 carre
```

Suis le programme pas à pas sur la grille, puis choisis le symbole de la case d’arrivée.

```
event: DÉBUT
move: AVANCER de (3) cases
move: TOURNER à gauche
move: AVANCER de (2) cases
end: FIN
```

# Réponses

1. Le cercle
2. Le triangle
3. Le carré

# Solution

2

# Feedback essai 1

Pas encore… Et si on posait le doigt sur la flèche pour suivre le robot, une case après l’autre ?

# Feedback essai 2
