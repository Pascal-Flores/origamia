# Contexte

Dans une cantine, un petit robot transporte un déchet vers la zone de tri indiquée. La flèche montre sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: A1 sud
target: B2 vert
target: D3 jaune
target: E4 bleu
```

Exécute le programme, puis indique sur quelle case colorée le robot arrive.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (3) cases
end: FIN
```

# Réponses

1. La case verte
2. La case jaune
3. La case bleue

# Solution

2

# Feedback essai 1

Déplace le robot une instruction à la fois. Après le virage, pense à changer son orientation avant de continuer.

# Feedback essai 2

Le robot descend d'abord de deux cases. Il tourne ensuite à gauche, puis avance encore de trois cases dans sa nouvelle direction.

# Feedback

Le robot part de A1 vers le sud, avance jusqu'en A3, tourne à gauche vers l'est puis avance de trois cases. Il arrive en D3, sur la case jaune.
