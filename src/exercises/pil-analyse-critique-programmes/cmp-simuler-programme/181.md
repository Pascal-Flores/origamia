# Contexte

Dans une cantine, un petit robot transporte un déchet vers la zone de tri indiquée. La flèche montre sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: A1 sud
target: B2 cercle
target: D3 carre
target: E4 triangle
```

Suis le programme pas à pas sur la grille, puis choisis le symbole de la case d’arrivée.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (3) cases
end: FIN
```

# Réponses

1. Le cercle
2. Le carré
3. Le triangle

# Solution

2

# Feedback essai 1

On peut suivre le robot du doigt. La flèche regarde vers le bas au départ. Où s’arrête le robot avant de tourner ?

# Feedback essai 2

Quand le robot regarde vers le bas, sa gauche et la nôtre ne sont pas du même côté. Vers quel bord tourne-t-il ?

# Feedback

On a suivi le trajet. Le robot descend de deux cases, tourne à gauche puis avance de trois cases jusqu’au carré.
