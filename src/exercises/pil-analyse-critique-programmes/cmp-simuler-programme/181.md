# Contexte

Dans une cantine, un petit robot transporte un déchet vers la zone de tri indiquée. La flèche montre sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: A1 sud
target: B2 vert
target: D3 jaune
target: E4 bleu
```

Suis le programme pas à pas sur la grille, puis choisis la case d’arrivée parmi les propositions. Compte les rangées depuis le haut et les colonnes depuis la gauche.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (3) cases
end: FIN
```

# Réponses

1. 2e rangée, 2e colonne
2. 3e rangée, 4e colonne
3. 4e rangée, 5e colonne

# Solution

2

# Feedback essai 1

On peut suivre le robot du doigt. La flèche regarde vers le bas au départ. Où s’arrête le robot avant de tourner ?

# Feedback essai 2

Quand le robot regarde vers le bas, sa gauche et la nôtre ne sont pas du même côté. Vers quel bord tourne-t-il ?

# Feedback

On a suivi le trajet : deux cases vers le bas, puis on tourne à gauche et on avance de trois cases. Arrivée en 3e rangée, 4e colonne.
