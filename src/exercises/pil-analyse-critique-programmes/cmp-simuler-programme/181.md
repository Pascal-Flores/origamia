# Contexte

Dans une cantine, un petit robot transporte un déchet vers la zone de tri indiquée. La flèche montre sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: A1 sud
target: B2 cercle
target: D3 carre
target: E4 triangle
```

Suis le programme pas à pas sur la grille, puis choisis le symbole de la case d’arrivée.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (3) cases
end: FIN
```

# Réponses

1. Le cercle
2. Le carré
3. Le triangle

# Solution

2
