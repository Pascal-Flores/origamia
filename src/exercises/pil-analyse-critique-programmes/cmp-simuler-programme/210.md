# Contexte

La table est vide. Le programme fait :

```
POSER 1 bol
POSER 2 pommes
POSER 1 cuillère
```

# Consigne

Combien d'objets sont sur la table à la fin ?

# Réponses

1. 3
2. 4
3. 5

# Solution

2

# Feedback essai 1

Additionne seulement les objets réellement posés.

# Feedback

Il y a 1 bol + 2 pommes + 1 cuillère, soit 4 objets.
