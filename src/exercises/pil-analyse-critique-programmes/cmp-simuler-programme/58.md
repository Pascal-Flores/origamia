# Contexte

Au départ, le réservoir d’un robot nettoyeur contient `50 cL` de produit. Lorsqu’il nettoie, la quantité utilisée est retirée du réservoir ; lorsqu’il se remplit, la quantité indiquée est ajoutée.

# Consigne

Exécute le programme, puis classe chaque affirmation dans `Vrai` ou `Faux`.

```
event: DÉBUT
move: NETTOYER le sol avec (15 cL) de produit
move: REMPLIR le réservoir de (20 cL)
move: NETTOYER le sol avec (10 cL) de produit
end: FIN
```

# Catégories

1. Vrai
2. Faux

# Étiquettes

1. Après le premier nettoyage, le réservoir contient 35 cL.
2. Après le remplissage, le réservoir contient 55 cL.
3. À la fin, le réservoir contient 65 cL.
4. À la fin, le réservoir contient 45 cL.
5. Le réservoir contient plus de produit à la fin qu’au départ.

# Solution

1: 1, 2, 4
2: 3, 5

# Feedback essai 1

Écris la quantité de départ, puis calcule une nouvelle valeur après chaque instruction.

# Feedback essai 2

Après la première utilisation, il reste 35 cL. Le remplissage fait ensuite monter le réservoir à 55 cL ; poursuis avec la dernière instruction.

# Feedback

La quantité évolue ainsi : `50 cL`, puis `35 cL`, puis `55 cL`, puis `45 cL`. Les affirmations `1`, `2` et `4` sont vraies.
