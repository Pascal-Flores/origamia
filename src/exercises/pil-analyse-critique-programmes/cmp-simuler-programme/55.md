# Contexte

Un robot de bibliothèque se déplace sur une grille pour ranger un livre. La flèche indique sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: B4 nord
target: B2 carre
target: C2 cercle
target: D3 triangle
```

Suis le programme pas à pas sur la grille, puis choisis le symbole de la case d’arrivée.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (1) case
end: FIN
```

# Réponses

1. Le carré
2. Le cercle
3. Le triangle

# Solution

2

# Feedback essai 1

Oups, mon doigt s’est peut-être perdu dans la bibliothèque ! Si on repartait de la flèche, où est-ce qu’on ferait les premiers pas ?

# Feedback essai 2

Après deux cases, le robot tourne sur place. Moi, je ferais pivoter mon doigt avant de le déplacer. De quel côté regarde-t-il ?

# Feedback

Mince, pas cette fois ! Deux cases, il tourne à droite, puis une case et le robot arrive au cercle. On a bien exploré les rayons !
