# Contexte

Un robot de bibliothèque se déplace sur une grille pour ranger un livre. La flèche indique sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: B4 nord
target: B2 vert
target: C2 bleu
target: D3 orange
```

Exécute le programme, puis indique sur quelle case colorée le robot arrive.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (1) case
end: FIN
```

# Réponses

1. La case verte
2. La case bleue
3. La case orange

# Solution

2

# Feedback

Le robot avance de deux cases, tourne à droite, puis avance encore d’une case : il arrive sur la case bleue.
