# Contexte

Un robot de bibliothèque se déplace sur une grille pour ranger un livre. La flèche indique sa case de départ et son orientation.

# Consigne

```robot-grid
grid: 5x4
start: B4 nord
target: B2 vert
target: C2 bleu
target: D3 orange
```

Suis le programme pas à pas sur la grille, puis choisis la case d’arrivée parmi les propositions. Compte les rangées depuis le haut et les colonnes depuis la gauche.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à droite
move: AVANCER de (1) case
end: FIN
```

# Réponses

1. 2e rangée, 2e colonne
2. 2e rangée, 3e colonne
3. 3e rangée, 4e colonne

# Solution

2

# Feedback essai 1

Mon doigt peut jouer le robot. Si on part de la flèche, où nous mène la première instruction ?

# Feedback essai 2

Après deux cases, le robot tourne sur place. De quel côté regarde-t-il avant sa dernière avancée ?

# Feedback
