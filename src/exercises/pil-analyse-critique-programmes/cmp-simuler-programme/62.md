# Contexte

Un chariot transporte déjà `3 colis`. Sa mission est réussie si, à la fin, le quai `2` contient exactement `10 colis` et le voyant `LIVRÉ` est allumé.

# Consigne

Le même programme est lancé dans plusieurs états initiaux. Coche tous les tests où la mission réussit.

```
event: DÉBUT
move: DÉPOSER les (3) colis au quai (2)
say: ALLUMER le voyant (LIVRÉ)
end: FIN
```

# Réponses

1. Au départ, le quai 2 contient 7 colis et le voyant est éteint.
2. Au départ, le quai 2 contient 10 colis et le voyant est éteint.
3. Au départ, le quai 2 contient 7 colis et le voyant est déjà allumé.
4. Au départ, le quai 2 contient 4 colis et le voyant est déjà allumé.

# Solution

1, 3

# Feedback essai 1

Le programme est identique pour tous les tests. Calcule d'abord ce qu'il ajoute au quai et ce qu'il fait au voyant.

# Feedback essai 2

Le programme ajoute 3 colis et allume le voyant. Cherche donc les tests qui commencent avec 7 colis sur le quai 2.

# Feedback

Le dépôt ajoute `3 colis` au quai `2` et le programme allume le voyant. Les tests `1` et `3` commencent avec `7 colis` : ils se terminent donc avec `10 colis` et le voyant allumé. Les autres tests n’atteignent pas la quantité attendue.
