# Contexte

Une barrière automatique gère la sortie d'un petit parking. Lorsqu'une voiture sort, le système met à jour le compteur des places libres, ouvre la barrière et allume le voyant `SORTIE`.

La mission est réussie si, à la fin :

- le compteur indique exactement `5 places libres` ;
- la barrière est ouverte ;
- le voyant `SORTIE` est allumé.

# Consigne

Le même programme est lancé dans plusieurs états initiaux. Coche tous les tests où la mission réussit à la fin.

```
event: DÉBUT
move: AJOUTER (1) place libre au compteur
move: OUVRIR la barrière
say: ALLUMER le voyant (SORTIE)
end: FIN
```

# Réponses

1. Au départ : 4 places libres ; barrière fermée ; voyant SORTIE éteint.
2. Au départ : 5 places libres ; barrière fermée ; voyant SORTIE éteint.
3. Au départ : 3 places libres ; barrière ouverte ; voyant SORTIE allumé.
4. Au départ : 4 places libres ; barrière ouverte ; voyant SORTIE allumé.

# Solution

1, 4

# Feedback essai 1

Le programme est identique pour tous les tests. Commence par calculer le nombre de places libres après la sortie de la voiture, puis vérifie les deux autres états finaux.

# Feedback essai 2

Le programme ajoute toujours `1` place libre, ouvre la barrière et allume le voyant. Cherche donc les tests qui commencent avec le nombre de places permettant d'arriver exactement à `5`.

# Feedback

Le programme ajoute une place libre puis force la barrière ouverte et le voyant `SORTIE` allumé. Les tests `1` et `4` commencent avec `4 places libres` : ils se terminent donc avec `5 places libres`, la barrière ouverte et le voyant allumé. Le test `2` termine avec `6 places libres` et le test `3` avec `4`.
