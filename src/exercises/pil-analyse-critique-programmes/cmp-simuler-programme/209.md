# Contexte

Deux bacs sont vides au départ. Le programme exécute :

```
METTRE 1 emballage dans le bac recyclage
METTRE 1 reste dans le bac déchets
METTRE 1 emballage dans le bac recyclage
```

# Consigne

Quel est l'état final ?

# Réponses

1. Recyclage : 2 ; déchets : 1
2. Recyclage : 1 ; déchets : 2
3. Recyclage : 3 ; déchets : 0

# Solution

1

# Feedback essai 1

Suis les trois instructions une par une et compte séparément les deux bacs.

# Feedback

Deux emballages vont au recyclage et un reste va dans l'autre bac.
