# Contexte

Le robot part de la case A1 et regarde vers la droite.

```
AVANCER de 2 cases
TOURNER à droite
AVANCER de 1 case
```

# Consigne

Sur quelle case arrive-t-il ? Les colonnes vont de A à D vers la droite et les lignes de 1 à 4 vers le bas.

# Réponses

1. C2
2. B3
3. C1

# Solution

1

# Feedback essai 1

Après la première avance, le robot est en C1. Puis il tourne vers le bas.

# Feedback

Deux cases vers la droite mènent de A1 à C1. Après le virage à droite, une case vers le bas mène à C2.
