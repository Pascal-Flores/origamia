# Contexte

Sur chaque grille, le carré indique la borne de recharge.

# Consigne

Suis le programme à la main sur chaque grille. Coche toutes les grilles où le robot termine sur le carré.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (1) case
end: FIN
```

# Réponses

1.

```robot-grid
grid: 5x3
start: B2 est
target: D1 carre
```

2.

```robot-grid
grid: 5x3
start: E3 nord
target: D1 carre
```

3.

```robot-grid
grid: 5x3
start: B3 est
target: D1 carre
```

4.

```robot-grid

```

# Solution

1, 2

# Feedback essai 1

Une flèche, un départ différent à chaque fois. On arriverait à suivre les quatre trajets à la main ?

# Feedback essai 2

Une fois les deux cases parcourues, le robot tourne sur place. Dans quels tests peut-il alors atteindre le carré en une case ?

# Feedback

La flèche vers la droite la plus haute mène au carré par le bas. Depuis le coin en bas à droite, le robot y arrive par la droite.
