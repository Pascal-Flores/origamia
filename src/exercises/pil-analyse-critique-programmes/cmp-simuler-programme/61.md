# Contexte

La case verte représente la borne de recharge. Le même programme est essayé avec plusieurs positions de départ du robot.

# Consigne

Exécute le programme pour chaque test, puis coche tous les tests où le robot termine sur la borne verte.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (1) case
end: FIN
```

# Réponses

1.

```robot-grid
grid: 5x3
start: B2 est
target: D1 vert
```

2.

```robot-grid
grid: 5x3
start: E3 nord
target: D1 vert
```

3.

```robot-grid
grid: 5x3
start: B3 est
target: D1 vert
```

4.

```robot-grid
grid: 5x3
start: D3 nord
target: D1 vert
```

# Solution

1, 2

# Feedback essai 1

Simule chaque test depuis sa propre case de départ et compare uniquement la case finale avec la borne verte.

# Feedback essai 2

Après le premier déplacement, utilise le virage pour tracer le dernier segment. Deux positions de départ seulement placent alors le robot dans l'axe de la borne.

# Feedback

Depuis `B2` en regardant vers l’est, le robot atteint `D2`, tourne vers le nord et rejoint la borne. Depuis `E3` en regardant vers le nord, il atteint `E1`, tourne vers l’ouest et rejoint aussi la borne. Les deux autres positions de départ le conduisent sur une autre case.
