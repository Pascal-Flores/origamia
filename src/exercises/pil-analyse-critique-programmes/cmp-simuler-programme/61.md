# Contexte

La case verte représente la borne de recharge. Le même programme est essayé avec plusieurs positions de départ du robot.

# Consigne

Exécute le programme pour chaque test, puis coche tous les tests où le robot termine sur la borne verte.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (1) case
end: FIN
```

# Réponses

1. Test A

```robot-grid
grid: 5x3
start: B2 est
target: D1 vert
```

2. Test B

```robot-grid
grid: 5x3
start: E3 nord
target: D1 vert
```

3. Test C

```robot-grid
grid: 5x3
start: B3 est
target: D1 vert
```

4. Test D

```robot-grid
grid: 5x3
start: D3 nord
target: D1 vert
```

# Solution

1, 2

# Feedback

Dans le test A, le robot atteint `D2`, tourne vers le nord et rejoint la borne. Dans le test B, il atteint `E1`, tourne vers l’ouest et rejoint aussi la borne. Les tests C et D le conduisent sur une autre case.
