# Contexte

Sur chaque grille, le carré indique la borne de recharge.

# Consigne

Suis le programme à la main sur chaque grille. Coche toutes les grilles où le robot termine sur le carré.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche
move: AVANCER de (1) case
end: FIN
```

# Réponses

```robot-grid

target: D1 carre
```

2.

```robot-grid

target: D1 carre
```

3.


Oups, même programme mais quatre départs ! Je jouerais le robot avec mon doigt sur chaque grille. Est-ce que tous les trajets se ressemblent ?

# Feedback essai 2
