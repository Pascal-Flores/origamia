# Contexte

Sur chaque grille, la borne de recharge se trouve sur la rangée du haut, dans la quatrième colonne en partant de la gauche.

# Consigne

Suis le programme à la main sur chaque grille. Coche toutes les grilles où le robot termine sur la borne.

```
event: DÉBUT
move: AVANCER de (2) cases
move: TOURNER à gauche

end: FIN
```
