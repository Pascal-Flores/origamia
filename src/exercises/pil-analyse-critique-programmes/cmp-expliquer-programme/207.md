# Contexte

```
DÉBUT
AFFICHER « attention »
ATTENDRE 3 secondes
EFFACER l'écran
FIN
```

# Consigne

Complète l'explication du programme.

# Texte à trous

Le programme commence par [[1]]. Ensuite, il [[2]]. Enfin, il [[3]]. Le résultat est que le message reste visible pendant trois secondes avant de disparaître.

# Étiquettes

1. afficher le message « attention »
2. attendre 3 secondes
3. effacer l'écran
4. attendre avant d'afficher le message
5. afficher le message une deuxième fois
