# Contexte

Après la douche, plusieurs choses doivent encore être rangées. Pour représenter cette petite routine, on a écrit le programme ci-dessous.

Il faut faire attention à l'ordre : la douche a lieu d'abord, puis la serviette utilisée est mise à sécher et le linge sale est placé dans le panier prévu pour cela.

```
event: DÉBUT
move: PRENDRE une douche
move: METTRE la serviette à sécher
move: METTRE le linge sale dans le panier
end: FIN
```

# Consigne

Lis le programme du début à la fin. Quelle phrase décrit toutes les actions réalisées, dans le même ordre que les instructions ?

# Réponses

1. Le linge est rangé avant la douche.
2. La douche est prise, puis la serviette est mise à sécher et le linge sale au panier.
3. La serviette est rangée sans prendre de douche.

# Solution

2

# Feedback essai 1

Commence par identifier la première action, puis vérifie ce qui est fait de la serviette et du linge après la douche.

# Feedback

La deuxième proposition reprend l'ensemble du programme : on prend d'abord la douche, on met ensuite la serviette à sécher, puis on place le linge sale dans le panier. Les autres propositions modifient ou suppriment une partie de la séquence.
