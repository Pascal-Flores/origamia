# Contexte

Entre deux activités, la classe fait parfois une courte pause active pour bouger quelques instants avant de reprendre le travail.

Une fiche présente les trois mouvements de cette pause sous forme de programme afin de montrer clairement dans quel ordre les réaliser.

```blockly
event: DÉBUT
move: SE LEVER
move: ÉTIRER les bras vers le haut
move: SE RASSEOIR
end: FIN
```

# Consigne

Lis le programme du début à la fin, puis choisis la phrase qui décrit exactement les actions réalisées pendant cette pause active.

# Réponses

1. On se lève, on étire les bras vers le haut, puis on se rassoit.
2. On étire les bras en restant assis, puis on se lève à la fin.
3. On se lève et on se rassoit immédiatement, sans faire l'étirement.

# Solution

1

# Feedback essai 1

Repère les trois actions du programme et garde leur ordre : la première se fait avant l'étirement, et la dernière termine la pause.

# Feedback

La première proposition décrit exactement le programme : on commence par se lever, on étire ensuite les bras vers le haut, puis on se rassoit. Les autres propositions changent l'ordre ou oublient une des actions.
