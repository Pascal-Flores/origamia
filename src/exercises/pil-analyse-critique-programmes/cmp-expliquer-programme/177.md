# Contexte

Après un repas, on veut expliquer comment ranger une assiette et un verre dans le lave-vaisselle puis terminer correctement la procédure. Le programme a été séparé en trois parties.

### Partie A

```blockly
event: DÉBUT
move: OUVRIR la porte du lave-vaisselle
```

### Partie B

```blockly
move: PLACER l'assiette dans le lave-vaisselle
move: PLACER le verre dans le lave-vaisselle
```

### Partie C

```blockly
move: VÉRIFIER que l'assiette et le verre sont bien placés
move: FERMER la porte
end: FIN
```

# Consigne

Associe chaque partie du programme au rôle qu'elle joue dans la procédure.

# Catégories

1. Contrôler le rangement puis terminer la procédure.
2. Rendre l'intérieur du lave-vaisselle accessible.
3. Placer les éléments de vaisselle à l'intérieur.

# Étiquettes

1. Partie A
2. Partie B
3. Partie C

# Solution

1: 3
2: 1
3: 2

# Feedback essai 1

Pour chaque partie, demande-toi si elle prépare l'accès, réalise le rangement ou contrôle ce rangement avant de terminer.

# Feedback essai 2

L'ouverture ne range encore aucun objet. Les deux placements réalisent le rangement. La dernière partie intervient lorsque les objets sont déjà à l'intérieur.

# Feedback

La partie A ouvre la porte et rend l'intérieur accessible. La partie B place l'assiette et le verre dans le lave-vaisselle. La partie C contrôle leur placement puis ferme la porte : elle vérifie et termine la procédure.
