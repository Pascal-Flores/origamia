# Contexte

```
PRENDRE le tee-shirt blanc
PLACER le tee-shirt dans le panier blanc
PRENDRE le tee-shirt bleu
PLACER le tee-shirt dans le panier couleurs
TERMINER
```

# Consigne

Sélectionne les affirmations correctes.

# Réponses

1. Le tee-shirt blanc est placé dans le panier blanc.
2. Le tee-shirt bleu est placé avant le tee-shirt blanc.
3. À la fin, les deux tee-shirts sont rangés dans deux paniers différents.
4. Le programme mélange les deux tee-shirts dans le même panier.

# Solution

1, 3

# Feedback essai 1

Associe chaque instruction à l'objet qu'elle déplace.

# Feedback

Le programme range le blanc dans le panier blanc puis le bleu dans le panier couleurs ; les deux objets sont donc séparés.
