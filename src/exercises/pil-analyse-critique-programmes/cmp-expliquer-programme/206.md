# Contexte

Un robot regarde vers le nord.

```
AVANCER de 2 cases
TOURNER à droite
AVANCER de 1 case
```

# Consigne

Quelles affirmations sont correctes ?

# Réponses

1. Le robot avance d'abord vers le nord.
2. Après le virage, il regarde vers l'est.
3. Sa dernière avance se fait vers l'ouest.
4. Le programme contient deux déplacements et un changement de direction.

# Solution

1, 2, 4

# Feedback essai 1

Distingue les instructions qui déplacent le robot de celle qui change son orientation.

# Feedback

Le robot avance vers le nord, tourne à droite donc regarde vers l'est, puis avance d'une case vers l'est. Les affirmations 1, 2 et 4 sont exactes.
