# Contexte

Avant une lessive, le linge est séparé dans deux paniers. Pour représenter cette manière de trier deux tee-shirts, on a écrit le programme ci-dessous.

Le programme traite les vêtements l'un après l'autre. Pour le comprendre correctement, il faut repérer quel vêtement est pris, dans quel panier il est placé et ce que l'on obtient une fois toutes les instructions exécutées.

```
event: DÉBUT
move: PRENDRE le tee-shirt blanc
move: PLACER le tee-shirt blanc dans le panier blanc
move: PRENDRE le tee-shirt bleu
move: PLACER le tee-shirt bleu dans le panier couleurs
end: FIN
```

# Consigne

Lis attentivement la séquence, puis sélectionne toutes les affirmations qui décrivent correctement les actions du programme ou le résultat final du rangement.

# Réponses

1. Le tee-shirt blanc est placé dans le panier blanc.
2. Le tee-shirt bleu est placé avant le tee-shirt blanc.
3. À la fin, les deux tee-shirts sont rangés dans deux paniers différents.
4. Le programme mélange les deux tee-shirts dans le même panier.

# Solution

1, 3

# Feedback essai 1

Suis séparément le parcours de chaque tee-shirt : regarde d'abord où va le blanc, puis où va le bleu. Compare ensuite les deux paniers obtenus à la fin.

# Feedback

Les affirmations 1 et 3 sont correctes. Le tee-shirt blanc est placé dans le panier blanc, puis le tee-shirt bleu dans le panier couleurs. Les deux vêtements finissent donc dans deux paniers différents. Les affirmations 2 et 4 ne correspondent ni à l'ordre ni au résultat du programme.
