# Contexte

Avant une lessive, on sépare le linge dans deux paniers. Pour expliquer comment deux tee-shirts sont triés, la procédure a été représentée sous forme de programme.

```
event: DÉBUT
move: REGARDER la couleur du tee-shirt blanc
move: PLACER le tee-shirt blanc dans le panier blanc
move: REGARDER la couleur du tee-shirt bleu
move: PLACER le tee-shirt bleu dans le panier couleurs
move: VÉRIFIER que les deux tee-shirts sont séparés
end: FIN
```

# Consigne

Lis le programme puis sélectionne les affirmations qui expliquent correctement le rôle de certaines étapes ou le résultat obtenu.

# Réponses

1. Regarder la couleur d'un tee-shirt avant de le placer sert à déterminer vers quel panier il doit être dirigé.
2. La vérification finale sert à contrôler que les deux tee-shirts ne se retrouvent pas dans le même panier.
3. Le programme place d'abord les vêtements puis regarde leur couleur pour décider où ils auraient dû aller.
4. À la fin, le tee-shirt blanc et le tee-shirt bleu sont rangés dans deux paniers différents.
5. Le résultat recherché est de mélanger les deux tee-shirts dans un seul panier.

# Solution

1, 2, 4

# Feedback essai 1

Repère à quoi sert l'observation de la couleur, puis regarde ce que contrôle la dernière instruction et où se trouvent les deux tee-shirts à la fin.

# Feedback essai 2

Pour chaque tee-shirt, l'observation vient avant le placement. La dernière instruction ne déplace plus rien : elle contrôle le résultat obtenu après les deux rangements.

# Feedback

Les affirmations 1, 2 et 4 sont correctes. La couleur est observée avant le placement, chaque tee-shirt est dirigé vers le panier prévu et la dernière étape vérifie qu'ils sont bien séparés. Les réponses 3 et 5 décrivent un ordre ou un résultat opposé au programme.
