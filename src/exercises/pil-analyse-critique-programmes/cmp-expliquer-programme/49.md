# Contexte

Ce programme décrit comment préparer un poste de dessin.

# Consigne

Lis le programme ci-dessous, puis choisis la ou les phrases qui décrivent correctement ce qu’il faut faire.

```
event: DÉBUT
move: PRENDRE une feuille
move: SORTIR les crayons
move: TAILLER le crayon gris
move: POSER la gomme à côté de la feuille
move: COMMENCER le dessin
end: FIN
```

# Réponses

1. Il faut d’abord prendre une feuille avant de sortir les crayons.
2. Il faut tailler le crayon gris avant de commencer le dessin.
3. Il faut poser la gomme dans la trousse avant de dessiner.
4. Ce programme explique comment coller une fiche dans un cahier.

# Solution

1, 2

# Feedback

Les réponses `1` et `2` sont correctes : la feuille est prise avant les crayons, et le crayon gris est taillé avant le début du dessin. La réponse `3` est fausse, car la gomme est posée à côté de la feuille, pas rangée dans la trousse. La réponse `4` est fausse, car ce programme prépare un poste de dessin, il ne parle pas de collage.
