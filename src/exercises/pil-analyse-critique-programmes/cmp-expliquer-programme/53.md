# Contexte

Ce programme décrit comment vérifier qu’un groupe compte le même nombre d’élèves avant et après un déplacement.

# Consigne

Lis le programme ci-dessous, puis complète le texte avec les étiquettes dans le bon ordre pour expliquer :
- les étapes importantes ;
- à quoi elles servent ;
- le résultat obtenu à la fin.

```
event: DÉBUT
move: RASSEMBLER le groupe avant le départ
move: COMPTER les élèves avant le déplacement
move: NOTER combien d’élèves sont présents
move: EFFECTUER le déplacement en groupe
move: RASSEMBLER le groupe à l’arrivée
move: COMPTER les élèves à l’arrivée
move: COMPARER les deux nombres
move: DIRE à l’adulte si les deux nombres sont les mêmes ou différents
end: FIN
```

# Texte à trous

Avant le déplacement, le premier comptage permet de [[1]]. À l’arrivée, le second comptage indique [[2]]. Comparer les deux nombres sert à [[3]]. Le résultat est ensuite donné à l’adulte pour [[4]]. À la fin, le programme permet de [[5]].

# Étiquettes

1. connaître le nombre d’élèves avant de partir
2. combien d’élèves sont arrivés
3. voir si le nombre d’élèves a changé pendant le déplacement
4. l’informer du résultat de la vérification
5. vérifier que le groupe est arrivé avec le même nombre d’élèves
6. choisir la destination du groupe
7. savoir à quelle heure le groupe est parti

# Solution

1, 2, 3, 4, 5

# Feedback

Compter les élèves avant de partir permet de garder un nombre de départ. En comptant de nouveau à l’arrivée, puis en comparant les deux nombres, on peut vérifier si le groupe a gardé le même nombre d’élèves. L’adulte reçoit ensuite le résultat de cette vérification.
