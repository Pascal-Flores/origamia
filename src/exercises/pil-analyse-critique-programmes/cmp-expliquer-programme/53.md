# Énoncé

Ce programme décrit comment préparer une séance LEGO.

Lis le programme ci-dessous, puis complète le texte avec les étiquettes dans le bon ordre pour expliquer :
- les étapes importantes ;
- à quoi elles servent ;
- le résultat obtenu à la fin.

```
event: DÉBUT
move: OUVRIR la boîte
move: TRIER les pièces par taille
move: PRENDRE la notice
move: CHERCHER l’étape 1
move: ASSEMBLER la base du modèle
move: AJOUTER les pièces de l’étape suivante
move: VÉRIFIER que le modèle ressemble à l’image
move: RANGER les pièces restantes
end: FIN
```

# Texte à trous

Dans ce programme, l’instruction « trier les pièces par taille » sert à [[1]]. L’action « chercher l’étape 1 » permet de [[2]]. L’instruction « vérifier que le modèle ressemble à l’image » sert à [[3]]. À la fin, [[4]].

# Étiquettes

1. retrouver plus facilement les pièces utiles
2. savoir par quelle étape commencer la construction
3. comparer le montage avec le résultat attendu
4. le modèle est construit et les pièces restantes sont rangées
5. recommencer toute la construction depuis le début
6. cacher les pièces inutilisées

# Solution

1, 2, 3, 4

# Feedback

Pour bien expliquer ce programme, il faut préciser l’effet de certaines instructions. Trier les pièces aide à retrouver plus facilement ce dont on a besoin, chercher l’étape 1 permet de savoir comment commencer, et vérifier le modèle sert à le comparer avec l’image attendue. Le résultat final est que le modèle est construit et que les pièces restantes sont rangées.
