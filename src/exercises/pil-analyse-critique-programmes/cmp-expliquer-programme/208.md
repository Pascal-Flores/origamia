# Contexte

Pour une préparation froide, on veut transformer une banane entière en rondelles prêtes à être servies dans un bol. La procédure a été représentée sous forme de programme afin de montrer comment les étapes s'enchaînent et ce que chacune apporte au résultat final.

```blockly
event: DÉBUT
move: POSER la banane sur la planche
move: RETIRER la peau
move: COUPER la banane en rondelles
move: RASSEMBLER les rondelles sur la planche
move: DÉPOSER les rondelles dans le bol
end: FIN
```

# Consigne

Lis le programme, puis complète le texte pour expliquer le rôle des étapes importantes et la transformation obtenue à la fin.

# Texte à trous

Poser la banane sur la planche fournit d'abord [[1]]. Retirer la peau permet ensuite de [[2]]. La découpe réalise la transformation principale : elle [[3]]. Rassembler puis déposer les rondelles sert à [[4]]. Le résultat final est donc [[5]].

# Étiquettes

1. un emplacement où effectuer les étapes de préparation
2. rendre le fruit accessible pour pouvoir le découper
3. transforme la banane entière en plusieurs morceaux de même forme
4. réunir le résultat de la découpe puis le placer dans le récipient prévu
5. une banane épluchée et découpée en rondelles rassemblées dans le bol
6. remettre la peau autour de la banane après la découpe
7. transformer le bol en outil de découpe

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Cherche d'abord ce qui prépare la découpe, puis ce qui transforme réellement la banane, et enfin ce que les deux dernières instructions font du résultat obtenu.

# Feedback essai 2

La planche sert de support, la peau est retirée avant la découpe, puis les rondelles obtenues sont rassemblées et placées dans le bol.

# Feedback

La planche fournit le support de préparation et retirer la peau rend la banane disponible pour la découpe. Couper en rondelles transforme ensuite le fruit entier en plusieurs morceaux. Les dernières instructions réunissent ces morceaux puis les déposent dans le bol : le programme se termine donc avec une banane épluchée et découpée en rondelles prêtes dans le récipient.
