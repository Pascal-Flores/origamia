# Contexte

```
DÉBUT
POSER la banane sur la planche
RETIRER la peau
COUPER en rondelles
DÉPOSER les rondelles dans le bol
FIN
```

# Consigne

Complète l'explication du programme.

# Texte à trous

Le programme prépare d'abord [[1]], puis retire [[2]]. L'action principale consiste ensuite à [[3]]. La dernière étape place le résultat [[4]].

# Étiquettes

1. la banane sur la planche
2. la peau
3. couper en rondelles
4. dans le bol
5. le bol dans le placard
6. ajouter de l'eau

# Solution

1, 2, 3, 4

Reprends les quatre instructions principales sans ajouter d'action absente.

# Feedback
