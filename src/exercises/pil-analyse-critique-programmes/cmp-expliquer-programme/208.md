# Contexte

```
DÉBUT
RÉPÉTER 4 FOIS
  AVANCER d'une case
FIN RÉPÉTER
AFFICHER « arrivé »
FIN
```

# Consigne

Complète le texte qui décrit le rôle de la boucle et le résultat obtenu.

# Texte à trous

La boucle fait [[1]] quatre fois. Elle déplace donc le robot de [[2]] au total. Après la boucle, le programme [[3]].

# Étiquettes

1. avancer d'une case
2. quatre cases
3. affiche « arrivé »
4. tourner quatre fois
5. une case

# Solution

# Feedback
