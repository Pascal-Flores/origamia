# Énoncé

Ce programme décrit comment ranger un jeu complet dans sa boîte.

Lis le programme ci-dessous, puis choisis la phrase qui décrit correctement ce qu’il faut faire.

```
event: DÉBUT
move: RAMASSER les cartes
move: RANGER les cartes dans la boite
move: RANGER les pions dans la boîte
move: FERMER la boîte
end: FIN
```

# Réponses

1. Il faut ramasser les cartes et les ranger, ranger les pions dans la boîte, puis fermer la boîte.
2. Il faut fermer la boîte, puis ranger les cartes et les pions.
3. Il faut prendre les pions pour commencer une partie, puis poser les cartes sur la table.

# Solution

1

# Feedback

La réponse `1` est correcte, car elle reprend les trois actions à faire dans le bon ordre. La réponse `2` change l’ordre du programme, puisqu’on ne peut pas fermer la boîte avant d’avoir rangé le matériel. La réponse `3` change complètement le sens : ici, on range le jeu, on ne prépare pas une partie.
