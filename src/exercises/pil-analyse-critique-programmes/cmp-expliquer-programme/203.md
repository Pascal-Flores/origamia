# Contexte

Pour expliquer comment organiser un petit temps de devoirs sans travailler tout d'une traite, un élève a représenté sa méthode sous la forme du programme ci-dessous.

Il commence par faire un exercice. Il prévoit ensuite une courte pause, mais le travail n'est pas encore terminé : après la pause, il revient sur l'exercice pour vérifier ce qu'il a fait.

```
event: DÉBUT
move: FAIRE un exercice
move: FAIRE une pause
move: VÉRIFIER l'exercice
end: FIN
```

# Consigne

Lis les instructions dans l'ordre, puis choisis la phrase qui décrit exactement ce que montre le programme, du début jusqu'à la fin.

# Réponses

1. On fait un exercice, on fait une pause, puis on vérifie l'exercice.
2. On vérifie l'exercice avant de le faire.
3. On fait une pause puis on arrête sans vérifier.

# Solution

1

# Feedback essai 1

Repère ce qui se passe avant la pause et ce qui se passe après. La dernière instruction fait encore partie du programme.

# Feedback

La première phrase décrit bien les trois étapes : l'exercice est d'abord réalisé, une pause est ensuite prise, puis l'exercice est vérifié. Les autres propositions changent l'ordre ou oublient la vérification finale.
