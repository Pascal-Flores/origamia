# Contexte

Voici le programme :

```
FAIRE un exercice
FAIRE une pause
VÉRIFIER l'exercice
```

# Consigne

Choisis la phrase qui décrit exactement ce programme.

# Réponses

1. On fait un exercice, on fait une pause, puis on vérifie l'exercice.
2. On vérifie l'exercice avant de le faire.
3. On fait une pause puis on arrête sans vérifier.

# Solution

1

# Feedback essai 1

Suis les trois instructions dans leur ordre.

# Feedback
