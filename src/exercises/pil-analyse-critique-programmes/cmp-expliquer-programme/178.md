# Contexte

Avant une lessive, on sépare deux tee-shirts dans deux paniers. Pour expliquer ce tri, le programme a été découpé en trois parties.

### Partie A

```blockly
event: DÉBUT
move: REGARDER la couleur du tee-shirt blanc
move: PLACER le tee-shirt blanc dans le panier blanc
```

### Partie B

```blockly
move: REGARDER la couleur du tee-shirt bleu
move: PLACER le tee-shirt bleu dans le panier couleurs
```

### Partie C

```blockly
move: VÉRIFIER que les deux tee-shirts sont séparés
end: FIN
```

# Consigne

Associe chaque partie du programme au rôle qu'elle joue dans le tri.

# Catégories

1. Contrôler à la fin que les deux vêtements ont bien été séparés.
2. Identifier puis ranger le tee-shirt bleu dans le panier prévu pour les couleurs.
3. Identifier puis ranger le tee-shirt blanc dans le panier prévu pour le blanc.

# Étiquettes

1. Partie A
2. Partie B
3. Partie C

# Solution

1: 3
2: 2
3: 1

# Feedback essai 1

Repère quel vêtement est traité dans chaque partie et si la partie réalise encore un rangement ou seulement un contrôle.

# Feedback essai 2

Les deux premières parties traitent chacune un tee-shirt différent. La dernière ne déplace aucun vêtement : elle vérifie le résultat obtenu.

# Feedback

La partie A identifie le tee-shirt blanc puis le range dans le panier blanc. La partie B fait la même chose avec le tee-shirt bleu et le panier couleurs. La partie C ne range plus rien : elle contrôle que les deux vêtements ont bien été séparés.
