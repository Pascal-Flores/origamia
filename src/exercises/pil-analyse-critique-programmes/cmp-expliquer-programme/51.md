# Contexte

Ce programme décrit comment préparer une valise pour un week-end.

# Consigne

Lis le programme ci-dessous, puis choisis la ou les phrases qui décrivent correctement ce qu’il faut faire.

```
event: DÉBUT
move: OUVRIR la valise
move: METTRE le pyjama
move: METTRE une tenue de rechange
move: AJOUTER la trousse de toilette
move: VÉRIFIER la liste
move: FERMER la valise
end: FIN
```

# Réponses

1. Il faut vérifier la liste avant de fermer la valise.
2. Le pyjama et la tenue de rechange sont ajoutés avant la trousse de toilette.
3. Il faut fermer la valise avant de mettre les affaires.
4. Ce programme explique comment ranger des vêtements dans une armoire.

# Solution

1, 2

# Feedback essai 1

Pour chaque phrase, retrouve les actions concernées dans le programme et compare leur ordre.

# Feedback essai 2

La liste est vérifiée juste avant la fermeture. Le pyjama et la tenue de rechange sont ajoutés avant la trousse de toilette.

# Feedback

Les réponses `1` et `2` sont correctes : la liste est vérifiée juste avant de fermer la valise, et le pyjama comme la tenue de rechange sont ajoutés avant la trousse de toilette. La réponse `3` est fausse, car la valise est fermée à la fin, une fois les affaires préparées. La réponse `4` est fausse, car le programme décrit la préparation d’une valise, pas le rangement d’une armoire.
