# Contexte

Le programme contient :

```
ÉTEINDRE la lumière
OUVRIR les volets
```

# Consigne

Quelle phrase décrit exactement le comportement prévu ?

# Réponses

1. La lumière s'éteint puis les volets s'ouvrent.
2. Les volets se ferment puis la lumière s'allume.
3. La lumière s'éteint et rien n'arrive aux volets.

# Solution

1

# Feedback essai 1

# Feedback

La première instruction éteint la lumière ; la seconde ouvre les volets. La première phrase décrit donc exactement le programme.
