# Contexte

Le programme indique :

```
PRENDRE une douche
METTRE la serviette à sécher
METTRE le linge sale dans le panier
```

# Consigne

Quelle phrase décrit exactement son comportement ?

# Réponses

1. Le linge est rangé avant la douche.
2. La douche est prise, puis la serviette est mise à sécher et le linge sale au panier.
3. La serviette est rangée sans prendre de douche.

# Solution

2

# Feedback essai 1

Repère l'ordre des trois verbes.

# Feedback

La deuxième proposition reprend toutes les actions, dans le bon ordre.
