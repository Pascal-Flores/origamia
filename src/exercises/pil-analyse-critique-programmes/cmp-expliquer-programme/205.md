# Contexte

```
PRENDRE le sac
METTRE la tenue dans le sac
METTRE les chaussures dans le sac
FERMER le sac
```

# Consigne

Quelles affirmations décrivent correctement ce programme ?

# Réponses

1. Le sac est pris avant d'y mettre les affaires.
2. La tenue et les chaussures sont ajoutées avant la fermeture.
3. Le sac est fermé avant d'ajouter les chaussures.
4. À la fin, le sac contient la tenue et les chaussures et il est fermé.

# Solution

1, 2, 4

# Feedback essai 1

Vérifie chaque affirmation ligne par ligne puis observe l'état final.

# Feedback

Les affirmations 1, 2 et 4 correspondent au programme. La fermeture arrive seulement après l'ajout des deux affaires.
