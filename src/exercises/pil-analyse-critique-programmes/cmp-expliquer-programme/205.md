# Contexte

Après un repas, on veut expliquer comment ranger une assiette et un verre dans le lave-vaisselle avant de refermer la porte. La procédure a été représentée sous forme de programme.

```
event: DÉBUT
move: OUVRIR la porte du lave-vaisselle
move: PLACER l'assiette dans le lave-vaisselle
move: PLACER le verre dans le lave-vaisselle
move: VÉRIFIER que l'assiette et le verre sont bien placés
move: FERMER la porte
end: FIN
```

# Consigne

Lis le programme puis sélectionne les affirmations qui expliquent correctement le rôle de certaines étapes ou le résultat obtenu.

# Réponses

1. Ouvrir la porte prépare le lave-vaisselle pour pouvoir y placer la vaisselle.
2. Vérifier que l'assiette et le verre sont bien placés sert à contrôler le rangement avant de refermer la porte.
3. Fermer la porte sert à pouvoir placer ensuite l'assiette et le verre à l'intérieur.
4. À la fin du programme, l'assiette et le verre sont dans le lave-vaisselle et la porte est fermée.
5. Le programme vérifie la vaisselle sans jamais la déplacer.

# Solution

1, 2, 4

# Feedback essai 1

Repère ce qui prépare le rangement, ce qui permet de le contrôler et ce qui est vrai lorsque la dernière instruction a été exécutée.

# Feedback

Les affirmations 1, 2 et 4 sont correctes. La porte est ouverte pour permettre le rangement, la vérification contrôle que les deux objets sont bien placés, puis la porte est fermée. Les réponses 3 et 5 donnent un rôle ou un comportement contraire au programme.
