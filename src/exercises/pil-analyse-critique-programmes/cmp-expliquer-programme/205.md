# Contexte

Après un repas, on veut décrire une manière de ranger deux éléments de vaisselle dans le lave-vaisselle. Le programme ci-dessous représente la suite d'actions choisie.

Il ne suffit pas de repérer les objets mentionnés : il faut aussi suivre l'ordre des actions et regarder dans quel état se trouve la vaisselle lorsque le programme se termine.

```
event: DÉBUT
move: PRENDRE une assiette
move: PLACER l'assiette dans le lave-vaisselle
move: PRENDRE un verre
move: PLACER le verre dans le lave-vaisselle
move: FERMER la porte
end: FIN
```

# Consigne

Lis le programme du début à la fin, puis sélectionne toutes les affirmations qui décrivent correctement soit une action réalisée, soit le résultat obtenu à la fin.

# Réponses

1. L'assiette est placée avant le verre.
2. La porte est fermée avant de placer le verre.
3. À la fin, l'assiette et le verre sont dans le lave-vaisselle.
4. Le programme range seulement le verre.

# Solution

1, 3

# Feedback essai 1

Pour chaque affirmation, retrouve les instructions correspondantes. Pense aussi à vérifier ce qui est déjà dans le lave-vaisselle au moment où la porte est fermée.

# Feedback

Les affirmations 1 et 3 sont correctes. Le programme place d'abord l'assiette, puis le verre, et ferme seulement ensuite la porte : les deux objets sont donc dans le lave-vaisselle à la fin. Les affirmations 2 et 4 contredisent directement la séquence d'instructions.
