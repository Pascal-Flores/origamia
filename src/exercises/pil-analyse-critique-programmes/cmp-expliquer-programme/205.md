# Contexte

```
PRENDRE une assiette
PLACER l'assiette dans le lave-vaisselle
PRENDRE un verre
PLACER le verre dans le lave-vaisselle
FERMER la porte
```

# Consigne

Sélectionne les affirmations exactes.

# Réponses

1. L'assiette est placée avant le verre.
2. La porte est fermée avant de placer le verre.
3. À la fin, l'assiette et le verre sont dans le lave-vaisselle.
4. Le programme range seulement le verre.

# Solution

1, 3

# Feedback essai 1

Lis chaque instruction puis vérifie l'état final.

# Feedback

L'assiette est traitée avant le verre et les deux objets sont rangés avant la fermeture de la porte.
