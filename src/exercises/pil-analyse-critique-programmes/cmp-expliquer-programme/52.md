# Énoncé

Ce programme décrit comment envoyer un message poli sur l’ENT.

Lis le programme ci-dessous, puis complète le texte avec les étiquettes dans le bon ordre pour expliquer :
- les étapes importantes ;
- à quoi elles servent ;
- le résultat obtenu à la fin.

```
event: DÉBUT
move: OUVRIR l’ENT
move: SE CONNECTER à son compte
move: OUVRIR la messagerie
move: CHOISIR le destinataire
move: ÉCRIRE un objet clair
move: RÉDIGER le message avec bonjour, demande et merci
move: RELIRE le message
move: ENVOYER le message
end: FIN
```

# Texte à trous

Dans ce programme, les actions « ouvrir l’ENT » et « se connecter à son compte » servent d’abord à [[1]]. Ensuite, l’instruction « ouvrir la messagerie » permet de [[2]]. L’instruction « écrire un objet clair » sert à [[3]]. Enfin, l’instruction « relire le message » permet de [[4]]. À la fin, [[5]].

# Étiquettes

1. accéder à son compte sur l’ENT
2. arriver à l’endroit où le message peut être écrit
3. annoncer clairement le sujet du message
4. vérifier que le message est clair avant l’envoi
5. le message a été envoyé
6. effacer le message avant de l’envoyer
7. changer de destinataire au hasard

# Solution

1, 2, 3, 4, 5

# Feedback

Pour bien expliquer ce programme, il faut dire à quoi servent certaines instructions importantes. Ici, ouvrir l’ENT et se connecter permettent d’accéder à son compte, ouvrir la messagerie permet d’écrire le message, écrire un objet sert à en annoncer le sujet, et relire sert à vérifier la clarté avant l’envoi. Le résultat final est que le message a été envoyé.
