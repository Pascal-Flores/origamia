# Contexte

Ce programme décrit comment évaluer une information en la recherchant sur deux sites différents.

# Consigne

Lis le programme ci-dessous, puis complète le texte avec les étiquettes dans le bon ordre pour expliquer :
- les étapes importantes ;
- à quoi elles servent ;
- le résultat obtenu à la fin.

```
event: DÉBUT
move: FORMULER l’information à vérifier
move: CHERCHER cette information sur un premier site
move: NOTER le résultat trouvé
move: CHERCHER la même information sur un second site
move: NOTER le second résultat trouvé
move: COMPARER les deux résultats
move: NOTER les points communs et les différences
move: RÉDIGER ce que la comparaison permet d’affirmer
end: FIN
```

# Texte à trous

Ce programme ne retient pas immédiatement le premier résultat trouvé : la recherche sur un second site apporte [[1]]. Comparer les résultats puis noter leurs points communs et leurs différences sert à [[2]]. Cette étape évite de [[3]]. La dernière instruction transforme la comparaison en [[4]]. Le résultat du programme est donc [[5]].

# Étiquettes

1. une autre source à confronter à la première
2. repérer si les deux sources concordent ou se contredisent
3. recopier un seul résultat sans l’examiner avec l’autre
4. conclusion fondée sur les deux résultats
5. une conclusion sur le niveau de vérification de l’information
6. effacer la première source avant de la comparer
7. publier automatiquement un résultat sans l’analyser

# Solution

1, 2, 3, 4, 5

# Feedback essai 1

Repère ce que le programme recherche, ce qu'il compare, puis ce qu'il produit à la fin.

# Feedback essai 2

Le second résultat fournit un point de comparaison. Les accords et les différences servent ensuite à rédiger la conclusion.

# Feedback

Le premier résultat ne suffit pas à conclure. Le second fournit un point de comparaison ; relever les accords et les différences permet ensuite de rédiger ce que les deux recherches autorisent à affirmer. Le programme produit une conclusion argumentée, pas une simple copie d’un résultat.
