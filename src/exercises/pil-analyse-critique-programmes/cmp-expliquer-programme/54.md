# Énoncé

Ce programme décrit comment préparer un itinéraire simple.

Lis le programme ci-dessous, puis complète le texte avec les étiquettes dans le bon ordre pour expliquer :
- les étapes importantes ;
- à quoi elles servent ;
- le résultat obtenu à la fin.

```
event: DÉBUT
move: NOTER le lieu de départ
move: NOTER le lieu d’arrivée
move: CHERCHER un trajet possible
move: REPÉRER l’arrêt ou la station de départ
move: REPÉRER où changer si une correspondance est nécessaire
move: REPÉRER l’arrêt ou la station d’arrivée
move: NOTER une heure de départ conseillée
move: VÉRIFIER une dernière fois le trajet
end: FIN
```

# Texte à trous

Dans ce programme, les actions « noter le lieu de départ » et « noter le lieu d’arrivée » servent à [[1]]. L’instruction « chercher un trajet possible » permet de [[2]]. L’instruction « repérer où changer si une correspondance est nécessaire » sert à [[3]]. Enfin, l’instruction « noter une heure de départ conseillée » permet de [[4]]. À la fin, [[5]].

# Étiquettes

1. définir le trajet à préparer
2. savoir par où passer
3. savoir à quel endroit changer de ligne si besoin
4. choisir à quel moment commencer le trajet
5. l’itinéraire est prêt
6. changer de destination au dernier moment
7. repartir du début du trajet

# Solution

1, 2, 3, 4, 5

# Feedback

Pour bien expliquer ce programme, il faut montrer à quoi servent certaines actions. Noter le départ et l’arrivée sert à définir le trajet, chercher un trajet possible permet de savoir par où passer, repérer le changement éventuel sert à préparer la correspondance, et noter une heure de départ conseillée aide à savoir quand partir. Le résultat final est que l’itinéraire est prêt.
