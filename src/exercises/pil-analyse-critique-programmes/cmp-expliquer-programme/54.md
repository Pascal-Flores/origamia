# Contexte

Ce programme décrit comment organiser un mini-tournoi puis déterminer l’équipe gagnante.

# Consigne

Lis le programme ci-dessous, puis complète le texte avec les étiquettes dans le bon ordre pour expliquer :
- les étapes importantes ;
- à quoi elles servent ;
- le résultat obtenu à la fin.

```
event: DÉBUT
move: NOTER les équipes A, B et C
move: PRÉPARER un tableau des scores
move: FAIRE JOUER le match A contre B
move: NOTER l’équipe gagnante du match A contre B
move: FAIRE JOUER le match B contre C
move: NOTER l’équipe gagnante du match B contre C
move: FAIRE JOUER le match A contre C
move: NOTER l’équipe gagnante du match A contre C
move: ATTRIBUER un point par match gagné
move: CALCULER le total de chaque équipe
move: ANNONCER l’équipe qui a le plus de points
end: FIN
```

# Texte à trous

Faire jouer les trois matchs prévus et noter leur gagnant permet de [[1]]. Ces résultats servent ensuite à [[2]]. L’attribution des points transforme les victoires en [[3]]. Calculer les totaux sert à [[4]]. Le résultat du programme est [[5]].

# Étiquettes

1. conserver les résultats nécessaires au classement
2. construire le score de chaque équipe
3. des valeurs que l’on peut additionner pour chaque équipe
4. comparer les performances des équipes
5. l’annonce de l’équipe gagnante à partir des scores
6. annoncer un gagnant avant que les matchs soient joués
7. annoncer un gagnant sans utiliser les résultats

# Solution

1, 2, 3, 4, 5

# Feedback

Le programme ne se limite pas à faire jouer trois matchs : il conserve leurs résultats, transforme chaque victoire en point et additionne les points. Cette chaîne d’effets permet d’annoncer une équipe gagnante à partir des scores obtenus.
