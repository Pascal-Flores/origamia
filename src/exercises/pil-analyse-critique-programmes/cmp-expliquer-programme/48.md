# Contexte

Ce programme décrit comment remplacer un stylo vide par un stylo qui marche.

# Consigne

Lis le programme ci-dessous, puis choisis la phrase qui explique correctement ce qu’il faut faire.

```
event: DÉBUT
move: TESTER le stylo vide
move: JETER le stylo vide
move: PRENDRE un nouveau stylo
move: RANGER le nouveau stylo dans la trousse
end: FIN
```

# Réponses

1. Il faut tester le stylo vide, jeter le stylo vide, prendre un nouveau stylo, puis ranger le nouveau stylo dans la trousse.
2. Il faut tester le stylo vide, jeter le nouveau stylo, puis ranger le stylo vide dans la trousse.
3. Il faut tester le stylo vide, prendre un nouveau stylo, puis ranger le nouveau stylo dans la trousse.

# Solution

1

# Feedback essai 1

Vérifie ce qui arrive au stylo vide, ce qui arrive au stylo neuf et l'ordre de ces deux actions.

# Feedback

La réponse `1` est correcte, car elle reprend bien les quatre actions demandées. La réponse `2` change le sens du programme : il faut jeter le stylo vide et ranger le nouveau, pas l’inverse. La réponse `3` oublie une étape importante : jeter le stylo vide.
