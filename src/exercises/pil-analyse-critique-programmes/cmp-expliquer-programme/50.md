# Énoncé

Ce programme décrit comment télécharger un document puis le retrouver.

Lis le programme ci-dessous, puis choisis la ou les phrases qui décrivent correctement ce qu’il faut faire.

```
event: DÉBUT
move: OUVRIR l’espace de téléchargement
move: CLIQUER sur télécharger
move: ATTENDRE la fin du téléchargement
move: OUVRIR le dossier Téléchargements
move: CHERCHER le document téléchargé
move: OUVRIR le document téléchargé
end: FIN
```

# Réponses

1. Il faut attendre la fin du téléchargement avant de chercher le document.
2. Le dossier Téléchargements est ouvert pour retrouver le document téléchargé.
3. Une fois le document retrouvé, il faut l’ouvrir.
4. Il faut ouvrir le dossier Téléchargements avant de cliquer sur télécharger.
5. Le document est ouvert dès qu’on clique sur télécharger.

# Solution

1, 2, 3

# Feedback

Les réponses `1`, `2` et `3` sont correctes : il faut attendre la fin du téléchargement, ouvrir le dossier `Téléchargements` pour y chercher le document, puis ouvrir ce document une fois qu’il a été retrouvé. La réponse `4` est fausse, car le dossier `Téléchargements` est ouvert après le lancement et la fin du téléchargement. La réponse `5` est fausse, car le document n’est ouvert qu’à la fin, après avoir été cherché puis retrouvé.
