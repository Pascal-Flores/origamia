# Contexte

Pour expliquer comment récupérer un document téléchargé et l'ouvrir ensuite, on a représenté la procédure sous forme de programme.

```
event: DÉBUT
move: OUVRIR l'espace de téléchargement
move: CLIQUER sur télécharger
move: ATTENDRE la fin du téléchargement
move: OUVRIR le dossier Téléchargements
move: CHERCHER le document téléchargé
move: OUVRIR le document téléchargé
end: FIN
```

# Consigne

Lis le programme puis sélectionne les affirmations qui expliquent correctement le rôle de certaines étapes ou le résultat obtenu.

# Réponses

1. Attendre la fin du téléchargement évite de chercher le document avant qu'il soit entièrement téléchargé.
2. Ouvrir le dossier Téléchargements puis y chercher le document sert à retrouver le fichier qui vient d'être récupéré.
3. Cliquer sur télécharger suffit à ouvrir immédiatement le document.
4. À la fin du programme, le document téléchargé a été retrouvé puis ouvert.
5. Le programme se termine dès que le dossier Téléchargements est ouvert, sans rechercher le document.

# Solution

1, 2, 4

# Feedback essai 1

Regroupe les instructions en trois moments : télécharger, retrouver le fichier, puis l'ouvrir. Cherche ce que chaque moment permet de faire.

# Feedback essai 2

Le clic lance le téléchargement, mais le programme attend ensuite sa fin avant de chercher le fichier. Le résultat final arrive seulement après l'ouverture du document retrouvé.

# Feedback

Les réponses `1`, `2` et `4` sont correctes. L'attente garantit que le téléchargement est terminé avant la recherche ; le dossier Téléchargements sert ensuite à retrouver le fichier ; la dernière instruction ouvre enfin ce document. Les réponses `3` et `5` confondent une étape intermédiaire avec le résultat final.
