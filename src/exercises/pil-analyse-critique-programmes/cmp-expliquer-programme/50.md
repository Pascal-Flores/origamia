# Contexte

Pour expliquer comment récupérer un document téléchargé puis l'ouvrir, la procédure a été représentée sous forme de programme et découpée en trois parties.

### Partie A

```blockly
event: DÉBUT
move: OUVRIR l'espace de téléchargement
move: CLIQUER sur télécharger
move: ATTENDRE la fin du téléchargement
```

### Partie B

```blockly
move: OUVRIR le dossier Téléchargements
move: CHERCHER le document téléchargé
```

### Partie C

```blockly
move: OUVRIR le document téléchargé
end: FIN
```

# Consigne

Associe chaque partie du programme au rôle qu'elle joue dans la procédure.

# Catégories

1. Accéder au contenu du document une fois qu'il a été retrouvé.
2. Retrouver sur l'ordinateur le fichier qui vient d'être téléchargé.
3. Lancer le téléchargement et attendre que le fichier soit disponible.

# Étiquettes

1. Partie A
2. Partie B
3. Partie C

# Solution

1: 3
2: 2
3: 1

# Feedback essai 1

Repère les trois moments différents : obtenir le fichier, le retrouver sur l'ordinateur, puis accéder à son contenu.

# Feedback essai 2

La première partie se termine lorsque le téléchargement est fini. La partie suivante cherche le fichier. La dernière agit sur le document déjà retrouvé.

# Feedback

La partie A lance le téléchargement et attend sa fin. La partie B ouvre le dossier adapté et y retrouve le fichier téléchargé. La partie C ouvre ce fichier : elle permet donc d'accéder à son contenu.
