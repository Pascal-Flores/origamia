# Contexte

Un texte à trous doit être complété.

# Consigne

Complète le texte avec les étiquettes dans le bon ordre.

# Texte à trous

Pour envoyer un message sur l'ENT, il faut d'abord [[1]], puis [[2]]. À la fin, on peut [[3]].

# Étiquettes

1. ouvrir l'ENT
2. se connecter à son compte
3. envoyer le message
4. fermer l'ordinateur

# Solution

1, 2, 3

# Feedback

Le texte se complète en suivant l'ordre logique des actions : ouvrir l'ENT, se connecter, puis envoyer le message. Les étiquettes doivent être de simples morceaux de phrase qui s'insèrent directement dans le texte.
